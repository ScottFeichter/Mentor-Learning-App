# Insertion Sort In Place

Time: O(n²)
Space: O(1)

Mutates the original array.

```javascript
function insertionSortInPlace(arr) {
  let divider = 1;
  while (divider < arr.length) {
    let val = arr[divider];
    let i = divider;
    while (i > 0) {
      if (arr[i - 1] < val) {
        break;
      } else {
        arr[i] = arr[i - 1];
        i--;
      }
    }
    arr[i] = val;
    divider++;
  }
  return arr;
}
```
