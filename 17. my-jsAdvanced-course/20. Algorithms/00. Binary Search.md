# Binary Search

Time: O(log n)
Space: O(log n)

**MUST BE SORTED FIRST!**

```javascript
function binarySearch(arr, target) {
  let start = 0;
  let end = arr.length - 1;

  while (start <= end) {
    let mid = Math.floor((end + start) / 2);

    if (target === arr[mid]) {
      return mid; // returns index
    } else if (target > arr[mid]) {
      start = mid + 1;
    } else {
      end = mid - 1;
    }
  }

  return -1; // not found
}
```
