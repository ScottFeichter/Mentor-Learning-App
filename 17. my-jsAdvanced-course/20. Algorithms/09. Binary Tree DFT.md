# Binary Tree DFT

## DFT Iterative (Pre-order)

```javascript
function DFT_iPre(node) {
  const s = [node];
  while (s.length) {
    const curr = s.pop();

    console.log(curr.val);

    // NOTICE THIS ORDER IS OPPOSITE OF RECURSIVE
    if (curr.right) s.push(curr.right);
    if (curr.left) s.push(curr.left);
  }
}
```

## DFT Recursive (Pre-order)

```javascript
function DFT_rPre(node) {
  if (node === null) return;

  console.log(node.val);

  // NOTICE THIS ORDER IS OPPOSITE OF ITERATIVE
  if (node.left) DFT_rPre(node.left);
  if (node.right) DFT_rPre(node.right);
}
```

## Traversal Orders

Depth-first traversal of a binary tree:

- **Pre-order** (node visited first): F, B, A, D, C, E, G, I, H
- **In-order** (node visited between children): A, B, C, D, E, F, G, H, I
- **Post-order** (node visited last): A, C, E, D, B, H, I, G, F
