# Binary Search Concepts

## Logarithms

- O(log n)
- Logarithm is the inverse of exponent
  - 2⁵ = 32 → log₂(32) = 5

### The Binary Logarithm (base-2)

Powers of 2 to memorize:

| log₂(n) | n    |
|----------|------|
| 0        | 1    |
| 1        | 2    |
| 2        | 4    |
| 3        | 8    |
| 4        | 16   |
| 5        | 32   |
| 6        | 64   |
| 7        | 128  |
| 8        | 256  |
| 9        | 512  |
| 10       | 1024 |

JS has the handy `Math.log2` function:

```javascript
Math.log2(1024); // 10
```

Logarithms are important because log₂(n) is very efficient — growth is so slow it's almost constant.

## Binary Search Theory

- Linear visits each value one at a time: O(n)
- Binary uses divide and conquer: O(log n)

### Pre-conditions

1. Data must be sorted
2. Data can be accessed by index in constant time
   - Cannot binary search a linked list or a hash table

### Implementation Steps

- **Target**: what we are searching for
- **Low Index**: 0
- **High Index**: array.length - 1
- **Mid Index**: Math.floor((Low + High) / 2)
- Check value at mid:
  1. If mid === target → return mid
  2. Else adjust boundaries (right or left half depending on if mid < target)
- Repeat until either:
  1. You find the value
  2. Or Lo and Hi markers meet → return -1
