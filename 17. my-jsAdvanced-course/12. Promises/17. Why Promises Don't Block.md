# Why Promises Don't Block

A Promise doesn't block because it immediately returns a Promise object in the pending state, without waiting for the async operation to complete.

Here's what happens:

```javascript
// This line executes immediately and returns a Promise object
let myPromise = new Promise(function(resolve, reject) {
  setTimeout(function() { resolve(\"done\"); }, 3000);
});

// Code continues immediately - doesn't wait 3 seconds
console.log(\"This runs right away\");

// The Promise object exists but is still \"pending\"
myPromise.then(function(value) {
  console.log(\"This runs later when resolved\");
});
```

## The Non-blocking Mechanism

1. **Promise constructor runs immediately** - creates the Promise object
2. **Executor function runs immediately** - but any async operations inside (like setTimeout) are scheduled, not waited for
3. **Promise object returned immediately** - in pending state
4. **Main thread continues** - doesn't wait
5. **Later, when async operation completes** - Promise transitions to fulfilled/rejected and .then() handlers execute

The Promise is just a container that will eventually hold a value.

The actual async work still uses the event loop, but the Promise provides a structured way to handle the eventual result without blocking.
