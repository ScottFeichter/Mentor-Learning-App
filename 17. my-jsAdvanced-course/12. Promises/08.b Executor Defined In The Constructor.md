# Executor Defined In The Constructor

As we know, we can make a callback by defining the function in the argument.

We can do so with executor - by defining it in the Promise constructor!

## Basic Structure
As seen inside the Promise constructor:

```javascript
new Promise(function executor(resolve, reject) {
  // Your asynchronous logic goes here
  // Call resolve() for success
  // Call reject() for failure
});
```
This executor function itself has 2 callback arguments:
   - one in the case of success (resolve)
   - one in the case of error (reject)

The executor function will call one of those callbacks depending on some condition.

## Paramters To The Exectuor Function

The executor receives two parameters: `resolve` and `reject` functions.

These are pre-built functions provided by the Promise constructor.

You never modify `resolve` and `reject` functions.

## Example Instantiation

```javascript
let myPromise = new Promise(function executor(resolve, reject) {
  if (someCondition) {
    resolve("success data"); // CALLS resolve
  } else {
    reject("error data");    // CALLS reject
  }
  // No return statement needed
});
```


## What Do I Do With Resolve And Reject?

You simply pass them as callback arguments to the executor.

Then you have the executor call them in its body.

You will pass your data as arguments to `resolve` and `reject`:

```javascript
let myPromise = new Promise((resolve, reject) => {
  // Your asynchronous logic goes here
  if (someCondition) {
    resolve("success data");  // Just call it with your value
  } else {
    reject("error message");  // Just call it with your error
  }
});
```



## Executor Function Key Characteristics

- **Runs immediately** when the Promise is created
- **Receives two function parameters**: `resolve` and `reject`
- **Must call one of the functions** to settle the promise
- **Can be named or anonymous**
- **Sets up the asynchronous operation**

The executor function is the bridge between your asynchronous code and the Promise's state management system.



## Complete Promise Example

```javascript
let myPromise = new Promise(function executor(resolve, reject) {
  // Simulate async operation
  setTimeout(() => {
    const success = Math.random() > 0.5;

    if (success) {
      resolve("Operation completed successfully!");
    } else {
      reject("Operation failed!");
    }
  }, 1000);
});
```

## What Happens Internally

1. Promise constructor receives your executor function
2. Creates internal `resolve` and `reject` functions
3. Immediately calls your executor, passing these functions as arguments
4. Your executor runs and eventually calls one of the provided callbacks
5. Promise state changes from `pending` to either `fulfilled` or `rejected`

## Common Patterns

```javascript
// File reading example
let filePromise = new Promise((resolve, reject) => {
  fs.readFile('data.txt', (err, data) => {
    if (err) {
      reject(err);
    } else {
      resolve(data);
    }
  });
});

// HTTP request example
let apiPromise = new Promise((resolve, reject) => {
  fetch('/api/data')
    .then(response => resolve(response.json()))
    .catch(error => reject(error));
});
```
