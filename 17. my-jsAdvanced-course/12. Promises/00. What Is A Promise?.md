# What is a Promise?

A **Promise** is just a container that will eventually hold a value.

 - It is a JavaScript object
 - It comes from the Promise class that is pre built into JavaScript
 - You create a Promise object by instantiating from the Promise class
 - The Promise object you instantiated serves as a placeholder

## Why Promises?

Promises handle an eventual result without blocking the call stack.

- **Handle operations asynchronously**
  - API calls
  - file reading
  - timers

Promises also have a clean syntax that is easily readable.

- **Avoid callback hell** (nested callbacks)
  - clean chainable syntax with `.then()`
  - better error handling with `.catch()`

## When Do I Use Promises?

When you have code that may not fully execute right away and might block the call stack.

The code uses the event loop and fulfills the Promise upon completion.

## Key Points
- Promises make code asynchronous and non blocking.
- Promises are a cleaner way to handle synchronous blocking code.
- Promises are a placeholder for the result of the now asynchronous code.
