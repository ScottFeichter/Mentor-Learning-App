## COJO vs POJO

People typically use **COJO** to distinguish from a **POJO**.

**POJO** = Plain Old JavaScript Object

**COJO** = Class Object (JavaScript Object)

**COJO** is a term sometimes used, though not as widely as **POJO**.

Most developers just say "**class instance**" or "**object created from a class**".

## Our Example As A POJO

If we wanted to create the account1 example as a POJO we would do this:

```javascript
let account1 = {
  accountHolder: "John",
  balance: 1000,
  bankName: "Monopoly Bank"
};
```
## Key Differences:

- No class or constructor
- No new keyword
- Direct object literal with {}
- Same properties, same values
- Much simpler syntax for one-off objects
