# Promise Class - Complex - Custom Promise Implementation

This file demonstrates a custom Promise-like class called "Promise" that mimics JavaScript's built-in Promise functionality.


```javascript
class Promise {
  // Static property
  static version = "1.0";

  // Constructor - runs when creating new instance
  constructor(executor) {
    // Instance properties
    this.state = "pending";
    this.value = undefined;
    this.handlers = [];

    // Local functions (closures) - have access to this instance
    const resolve = (value) => {
      if (this.state !== "pending") return;

      this.state = "fulfilled";
      this.value = value;

      this.handlers.forEach(handler => {
        if (handler.onFulfilled) {
          handler.onFulfilled(value);
        }
      });
    };

    const reject = (reason) => {
      if (this.state !== "pending") return;

      this.state = "rejected";
      this.value = reason;

      this.handlers.forEach(handler => {
        if (handler.onRejected) {
          handler.onRejected(reason);
        }
      });
    };

    try {
      executor(resolve, reject);
    } catch (error) {
      reject(error);
    }
  }

  // Instance method
  then(onFulfilled, onRejected) {
    if (this.state === "fulfilled") {
      if (onFulfilled) {
        onFulfilled(this.value);
      }
    } else if (this.state === "rejected") {
      if (onRejected) {
        onRejected(this.value);
      }
    } else {
      // Still pending, queue the handlers
      this.handlers.push({
        onFulfilled,
        onRejected
      });
    }
  }

  // Instance method
  catch(onRejected) {
    return this.then(null, onRejected);
  }

  // Static method - called on class, not instance
  static resolve(value) {
    return new Promise(resolve => resolve(value));
  }

  // Static method - called on class, not instance
  static reject(reason) {
    return new Promise((resolve, reject) => reject(reason));
  }

  // Static method - waits for all promises to resolve
  static all(Promises) {
    return new Promise((resolve, reject) => {
      let results = [];
      let completed = 0;

      if (Promises.length === 0) {
        resolve(results);
        return;
      }

      Promises.forEach((Promise, index) => {
        Promise.then(value => {
          results[index] = value;
          completed++;
          if (completed === Promises.length) {
            resolve(results);
          }
        }).catch(reject);
      });
    });
  }
}

// Example usage:
console.log("Promise version:", Promise.version); // Static property

// Using static methods
let quickResolve = Promise.resolve("Quick success!");
let quickReject = Promise.reject("Quick error!");

// Using constructor
let myPromise = new Promise(function executor(resolve, reject) {
  let randomNumber = Math.random();

  if (randomNumber > 0.5) {
    resolve("Success! Number was: " + randomNumber);
  } else {
    reject("Failed! Number was: " + randomNumber);
  }
});

myPromise.then(function(value) {
  console.log("Success:", value);
});

myPromise.catch(function(error) {
  console.log("Error:", error);
});
```


## Class Structure

### Static Property
```javascript
static version = "1.0";
```
- Belongs to the class itself, not instances
- Accessed via `Promise.version`

### Constructor
```javascript
constructor(executor)
```
**Purpose:** Creates a new Promise instance with an executor function

**Instance Properties:**
- `state` - "pending", "fulfilled", or "rejected"
- `value` - stores resolved value or rejection reason
- `handlers` - array of queued `.then()` callbacks

**Local Functions (Closures):**
- `resolve(value)` - changes state to "fulfilled", executes handlers
- `reject(reason)` - changes state to "rejected", executes handlers

**Key Features:**
- Prevents multiple resolutions (checks if state is still "pending")
- Executes all queued handlers when resolved/rejected
- Wraps executor in try/catch to handle thrown errors

## Instance Methods

### `then(onFulfilled, onRejected)`
- If already resolved: executes callback immediately
- If pending: queues callbacks for later execution
- Handles both success and error callbacks

### `catch(onRejected)`
- Shorthand for `.then(null, onRejected)`
- Only handles rejections

## Static Methods

### `Promise.resolve(value)`
- Creates an immediately fulfilled Promise
- Equivalent to `new Promise(resolve => resolve(value))`

### `Promise.reject(reason)`
- Creates an immediately rejected Promise

### `Promise.all(Promises)`
- Waits for all Promises to resolve
- Returns array of results in original order
- Rejects if any Promise rejects

## Key Concepts Demonstrated

1. **Class vs Instance**: Static properties/methods vs instance properties/methods
2. **Closures**: Local functions accessing outer scope variables
3. **State Management**: Preventing multiple state changes
4. **Callback Queuing**: Storing handlers for later execution
5. **Error Handling**: Try/catch and rejection propagation

This implementation shows how JavaScript Promises work internally, making the abstract concept more concrete.
