# Instantiation With Constructor Arguments

Sometimes when instantiating we need to pass arguments to the constructor.

```javascript
let myObject = new ClassName(argument1, argument2);
```

This is permitted if the constructor was defined with parameters.

## Constructor Parameters

Constructor parameters are needed when objects require initial data to be useful.

A common example is to set an initial value on a property of the object.

```javascript
class BankAccount {
  constructor(accountHolder, initialBalance) {
    this.accountHolder = accountHolder;
    this.balance = initialBalance;
    this.bankName = "Monopoly Bank";
  }
}
```
The above class is a blueprint for bank account objects.

The constructor creates bankAccount objects with the following properties:

- accountHolder
- balance
- bankName

We defined the constructor to have the following parameters:
- accountHolder
- initialBalance


## Initial Values

A bank account needs an initial balance and account holder.

We could hard code it in the constructor if:
1. We knew what those values were **AND**
2. The values would be the same for each account

This is the case for the bankName property a it will always have the value "Monopoly Bank".

## Constructor Arguments

But we won't know what the other property values will be except at account creation.

Therefore we pass the information as arguments to the constructor during instantiation.

```javascript
let account1 = new BankAccount("John", 1000);
```
