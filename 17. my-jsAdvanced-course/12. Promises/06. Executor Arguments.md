
## Resolve and Reject Functions

Resolve and reject are functions.

Among other things they change the Promise's internal state when called.

The executor doesn't return them.

It executes one of them to signal success or failure.

**What Resolve and Reject do:**
1. **Change state** (`pending` → `fulfilled` or `rejected`) ✓
2. **Store the value/reason** (the data you pass to them)
3. **Execute queued handlers** (`.then()`, `.catch()`, `.finally()` callbacks)


## Example Of Fullfilled Promised Getting Data With then()

The then() method of the Promise object is used to get the value and use it
```javascript
myPromise.then(function(value) {
  console.log(value); // Gets "success data"
});
```

## The Sequence

1. If `resolve("success data")` is called
2. Promise state changes to `fulfilled`
3. Value `"success data"` is stored in Promise object
4. Any `.then()` handlers that were already registered get executed immediately
5. Future `.then()` calls will execute immediately since Promise is already resolved

## Key Points

Resolve/reject are like "trigger functions" that:
- Set the final state
- Store the result
- Execute all the waiting callback handlers

They're the bridge between your async operation and all the `.then()`/`.catch()` handlers.
