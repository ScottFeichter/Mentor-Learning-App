# Anatomy Of The Executor Function

You the programmer are responsible to create this function.

## Executor Function Structure

```javascript
function executor(resolve, reject) {
  // Asynchronous logic of your choosing goes here
  // Call to resolve goes here
  // Call to reject goes here
}
```

## The Executor Function Parameters

Your executor function will have two parameters.

These parameters will be for callback functions.

### The Parameters Are For Built In Methods From The Promise Constructor

The Promise object we are creating will automatically have two instance methods:

- **`resolve`**
- **`reject`**

You don't need to define these functions.

The Promise() constructor automatically provides these callbacks to your executor function.

You merely make placeholders for them as parameters to the executor function.

```javascript
function executor(resolve, reject) {
  // you could name the parameters anything
  // but resolve and reject shadow the callbacks
  // that will be feed to the executor function when it is called
}
```

## The Executor Function Body

The body of the exectuor function will have logic followed by invoked callbacks. 

The logic will be whatever code you want to run that may not complete immediately.

### The Executor Function Body Logic Example

```javascript
function executor(resolve, reject) {

  setTimeout(() => {
    let success = Math.random() > 0.5;

```

The logic in the executor function body comes before the calls to resolve and reject.

### The Executor Function Body Calls To Resolve And Reject

Then add the call to resolve and reject after you create your logic.
```javascript

    if (success) {
      resolve("Operation succeeded!");
    } else {
      reject("Operation failed!");
    }
  }, 1000);

};
```

The Promise API handles the rest.

## Full Example Using setTimeout To Simulate Async Operation

```javascript
function executor(resolve, reject) {

  setTimeout(() => {
    let success = Math.random() > 0.5;

    if (success) {
      resolve("Operation succeeded!");
    } else {
      reject("Operation failed!");
    }
  }, 1000);

};
```
## Key Points

The executor function:

1. Starts the asynchronous operation
2. The Promise immediately returns (in "pending" state)
3. Later, when the async operation completes, it calls resolve() or reject()
4. This changes the Promise from "pending" to "fulfilled" or "rejected"
