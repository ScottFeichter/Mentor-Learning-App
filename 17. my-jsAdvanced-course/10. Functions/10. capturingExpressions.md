## Can I Capture a Named Expression in Additional Variables?

Yes! You can capture a named function expression in additional variables:

```javascript
// Named function expression assigned to a variable
let originalVar = function namedFunc() {
  console.log("Hello from named function!");
};

// Capture it in additional variables
let secondVar = originalVar;
let thirdVar = originalVar;

// All three reference the same function
originalVar(); // "Hello from named function!"
secondVar();   // "Hello from named function!"
thirdVar();    // "Hello from named function!"

console.log(originalVar === secondVar); // true - same function
console.log(secondVar === thirdVar);    // true - same function
```

**Key points:**
- All variables reference the same function object in memory
- The internal name (`namedFunc`) is still only accessible inside the function
- You can create as many references as you want

**The internal name remains private:**
```javascript
let myFunc = function internalName() {
  console.log(internalName); // Works inside
};

let anotherRef = myFunc;
// console.log(internalName); // Still error - internal name not accessible
```
