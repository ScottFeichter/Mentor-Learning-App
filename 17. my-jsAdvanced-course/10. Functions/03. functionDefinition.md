# Function Definitions

## What is a Function Definition?

A **function definition** is the general term for the act of creating a function in JavaScript.

It includes the function's name (if any), parameters, and body code (including return).

```javascript
// This is a function definition
function greet(name) {
  console.log("Hello " + name);
}
```


**Function definition includes:**
- Function keyword or syntax
- Name (if any)
- Parameters
- Opening and closing braces
- **All body code**
  - (including explicit return statements or implicit return, variables, loops, etc.)


## Different Ways to Define a Function in JavaScript

There are several ways to define a function in JavaScript:

### 1. Function Declaration (Statement)
```javascript
function myFunction() {
  console.log("Function declaration");
}
```

### 2. Function Expression
```javascript
let myFunction = function() {
  console.log("Function expression");
};
```

### 3. Named Function Expression
```javascript
let myFunction = function namedFunc() {
  console.log("Named function expression");
};
```

### 4. Arrow Function (Expression)
```javascript
let myFunction = () => {
  console.log("Arrow function");
};

// Or shorter syntax for single expressions
let add = (a, b) => a + b;
```

### 5. Function Constructor (Expression)
```javascript
let myFunction = new Function('console.log("Function constructor")');
```

### 6. Method Definition (in objects)

```javascript
let obj = {
  myMethod() {
    console.log("Method definition");
  }
};
```
- Note:
  - This is not a function statement or expression.
  - It is a special syntax for defining methods in object literals.

### 7. Method Definition (in classes)
```javascript
class MyClass {
  myMethod() {
    console.log("Class method");
  }
}
```
- Note:
  - This is a class method definition.
  - It's not a function statement or expression, but part of class syntax.
<br>
<br>
---

**Most common:** Function declarations, function expressions, and arrow functions are the most frequently used methods.
