# Capturing Function Declarations in Variables

## Can a Function Declaration be Captured in a Variable?

Yes! A **function declaration** can be captured in a variable by assigning it:

```javascript
// Function declaration
function myFunction() {
  console.log("Original function");
}

// Capture the declaration in a variable
let captured = myFunction; // No parentheses - function reference

captured(); // "Original function"
myFunction(); // "Original function" - both work
```

## Key Points

- The function declaration creates a named function in the current scope
- You can assign that function to a variable using its name
- Use no parentheses when capturing (function reference, not call)
- Both the original name and the variable name work
- It's exactly the same function:
  - Both names are references to the same function object in memory.

## Multiple References

```javascript
function sayHello() {
  console.log("Hello!");
}

let greeting = sayHello;
let hello = sayHello;

sayHello(); // "Hello!"
greeting(); // "Hello!"
hello();    // "Hello!" - all reference the same function
```

## Difference from Named Function Expressions

- **Declaration**: Function exists first, then optionally captured
- **Named expression**: Must be captured during creation

```javascript
// Declaration - exists independently, then captured
function myFunc() { ... }
let captured = myFunc;

// Named expression - must be captured during creation
let captured = function myFunc() { ... };
```

Function declarations can be captured in variables after they're declared, giving you multiple ways to reference the same function.
