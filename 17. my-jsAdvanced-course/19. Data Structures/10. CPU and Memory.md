# CPU and Memory Concepts

## Terminology

- **Opcode** — the code for what operation to perform
- **Operand** — the code for the memory address of the value
- **Bus** — the wires that connect RAM to the CPU
- **Address bus** — sends the address from RAM to the CPU (width determines total possible addresses)
- **Data bus** — sends the value of the address to the CPU (wider bus = higher max value)

## Memory

- **Memory address** — the vertical path of a binary tree of bits
- **Cell** — the bit on the horizontal tape on a Turing machine
- **Word** — the natural, fixed-sized unit of data used by a particular processor design
- **Word size** — the number of bits in a word; how much data the CPU's internal registers can hold and process at one time
- **Register** — a quickly accessible location available to a computer's processor (cache memory)
- **Contiguous block** — a sequence of adjacent memory cells

## Example

If an integer is 32 bits (4 bytes):
- Storing 4 integers requires 16 bytes of memory
- An array of 4 integers requires 16 bytes of contiguous memory

## Arrays in Memory

- Arrays are an optimally space-efficient way to store data
- Arrays are the fastest method of access via indexing

The **indexing equation**:

```
valueAddress = startAddress + index * sizeof(dataType)
```

Indices are found by the offset, requiring:
1. A contiguous block of memory
2. Same data type throughout
3. Stored in ordinal sequence

## Pointers

- A **pointer** is a variable that stores the memory address of another variable as its value
- A **reference** is an alternate name for an existing variable
- In JavaScript, pointers are hidden but used under the hood
