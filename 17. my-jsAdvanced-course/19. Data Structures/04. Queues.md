# Queues

An ADT that returns values in the same order they are added: **FIFO** (First In, First Out).

- Differs from a stack (which is LIFO)
- **Enqueue**: getting in back of line
- **Dequeue**: exiting front of line

## Array Implementation

- enqueue = `push()` — O(1)
- dequeue = `shift()` — O(n)

## Linked List Implementation

- enqueue = `addToTail()` — O(1) with tail pointer
- dequeue = `removeFromHead()` — O(1)

There is a cost of space and code complexity if implementing as a linked list. If the values and sizes are not large, perhaps it is not worth the tradeoffs.

## Implementation (Array-based)

```javascript
class Queue {
  constructor() {
    this.store = new Array();
  }

  enqueue(ele) {
    this.store.push(ele);
    return true;
  }

  dequeue() {
    return this.store.shift();
  }

  size() {
    return this.store.length;
  }

  peek() {
    return this.store[0];
  }
}
```
