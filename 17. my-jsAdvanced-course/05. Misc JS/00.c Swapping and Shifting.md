# Swapping and Shifting

## Swapping

Using a temp variable:

```javascript
let tmp = arr[1];
arr[1] = arr[2];
arr[2] = tmp;
```

Using destructuring:

```javascript
[arr[4], arr[6]] = [arr[6], arr[4]];
```

## Shifting

When shifting to the right you must shift BACK TO FRONT:

```javascript
for (let i = arr.length - 1; i > 0; i--) {
  arr[i] = arr[i - 1];
}
```
