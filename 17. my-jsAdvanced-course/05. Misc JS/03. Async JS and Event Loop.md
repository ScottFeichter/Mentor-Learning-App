# Asynchronous JS and Event Loop

Because JS is a single-threaded language, we need asynchronous code so we can perform two things at once.

- No guaranteed order of execution
- The call stack is not blocked by a task that takes longer to finish
- Allows smooth handling of user behavior and other factors

## Event Loop

Consists of the **call stack** and the **message queue**.

- **Call Stack** — a LIFO stack of frames that have first priority
- **Message Queue** — a FIFO queue for tasks to complete when the stack is clear

In JS, an event can only be handled once the call stack is empty.
