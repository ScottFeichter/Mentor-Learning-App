Sometimes a function that expects a callback recieves an invocation and still runs correctly.

This occurs when a function is invoked but returns a callback.

Callback Functions

This can be confusing so here are some guidelines:


express middleware functions are ALWAYS callbacks



callbacks are when we pass a reference to a function definition as an argument

app.use(someMiddleware) is a callback
app.use(someMiddleware()) is NOT a callback
please continue reading for the big gotchya on this



callbacks do not invoke the function in the argument list

instead they give the function definition to the receiving function
so the receiving function in its body can invoke the callback function





some built in express middleware functions appear to be invocations
and they are
but they return a callback function




app.use(express.json())

express.json() here is NOT a callback
it is being invoked
however, it RETURNS a callback

we don’t see the callback it returns because this is pre built internally to express.json()
one reason they do it like this is so you can pass arguments to express.json()
those arguments will adjust the callback that is returned
this example is the gotchya
