# HTML Fundamentals

## HTML Particulars

- **Whitespace** — ignored by HTML (except in text content)
- **Tags** — Opening `<h1>`, Closing `</h1>`
- **Attributes** — extra information in tags, always inside opening tag
  - `name`, `id`, `class`, `title`, `src`, `alt`, `href`, `form`, `method`, `label`, `onsubmit`, `onclick`
- **Content** — information between opening and closing tags
- **Elements** — includes tag(s), attributes, and content between

## Element Categories

**Component Elements:** `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`

**Document Metadata:** `<link>`, `<title>`, `<lang>`, `<script>`, `<meta>`, `<base>`

**Text Content:** `<ol>`, `<ul>`, `<li>`, `<p>`, `<h1>` etc.

**Inline Text Semantics:** `<a>`, `<br>`, `<hr>`, `<em>`, `<strong>`

**Grouping:** `<span>`, `<div>`, `<nav>`, `<header>`, `<main>`, `<section>`, `<footer>`

**Forms:** `<form>`, `<fieldset>`, `<legend>`, `<label>`, `<input>`

## HTML Starter Code

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <link rel="stylesheet" href="main.css">
  <title>Page Title</title>
</head>
<body>
  <!-- content here -->
</body>
</html>
```
