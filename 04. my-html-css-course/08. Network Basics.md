# Network Basics

## MAC Address

**Media Access Control Address** — permanent identifier assigned to network interface hardware.

- Hardcoded into the device (can't be changed without changing hardware)
- Represented by 6 pairs of hexadecimal digits: `A1-B2-C3-D4-E5-F6`
- Used to differentiate devices from each other
- **MAC filtering** — limits access in corporate networks
- **Spoofing** — changing what MAC address is reported by an OS

### Frames

A **frame** is the external wrapper for data transmitted through a network:
- Source MAC address
- Destination MAC address
- Payload (TCP/UDP wrapper, IP wrapper, application data)

## Ports

A **port** is a virtual interface — a connection point for a service/application to the network.

- Defined by a number (0–65535) and transport protocol
- TCP and UDP have different sets of ports

### Port Ranges

| Range | Category | Usage |
|-------|----------|-------|
| 0–1023 | System (Well-known) | Reserved for well-known services |
| 1024–49151 | User (Registered) | Custom software, dev ports (3000, 5000, 8080) |
| 49152–65535 | Dynamic (Ephemeral) | Short-living, used for TCP connections |

> Treat ports below 1024 as untouchable for custom servers.

## DNS (Domain Name System)

Translates long numeric identifiers into friendly, human-readable addresses (like a phone book).

### Domain Name Structure

Example: `students.appacademy.io`

| Part | Name | Example |
|------|------|---------|
| Right of last dot | Top-Level Domain (TLD) | `.io` |
| Left of last dot | Second-Level Domain | `appacademy` |
| Further left | Third-Level Domain | `students` |

- **TLD** — managed by a single domain registry (.com, .net, .org, .gov)
- **Second-level domain** — purchased from a domain registrar
- **Other levels** — don't need separate purchase

### Domain vs URL

The domain is only the server's identifier, not other protocol/application data in the URL.
