# CSS Fundamentals

## Ways to Apply CSS

- **External** — separate file: `<link rel="stylesheet" href="mystyle.css">`
- **Internal** — in `<style>` tags in the HTML file
- **Inline** — in the HTML tag: `style="color:blue;"`
- **Importing** — CSS from web imported to CSS file

## CSS Syntax

```css
selector { property: value; }
```

## Simple Selectors

| Selector | Syntax | Example |
|----------|--------|---------|
| Type | `element` | `div {}` |
| Class | `.className` | `.theClass {}` |
| ID | `#idName` | `#theId {}` |
| Universal | `*` | `* {}` |
| Attribute | `element[attr]` | `a[label] {}` |

## Compound Selectors

- **And (grouping):** `h1, h2 {}`
- **Is both:** `p.myquote {}`

## Complex Selector Combinators

| Combinator | Syntax | Meaning |
|-----------|--------|---------|
| Descendant | `div p` | All p inside div |
| Child | `div > p` | Direct children only |
| General sibling | `div ~ p` | All p with shared parent |
| Adjacent sibling | `div + p` | Next sibling only |

## Attribute Selectors

- `[id]` — has attribute
- `[id=value]` — has specific value
- `[id^=m]` — starts with
- `[id$=ess]` — ends with
- `[id*=string]` — contains string

## Pseudo Classes & Elements

- **Pseudo class** (state): `a:hover {}`
- **Pseudo element** (part): `p::first-letter {}`

## Specificity (highest to lowest)

1. `!important`
2. Inline style
3. ID
4. Class
5. Element

## CSS Position

| Value | Behavior |
|-------|----------|
| `static` | Default. top/right/bottom/left have no effect |
| `relative` | Relative to where it would normally be |
| `absolute` | Relative to nearest positioned ancestor (or body) |
| `fixed` | Relative to viewport, stays on scroll |
| `sticky` | Toggles between relative and fixed on scroll |

## CSS Box Model

**MBPC** — Margin, Border, Padding, Content

## CSS Shapes (clip-path)

```css
clip-path: circle(40%);
clip-path: ellipse(130px 140px at 10% 20%);
clip-path: polygon(50% 0, 100% 50%, 50% 100%, 0 50%);
clip-path: inset(100px 50px);
```
