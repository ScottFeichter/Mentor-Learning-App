# Web Accessibility

## What is Web Accessibility?

Creating a better user-experience for all users, making the web a more inclusive space for users of various ages, languages, and other characteristics.

## Why It Matters

A software developer understands that the tools they develop are used by a diverse group of people and must be specifically designed to meet the needs of each user. This includes considering:
- Various ways users engage and interact with content
- Various devices, hardware, and browsers

## WCAG Compliance

**Web Content Accessibility Guidelines** — a set of guidelines for designing accessible web content.

- WCAG 2.0 Guidelines set the bar for Section 508 compliance of the Rehabilitation Act
- If a software company does not provide accessible resources, they can be sued for violating federal law

## WCAG Four Principles

[Quick Reference](https://www.w3.org/WAI/WCAG21/quickref/) | [Checklist](https://www.wuhcag.com/wcag-checklist/)

1. **Perceivable** — information must be presentable to users in ways they can perceive
2. **Operable** — UI components and navigation must be operable
3. **Understandable** — information and UI operation must be understandable
4. **Robust** — content must be robust enough to be interpreted by a wide variety of user agents
