# Rust Compiler (rustc)

## What is rustc?

**rustc** is the **Rust compiler** - the core tool that transforms Rust source code into executable programs.

## What it does:
- Compiles `.rs` files into machine code
- Performs type checking and borrow checking
- Applies optimizations
- Generates executables, libraries, or other targets

## Basic Usage

### Compile a Single File
```bash
rustc main.rs
```

### Compile with Optimizations
```bash
rustc -O main.rs
```

### Compile to Specific Target
```bash
rustc --target wasm32-unknown-unknown main.rs
```

### Common Options
```bash
# Debug information
rustc -g main.rs

# Specify output name
rustc main.rs -o my_program

# Library compilation
rustc --crate-type lib lib.rs

# Show warnings
rustc -W unused main.rs
```

## Relationship to Other Tools

### Cargo
- **Cargo** uses rustc under the hood for building projects
- `cargo build` calls rustc with appropriate flags
- Most developers use Cargo instead of calling rustc directly

### rustfmt
- **rustfmt** formats code, rustc compiles it
- Complementary tools in the Rust toolchain

### Clippy
- **clippy** analyzes code for improvements
- **rustc** produces the final binary
- Both perform static analysis but serve different purposes

## Key Features

### Memory Safety Checking
- Prevents buffer overflows, use-after-free, null pointer dereferences
- Catches memory errors at compile time
- No runtime overhead for safety checks

### Borrow Checker
- Enforces ownership rules
- Prevents data races and memory leaks
- Unique to Rust among systems languages

### Cross-Compilation
- Can target different architectures from single source
- Supports embedded systems, WebAssembly, mobile platforms
- No need for separate toolchains

### LLVM Backend
- Uses LLVM for code generation and optimization
- World-class optimization capabilities
- Multiple target architecture support

## Compilation Process

### High-Level Flow
```
.rs files → rustc → Executable/Library
```

### Detailed Steps
1. **Parsing**: Source code → Abstract Syntax Tree (AST)
2. **HIR**: AST → High-level Intermediate Representation
3. **Type checking**: Verify types and borrow rules
4. **MIR**: HIR → Mid-level Intermediate Representation
5. **LLVM IR**: MIR → LLVM Intermediate Representation
6. **Machine code**: LLVM IR → Native binary

## Output Types

### Executables
```bash
rustc main.rs  # Creates executable
```

### Libraries
```bash
rustc --crate-type lib lib.rs      # Static library
rustc --crate-type dylib lib.rs    # Dynamic library
rustc --crate-type cdylib lib.rs   # C-compatible library
```

### Other Targets
```bash
rustc --crate-type bin main.rs     # Binary executable
rustc --crate-type rlib lib.rs     # Rust library
```

## Advanced Features

### Incremental Compilation
- Only recompiles changed code
- Faster rebuild times
- Enabled by default in newer versions

### Link-Time Optimization (LTO)
```bash
rustc -C lto main.rs  # Enable LTO for smaller, faster binaries
```

### Target Specification
```bash
# List available targets
rustc --print target-list

# Use specific target
rustc --target x86_64-pc-windows-gnu main.rs
```

## Why rustc Matters

- **Foundation**: Core of the entire Rust ecosystem
- **Safety**: Prevents entire classes of bugs at compile time
- **Performance**: Generates highly optimized machine code
- **Reliability**: Extensive testing and formal verification
- **Innovation**: Pioneering approach to systems programming safety
