The main function is a special function that is always the first code that runs in every executable Rust program.

It is not only the entry point to the application, it could be said that it IS the application.

Usually this function can be found in a file called main.rs, though it is not completely necessary to follow this convention in some instances.

create a file called hello_world.rs:
touch hello_world.rs

add the following code:
fn main() {
println!("Hello, world!");
}

compile:
$ rustc main.rs

run:
$ ./main
