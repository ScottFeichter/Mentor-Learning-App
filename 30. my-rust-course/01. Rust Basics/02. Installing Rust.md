Installing Rust
Rust has a version manager called rustup:

- rustup is equivalent to nvm
- do install Linux/Mac
$ curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh

To utilize Rust you will need a linker:
- A linker is a program that to join Rust's compiled outputs into one file.

C compilers typically include linkers and some common Rust packages depend on C code and will need a C compiler.

Mac:
$ xcode-select --install

Linux:
Linux users should generally install GCC or Clang



check installation
$ rustc --version

check path:
$ echo $PATH

updating:
$ rustup update

to open the local documentation in your browser:
rustup doc

IDE support via rust-analyzer

## REPL (Read-Eval-Print Loop)

Rust doesn't have an official built-in REPL, but there are third-party options available:

### evcxr (Most Popular)
```bash
# Install
cargo install evcxr_repl

# Run
evcxr
```

**Features:**
- Interactive Rust evaluation
- Supports most Rust features
- Can add dependencies on the fly
- Syntax highlighting

**Example usage:**
```rust
>> let x = 5;
>> x + 10
15
>> :dep rand = "0.8"
>> use rand::Rng;
```

### Rust Playground (Web-based)
- Online at https://play.rust-lang.org/
- No installation needed
- Share code snippets
- Not a true REPL but useful for quick testing

### Why No Official REPL?

Rust's design makes a traditional REPL challenging:
- **Compile-time checking**: Requires full compilation
- **Ownership system**: Needs complete context to verify
- **Type inference**: Works best with full program view
- **Performance focus**: Compilation overhead for each line

Most Rust developers use:
- **Quick compilation**: `cargo run` is fast for small programs
- **Unit tests**: `cargo test` for experimentation
- **Rust Analyzer**: IDE integration with instant feedback
