# Aliases and Permissions

## Command Aliases

**Aliases** — shortcuts or abbreviations you create in place of longer CLI commands.

Example: `cd /directory/path` can be abbreviated as `docs`

### Built-in Directory Aliases

- `~` — home directory (`cd ~` takes you home)

### Creating Custom Aliases

Requires updating `~/.bash_profile` or `~/.zshrc` (profile files).

```bash
open ~/.bash_profile    # opens profile in default text editor
source ~/.bash_profile  # applies saved changes
```

Bash must be done manually; plugins can be used for zsh.

## SU, SUDO, and Elevated Permissions

For safety, some tasks require elevated permissions.

- **su** — super user (switches to root user account, requires root password)
- **sudo** — super user do (runs a single command with root privileges)

### Root Privileges / Root User / Super User

- In Linux, elevated permissions = root privileges
- Root user is equivalent to admin user on Windows
- Different distros have slight variations on su/sudo configuration

### SU vs SUDO

- `su` — switches to root user account
- `sudo` — runs a single command with root privileges

### Syntax

When using su/sudo, an entire command becomes a single argument:

```bash
sudo ls -l ~/Desktop
# sudo is the utility
# ls -l ~/Desktop is the argument
```

### Using SUDO

- Prompts for admin password
- Screen does NOT display anything as you type (not even asterisks)
- If correct, executes the command with elevated permissions
- **Be careful!** Super user has no safety restraints
- Must use sudo to install programs and affect how your computer runs
