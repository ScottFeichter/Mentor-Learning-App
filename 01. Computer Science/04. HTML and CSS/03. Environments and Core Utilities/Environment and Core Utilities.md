**Core Utils and Env Scripting**

The core utils are the programs that come shipped with your computer.

These are all things that you can do directly from the command line.

Examples:

	Safari
	GREP
	GIT
	Finder
	etc…

Core Utils are everywhere \-

- If you need to work on a new computer or remote into a server, core utils will be there.

Core Utilis are powerful \-

- Anything your computer can do, can be controlled directly via terminal programs.

- They are not restricted by the imagination of the developer who created your favorite GUI.

Environment Variables \- things you can change in your environment \- can be lots of things.

You're terminal has a 'settings' or config file and you can change those setting based on your preferences; file is named .bashrc or the .zshrc

Aliases \- one of William’s favorite things to this is a way to make your own custom short hand abbreviations for terminal commands

Functions \- he keeps a file called bash functions file where he keeps his functions you could but these in the bash rc file but he prefers separate he feels it is more organized
