# Promises vs Async/Await

## Key Differences

**Async/await is syntactic sugar built on top of Promises** - they're not competing technologies, but different ways to work with the same underlying Promise system.

## Syntax Comparison

**Promises (traditional):**
```javascript
fetchUser()
  .then(user => fetchPosts(user.id))
  .then(posts => console.log(posts))
  .catch(error => console.error(error));
```

**Async/await:**
```javascript
async function getPosts() {
  try {
    const user = await fetchUser();
    const posts = await fetchPosts(user.id);
    console.log(posts);
  } catch (error) {
    console.error(error);
  }
}
```

## Main Differences

**1. Readability**
- Async/await looks like synchronous code
- Promises use chaining with `.then()`

**2. Error Handling**
- Async/await uses try/catch blocks
- Promises use `.catch()` method

**3. Debugging**
- Async/await provides better stack traces
- Easier to set breakpoints in async/await

**4. Return Values**
- Async functions always return a Promise
- You can return raw values from async functions (automatically wrapped in Promise)

## When to Use Each

**Use Promises when:**
- Simple chaining operations
- Working with multiple parallel operations (`Promise.all()`)

**Use Async/await when:**
- Complex sequential operations
- Need better error handling
- Want more readable code

Both compile to the same underlying Promise mechanism - async/await is just easier to read and write.
