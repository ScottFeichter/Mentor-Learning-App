# Function Expressions

## What is a Function Expression?

A **function expression** is a function defined as part of an expression, typically without a name (anonymous).

```javascript
// Function declaration
function myFunction() {
  console.log("I'm a declaration");
}

// Function expression
let myFunc = function() {
  console.log("I'm an expression");
};
```

## Using Function Expressions

Function expressions can be used in several ways:

### Saved as a Variable
```javascript
let myFunc = function() {
  console.log("I'm a function expression saved in a variable!");
};

myFunc(); // Now I can call it
```

### Immediately Invoked (IIFE)
```javascript
(function() {
  console.log("I'm a function expression that runs immediately!");
})();
```

### As an Argument (Callback)
```javascript
function processCallback(callback) {
  callback();
}

processCallback(function() {
  console.log("I'm a function expression used as argument!");
});
```

## When Function Expressions Are Useless

A function expression by itself is useless - it gets created and discarded:

```javascript
// This does nothing - function is created but never callable
(function() {
  console.log("I'll never run!");
});
```

## Key Difference Summary

- **Function expression alone**: useless, never runs
  ```javascript
  (function() { ... });
  ```

- **Function expression in variable**: useful, can call later
  ```javascript
  let f = function() { ... };
  ```

- **Function expression immediately invoked**: useful, IIFE
  ```javascript
  (function() { ... })();
  ```

- **Function expression immediately invoked as argument**: useful, IIFE as argument
  ```javascript
  (function() { ... })();
  ```

- **Function expression as argument**: useful, callback argument
  ```javascript
  callback(function() { ... });
  ```


## When Are Function Expressions Useful?

Function expressions are only useful when they're:
1. **Assigned to something** (variable, property)
2. **Immediately invoked** (IIFE)
3. **Immediately invoked as argument** (IIFE as argument) (note this is NOT a callback)
4. **Passed as arguments** (callbacks) (this IS a callback)


Without one of these, a function expression just gets created and discarded without ever being callable.

## How Does a Function Call a Function Expression Callback?

The receiving function calls the function expression by using the parameter name with parentheses:

```javascript
function processCallback(callback) {
  console.log("Before calling callback");
  callback(); // This is how it calls the function expression
  console.log("After calling callback");
}

// Pass function expression as callback
processCallback(function() {
  console.log("I'm the callback!");
});
```

**What happens:**
1. `processCallback` receives the function expression as the `callback` parameter
2. Inside `processCallback`, when it reaches `callback()`, it executes the function expression
3. The function expression runs: `console.log("I'm the callback!");`

**The key:** The receiving function treats the parameter like any function variable and calls it with `parameterName()`.

**With parameters:**
```javascript
function processCallback(callback) {
  callback("Hello", "World"); // Calling with arguments
}

processCallback(function(greeting, target) {
  console.log(greeting + " " + target); // "Hello World"
});
```

So the receiving function calls the function expression just like calling any other function - by using the parameter name followed by parentheses.
