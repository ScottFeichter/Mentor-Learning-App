# Bubble Sort

Time: O(n²)
Space: O(1)

```javascript
function bubbleSort(arr) {
  let swapFlag = true;

  while (swapFlag) {
    swapFlag = false;
    for (let i = 0; i < arr.length; i++) {
      if (arr[i] > arr[i + 1]) {
        [arr[i], arr[i + 1]] = [arr[i + 1], arr[i]];
        swapFlag = true;
      }
    }
  }

  return arr;
}
```
