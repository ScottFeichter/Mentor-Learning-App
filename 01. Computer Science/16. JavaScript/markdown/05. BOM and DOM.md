# BOM and DOM

## The BOM (Browser Object Model)

The hierarchy of browser objects. The chief object is `window`.

### Window Properties

```javascript
window.navigator.userAgent      // browser info
window.screen.height            // screen height
window.screen.width             // screen width
window.history.length           // pages in tab history
window.history.back             // go to previous page
window.location.host            // hostname
window.location.pathname        // URL path
window.document.head            // <head>...</head>
window.document.body            // <body>...</body>
```

### window.onload

Wait for all assets to load before running script:

```javascript
window.onload = () => {
  let div = document.body.children[1];
  let ul = div.children[0];
  let thirdLi = ul.children[2];
  thirdLi.innerText = "New Text";
};
```

## The DOM (Document Object Model)

A collection of nodes that can be accessed and manipulated. Represents `window.document`.

### Nodes and NodeLists

**Node** — anything inside an HTML document (3 kinds: element, attribute, text)

**NodeList** — static collection of nodes (index starting at 0)
- Properties/methods: `length`, `entries()`, `forEach()`, `item()`, `keys()`, `values()`

### Getting Nodes

```javascript
document.querySelector("selector")         // first match
document.querySelectorAll(".className")     // all matches (static NodeList)
document.getElementsByName("name")
element.firstChild / element.lastChild
element.parentNode / element.nextSibling / element.previousSibling
```

### Getting HTML Elements

```javascript
document.getElementById("id")
document.getElementsByTagName("tag")
document.getElementsByClassName("class")
element.children / element.firstElementChild / element.lastElementChild
element.parentElement / element.nextElementSibling / element.previousElementSibling
```

### Changing Elements

```javascript
element.innerHTML = content    // interprets as HTML
element.innerText = content    // interprets as text
element.setAttribute(attribute, value)
element.style.property = style
```

### Adding/Deleting Elements

```javascript
document.createElement(element)
document.removeChild(element)
document.appendChild(element)
document.replaceChild(newEl, oldEl)
```

### innerHTML vs innerText vs textContent

| Property | Returns |
|----------|---------|
| `innerHTML` | Text + inner HTML tags + spacing |
| `innerText` | Just visible text (no hidden, no tags) |
| `textContent` | All text including hidden, without tags |
