# The Ethernet Frame

&nbsp;

## Frame Structure

| Field | Description |
|-------|-------------|
| Ethernet | NIC to NIC on the same network |
| Preamble | Gets the receiving card in sync with the bits |
| Start Frame Delimiter | Indicates the next info will be the actual data |
| Destination MAC Address | The destination device on the receiving network |
| Source MAC Address | The sending device |
| Length/Type | Length in bytes of the data or the type of data (e.g. IPv4 or IPv6 packet) |
| Data | The actual data packet being delivered |
| Frame Check Sequence | Checks for no loss of data |

## Encapsulation

The process of placing one message format (the letter) inside another message format (the envelope).

**De-encapsulation** is when the process is reversed by the recipient.

Each computer message is encapsulated in a specific form called a **frame**. The frame provides the addresses. If it is not correctly formatted it is not successfully delivered.
