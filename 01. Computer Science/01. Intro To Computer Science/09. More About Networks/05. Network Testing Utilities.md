# Network Testing Utilities

&nbsp;

## Common Commands

| Command | Description |
|---------|-------------|
| `ipconfig` | Displays IP configuration information |
| `ping` | Tests connections to other IP hosts |
| `netstat` | Displays network connections |
| `tracert` | Displays the route taken to the destination |
| `nslookup` | Directly queries the name server for information on a destination domain |

&nbsp;

---

&nbsp;

## ipconfig

Displays the basic configuration including IP address, subnet mask, and default gateway.

```bash
ipconfig /all      # shows MAC address, DNS servers, DHCP info
ipconfig /release  # releases current DHCP bindings
ipconfig /renew    # requests fresh configuration from DHCP server
```

## ping

The most commonly used network utility. Sends an **echo request** to an IP address. If the destination host receives it, it responds with an **echo reply** — confirming connectivity.
