# Subnets

&nbsp;

## Network Segmentation

Switches broadcast out all interfaces except the interface on which a packet was received. Routers do not propagate broadcasts.

Each router interface connects to a broadcast domain and broadcasts are only propagated within that specific broadcast domain.

If a broadcast domain is very large with many hosts there may be excessive broadcasts that negatively affect the network.

&nbsp;

---

&nbsp;

## Subnetting

The solution to excessive broadcasts is to reduce the size of the network by creating smaller broadcast domains — this process is called **subnetting**.

Subnetting uses host bits of the prefix to create additional subnets.

Benefits of subnetting:

- Reduces overall network traffic
- Improves network performance
- Allows security policies governing which subnets can communicate
- Reduces the number of devices affected by abnormal broadcast traffic

Devices can be separated by location, group, function, device type, or whatever the administrator desires.
