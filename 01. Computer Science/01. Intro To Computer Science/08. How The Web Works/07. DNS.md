# DNS

&nbsp;

## Domain Name System

DNS servers resolve hostnames to IP addresses. A host requests from the DNS server the IP address of a hostname.

&nbsp;

---

&nbsp;

## URL Anatomy

- **URN** — Uniform Resource Name — identifies only the namespace of the resource without reference to the protocol (e.g. `www.google.com`)
- **URL** — Uniform Resource Locator — defines the network location of a specific resource (e.g. `https://www.google.com`)
- **Protocol/scheme** — HTTPS, FTP, SFTP, etc.
- **Hostname** — `www.google.com`
- **Path and file name** — `/author/book.html`
- **Fragment** — `#page155`

## DNS Configuration

When you manually configure a device for network connectivity you include a DNS server address. This is provided by the ISP to your home router and handled by DHCP to send the configuration to all network devices.

## nslookup

You can use this command to discover the IP address for any domain name.

```bash
nslookup www.google.com
```
