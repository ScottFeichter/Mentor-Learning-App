# Protocols

&nbsp;

There are several protocols required for the internet to function.

&nbsp;

---

&nbsp;

## Transport Protocols

### TCP — Transmission Control Protocol

- Establishes a connection between two sockets
- Data is sent as ordered segments
- The receiver will ask the transmitter to re-send any missing segment
- Data cannot be lost — making TCP a reliable protocol
- The trade off is it may take longer

Common use cases:
- Web browsing
- CRUD operations
- File transfer

&nbsp;

### UDP — User Datagram Protocol

- Does not establish a connection
- Data is sent unordered
- Does not provide verification that data was received
- If some data is lost that is ok — making UDP an unreliable protocol
- Trades reliability for speed

Common use cases:
- Real time video
- Voice over IP
- DNS

## Internet Protocol

### IP — Internet Protocol

The protocol responsible for the end-to-end nature of joined networks.

### HTTP / HTTPS

Protocols for transferring web content.

### QUIC

A modern transport protocol built on UDP.
