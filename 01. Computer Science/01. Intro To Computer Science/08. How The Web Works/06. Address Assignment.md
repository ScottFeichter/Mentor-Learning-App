# Address Assignment

&nbsp;

## Static vs DHCP

&nbsp;

### Static IP Address

Does not change — the admin must manually configure:

- **IP address** — identifies the host on the network
- **Subnet mask** — identifies the network the host is connected to
- **Default gateway** — identifies the networking device the host uses to access the internet

Advantages:
- Useful for printers, servers, and devices accessible to clients
- Provides increased control of network resources

Disadvantages:
- Can be time consuming
- More prone to errors
- Must maintain accurate list of addresses

&nbsp;

### Dynamic IP Address (DHCP)

Automatically assigned via a DHCP server. Various devices can be DHCP servers as long as they are running DHCP service software.

A router is often both a DHCP client and server — client to the ISP for its public address, and server to its hosts to give them their private addresses.

## DHCP Process

**Dynamic Host Control Protocol** — a set of messages that go between the device wanting an IP address and the device that can assign it.

1. **DHCP Discover** — a broadcast to `255.255.255.255` from a host looking for a DHCP server
2. **DHCP Offer** — reply from server with an IP address offer including subnet and default gateway
3. **DHCP Request** — reply from host accepting the offer
4. **DHCP Acknowledgement** — reply from server confirming the address has been assigned
