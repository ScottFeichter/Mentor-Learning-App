# Wired Networks

&nbsp;

Wireless technologies tend to iterate the various kinds of networking technologies that people already use.

&nbsp;

---

&nbsp;

## Network Types

- **PAN** — Personal Area Network (e.g. Bluetooth between earbuds and phone)
- **LAN** — Local Area Network (e.g. your home or office network)
- **MAN** — Metropolitan Area Network
- **WAN** — Wide Area Network (e.g. the internet)
