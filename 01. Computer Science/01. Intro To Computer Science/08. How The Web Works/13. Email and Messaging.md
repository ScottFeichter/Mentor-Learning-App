# Email and Messaging

&nbsp;

## Email Protocols

### SMTP — Simple Mail Transfer Protocol

- Used by email client to send messages to its local email server
- Server decides if the message is destined for a local mailbox or a mailbox on another server
- If a different server, SMTP is used between those two servers on port `25`

### POP3 — Post Office Protocol

- POP servers store messages addressed to its user clients
- When client connects, messages are downloaded to the client
- Messages are not kept on the server after the client has them
- Clients contact POP3 servers on port `110`

### IMAP4 — Internet Message Access Protocol

- IMAP servers store messages addressed to its user clients
- When client connects, messages are downloaded to the client
- Unlike POP, IMAP keeps messages on the server unless deleted by the user
- Servers listen for client requests on port `143`

## Text Messaging

Also known as Instant Message, Direct Message, Private Message, or Chat Message.

- Allows real time communication
- Usually accessed through a web-based client integrated into social media
- Can be standalone clients (e.g. WhatsApp)
- Usually peer-to-peer (P2P)

## VoIP — Voice over IP

- Uses peer-to-peer technology
- Analog voice signals are converted to digital data
- Voice data is encapsulated into IP packets
- Calls are made to other users of the same service over the internet
- A call to a regular telephone requires using a gateway to access the PSTN (Public Switched Telephone Network)
- Protocols and ports vary by software
