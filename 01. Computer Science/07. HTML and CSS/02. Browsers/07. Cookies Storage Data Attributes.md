# Cookies, Storage, and Data Attributes

## Storage Options Overview

| Option | Size | Persistence | Shared with Server? |
|--------|------|-------------|-------------------|
| Session cookie | 4KB | Until tab closes | Yes |
| Persistent cookie | 4KB | Until expiration | Yes |
| sessionStorage | 5MB | Until tab closes | No |
| localStorage | 5MB | Until cache cleared | No |
| Backend database | Large | Until deleted | Yes (on request) |

## Cookies

A small file (< 4KB) stored on user's computer. Included with HTTP requests.

### Create a Session Cookie

```javascript
document.cookie = "favoriteCat=million";
```

### Create a Persistent Cookie

```javascript
document.cookie = "favoriteCat=million; expires=Thu, 01 Jan 2070 00:00:00 GMT";
```

### Delete a Cookie

Set expiration to past date:
```javascript
document.cookie = "favoriteCat=; expires=Thu, 01 Jan 1970 00:00:00 GMT";
```

## Web Storage API

### localStorage

```javascript
localStorage.setItem("key", "value");
localStorage.getItem("key");
localStorage.removeItem("key");
```

### sessionStorage

Same API as localStorage, but data disappears when tab closes.

> Use `JSON.stringify()` for non-string data.

## Data Attributes

Store data on HTML elements that doesn't need to be displayed:

```html
<div data-banana="yellow"></div>
```

Read and update in JavaScript:

```javascript
const div = document.querySelector('div');
div.dataset.banana;              // "yellow"
div.dataset.coolInfo = "Hello World!";
```

Result:
```html
<div data-banana="yellow" data-cool-info="Hello World!"></div>
```

> Use the "Application" tab in Developer Tools to read/manipulate client storage.
