# Web and Networking Terms

## HTML

**Hypertext Markup Language** — the language that the content of websites are written in.

## HTTP

**Hypertext Transfer Protocol** — the protocol used to transfer data on the internet.

## HTTPS

**Hypertext Transfer Protocol Secure** — encrypted version of HTTP.

## SSH

**Secure Shell** — a method of securely communicating with another computer. The "shell" part is based on a Unix shell (a program that interprets commands). Standard Unix commands can be used to manipulate files from a remote machine once an SSH connection has been established.

## Firewall

Originally referred to fireproof walls designed to limit the spread of fire. In IT, a computer firewall limits the data that can pass through it to protect a networked server or client machine from damage by unauthorized users.

## Port 80

The non-secure HTTP protocol port.

## Port 443

The secure HTTPS protocol port.

## Viewing HTML Code

Right-click on any webpage in Chrome → Inspect (or Cmd+Opt+I on Mac).
