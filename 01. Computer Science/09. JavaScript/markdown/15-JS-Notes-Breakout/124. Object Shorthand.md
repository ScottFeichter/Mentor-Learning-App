# Object Shorthand

&nbsp;

## Object Shorthand---------------------

```javascript
const firstName = "Spencer";

const lastName = "Armini";
```

ES5

```javascript
const developer = {

firstName: firstName,

lastName: lastName,

}

const firstName = "Spencer";

const lastName = "Armini";
```

ES6

```javascript
const developer = {

firstName,

lastName,

}
```

## Object Methods---------------------

ES5

```javascript
var instructor = {

sayHello: function () {

return "Hello!";

}

}
```

ES2015 - do NOT use arrow func!

```javascript
let instructor = {

sayHello() {

return "Hello!";

}

}
```

## Computed Property Names---------------------

ES5

```javascript
var firstName = "Elie";

var instructor = {};

instructor[firstName] = "That's me!";

instructor.Elie; // "That's me!"
```

## Es2015

```javascript
let firstName = "Elie";

let instructor = {

[firstName]: "That's me!",

}

instructor.Elie; // "That's me!"
```

## Object Destructuring---------------------

## Old Way

```javascript
let userData = {

username: 'janet',

id: 12345,

firstName: 'Janet',

lastName: 'Cho',

age: 34,

};

let username = userData.username;

let firstName = userData.firstName;

let lastName = userData.lastName;

let id = userData.id;
```

## New Way

```javascript
const userData = {

username: 'janet',

id: 12345,

firstName: 'Janet',

lastName: 'Cho',

age: 34,

};
```

declare variables: username, firstName, lastName, id

  values taken from the keys of the same name in userData

```javascript
const { username, firstName, lastName, id } = userData;

console.log(username);  // janet

console.log(id);        // 12345
```
