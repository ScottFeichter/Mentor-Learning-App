# Multiple Ways to Write Same Function

&nbsp;

## Start With Some Variables We Will Pass As Arguments

```javascript
let a = 5;

let b = 6;
```

## Then We Make a Funciton the Old Fashioned Way

```javascript
function sample(a, b) {

if (a === b) {

console.log('equal');

} else console.log('not equal');

console.log(a + b);

return a + b;

};
```

## Then We Make an Anonymous Function

```javascript
(function(){

if (a === b)

console.log('equal');

else console.log('not equal');

console.log(a + b);

return a + b;

}) (a, b);
```

