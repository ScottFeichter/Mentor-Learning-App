# Troubleshooting Model and Port Numbers

## CompTIA Troubleshooting Model

1. Identify the problem
2. Establish a theory of probable cause
3. Test the theory to determine cause
4. Establish a plan of action to resolve the problem & implement the solution
5. Verify full system functionality
6. Document findings, actions, and outcomes

*Mnemonic: "In Egypt, the elephant invented Valentine's Day"*

## Port Number Mnemonics

- FTP 20/21 — File Transfers are fun
- SSH 22 — Secure communication in my Shell
- Telnet 23 — Nobody likes you when you're port 23
- SMTP 25 — Simple Mail Transferred to servers
- DNS 53 — Convert Names to IP
- HTTP 80 — Browsing with port eight-zero
- HTTPS 443 — More Secure with port 443
- POP3 110 — Post Office in port 110
- IMAP 143 — Internet Message Access with port 143
- RDP 3389 — Remote Desktop code is 3-3-8-9
- NetBIOS 137 — Search by Name (UDP)
- NetBIOS 138 — Data transfers without connections (UDP)
- NetBIOS 139 — Data transfers with Session connection
- SMB 445 — Transfers without NetBIOS
- SNMP 161 — Managing a Network is Simple (UDP)
- LDAP 389 — Read and write Directories, gain Access
- DHCP 67/68 — Automatically assign an IP (UDP)
