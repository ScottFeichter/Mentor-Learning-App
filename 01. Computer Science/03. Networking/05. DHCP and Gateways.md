# DHCP and Gateways

## Static vs Dynamic IP Assignment

### Static IP

Manually configured by admin:
- IP address — identifies the host
- Subnet mask — identifies the network
- Default gateway — identifies the router to access internet

Advantages: useful for printers/servers, increased control
Disadvantages: time consuming, error prone, must maintain address list

### Dynamic IP (DHCP)

Automatically assigned via a DHCP server.

**DHCP Process:**
1. **DHCP Discover** — broadcast to 255.255.255.255 from host looking for a server
2. **DHCP Offer** — reply from server with IP, subnet, and default gateway
3. **DHCP Request** — reply from host accepting the offer
4. **DHCP Acknowledgement** — server confirms and updates its records

## Gateways

**Gateway** — the way traffic leaves a LAN and goes to other networks (like an exit door).

**Default Gateway** — the first gateway a host will try. Often the router serves as default gateway for all hosts on its network.

- Each router interface connects to a separate network
- The IPv4 address assigned to the interface identifies which local network is directly connected
- Each host must know the router interface address — this is the default gateway

## NAT (Network Address Translation)

- Internal networks use private IPv4 for all internal devices
- Private addresses are NOT globally routable
- When a packet with a private source IP goes to a public destination, the router translates the private address to a public address
- The router keeps a table mapping private ↔ public addresses
- This translation process is NAT
