# BSON (Binary JSON)

**BSON** is a binary representation of JSON-like documents. It extends JSON's data model to provide additional data types and enable efficient encoding/decoding.

## Key Features

- **Binary Format**: More compact and faster to parse than text-based JSON
- **Rich Data Types**: Supports types not available in JSON (dates, binary data, ObjectId)
- **Traversable**: Allows efficient field access without parsing entire document
- **Ordered**: Maintains field order (unlike some JSON implementations)

## BSON vs JSON Comparison

| Feature | JSON | BSON |
|---------|------|------|
| Format | Text-based | Binary |
| Size | Human-readable, larger | Compact, smaller |
| Parsing Speed | Slower | Faster |
| Data Types | Limited (string, number, boolean, null, object, array) | Extended (Date, ObjectId, Binary, etc.) |
| Use Case | Web APIs, config files | Database storage, network protocols |

## Additional BSON Types

```javascript
{
  "_id": ObjectId("507f1f77bcf86cd799439011"),
  "date": ISODate("2023-01-15T10:30:00Z"),
  "binary": BinData(0, "SGVsbG8gV29ybGQ="),
  "regex": /pattern/flags,
  "decimal": NumberDecimal("123.45")
}
```

## Primary Usage

- **MongoDB**: Native storage format
- **Network Protocols**: Efficient data transmission
- **Caching Systems**: Fast serialization/deserialization

BSON trades human readability for performance and extended functionality.
