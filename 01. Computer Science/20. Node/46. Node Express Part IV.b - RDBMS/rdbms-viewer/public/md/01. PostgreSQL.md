# PostgreSQL

## What Is PostgreSQL?

**PostgreSQL** (often called "Postgres") is an open-source, object-relational database management system known for its reliability, feature richness, and standards compliance. It's widely considered the most advanced open-source relational database.

## History

- **1986**: Originated as the POSTGRES project at UC Berkeley, led by Professor Michael Stonebraker
- **1996**: Renamed to PostgreSQL when SQL support was added
- **1997**: First open-source release (v6.0)
- **2000s**: Gained reputation for reliability and advanced features
- **2010s**: Became the go-to choice for startups and enterprises alike
- **Today**: One of the most popular databases worldwide, used by Apple, Instagram, Spotify, Reddit, and many others

## Key Features

- Full ACID compliance
- Advanced data types (JSON, JSONB, arrays, hstore, geometric, UUID)
- Full-text search built in
- Table inheritance
- Extensible (custom types, functions, operators, index types)
- Robust concurrency with MVCC (Multi-Version Concurrency Control)
- Supports both SQL and JSON querying
- Powerful indexing (B-tree, Hash, GiST, GIN, BRIN)
- Materialized views
- Common Table Expressions (CTEs) and window functions
- Foreign data wrappers (query external data sources)

## Running Locally (psql Shell)

### Connect to PostgreSQL

```bash
# Connect as default user
psql postgres

# Connect to a specific database
psql -d mydb

# Connect as a specific user
psql -U username -d mydb

# Connect with host and port
psql -h localhost -p 5432 -U username -d mydb
```

### Basic Shell Commands

```sql
-- List all databases
\l

-- Connect to a database
\c mydb

-- List all tables
\dt

-- Describe a table
\d users

-- List all schemas
\dn

-- Show current user
\conninfo

-- Quit psql
\q

-- Run a SQL file
\i /path/to/file.sql

-- Toggle expanded display
\x
```

### Basic SQL Operations

```sql
-- Create a database
CREATE DATABASE myapp;

-- Create a table
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL,
  age INTEGER CHECK (age >= 0),
  created_at TIMESTAMP DEFAULT NOW()
);

-- Insert data
INSERT INTO users (name, email, age) VALUES ('John', 'john@example.com', 30);

-- Query data
SELECT * FROM users WHERE age > 21 ORDER BY name;

-- Update data
UPDATE users SET age = 31 WHERE email = 'john@example.com';

-- Delete data
DELETE FROM users WHERE id = 1;

-- Drop a table
DROP TABLE users;

-- Drop a database
DROP DATABASE myapp;
```

### User Management

```sql
-- Create a user
CREATE USER myuser WITH PASSWORD 'mypassword';

-- Grant privileges
GRANT ALL PRIVILEGES ON DATABASE myapp TO myuser;

-- List users
\du
```

### Connecting from Node.js

```javascript
// Using pg (node-postgres)
const { Pool } = require('pg');

const pool = new Pool({
  connectionString: 'postgresql://user:pass@host:5432/mydb?sslmode=require'
});

const result = await pool.query('SELECT * FROM users');
```

## Default Port

**5432**

## When to Use PostgreSQL

- Complex queries and reporting
- Applications needing advanced data types (JSON, geospatial)
- Projects requiring strict data integrity
- When you need extensibility
- Full-text search requirements
- Any production application (it's a safe default choice)
