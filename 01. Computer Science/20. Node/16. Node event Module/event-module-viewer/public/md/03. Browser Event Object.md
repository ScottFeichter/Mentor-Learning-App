# Browser Event Object

In browsers an event is programatically expressed as a JS object.

This object is a CIJO - it is an object instantiated from a pre existing class.

## Example Browser Event Object

A syntactic approximation of a browser event object instantiated from the built in Event class:

```js
PointerEvent {
  type: "click",                // The event name
  target: button#submit-btn,    // The exact DOM element clicked
  currentTarget: form#login,    // The element listening to the event
  bubbles: true,                // Does it travel up the DOM?
  cancelable: true,             // Can preventDefault() be called?
  defaultPrevented: false,      // Has preventDefault() been called?
  timeStamp: 1432.5,            // Milliseconds since page load
  clientX: 142,                 // X-coordinate of the click (UI specific)
  clientY: 85,                  // Y-coordinate of the click (UI specific)
  altKey: false,                // Was the Alt key held down?
  isTrusted: true,              // True if generated by user, false if by script

  // Methods
  stopPropagation: ƒ stopPropagation(),
  preventDefault: ƒ preventDefault()
}

```
