# Events In The Browser

In the browser, DOM elements are targets of triggers (clicks, key presses, page loads).

The triggering induces the browser rendering engine to emit an event object.

The browser looks for listeners; which act as flags and include a handler.

The listener signals the browser rendering engine to call the handler associated with the target.

```javascript
button.addEventListener('click', () => {
  console.log('Button clicked!');
});
```

## Event Emitting

In the browser, emitting is a multi-step process.

It includes instantiation of the event object, among other things.

When the user clicks, the browser engine instantiates a 'click' event and emits it through the dom tree.

The engine checks each dom component for listeners that match the click event.

If if a match is made the engine grabs the handler and calls it.

The handler is an argument of the listener that is attached to the html component.
