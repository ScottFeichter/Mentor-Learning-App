# DoOver

## The Question

"So a sandbox was needed for the browsers made with C etc. why not use Rust as the sandbox language why create JS?"

## The Timeline Problem

**Rust didn't exist when JavaScript was created!**

- **1995**: JavaScript created by Brendan Eich in 10 days for Netscape Navigator
- **2010**: Rust development started at Mozilla (15 years later!)
- **2015**: Rust 1.0 released (20 years later!)

JavaScript was created in a rush to add interactivity to web pages. Rust wasn't even a concept yet.

## Why Not Use An Existing Safe Language?

In 1995, the options were:

### Java
- **Too heavy**: Required a large runtime (JVM)
- **Too slow**: Startup time was terrible on 1995 hardware
- **Too complex**: Full OOP language, steep learning curve
- Sun Microsystems tried with Java Applets - they failed and died

### Python
- Existed but was niche
- Also requires a runtime
- Not designed for browsers

### Scheme/Lisp
- Brendan Eich actually wanted to use Scheme!
- Netscape management said "make it look like Java" for marketing reasons
- So we got JavaScript (Java-like syntax, Scheme-like semantics)

## Why JavaScript Succeeded

**1. Simplicity**
- Easy to learn for non-programmers
- Forgiving (dynamic typing, automatic type coercion)
- No compilation step

**2. Lightweight**
- Small interpreter could fit in the browser
- Fast enough for simple scripts on 1995 hardware

**3. Embedded**
- Ran directly in the browser
- No plugins or external runtimes needed

**4. "Good Enough"**
- Solved the immediate problem (form validation, simple interactions)
- Could be improved over time

## If We Could Do It Over Today?

If we were designing the web from scratch in 2025, we might choose:
- **Rust**: Memory safe, fast, but complex
- **Go**: Simple, safe, good concurrency
- **WebAssembly from day one**: Multi-language support

But we're stuck with JavaScript due to **backwards compatibility** - billions of websites depend on it.

## The Irony

You're right to see the irony: We created JavaScript because we needed something simple and safe, then spent 30 years making it more complex (TypeScript, build tools, frameworks) to compensate for its weaknesses.

If Rust had existed in 1995, the web might look very different today!

## The Bottom Line

JavaScript wasn't chosen over Rust - Rust didn't exist. JavaScript was the best option available in 1995 for the constraints of the time (simple, lightweight, safe enough). 

Now we're living with that decision, and the web platform has too much momentum to start over, even though better options exist today.
