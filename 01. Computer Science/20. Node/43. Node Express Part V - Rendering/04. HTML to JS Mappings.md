# HTML to JS Mappings

## HTML Tag to JavaScript Object Type

Each HTML tag maps to a specific JavaScript object class when the browser creates the DOM:

```html
<!DOCTYPE html>           → Document object (document)
<html>                    → HTMLHtmlElement (document.documentElement)
  <head>                  → HTMLHeadElement (document.head)
    <title>               → HTMLTitleElement
    <meta>                → HTMLMetaElement
    <link>                → HTMLLinkElement
    <script>              → HTMLScriptElement
  </head>
  <body>                  → HTMLBodyElement (document.body)
    <div>                 → HTMLDivElement
    <button>              → HTMLButtonElement
    <input>               → HTMLInputElement
    <a>                   → HTMLAnchorElement
    <img>                 → HTMLImageElement
    <p>                   → HTMLParagraphElement
    <span>                → HTMLSpanElement
    <form>                → HTMLFormElement
  </body>
</html>
```

## Inheritance Chain

All of these object types inherit from a common hierarchy:

```
Object
  └── EventTarget
      └── Node
          └── Element
              └── HTMLElement
                  └── HTMLDivElement, HTMLButtonElement, etc.
```

This is why all HTML elements share common properties and methods like `addEventListener()`, `appendChild()`, `classList`, etc.
