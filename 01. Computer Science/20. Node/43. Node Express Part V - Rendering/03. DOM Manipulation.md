# DOM Manipulation

## What You're Actually Manipulating

When you use JavaScript to interact with the page, you're **not touching the actual HTML text** - you're manipulating the **JavaScript objects** that represent those HTML elements.

## The Process

1. **HTML (text file)** → Browser reads it once
2. **Browser creates JS objects** → One object per HTML element
3. **You manipulate the objects** → Using JavaScript
4. **Browser re-renders** → Updates what you see on screen

## Example

```html
<button id="myBtn">Click me</button>
```

The browser creates a JavaScript object for this button:

```javascript
const btn = document.getElementById('myBtn');
// btn is a JavaScript object with properties and methods:
btn.textContent = 'New text';  // Change the object's property
btn.addEventListener('click', ...);  // Call the object's method
```

You're modifying the **object in memory**, not the original HTML file. The browser then updates the visual rendering based on the object's current state.

This is why it's called the **Document Object Model** - it's an object-based model of the document, not the document itself.
