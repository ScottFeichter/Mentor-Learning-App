# express-rate-limit

## What is express-rate-limit?

express-rate-limit is an Express middleware that limits repeated requests to APIs or endpoints. It helps protect against brute-force attacks, DDoS, and API abuse.

## Installation

```bash
npm install express-rate-limit
```

## Basic Usage

```javascript
const express = require('express');
const rateLimit = require('express-rate-limit');

const app = express();

const limiter = rateLimit({
  windowMs: 15 * 60 * 1000, // 15 minutes
  max: 100, // limit each IP to 100 requests per window
  message: 'Too many requests, please try again later.'
});

app.use(limiter);
```

## Route-Specific Limiting

```javascript
// Strict limit on login attempts
const loginLimiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 5,
  message: 'Too many login attempts. Try again in 15 minutes.'
});

app.post('/login', loginLimiter, (req, res) => {
  // Handle login
});

// Relaxed limit on general API
const apiLimiter = rateLimit({
  windowMs: 60 * 1000, // 1 minute
  max: 30
});

app.use('/api/', apiLimiter);
```

## Configuration Options

| Option | Default | Description |
|--------|---------|-------------|
| `windowMs` | 60000 | Time window in milliseconds |
| `max` | 5 | Max requests per window per IP |
| `message` | 'Too many requests...' | Response when limit exceeded |
| `statusCode` | 429 | HTTP status code when limited |
| `headers` | true | Send rate limit headers |
| `standardHeaders` | true | Use `RateLimit-*` headers |
| `legacyHeaders` | false | Use `X-RateLimit-*` headers |

## Response Headers

When rate limiting is active, these headers are sent:

```
RateLimit-Limit: 100
RateLimit-Remaining: 95
RateLimit-Reset: 1620000000
```

## Custom Key Generator

By default, rate limiting is per IP. You can customize this:

```javascript
const limiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 100,
  keyGenerator: (req) => {
    return req.headers['x-api-key'] || req.ip;
  }
});
```

## Skip Certain Requests

```javascript
const limiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 100,
  skip: (req) => {
    // Don't rate limit admins
    return req.user && req.user.role === 'admin';
  }
});
```

## Custom Handler

```javascript
const limiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 100,
  handler: (req, res) => {
    res.status(429).json({
      error: 'Rate limit exceeded',
      retryAfter: Math.ceil(req.rateLimit.resetTime / 1000)
    });
  }
});
```

## Summary

- **express-rate-limit** protects against brute-force and abuse
- Apply globally or per-route with different limits
- Use strict limits on sensitive endpoints (login, signup)
- Customize by IP, API key, or user
- Returns standard rate limit headers for client awareness
