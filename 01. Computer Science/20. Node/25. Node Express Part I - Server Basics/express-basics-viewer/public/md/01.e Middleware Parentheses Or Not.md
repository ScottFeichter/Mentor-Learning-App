# Middleware — Do We Include `()` or Not?

It depends on the middleware.

---

## No parentheses — the middleware IS the function

app.use expects one of its arguments to be a callback.

This is a reference to a function definition passed as an argument.

```js

function someMiddleware(req, res, next) {
    // some logic
    next();
}


app.use(someMiddleware);
```

You are passing the function itself so app.use can call it in its body.

You are not calling the function yourself only defining it.

---

## With parentheses — the middleware RETURNS a function

In some cases it looks as if we are passing a function invocation.

And this is technically true:

```js
app.use(express.json());
app.use(helmet());
app.use(cors());
```

However in these cases these functions themselves return a reference to a function definition.

Here, `express.json()` is being *called*, and what it **returns** is the actual middleware function.

The parentheses also let you pass in configuration options — like `express.json({ limit: '1mb' })`.

---

## The Rule

- If it **is** the middleware → no `()`
- If it **returns** the middleware → yes `()`
