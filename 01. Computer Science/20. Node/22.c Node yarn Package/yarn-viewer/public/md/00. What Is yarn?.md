# yarn

## What Is yarn?

yarn (Yet Another Resource Negotiator) is a package manager for Node.js created by Facebook in 2016. It was built to address speed, reliability, and security issues with npm at the time.

## Installation

```bash
# Via npm
npm install -g yarn

# Via corepack (Node 16+)
corepack enable
corepack prepare yarn@stable --activate

# Via Homebrew (macOS)
brew install yarn
```

## Versions

- **yarn 1 (Classic)** — Original version, flat node_modules
- **yarn 2+ (Berry)** — Complete rewrite, Plug'n'Play (PnP) by default

## Basic Usage

```bash
# Initialize a project
yarn init

# Install all dependencies
yarn install
# or just
yarn

# Add a package
yarn add express

# Add a dev dependency
yarn add -D nodemon

# Remove a package
yarn remove express

# Run a script
yarn run dev
# or just
yarn dev
```

## Key Features

### Offline Mode
yarn caches every package it downloads. You can install packages without an internet connection if they've been installed before.

### Deterministic Installs
`yarn.lock` ensures every install produces the exact same file structure on every machine.

### Workspaces
Built-in monorepo support for managing multiple packages in one repository.

```json
{
  "workspaces": [
    "packages/*",
    "apps/*"
  ]
}
```

### Plug'n'Play (yarn 2+)
Eliminates `node_modules` entirely. Dependencies are stored as zip files and resolved through a `.pnp.cjs` file.

```bash
# Enable PnP
yarn set version berry
yarn install
```

## yarn.lock

The lockfile ensures reproducible installs:

```yaml
express@^4.18.0:
  version "4.18.2"
  resolved "https://registry.yarnpkg.com/express/-/express-4.18.2.tgz#..."
  integrity sha512-...
  dependencies:
    accepts "~1.3.8"
    body-parser "1.20.1"
```

## Summary

- yarn is a fast, reliable alternative to npm
- Pioneered lockfiles and workspaces
- yarn 2+ (Berry) introduces Plug'n'Play for zero-install
- Great for monorepos and teams needing deterministic builds
- Uses the same npm registry as npm and pnpm
