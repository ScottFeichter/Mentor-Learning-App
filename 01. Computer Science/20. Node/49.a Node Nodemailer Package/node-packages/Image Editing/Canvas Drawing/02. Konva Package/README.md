# Konva

**npm:** `konva`

Higher-level 2D canvas framework with a scene graph. Supports layers, shapes, images, text, transforms, drag/drop, and event handling. Works server-side with the `canvas` package.

**Use cases:**
- Complex multi-layer canvas compositions
- Interactive graphics (server-side rendering of scenes)
- Exporting layered designs to images
- Stage/layer-based rendering pipeline

**Install:**
```bash
npm install konva canvas
```
