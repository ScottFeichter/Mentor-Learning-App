# Node Canvas

**npm:** `canvas`

Cairo-backed implementation of the HTML5 Canvas API for Node.js. Draw shapes, text, images, gradients, and patterns — full 2D rendering without a browser. Outputs PNG, JPEG, or PDF.

**Use cases:**
- Server-side image generation (charts, badges, social cards)
- Drawing text with custom fonts
- Compositing images with shapes and gradients
- Generating images for email or PDF embedding

**Install:**
```bash
npm install canvas
```
