# Jimp

**npm:** `jimp`

Pure JavaScript image processing library — no native dependencies. Resize, crop, blur, color adjust, text overlay, and filters. Slower than Sharp but installs anywhere without compilation issues.

**Use cases:**
- Image manipulation in environments where native modules are problematic
- Adding text/watermarks to images
- Color adjustments and filters
- Simple image editing without native dependencies

**Install:**
```bash
npm install jimp
```
