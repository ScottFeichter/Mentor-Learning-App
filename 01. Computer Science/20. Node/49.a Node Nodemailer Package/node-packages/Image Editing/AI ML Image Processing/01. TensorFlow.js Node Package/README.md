# TensorFlow.js Node

**npm:** `@tensorflow/tfjs-node`

Machine learning library for Node.js. Run pre-trained models or train custom models for image classification, object detection, style transfer, super-resolution, and segmentation.

**Use cases:**
- Object detection in images
- Image classification (is this a cat? a document?)
- Neural style transfer
- Image super-resolution (upscaling)
- Face detection and landmark recognition

**Install:**
```bash
npm install @tensorflow/tfjs-node
```
