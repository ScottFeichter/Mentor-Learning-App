# Mammoth

**npm:** `mammoth`

Converts .docx files to clean HTML or plain text. Read-only — does not write .docx files. Focuses on semantic conversion rather than visual fidelity.

**Use cases:**
- Importing Word documents into a CMS
- Extracting text content from .docx uploads
- Converting .docx to HTML for web display

**Install:**
```bash
npm install mammoth
```
