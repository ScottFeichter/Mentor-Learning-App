# ExcelJS

**npm:** `exceljs`

Full-featured Excel workbook library. Read and write .xlsx files with support for styles, fonts, colors, formulas, charts, images, freeze panes, data validation, and conditional formatting.

**Use cases:**
- Generating styled reports
- Reading/writing spreadsheets with formatting
- Template-based Excel generation

**Install:**
```bash
npm install exceljs
```
