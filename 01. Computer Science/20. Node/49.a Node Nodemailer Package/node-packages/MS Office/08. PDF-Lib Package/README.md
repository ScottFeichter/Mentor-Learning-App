# PDF-Lib

**npm:** `pdf-lib`

Create and modify PDF documents. Add pages, text, images, forms, and annotations. Can also modify existing PDFs (merge, split, add watermarks). Pure JavaScript — no native dependencies.

**Use cases:**
- Generating PDF reports
- Filling in PDF forms programmatically
- Merging/splitting PDFs
- Adding watermarks or stamps

**Install:**
```bash
npm install pdf-lib
```
