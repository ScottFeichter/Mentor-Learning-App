# Add Scripts

## Create Scripts in package.json

Add scripts to build, run, and test (can adjust later):

```json
"scripts": {
  "start": "node server.js",
  "dev": "nodemon server.js",
  "test": "echo \"Error: no test specified\" && exit 1"
}
```

## Configure Main Entry File

Notice the following section in `package.json`:

```json
"main": "index.js",
```

This indicates the entry file. Common options:

- `server.js`
- `app.js`
- `entry.js`
- `index.js`

## Subdirectory Entry Files

If your entry file is in a subdirectory, include the relative path:

```json
"main": "src/server.js"

"scripts": {
  "start": "node src/server.js",
  "dev": "nodemon src/server.js"
}
```

**Note:** The `main` field is primarily used when your project is published as an npm package. For server applications that aren't published, it's less critical, but it's still good practice to set it correctly.
