# yarn Commands

## Command Comparison with npm

| Action | npm | yarn |
|--------|-----|------|
| Install all deps | `npm install` | `yarn` |
| Add package | `npm install pkg` | `yarn add pkg` |
| Add dev dep | `npm install -D pkg` | `yarn add -D pkg` |
| Add global | `npm install -g pkg` | `yarn global add pkg` |
| Remove package | `npm uninstall pkg` | `yarn remove pkg` |
| Update package | `npm update pkg` | `yarn upgrade pkg` |
| Run script | `npm run script` | `yarn script` |
| Init project | `npm init` | `yarn init` |
| Run binary | `npx command` | `yarn dlx command` |
| View outdated | `npm outdated` | `yarn outdated` |
| List packages | `npm list` | `yarn list` |
| Clean cache | `npm cache clean` | `yarn cache clean` |

## Useful Commands

### Check why a package is installed
```bash
yarn why express
```

### Upgrade interactively
```bash
yarn upgrade-interactive
```

### Check for vulnerabilities
```bash
yarn audit
```

### View package info
```bash
yarn info express
```

### Set a specific version
```bash
yarn set version 4.0.0
```

## Workspace Commands

```bash
# Run a script in a specific workspace
yarn workspace @myapp/server dev

# Run a script in all workspaces
yarn workspaces foreach run build

# Add a dep to a specific workspace
yarn workspace @myapp/server add express
```

## Configuration

### .yarnrc.yml (yarn 2+)
```yaml
nodeLinker: node-modules  # Use traditional node_modules
enableGlobalCache: true

npmRegistryServer: "https://registry.npmjs.org"
```

### .yarnrc (yarn 1)
```ini
registry "https://registry.npmjs.org"
save-prefix ""
```

## Common Flags

| Flag | Description |
|------|-------------|
| `--frozen-lockfile` | Fail if lockfile needs updating (CI) |
| `--production` | Skip devDependencies |
| `--silent` | Suppress output |
| `--ignore-engines` | Skip engine checks |
| `--prefer-offline` | Use cache when possible |

## CI/CD Best Practice

```bash
# Ensure reproducible installs in CI
yarn install --frozen-lockfile
```

## Summary

- yarn commands are similar to npm but often shorter
- `yarn` alone runs install (no `install` keyword needed)
- Scripts can be run without `run` keyword
- Workspace commands enable monorepo management
- Use `--frozen-lockfile` in CI for reproducibility
