# The window Object

The ```js window``` object is the ```js globalThis``` object **in the browser**.

In the browser they are one and the same; in fact window is a self reference in the globalThis object.

```js window``` lets JS interact with the browser itself — not just the page content.

In this way window gives access to things like the URL, navigation history, screen info, and storage.

There is no official standard for the BOM (unlike the DOM), but all major browsers implement the same core objects.
