
# The globalThis Object

The outer most object in both the browser and Node is called "globalThis".

## Built-Ins

Items inside globalThis are referred to as "built-ins" and they include the language itself and other things.

However, the globalThis in the browser is not identical to the globalThis in Node.

## globalThis Similarities in Browser and Node

We will explore differences later in this chapter but let's see what they have in common.

Here is a list of globalThis built-ins that are identical in globalThis in the browser and node:

1. Core ECMAScript Built-ins (The Language Itself)
   - **Object & Array Classes:** Object, Array, Function, RegExp, Date
   - **Primitive Wrappers:** String, Number, Boolean, Symbol, BigInt
   - **Collections:** Map, Set, WeakMap, WeakSet
   - **Asynchronous Tools:** Promise, AsyncFunction, Generator
   - **Math & Data Namespaces:** Math, JSON, Reflect, Proxy
   - **Error Constructors:** Error, TypeError, SyntaxError, ReferenceError
   - **Global Functions:** parseInt(), parseFloat(), isNaN(), isFinite()

2. The Shared Web APIs (Modern Standardizations)
   These are APIs that originated in the browser but were officially added to Node.js in recent years to ensure cross-platform compatibility:
   - **Networking:** fetch(), Request, Response, Headers, WebSocket
   - **Timers:** setTimeout(), setInterval(), clearTimeout(), clearInterval()
   - **Performance & Control:** performance, AbortController, AbortSignal, queueMicrotask()
   - **Data Handling:** TextEncoder, TextDecoder, atob(), btoa()
