# GM (GraphicsMagick / ImageMagick)

**npm:** `gm`

Node.js wrapper for GraphicsMagick and ImageMagick CLI tools. Massive feature set — virtually anything Photoshop can do in batch mode. Requires GraphicsMagick or ImageMagick installed on the system.

**Use cases:**
- Complex image transformations (distort, perspective, morphology)
- Batch processing large numbers of images
- Advanced compositing and effects
- Format support for obscure image types

**Install:**
```bash
npm install gm
# Also requires: brew install graphicsmagick (or imagemagick)
```
