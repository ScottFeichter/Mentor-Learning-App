# Terminal

&nbsp;

A **terminal application** is the window you type shell commands in, not the shell itself that runs them.

You access a shell through a **terminal application**.

## Mac and Linux Users

You do not need to download anything as you will have a **terminal application** already installed.

Look for Gnome Terminal, Terminal.app, or Konsole in your applications.


## Windows Users

We could use Command Prompt or PowerShell to interact with WSL 2.

However, it is preferred to use the application **Windows Terminal** to interact with WSL 2.

This is because **Windows Terminal** has more features that are taylored to WSL 2.

### Installing Windows Terminal

Open PowerShell or Command Prompt as an Administrator and run:

```cmd
winget install Microsoft.WindowsTerminal
```

Use **Windows Terminal** app to access WSL 2, your new Bash shell.
