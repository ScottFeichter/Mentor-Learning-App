# Libraries

&nbsp;

A library is a collection of pre-written code that you can use in your project.

You call library code when you need it — you're in control of the flow.

## Do I Need To Install A Library Now?

No. You will learn to install libraries as needed in subsequent chapters.

The remaining content on this page is for informational purposes only.

## Examples

- **Lodash** — utility functions for arrays, objects, strings
- **Axios** — HTTP requests (alternative to fetch)
- **Moment.js** — date formatting and manipulation
- **DOMPurify** — sanitize HTML to prevent XSS
- **bcrypt** — password hashing
- **chalk** — colored terminal output

## Installing a Library

```bash
npm install lodash
```

## Using a Library

```javascript
const lodashLibrary = require('lodash');

lodashLibrary.capitalize('hello'); // 'Hello'
lodashLibrary.shuffle([1, 2, 3, 4]); // [3, 1, 4, 2]
```

## Library vs Framework

A library is a tool you reach for.

A framework is a structure you build within.

**You call a library. A framework calls you.**
