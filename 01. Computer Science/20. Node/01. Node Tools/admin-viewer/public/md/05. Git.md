# GIT

&nbsp;

Git is a version control system that tracks changes to your code over time.

It lets you save snapshots, branch off, and collaborate without losing work.

---

## Mac Users

Git is not pre-installed on a Mac.

The best way is to install Xcode Command Line Tools which includes Git.

### Install Xcode Command Line Tools

In terminal app run:

```bash
xcode-select --install
```
Click **Install** and accept the terms in the pop up.

### Verfify Install Success

In terminal app run:

```bash
git --version
```

You should see the version number displayed.

---

## Linux Users

If Git is pre installed on Linux depends on the distro.

Many (like Ubuntu) don't include it by default but some do ship with it.

### Install Git via Shell

In terminal app run:

```bash
sudo apt install git
```

### Verfify Install Success

In terminal app run:

```bash
git --version
```

You should see the version number displayed.

---

## Windows Users

Git does not come pre installed on Windows.

We need to install Git on both Windows and in the WSL environment.

### Install Git on Windows

In Command Prompt or PowerShell app run:

```cmd
winget install --id Git.Git -e --source winget

```

### Verfify Install Success

In Command Prompt or PowerShell app run:

```cmd
git --version
```

You should see the version number displayed.


### Install Git in WSL Environment

In WSL 2 app run:

```wsl
sudo apt update && sudo apt install git -y
```

### Verfify Install Success

In WSL 2 app run:

```wsl
git --version
```

You should see the version number displayed.
