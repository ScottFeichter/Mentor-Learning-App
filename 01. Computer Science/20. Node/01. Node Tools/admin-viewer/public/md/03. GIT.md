# GIT

&nbsp;

Git is a version control system that tracks changes to your code over time.

It lets you save snapshots, branch off, and collaborate without losing work.

## Is Git Already Installed?

- **macOS** — Not pre-installed, but the first time you run `git` in the terminal, macOS prompts you to install the Xcode Command Line Tools, which includes Git.
```bash
brew install git
```
- **Linux** — Depends on the distro. Many (like Ubuntu) don't include it by default but some do ship with it.
```bash
sudo apt install git
```
- **Windows** — No. You have to download and install it from [git-scm.com](https://git-scm.com). The installer also bundles Git Bash, which is a popular Bash environment for Windows dev.
