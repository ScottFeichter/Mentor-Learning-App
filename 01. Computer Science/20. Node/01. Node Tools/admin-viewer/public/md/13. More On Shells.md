# More On Shells

Below is some general information about shells for better understanding. 

## Shell vs. GUI

A shell and a graphical user interface (GUI) are both ways to tell your computer what to do.

Using a mouse to point and click items on the screen is an example of using a GUI.


### Accessing A Shell

You access a shell through a **terminal application** like Gnome Terminal, Terminal.app, or Windows Terminal.

The terminal application is the window you type shell commands in, not the shell itself that runs them.


### Default Shells

A shell is always included with the operating system on your computer.

On Linux it is usually Bash (Born Again Shell).

On macOS the default shell is Zsh (Z Shell), which has high interoperability with Bash commands.

Windows has Command Prompt (cmd) and PowerShell — but neither uses Bash syntax.


### Example Bash Shell Commands

Common commands include `cd`, `ls`, `mkdir`, `rm`, `cp`, and `mv`.

You will use the shell constantly as a developer.


## Review: Shell vs Terminal vs Command Line

- **Terminal** — the application/window you type in
- **Shell** — the program running inside the terminal that interprets your commands
- **Command Line** — the text interface itself (the prompt where you type)

## Common Shells

- **Bash** — default on most Linux distros, available everywhere
- **Zsh** — default on macOS, superset of Bash with extra features
- **PowerShell** — Windows shell with its own syntax
- **Command Prompt (cmd)** — legacy Windows shell
- **Git Bash** — Bash emulator for Windows (comes with Git)
- **WSL** — runs a real Linux shell inside Windows
