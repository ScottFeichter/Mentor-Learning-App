# Frameworks

&nbsp;

A framework is a pre-built structure that provides the architecture for your application.

You build within the framework's rules — it calls your code, not the other way around.

## Do I Need To Install A Framework Now?

No. You will learn to install frameworks as needed in subsequent chapters.

The remaining content on this page is for informational purposes only.

## Examples

- **Express** — minimal web server framework for Node
- **React** — UI component framework (technically a library, but used as a framework)
- **Next.js** — full-stack React framework with SSR, SSG, and routing
- **Angular** — full-featured frontend framework by Google
- **Vue** — progressive frontend framework
- **Astro** — content-focused framework with islands architecture

## Using a Framework

```bash
npm install express
```

```javascript
const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('Hello World');
});

app.listen(3000);
```

Notice you define the handler, but Express decides when to call it. That's the framework pattern.

## Framework vs Library

**You call a library. A framework calls you.**

This is known as **Inversion of Control**.

The framework is in charge of the flow, you just fill in the pieces.
