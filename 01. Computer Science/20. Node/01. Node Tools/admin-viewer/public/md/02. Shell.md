# Shell

&nbsp;

A shell is a program that lets you interact with your computer using text commands.

With commands in a shell we can do anything we could with a GUI and much more.

## Mac and Linux Users

You do not need to download anything as you will have a bash interoperable shell already installed.

You also should have a terminal application already installed on your computer.


## Windows Users

Windows does not come with a pre installed shell that is bash interoperable.

For development on Windows, it is preferred to use a Bash environment such as **WSL 2**.

This keeps your commands consistent with macOS and Linux, which is what most tutorials and tools expect.

### Installing A Bash Environment For Windows

#### Install WSL 2

Open PowerShell or Command Prompt as an Administrator and run:

```cmd
wsl --install
```

Restart your computer.

#### Install Windows Terminal

Open PowerShell or Command Prompt as an Administrator and run:

```cmd
winget install Microsoft.WindowsTerminal
```

Use Windows Terminal app to access your new Bash environment WSL 2.
