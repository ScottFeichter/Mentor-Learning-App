# Query, Filter, Sort, Select, Limit, Skip

Used in PostgreSQL/Prisma

## What is a Query?

A **query** is a request to retrieve data from a database. It's the overall operation that asks the database to find and return records that match certain criteria.

```javascript
// SQL query - asking for user records
SELECT * FROM users;

// Prisma query - same concept
prisma.user.findMany()
```

## What is a Filter?

A **filter** is the criteria or conditions that determine which records to include in the query results. It's the "WHERE" clause in SQL.

```javascript
// SQL filter - only users with age greater than 18
SELECT * FROM users WHERE age > 18;

// Prisma filter - same logic
prisma.user.findMany({ where: { age: { gt: 18 } } })
```

## What is Sorting?

**Sorting** determines the order in which the filtered results are returned. It doesn't change which records are returned, only their sequence.

```javascript
// SQL sort - alphabetical by name
SELECT * FROM users ORDER BY name ASC;

// Prisma sort - same ordering
prisma.user.findMany({ orderBy: { name: 'asc' } })
```

## What is Select?

**Select** (also called projection) determines which fields are included in the returned records. It controls what data is sent back, reducing bandwidth and improving performance.

```javascript
// SQL select - only return name and email fields
SELECT name, email FROM users;

// Prisma select - same field selection
prisma.user.findMany({ select: { name: true, email: true } })
```

## What is Limit?

**Limit** restricts the maximum number of records returned by a query. It's essential for pagination and performance optimization.

```javascript
// SQL limit - return only 10 records
SELECT * FROM users LIMIT 10;

// Prisma limit - same functionality
prisma.user.findMany({ take: 10 })
```

## What is Skip?

**Skip** bypasses a specified number of records before returning results. Combined with limit, it enables pagination.

```javascript
// SQL skip - skip first 20 records
SELECT * FROM users OFFSET 20;

// Prisma skip - same functionality
prisma.user.findMany({ skip: 20 })
```

## How They Work Together

### Complete Example
```javascript
// SQL: Query with all operations
SELECT name, email, age FROM users
WHERE age >= 18 AND status = 'active'
ORDER BY name ASC
LIMIT 10 OFFSET 20;

// Prisma: Same operation
prisma.user.findMany({
  where: { age: { gte: 18 }, status: 'active' },
  select: { name: true, email: true, age: true },
  orderBy: { name: 'asc' },
  skip: 20,
  take: 10
})
```

### Step-by-Step Process
1. **Query**: "Find user records"
2. **Filter**: "Where age >= 18 AND status = 'active'"
3. **Select**: "Only return name, email, and age fields"
4. **Sort**: "Order results by name A-Z"
5. **Skip**: "Skip the first 20 results"
6. **Limit**: "Return maximum 10 records"

## Filter Examples

### Basic Filters
```javascript
// Equality
prisma.user.findMany({ where: { name: "John" } })
prisma.user.findMany({ where: { age: 25 } })

// Comparison
prisma.user.findMany({ where: { age: { gt: 18 } } })        // Greater than
prisma.user.findMany({ where: { price: { lte: 100 } } })    // Less than or equal

// Multiple conditions (AND - implicit)
prisma.user.findMany({ where: { age: { gte: 18 }, status: "active" } })

// OR conditions
prisma.user.findMany({
  where: {
    OR: [
      { age: { lt: 18 } },
      { status: "inactive" }
    ]
  }
})
```

### Advanced Filters
```javascript
// String contains (case-insensitive)
prisma.user.findMany({ where: { name: { contains: "john", mode: "insensitive" } } })

// Starts with
prisma.user.findMany({ where: { name: { startsWith: "John" } } })

// In array of values
prisma.user.findMany({ where: { status: { in: ["active", "pending"] } } })

// NOT conditions
prisma.user.findMany({ where: { NOT: { status: "inactive" } } })

// Null check
prisma.user.findMany({ where: { email: { not: null } } })
```

## Select Examples

### Basic Field Selection
```javascript
// Include specific fields
prisma.user.findMany({
  select: { name: true, email: true }
})

// Exclude specific fields (use select with all fields except those you want to exclude)
// Prisma doesn't have an "exclude" - you explicitly select what you want
prisma.user.findMany({
  select: { id: true, name: true, email: true, createdAt: true }
  // hashedPassword is excluded by not selecting it
})
```

### Advanced Selection
```javascript
// Select with relations
prisma.user.findMany({
  select: {
    name: true,
    email: true,
    Task: {
      select: { title: true, isCompleted: true }
    }
  }
})

// Select with count of relations
prisma.user.findMany({
  select: {
    name: true,
    email: true,
    _count: { select: { Task: true } }
  }
})
```

## Limit and Skip Examples

### Basic Pagination
```javascript
// Page 1: First 10 users
prisma.user.findMany({ take: 10 })

// Page 2: Skip 10, take next 10
prisma.user.findMany({ skip: 10, take: 10 })

// Page 3: Skip 20, take next 10
prisma.user.findMany({ skip: 20, take: 10 })
```

### Pagination Formula
```javascript
const page = 2;        // Current page (1-based)
const limit = 10;      // Items per page
const skip = (page - 1) * limit;  // Calculate skip value

prisma.user.findMany({ skip, take: limit })
```

### Combined with Other Operations
```javascript
// Filter, sort, then paginate
prisma.user.findMany({
  where: { status: 'active' },
  orderBy: { createdAt: 'desc' },
  skip: 20,
  take: 10
})
```

## Sort Examples

### Basic Sorting
```javascript
// Ascending
prisma.user.findMany({ orderBy: { name: 'asc' } })

// Descending
prisma.user.findMany({ orderBy: { createdAt: 'desc' } })
```

### Multiple Field Sorting
```javascript
// Sort by category first, then price descending
prisma.product.findMany({
  orderBy: [
    { category: 'asc' },
    { price: 'desc' }
  ]
})
```

## REST API Integration

### Express Route Example
```javascript
app.get('/api/users', async (req, res) => {
  try {
    // Extract query parameters
    const { age, status, sort, fields, page, limit } = req.query;

    // Build filter object
    let where = {};
    if (age) where.age = { gte: parseInt(age) };
    if (status) where.status = status;

    // Build orderBy
    let orderBy = { createdAt: 'desc' };
    if (sort) {
      const sortFields = sort.split(',');
      orderBy = sortFields.map(field => {
        if (field.startsWith('-')) {
          return { [field.substring(1)]: 'desc' };
        }
        return { [field]: 'asc' };
      });
    }

    // Build select object
    let select = undefined;
    if (fields) {
      select = {};
      fields.split(',').forEach(field => {
        select[field.trim()] = true;
      });
    }

    // Pagination
    const pageNum = parseInt(page) || 1;
    const limitNum = parseInt(limit) || 10;
    const skip = (pageNum - 1) * limitNum;

    // Execute query with all operations
    const users = await prisma.user.findMany({
      where,
      select,
      orderBy,
      skip,
      take: limitNum
    });

    // Get total count for pagination info
    const total = await prisma.user.count({ where });

    res.json({
      users,
      pagination: {
        page: pageNum,
        limit: limitNum,
        total,
        pages: Math.ceil(total / limitNum)
      }
    });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});
```

### URL Examples
```
GET /api/users                                    // Query all users
GET /api/users?page=2&limit=5                     // Pagination
GET /api/users?age=18&sort=name&fields=name,email&page=1&limit=10  // All operations
```

## Query Operations Summary

| Component | Purpose | Example |
|-----------|---------|---------|
| **Query** | Request data from database | `prisma.user.findMany()` |
| **Filter** | Specify which records to return | `{ where: { age: { gte: 18 } } }` |
| **Sort** | Order the returned records | `{ orderBy: { name: 'asc' } }` |
| **Select** | Choose which fields to include | `{ select: { name: true, email: true } }` |
| **Skip** | Bypass a number of records | `{ skip: 20 }` |
| **Limit** | Restrict maximum records returned | `{ take: 10 }` |

## SQL vs Prisma Syntax

### Raw SQL
```sql
SELECT name, email FROM users WHERE age >= 18 ORDER BY name ASC LIMIT 10 OFFSET 20;
```

### Prisma
```javascript
prisma.user.findMany({
  where: { age: { gte: 18 } },
  select: { name: true, email: true },
  orderBy: { name: 'asc' },
  skip: 20,
  take: 10
})
```

## Key Concepts

- **Query**: The overall database operation
- **Filter**: Conditions that determine which records match (`where`)
- **Sort**: Ordering applied to the matching records (`orderBy`)
- **Select**: Field projection to control returned data (`select`)
- **Skip/Take**: Pagination controls for offset and limit
- **Performance**: Filters reduce data, sorting organizes results, select reduces bandwidth

These concepts work together to provide precise, ordered, and optimized data retrieval from PostgreSQL tables using Prisma.
