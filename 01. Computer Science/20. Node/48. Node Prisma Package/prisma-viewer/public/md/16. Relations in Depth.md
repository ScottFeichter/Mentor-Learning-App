# Relations in Depth

## Defining Relations in Prisma

Relations in Prisma are defined in the schema file using the `@relation` attribute. Prisma supports one-to-one, one-to-many, and many-to-many relationships.

## One-to-One

One record in Table A relates to exactly one record in Table B.

```prisma
model User {
  id      Int      @id @default(autoincrement())
  email   String   @unique
  profile Profile?
}

model Profile {
  id     Int    @id @default(autoincrement())
  bio    String
  userId Int    @unique
  user   User   @relation(fields: [userId], references: [id])
}
```

### Querying One-to-One

```javascript
// Create user with profile
const user = await prisma.user.create({
  data: {
    email: 'john@example.com',
    profile: {
      create: { bio: 'Developer' }
    }
  },
  include: { profile: true }
});

// Get user with profile
const user = await prisma.user.findUnique({
  where: { id: 1 },
  include: { profile: true }
});
```

## One-to-Many

One record in Table A relates to many records in Table B.

```prisma
model User {
  id    Int    @id @default(autoincrement())
  email String @unique
  name  String
  tasks Task[]
}

model Task {
  id     Int    @id @default(autoincrement())
  title  String
  userId Int
  user   User   @relation(fields: [userId], references: [id])
}
```

### Querying One-to-Many

```javascript
// Create user with tasks
const user = await prisma.user.create({
  data: {
    name: 'John',
    email: 'john@example.com',
    tasks: {
      create: [
        { title: 'Task 1' },
        { title: 'Task 2' }
      ]
    }
  },
  include: { tasks: true }
});

// Get user with their tasks
const user = await prisma.user.findUnique({
  where: { id: 1 },
  include: { tasks: true }
});

// Get tasks with user info
const tasks = await prisma.task.findMany({
  include: { user: { select: { name: true, email: true } } }
});
```

## Many-to-Many

Many records in Table A relate to many records in Table B.

### Implicit Many-to-Many (Prisma manages the join table)

```prisma
model Student {
  id      Int      @id @default(autoincrement())
  name    String
  courses Course[]
}

model Course {
  id       Int       @id @default(autoincrement())
  title    String
  students Student[]
}
```

Prisma automatically creates a `_CourseToStudent` join table.

### Explicit Many-to-Many (You define the join table)

```prisma
model Student {
  id          Int          @id @default(autoincrement())
  name        String
  enrollments Enrollment[]
}

model Course {
  id          Int          @id @default(autoincrement())
  title       String
  enrollments Enrollment[]
}

model Enrollment {
  id        Int      @id @default(autoincrement())
  studentId Int
  courseId   Int
  grade     String?
  student   Student  @relation(fields: [studentId], references: [id])
  course    Course   @relation(fields: [courseId], references: [id])

  @@unique([studentId, courseId])
}
```

### Querying Many-to-Many

```javascript
// Connect a student to a course (implicit)
await prisma.student.update({
  where: { id: 1 },
  data: {
    courses: { connect: { id: 1 } }
  }
});

// Get student with courses
const student = await prisma.student.findUnique({
  where: { id: 1 },
  include: { courses: true }
});

// Disconnect
await prisma.student.update({
  where: { id: 1 },
  data: {
    courses: { disconnect: { id: 1 } }
  }
});
```

## Relation Operations

| Operation | Purpose |
|-----------|---------|
| `create` | Create a related record |
| `createMany` | Create multiple related records |
| `connect` | Link to an existing record |
| `connectOrCreate` | Link to existing or create new |
| `disconnect` | Remove the link |
| `set` | Replace all connections |

```javascript
// Connect to existing
await prisma.task.create({
  data: {
    title: 'New Task',
    user: { connect: { id: 1 } }
  }
});

// connectOrCreate
await prisma.task.create({
  data: {
    title: 'New Task',
    user: {
      connectOrCreate: {
        where: { email: 'john@example.com' },
        create: { name: 'John', email: 'john@example.com' }
      }
    }
  }
});
```

## Cascading Deletes

By default, Prisma prevents deleting a record that has related records. Configure cascade behavior in the schema:

```prisma
model Task {
  id     Int  @id @default(autoincrement())
  userId Int
  user   User @relation(fields: [userId], references: [id], onDelete: Cascade)
}
```

| Action | Behavior |
|--------|----------|
| `Cascade` | Delete related records too |
| `SetNull` | Set foreign key to null |
| `Restrict` | Prevent deletion (default) |
| `NoAction` | Database handles it |
