## General Differences

### Node.js
- **Version Control**: Tied to Node.js version, not browser
- **ES Support**: Modern Node.js (14+) supports most ES2020+ features
- **Check Support**: Run `node --v8-options | grep harmony` to see available features
- **Upgrade**: Update Node.js version to get newer ES features

### Browser
- **Version Control**: Depends on user's browser version
- **ES Support**: Varies widely (IE11 vs Chrome vs Safari)
- **Check Support**: Use [caniuse.com](https://caniuse.com)
- **Solution**: Transpile with Babel for older browser support
