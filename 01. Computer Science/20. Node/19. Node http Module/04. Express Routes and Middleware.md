# Express Routes and Middleware

## Route Handler Methods

```javascript
app.get(path, callback)
app.post(path, callback)
app.put(path, callback)
app.delete(path, callback)
app.patch(path, callback)
```

## Route Path Argument

- Single path: `app.get("/", ...)`
- Array: `app.get(["/", "/posts", "/comments"], ...)`
- Variable: `const paths = [...]; app.get(paths, ...)`

## Response Methods

- `res.send("plain text")`
- `res.json(data)` — JSON.stringifies the data

## Request Object Properties

- `req.body` — parsed body (requires `app.use(express.json())`)
- `req.query` — query string parameters as object
- `req.params` — named route parameters

## Testing POST Routes in Browser

```javascript
fetch('/users', {
  method: "POST",
  body: JSON.stringify({username: "Demo"}),
  headers: {"Content-Type": "application/json"}
}).then(res => res.json()).then(resBody => console.log(resBody));
```

## Middleware

- Has access to `req`, `res`, and `next`
- Must take at least 3 params (optionally 4 with `error` first)

### Using Middleware

**Global** (all routes):
```javascript
app.use(someMiddleWare);
```

**By prefix** (routes with matching prefix):
```javascript
app.use('/users', someMiddleWare);
```

**Specific route**:
```javascript
const printPath = (req, res, next) => {
  console.log(`path: ${req.path}`);
  next();
};

app.get('/', printPath, (req, res) => { ... });
```

### Error Handling Middleware

```javascript
app.use((req, res, next) => {
  const error = new Error("There was an error");
  next(error); // skips to error-handling middleware
});

app.use((error, req, res, next) => {
  const status = error.statusCode || 500;
  res.status(status).json({ message: error.message });
});
```

## Routers

Separate route handlers into different files:

**app.js:**
```javascript
const peopleRouter = require('./routes/people');
app.use("/people", peopleRouter);
```

**routes/people.js:**
```javascript
const express = require('express');
const router = express.Router();

router.get('/', (req, res) => {
  res.send("Hello from our router");
});

module.exports = router;
```

## Environment Variables

### Using .env file

```bash
npm install dotenv
```

Create `.env`:
```
MESSAGE="hello from .env"
```

In app.js:
```javascript
require('dotenv').config();
console.log(process.env.MESSAGE);
```

Add `.env` to `.gitignore`.

## Express Async Errors

```bash
npm install express-async-errors --save
```

```javascript
require('express-async-errors');

app.get('/users', async (req, res) => {
  const users = await User.findAll();
  res.send(users);
});
```

## Static Files in Express

```javascript
app.use('/static', express.static('public'));
```

- `root` arg is physical location on machine
- Prefix maps URL path to folder
- Example: `GET /static/css/style.css` → `/public/css/style.css`
