# Create Database ERD

## What is an ERD?

An ERD (Entity-Relationship Diagram) is a visual representation of the relationship for data in your database.

## Importance

- Especially important for Relational Databases
- Still worthwhile for Non-Relational Databases to flush out your data
- Helps plan models/schemas even without joins

## Tools

There are many tools online to help with this:

- https://dbdiagram.io/
- Some tools can create the database from the diagram, though these may be more trouble than they're worth

## Storage

Once you have your diagram created, store it in the `database` folder.
