# MongoDB Connection Methods

Different ways to connect and interact with MongoDB databases.

## mongosh (MongoDB Shell)

**Interactive command-line interface** for MongoDB operations.

- **Purpose**: Direct database administration and testing
- **Environment**: Terminal/command line
- **Language**: JavaScript-based commands
- **Use Case**: Development, debugging, admin tasks

```bash
mongosh "mongodb://localhost:27017/mydb"
db.users.find()
```

## Mongoose (Node.js ODM)

**Object Document Mapper** for Node.js applications.

- **Purpose**: Application-level database integration
- **Environment**: Node.js applications
- **Language**: JavaScript/TypeScript
- **Features**: Schema validation, middleware, type casting

```javascript
const mongoose = require('mongoose');
mongoose.connect('mongodb://localhost:27017/mydb');

const User = mongoose.model('User', { name: String });
const user = new User({ name: 'John' });
```

## MongoDB Native Driver

**Low-level driver** for direct MongoDB operations.

- **Purpose**: Fine-grained control without ODM overhead
- **Environment**: Node.js applications
- **Language**: JavaScript/TypeScript
- **Features**: Direct MongoDB API access

```javascript
const { MongoClient } = require('mongodb');
const client = new MongoClient('mongodb://localhost:27017');
const db = client.db('mydb');
```

## Other Connection Methods

| Method | Language | Use Case |
|--------|----------|----------|
| PyMongo | Python | Python applications |
| Motor | Python | Async Python applications |
| MongoDB Compass | GUI | Visual database management |
| Spring Data MongoDB | Java | Spring Boot applications |
| MongoDB Atlas | Web | Cloud-hosted MongoDB |

## When to Use What

- **mongosh**: Quick queries, admin tasks, learning
- **Mongoose**: Node.js apps needing schema validation
- **Native Driver**: Performance-critical Node.js apps
- **Compass**: Visual data exploration and management
