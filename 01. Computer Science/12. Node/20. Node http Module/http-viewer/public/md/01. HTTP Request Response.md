# HTTP Request/Response Handling

## Parse the Request Body

Request body is separated into data packets. Reassemble as a single string:

```javascript
let reqBody = '';
req.on("data", (data) => { reqBody += data; });
req.on("end", () => { console.log(reqBody); });
```

### Parsing `application/x-www-form-urlencoded`

Body is a string of `key=value` pairs separated by `&`:
1. Separate pairs by `&`
2. Separate key from value by `=`
3. Replace `+` with space
4. Decode values: `decodeURIComponent(encodedString)`
5. Turn pairs into an object

## Formulate and Send a Response

### Set the status code

```javascript
res.statusCode = 200;
```

### Set the header

```javascript
res.setHeader("Content-Type", "text/css");
```

### Write the response body

Two ways:

**write** — adds to body (can call multiple times):

```javascript
const server = http.createServer((req, res) => {
  res.write('Hello');
  res.write(' ');
  res.write('World');
  res.write('!');
});
```

**end** — adds to body AND sends response (call once):

```javascript
const server = http.createServer((req, res) => {
  res.write('Hello');
  res.write(' ');
  res.write('World');
  res.end('!');
});
```

Send response with no body:

```javascript
const server = http.createServer((req, res) => {
  res.statusCode = 200;
  res.end();
});
```

## Hanging Server

When there is no response for a request, the server becomes unresponsive. Always send a response for all requests, even errors.
