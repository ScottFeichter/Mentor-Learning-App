# Fabric.js

**npm:** `fabric`

Canvas-based graphics library with an object model. Works in Node.js via the `canvas` package. Supports objects, layers, transforms, filters, free drawing, and serialization to JSON/SVG.

**Use cases:**
- Interactive canvas editors (server-side rendering)
- Object-based image composition
- Applying filters and transforms to canvas objects
- Exporting canvas scenes to images or SVG

**Install:**
```bash
npm install fabric canvas
```
