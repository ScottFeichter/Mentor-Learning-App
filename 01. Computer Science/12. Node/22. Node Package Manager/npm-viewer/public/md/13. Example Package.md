# Example Package

A **package** is a folder that contains a `package.json` file. It can contain multiple modules (JS files) organized into subfolders.

This example shows a basic package with:
- A `package.json` that describes the package
- Two subfolders (`someCode1/` and `someCode2/`) each containing a module

## Key Point

The `package.json` is what makes a folder a "package" rather than just a collection of files. It provides metadata like the package name, version, and entry point.
