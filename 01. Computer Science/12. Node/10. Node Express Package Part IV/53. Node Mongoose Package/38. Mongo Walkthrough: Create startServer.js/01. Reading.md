# Create startServer.js

In the server folder create a file called startServer.js.

Import connectDB() function.

Create an async function startServer that takes the following paramters:

- SERVER
- PORT
- MONGO_URI

Inside this function in a try/catch call await connectDB passing the MONGO_URI.

Then SERVER.listen passing in the PORT with a console.log.

catch and console.log any errors.

export the function

```javascript
const connectDB = require('../database/connect');

const startServer = async (server, PORT, MONGO_URI) => {
  try {
    await connectDB(MONGO_URI);
    server.listen(PORT, () =>
      console.log(`Server is listening on port ${PORT}...`)
    );
  } catch (error) {
    console.log(error);
  }
};

module.exports = startServer
```
