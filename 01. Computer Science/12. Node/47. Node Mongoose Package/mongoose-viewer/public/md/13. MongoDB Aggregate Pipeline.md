# MongoDB Aggregation Pipeline

## Aggregation Pipeline

The **Aggregation Pipeline** is a framework for data processing that transforms documents through a sequence of stages.

### Key Concepts

- **Pipeline**: Series of stages that process documents sequentially
- **Stages**: Each stage transforms the document stream
- **Operators**: Functions used within stages for calculations and transformations

### Common Pipeline Stages

```javascript
db.orders.aggregate([
  // Stage 1: Filter documents
  { $match: { status: "completed" } },

  // Stage 2: Group and calculate
  { $group: {
    _id: "$customerId",
    totalAmount: { $sum: "$amount" },
    orderCount: { $sum: 1 }
  }},

  // Stage 3: Sort results
  { $sort: { totalAmount: -1 } },

  // Stage 4: Limit results
  { $limit: 10 }
])
```

### Pipeline Stages Overview

| Stage | Purpose |
|-------|---------|
| $match | Filter documents (like WHERE in SQL) |
| $group | Group documents and perform calculations |
| $sort | Sort documents |
| $project | Reshape documents, add/remove fields |
| $lookup | Join with other collections |
| $unwind | Deconstruct array fields |
| $limit | Limit number of documents |
| $skip | Skip documents for pagination |

## Query API vs Aggregation Pipeline

| Feature | Query API | Aggregation Pipeline |
|---------|-----------|---------------------|
| Use Case | Simple filtering and retrieval | Complex data processing and analysis |
| Performance | Faster for simple queries | Better for complex transformations |
| Capabilities | Basic filtering, sorting, projection | Grouping, joining, calculations, reshaping |
| Syntax | Simple method calls | Multi-stage pipeline array |

### When to Use Each

- **Query API**: Finding documents, simple filtering, basic CRUD operations
- **Aggregation Pipeline**: Data analysis, reporting, complex transformations, joining collections
