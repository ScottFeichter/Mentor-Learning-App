# OOP

&nbsp;

**Object Oriented Programming (OOP)** is a coding paradigm to use objects to organize related data.

## OOP Benefits

One of the benefits of **OOP** is to more accurately model things from the real world.

This is because in life most things have characteristcs and behaviors.

In **OOP** these are represented with properties and methods.
