**Node Api/Web Api** \- a holding area for tasks counting down a delay before being sent to the message queue

- DOM
- ajax
- setTimeout

Because of how this all connects it is not fully possible to predict exactly the order of events

**Promises** and **Await** help to ensure a certain something happens before a certain something else

**setTimeout** \- global method sets timer for a function or piece of code

timeoutID \= setTimeout(callback, delayInMilliseconds, param1, param2)

timeoutID \- a positive integer value which identifies the timer created by the call to setTimeout. Can be passed to clearTime() to clear a setTimeout()

It is possible to have a message queue overflow situation

READ LINE

- allows for input from terminal
- is a node module
- const readline \= require(‘readline’);
- [Node documentation has info](https://nodejs.org/api/readline.html)
- Example:

const readline \= require('node:readline');
const { stdin: input, stdout: output } \= require('node:process');

const rl \= readline.createInterface({ input, output });

rl.question('What do you think of Node.js? ', (answer) \=\> {
  // TODO: Log the answer in a database
  console.log(\`Thank you for your valuable feedback: ${answer}\`);

  rl.close();
});
