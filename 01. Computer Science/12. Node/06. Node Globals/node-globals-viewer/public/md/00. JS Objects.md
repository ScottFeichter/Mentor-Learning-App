# JS Objects

Recall that an object in JS is:
- a container for multiple properties
- properties are key:value pairs
- a property whose value is a function is called a method

```js

let myObject = {
    "someKey": "someValue",
    "anotherKey": "anotherValue",
    "thisKeyHasAFunctionForItsValue": function() {
        return "we refer to functions as methods when they are properties of an object"
    }
}
```

## Dot vs Bracket Notation

We can interact programatically with objects using syntactic notation in two styles:

```js
myObject.someProperty = "adding a new property";

myObject["someOtherProperty"] = "adding yet another property";
```

## Built In JS Methods That Help Interact With Objects

We can also interact with objects using methods that are built in to the language such as:

- **Object.keys(obj)**
- **Object.values(obj)**
- **Object.entries(obj)**

## POJO vs COJO

Objects in JS come in two flavors:

**POJO**
- Plain Old JavaScript Object
- Declared as you would a variable

**COJO**
- Class Object (JavaScript Object)
- Instantiated from a Class constructor
