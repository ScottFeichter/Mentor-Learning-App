# globalThis

&nbsp;

As stated, the outer most object in both the browser and Node is <span class="purple-bold">globalThis</span>.

However, <span class="purple-bold">globalThis</span> in the browser is not identical to <span class="purple-bold">globalThis</span> in Node.

## Similarities in Browser and Node

We will explore differences of <span class="purple-bold">globalThis</span> later in this chapter.

First let's see what browser and Node <span class="purple-bold">globalThis</span> have in common.

### Browser and Node Built-Ins

Here is a list of <span class="purple-bold">globalThis</span> built-ins identical in both the browser and node:

1. <u>Core ECMAScript Built-ins (The Language Itself)</u>
   - **Object & Array Classes:** Object, Array, Function, RegExp, Date
   - **Primitive Wrappers:** String, Number, Boolean, Symbol, BigInt
   - **Collections:** Map, Set, WeakMap, WeakSet
   - **Asynchronous Tools:** Promise, AsyncFunction, Generator
   - **Math & Data Namespaces:** Math, JSON, Reflect, Proxy
   - **Error Constructors:** Error, TypeError, SyntaxError, ReferenceError
   - **Global Functions:** parseInt(), parseFloat(), isNaN(), isFinite()

&nbsp;

2. <u>The Shared Web APIs (Modern Standardizations)</u>
   - **Networking:** fetch(), Request, Response, Headers, WebSocket
   - **Timers:** setTimeout(), setInterval(), clearTimeout(), clearInterval()
   - **Performance & Control:** performance, AbortController, AbortSignal, queueMicrotask()
   - **Data Handling:** TextEncoder, TextDecoder, atob(), btoa()
