## APIE

**APIE** is an acronym to represent the four pillars of Object Oriented Programming (OOP).

#### Abstraction

Hiding complex details ie you use a method without needing to know how it works internally.

#### Inheritance

A class can inherit properties and methods from another class.

#### Polymorphism

The same method name can behave differently depending on which object is calling it.

#### Encapsulation

Bundling data and the methods inside an object and controlling what the outside world can access.
