# POJO vs CIJO

&nbsp;

**Objects** in JS come in two flavors:

## POJO
- Plain Old JavaScript Object
- Declared as you would a variable

```js
let myPojo = {
    "name": "Scott",
    "age": 30
}

console.log(myPojo) // {name: 'Scott', age: 30}
```


## CIJO
- Class Instantiated JavaScript Object
- Instantiated from a Class constructor

```js
class Cijo {
  constructor(name, age) {
    this.name = name
    this.age = age
  }
}

let myCijo = new Cijo('Scott', 30)

console.log(myCijo) // Cijo { name: 'Scott', age: 30 }
```
