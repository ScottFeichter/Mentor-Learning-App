# Base64URL Encoding

## What is Base64URL?

Base64URL is a **URL-safe variant** of Base64 encoding that converts binary data or text into a string using only characters that are safe to use in URLs and filenames.

## Why Base64URL Exists

### The Problem with Regular Base64

Regular Base64 uses characters that cause issues in URLs:
- `+` (plus sign) - interpreted as space in URLs
- `/` (forward slash) - path separator in URLs
- `=` (equals sign) - query parameter separator in URLs

```
Regular Base64:  abc+def/ghi==
URL interpretation: abc def/ghi (broken!)
```

### The Solution: Base64URL

Base64URL replaces problematic characters:
- `+` → `-` (hyphen)
- `/` → `_` (underscore)
- `=` → removed (padding optional)

```
Base64URL:  abc-def_ghi
URL safe: ✅ Works perfectly in URLs
```

---

## How Base64URL Encoding Works

### Step 1: Convert to Binary

```
Text: "Hi"
ASCII: H=72, i=105
Binary: 01001000 01101001
```

### Step 2: Group into 6-bit Chunks

```
Binary: 010010 000110 1001
Decimal: 18     6      41
```

### Step 3: Map to Base64URL Characters

Base64URL uses 64 characters:
```
A-Z (0-25), a-z (26-51), 0-9 (52-61), - (62), _ (63)
```

```
18 → S
6  → G
41 → p
```

### Step 4: Handle Padding (Optional)

If bits don't divide evenly by 6, pad with zeros and add `=` (but Base64URL often omits `=`).

## Code Examples

### Node.js

```javascript
// Encode to Base64URL
const text = 'Hello World!';
const base64url = Buffer.from(text).toString('base64url');
console.log(base64url);
// Output: SGVsbG8gV29ybGQh

// Decode from Base64URL
const decoded = Buffer.from(base64url, 'base64url').toString('utf8');
console.log(decoded);
// Output: Hello World!
```

### Manual Conversion (Base64 to Base64URL)

```javascript
// Base64 to Base64URL
function base64ToBase64URL(base64) {
  return base64
    .replace(/\+/g, '-')
    .replace(/\//g, '_')
    .replace(/=/g, '');
}

// Base64URL to Base64
function base64URLToBase64(base64url) {
  let base64 = base64url
    .replace(/-/g, '+')
    .replace(/_/g, '/');
  
  // Add padding if needed
  while (base64.length % 4 !== 0) {
    base64 += '=';
  }
  
  return base64;
}

// Usage
const base64 = 'SGVsbG8gV29ybGQh';
const base64url = base64ToBase64URL(base64);
console.log('Base64URL:', base64url);

const backToBase64 = base64URLToBase64(base64url);
console.log('Base64:', backToBase64);
```

## Why Use Base64URL?

### 1. URL Safety
```javascript
// JWT in URL parameter
const jwt = 'eyJhbGci.eyJ1c2Vy.SflKxw';  // Base64URL encoded
const url = `https://example.com/verify?token=${jwt}`;
// Works perfectly! No encoding needed
```

### 2. Filename Safety
```javascript
// Save token as filename
const filename = `token_${base64url}.txt`;
// No issues with / or + in filenames
```

### 3. No Escaping Required
```javascript
// Regular Base64 (needs escaping)
const base64 = 'abc+def/ghi==';
const url = `https://example.com?token=${encodeURIComponent(base64)}`;
// Result: https://example.com?token=abc%2Bdef%2Fghi%3D%3D

// Base64URL (no escaping needed)
const base64url = 'abc-def_ghi';
const url = `https://example.com?token=${base64url}`;
// Result: https://example.com?token=abc-def_ghi
```

## Real-World Usage

### JWT (JSON Web Tokens)
```javascript
const crypto = require('crypto');

// JWT uses Base64URL for all three parts
const header = { alg: 'HS256', typ: 'JWT' };
const payload = { userId: 123 };

const headerBase64URL = Buffer.from(JSON.stringify(header)).toString('base64url');
const payloadBase64URL = Buffer.from(JSON.stringify(payload)).toString('base64url');

console.log('Header:', headerBase64URL);
// Output: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9

console.log('Payload:', payloadBase64URL);
// Output: eyJ1c2VySWQiOjEyM30

// Can be safely used in URLs
const url = `https://api.example.com/verify?token=${headerBase64URL}.${payloadBase64URL}`;
```

### OAuth 2.0 / PKCE
```javascript
// Code verifier (Base64URL encoded random string)
const verifier = crypto.randomBytes(32).toString('base64url');
console.log('Code Verifier:', verifier);
// Safe to send in URL parameters
```

| Hex | `0-9 a-f` | ✅ Yes | Hashes, IDs |

## Common Pitfalls

### ❌ Using Regular Base64 in URLs
```javascript
const token = Buffer.from('data').toString('base64');
const url = `https://example.com?token=${token}`;
// May break if token contains +, /, or =
```

### ✅ Using Base64URL in URLs
```javascript
const token = Buffer.from('data').toString('base64url');
const url = `https://example.com?token=${token}`;
// Always safe!
```

### ❌ Forgetting to Add Padding When Decoding
```javascript
// Base64URL without padding
const base64url = 'SGVsbG8';

// Wrong - may fail
Buffer.from(base64url, 'base64');

// Right - use 'base64url' encoding
Buffer.from(base64url, 'base64url');
```

## Summary

**Base64URL** is a URL-safe encoding that:
- Replaces `+` with `-`
- Replaces `/` with `_`
- Removes `=` padding

**Use it when:**
- Encoding data for URLs (query parameters, paths)
- Creating JWTs
- Generating URL-safe tokens
- Storing data in filenames

**Don't use it when:**
- Regular Base64 is sufficient (email attachments, file storage)
- You need standard Base64 compatibility


## Is Base64 Encryption?

**No, Base64 encoding is NOT encryption.** It's just encoding - a way to represent data.

### Key Differences

**Encoding (Base64)**
- **Purpose**: Change data format for compatibility
- **Reversible**: Anyone can decode it
- **No key needed**: Decoding is automatic
- **Security**: ❌ None - provides zero protection

**Encryption**
- **Purpose**: Hide data from unauthorized access
- **Reversible**: Only with the correct key
- **Key required**: Secret key needed to decrypt
- **Security**: ✅ Protects data

### Visual Comparison

```javascript
// BASE64 ENCODING - NOT SECURE
const text = 'secret password';
const encoded = Buffer.from(text).toString('base64');
console.log(encoded);
// Output: c2VjcmV0IHBhc3N3b3Jk

// Anyone can decode it instantly:
const decoded = Buffer.from(encoded, 'base64').toString();
console.log(decoded);
// Output: secret password
// ❌ NO PROTECTION!

// ENCRYPTION - SECURE
const crypto = require('crypto');
const key = crypto.randomBytes(32);
const iv = crypto.randomBytes(16);
const cipher = crypto.createCipheriv('aes-256-cbc', key, iv);
let encrypted = cipher.update(text, 'utf8', 'hex');
encrypted += cipher.final('hex');
console.log(encrypted);
// Output: 8f3a9b2c... (unreadable without key)
// ✅ PROTECTED - needs key to decrypt
```

### Why Base64 Looks "Encrypted"

Base64 output looks scrambled, but it's just a different representation:

```
Original: "Hello"
Base64:   "SGVsbG8="
```

This is like writing "Hello" in a different alphabet - anyone who knows the alphabet can read it. There's no secret key.

### Common Misconception

```javascript
// ❌ WRONG - This is NOT secure
const password = 'myPassword123';
const "encrypted" = Buffer.from(password).toString('base64');
// Anyone can decode this!

// ✅ RIGHT - This IS secure
const bcrypt = require('bcrypt');
const hashed = await bcrypt.hash(password, 10);
// Cannot be reversed without brute force
```

### Bottom Line

- **Base64 = Encoding** → Changes format (like translating languages)
- **Encryption** → Hides data (like a locked safe)

Base64 is used for **compatibility** (URLs, emails), not **security**. Never use Base64 to protect sensitive data!
