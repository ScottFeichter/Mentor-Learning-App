# Paper.js

**npm:** `paper`

Vector graphics scripting framework. Provides a scene graph, path operations (boolean union/intersection/subtraction), bezier curves, and hit testing. Runs on HTML5 Canvas.

**Use cases:**
- Complex path/shape manipulation
- Boolean operations on vector shapes
- Generative art and procedural graphics
- Interactive vector drawing tools

**Install:**
```bash
npm install paper
```
