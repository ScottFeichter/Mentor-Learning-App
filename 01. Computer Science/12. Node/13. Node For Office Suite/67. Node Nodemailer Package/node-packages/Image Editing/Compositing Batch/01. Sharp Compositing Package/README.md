# Sharp (Compositing & Batch)

**npm:** `sharp`

Sharp's compositing capabilities for layering multiple images, adding text overlays via SVG, and batch processing pipelines. Extremely fast due to libvips streaming architecture.

**Use cases:**
- Layering images (watermarks, badges, overlays)
- Batch resizing/converting hundreds of images
- Template-based image generation (social cards, thumbnails)
- Pipeline processing (resize → crop → overlay → format convert)

**Note:** Same package as Sharp (General Purpose) — this documents its compositing and batch capabilities specifically.
