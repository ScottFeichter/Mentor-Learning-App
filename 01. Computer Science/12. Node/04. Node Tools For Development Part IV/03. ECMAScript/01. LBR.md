# ECMAScript

&nbsp;

ECMAScript is JavaScript.

It refers to a standardized edition of the language.

You don't need to download anything for it.

## What Is ECMA?

ECMA is an international non-profit standards organization headquartered in Switzerland.

Formerly known as European Computer Manufacturers Association.

They create a standardization of rules and syntax for JS.

People who want to use JS can follow or not follow this standard, but there are benefits to following it.

## The Committee

The standardization work is done by a Technical Committee.

If you see TC39, it is the 39th Technical Committee of ECMA.

Members consist of delegates from tech companies, academics, and implementers.

JS is not the only language that the ECMA TC creates standards for, but ECMAScript only refers to JS.

## Language Editions

ES6 is the same thing as ES2015.

The TC manages a multi-stage process to introduce new features and changes.

The goal is to ensure JS remains modern and versatile.
