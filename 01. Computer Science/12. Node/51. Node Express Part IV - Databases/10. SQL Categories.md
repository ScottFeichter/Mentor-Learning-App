## How SQL Works (The Flow)

1. You write a SQL query (a statement describing what you want)
2. The database receives the query
3. The database parses and optimizes the query (figures out the fastest way to get the data)
4. The database executes the query
5. The database returns the results

## SQL Categories

| Category | Purpose | Commands |
|---|---|---|
| **DDL** (Data Definition) | Define structure | CREATE, ALTER, DROP |
| **DML** (Data Manipulation) | Work with data | SELECT, INSERT, UPDATE, DELETE |
| **DCL** (Data Control) | Manage permissions | GRANT, REVOKE |
