# Models

A **model** is a representation of real-world entities or concepts in software. Models define the structure, behavior, and relationships of data within an application.

## Purpose

- **Data Representation**: Define how information is structured and stored
- **Business Logic**: Encapsulate rules and operations related to the data
- **Abstraction**: Simplify complex real-world concepts into manageable code
- **Consistency**: Provide a single source of truth for data structure

## Types of Models

- **Data Models**: Represent database entities (User, Product, Order)
- **Domain Models**: Capture business concepts and rules
- **View Models**: Format data for user interfaces
- **API Models**: Define request/response structures

## Common Patterns

- **ORM Models**: Map database tables to objects
- **MVC Models**: Handle data logic in Model-View-Controller architecture
- **Entity Models**: Represent core business objects

## Example

```javascript
// Mongoose model (MongoDB)
const userSchema = new mongoose.Schema({
  name: { type: String, required: true },
  email: { type: String, required: true, unique: true },
  age: { type: Number, min: 0 }
});

userSchema.methods.isAdult = function() {
  return this.age >= 18;
};

userSchema.methods.getDisplayName = function() {
  return `${this.name} (${this.email})`;
};

const User = mongoose.model('User', userSchema);
```

```javascript
// Sequelize model (PostgreSQL/MySQL)
const User = sequelize.define('User', {
  name: { type: DataTypes.STRING, allowNull: false },
  email: { type: DataTypes.STRING, allowNull: false, unique: true },
  age: { type: DataTypes.INTEGER }
}, {
  instanceMethods: {
    isAdult() {
      return this.age >= 18;
    }
  }
});
```

Models bridge the gap between raw data and meaningful application functionality.
