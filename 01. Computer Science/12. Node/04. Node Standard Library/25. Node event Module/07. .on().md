# .on()

.on() is a method from the EventEmitter class.

.on() is the Node equivalent to the browser event object method .addEventListener().


## Calling .on()

Every instantiated event emitter can call .on().

In fact, the same emitter can call .on() mutliple times to listen for different events simultaneously.

## Syntax of .on()

function handlerCallback(someArg) {
    return "some logic " + someArg;
}

emitter.on(eventName, handlerCallback)
