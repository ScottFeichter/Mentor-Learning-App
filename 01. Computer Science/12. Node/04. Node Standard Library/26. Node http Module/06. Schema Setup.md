# Schema Setup in Express and Sequelize

## Overview

Changing from Pattern 1 to Pattern 4 requires small changes to:
- Config files
- Migration files
- Seeder files

Sequelize automatically applies the schema name when executing SQL commands in production.

## Step 1: Create a Setup Script

Add `SCHEMA` to `.env`:
```
SCHEMA=<schema_name>
```

Create `backend/psql-setup-script.js`:
```javascript
const { sequelize } = require('./db/models');

sequelize.showAllSchemas({ logging: false }).then(async (data) => {
  if (!data.includes(process.env.SCHEMA)) {
    await sequelize.createSchema(process.env.SCHEMA);
  }
});
```

Add build command to `package.json`:
```json
"build": "node psql-setup-script.js"
```

## Step 2: Define Schema in Config

In `config/database.js`:
```javascript
production: {
  // ...
  define: {
    schema: process.env.SCHEMA
  }
}
```

Only applies in production — schema name auto-prefixed to every request.

## Step 3: Define Schema in Migration Files

### Create Table Migrations

```javascript
let options = {};
if (process.env.NODE_ENV === 'production') {
  options.schema = process.env.SCHEMA;
}

module.exports = {
  up: (queryInterface, Sequelize) => {
    return queryInterface.createTable('table-name', {
      // ...
    }, options);
  },
  down: async (queryInterface, Sequelize) => {
    return queryInterface.dropTable('table-name', options);
  }
};
```

### Alter Table Migrations

```javascript
let options = {};
options.tableName = '<TableName>';

if (process.env.NODE_ENV === 'production') {
  options.schema = process.env.SCHEMA;
}

module.exports = {
  async up(queryInterface, Sequelize) {
    await queryInterface.addColumn(options, 'firstName', {
      type: Sequelize.STRING(30),
      allowNull: false,
    });
  },
  async down(queryInterface, Sequelize) {
    await queryInterface.removeColumn(options, 'firstName');
  }
};
```

## Step 4: Define Schema in Seeder Files

```javascript
let options = {};
if (process.env.NODE_ENV === 'production') {
  options.schema = process.env.SCHEMA;
}

module.exports = {
  up: (queryInterface, Sequelize) => {
    options.tableName = '<TableName>';
    return queryInterface.bulkInsert(options, [
      // ...
    ]);
  },
  down: (queryInterface, Sequelize) => {
    options.tableName = '<TableName>';
    return queryInterface.bulkDelete(options);
  }
};
```

> Note: If using `Model.bulkCreate` for dynamic seeding, no schema changes needed — the model already has the schema defined.
