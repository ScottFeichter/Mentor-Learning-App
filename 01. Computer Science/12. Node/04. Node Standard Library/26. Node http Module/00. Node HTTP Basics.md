# Node HTTP Basics

## What is Node http?

`http` is a built-in package in Node.js.

## Getting Started

1. Import the http package
2. Call `createServer` and pass a function with `req` and `res` parameters

```javascript
const http = require('http');

const server = http.createServer((req, res) => {
  // ...
});
```

3. Define a port number (0–65,535). Common dev ports: 3000, 5000, 8000
4. Use the `listen` method:

```javascript
const port = 5000;

server.listen(port, () => console.log('Server is listening on port', port));
```

5. Start server: `node server.js`

## Request Object

When a server gets a request, `http` creates a Request object with:
- **method** — string of HTTP method
- **url** — string of the URL path
- **headers** — object of headerName: value
- **on** — used to parse the body of the request

## Response Object

To formulate a response, `http` creates a Response object with:
- **statusCode** — number status code
- **setHeader** — method that sets a header name to a value
- **write** — adds to the body of the response
- **end** — adds to the body and sends the response
