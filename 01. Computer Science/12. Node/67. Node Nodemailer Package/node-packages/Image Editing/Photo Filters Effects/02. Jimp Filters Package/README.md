# Jimp (Filters & Effects)

**npm:** `jimp`

Jimp's built-in filter and effect operations. Includes Gaussian blur, pixelate, posterize, sepia, dither, contrast, brightness, hue rotation, and color channel manipulation.

**Use cases:**
- Applying Instagram-style filters
- Pixelation for privacy/censoring
- Color manipulation (sepia, posterize)
- Brightness/contrast adjustments

**Note:** Same package as Jimp (General Purpose) — this documents its filter/effect capabilities specifically.
