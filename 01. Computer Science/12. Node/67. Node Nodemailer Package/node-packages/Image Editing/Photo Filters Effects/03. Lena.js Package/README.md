# Lena.js

**npm:** `lena.js`

Collection of image processing filters implemented in pure JavaScript. Includes edge detection (Sobel, Prewitt), convolution kernels, emboss, Laplacian, and custom kernel support.

**Use cases:**
- Edge detection and feature extraction
- Custom convolution filters
- Educational/experimental image processing
- Lightweight filter application without heavy dependencies

**Install:**
```bash
npm install lena.js
```
