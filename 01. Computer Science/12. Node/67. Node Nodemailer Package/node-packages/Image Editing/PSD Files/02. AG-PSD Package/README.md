# AG-PSD

**npm:** `ag-psd`

Read and write Adobe Photoshop .psd files. Full layer support including groups, masks, blend modes, effects, and smart objects. Can both parse existing PSDs and create new ones.

**Use cases:**
- Reading and writing .psd files with full layer fidelity
- Programmatically modifying PSD layers
- Creating PSD files from scratch
- Extracting layer compositions

**Install:**
```bash
npm install ag-psd
```
