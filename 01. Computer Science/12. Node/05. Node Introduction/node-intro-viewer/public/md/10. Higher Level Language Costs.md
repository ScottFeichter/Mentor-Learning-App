# Higher Level Language Costs

&nbsp;

Higher level languages trade execution speed for developer productivity.

- The higher the level, the more the language handles for you.

- But the less control you have over performance.

---

&nbsp;

## The General Tradeoffs

- Higher level = less developer effort + less control + slower execution
- Lower level = more developer effort + more control + faster execution
- AI/LLMs sit at the top of this spectrum — maximum abstraction, minimum syntax, highest compute cost

&nbsp;

---

&nbsp;

### Shell (Bash, Zsh, etc.)

Shell sits in a category of its own.

It is not a general purpose programming language like the others on this list.

But it also belongs here because writing a shell script is far simpler than writing C or Assembly.

- Very low developer cost for simple tasks — easy to write quick scripts
- Not designed for complex logic — gets messy fast
- No data types, no classes, limited abstractions
- Best used for automation, scripting, and orchestrating other programs

---

&nbsp;

### Python

- Slower execution due to being interpreted and dynamically typed
- Very low developer cost — simple, readable syntax
- Garbage collected memory management
- Huge ecosystem, widely used in data science, scripting, and AI

&nbsp;

---

&nbsp;

### Ruby

- Similar speed to Python
- Very low developer cost — designed to be expressive and readable
- Garbage collected
- Popular for web development via Ruby on Rails

&nbsp;

---

&nbsp;

### JavaScript / Node.js

- Slower than compiled languages but fast for an interpreted language (V8 engine helps)
- Low to medium developer cost — flexible but has quirks
- Garbage collected
- The only language that runs natively in the browser, also used on the server via Node.js

&nbsp;

---

&nbsp;

### TypeScript

- Same runtime performance as JavaScript — compiles down to JS
- Slightly higher developer cost than JS due to type annotations
- Catches errors at compile time, reducing bugs in large codebases

&nbsp;

---

&nbsp;

### PHP

- Slower execution, interpreted
- Low developer cost — easy to learn
- Garbage collected
- Widely used for server-side web development

&nbsp;

---

&nbsp;

### AI / LLMs (Highest Level)

AI and Large Language Models (LLMs) represent the highest level of abstraction.

**Examples:**

- ChatGPT
- Claude
- Gemini

Instead of writing code syntax, you describe what you want in plain human language.

- No syntax to learn — you communicate in natural language
- The lowest possible developer cost for producing output
- You have the least control over exactly how the task is performed
- Output must be reviewed — the "language" is probabilistic, not deterministic
- Extremely high computational cost to run compared to any traditional language
- Built on top of lower level languages (Python, C++, CUDA) under the hood
