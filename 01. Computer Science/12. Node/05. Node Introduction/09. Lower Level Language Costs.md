# Lower Level Language Costs

&nbsp;

There are a few different "costs" to consider when working with languages —

- execution speed
- memory management
- developer effort

---

&nbsp;

## The General Tradeoffs

- Lower level = faster execution + more developer responsibility
- Higher level = slower execution + less developer responsibility
- Rust is unique in that it achieves low-level speed without the memory management burden of C/C++

&nbsp;

---

&nbsp;

### Assembly

- Fastest execution, closest to hardware
- Extremely high developer cost — very hard to write and maintain
- No memory management help, you handle everything manually

&nbsp;

---

&nbsp;

### C

- Very fast execution
- Manual memory management — you allocate and free memory yourself
- Risk of memory leaks and crashes if done wrong
- High developer cost but much more readable than Assembly

&nbsp;

---

&nbsp;

### C++

- Slightly more overhead than C due to added features (OOP, templates)
- Still manual memory management (though smart pointers help)
- High developer cost — complex language with many ways to do things

&nbsp;

---

&nbsp;

### Rust

- Similar speed to C/C++
- No manual memory management and no garbage collector — uses an ownership model
- High learning curve (the borrow checker is strict) but very safe
- Lower risk of memory bugs than C/C++

&nbsp;

---

&nbsp;

### Go

- Slightly slower than C/Rust due to a garbage collector
- Much lower developer cost — simple syntax, easy to learn
- Good balance between performance and productivity

&nbsp;

---

&nbsp;

### Shell (Bash, Zsh, etc.)

Shell sits in a category of its own.

It is not a general purpose programming language like the others on this list.

But it belongs here because it operates close to the OS and directly controls system resources.

- Directly interacts with the operating system, files, and processes
- No memory management — the OS handles everything
- Low execution overhead for system tasks
- High developer cost for complex logic — not designed for it
- Best used for automation, scripting, and orchestrating other programs
