# Isomorphic JavaScript

&nbsp;

Isomorphic in a general sense means two things that have the same structure or form.

## Universal JavaScript (Isomorphic)

In Computer Science isomorphic means code that has the same structure and behavior regardless of envirnoment:

**Works Everywhere**:
- Core JavaScript (variables, functions, classes)
- Promises and async/await
- Array/Object methods
- JSON operations
- Math operations

**Requires Abstraction**:
- HTTP requests (use fetch or axios)
- Storage (localStorage vs file system)
- Environment variables (process.env vs config)
