# Servers and APIs

## What is a Server?

A server is hardware or software that pushes and pulls data across a network. Its purpose is to send data to a client by request.

## Traditional Server vs Web API Server

**Traditional Server:**
- One request for a resource, one response
- Request is either successful or failing, response sends outcome

**Web API Server:**
- Similar to a library — functionality is whatever the API author has decided is useful
- Some operations (CRUD) are nearly 1-to-1 overlaps with HTTP verbs
- Others do much more powerful things
- Only needs to return and manipulate data (no HTML needed)
- No need for `GET` endpoints for viewing HTML form pages
- Not limited to `GET` and `POST` (unlike traditional HTML forms)

## What is an API?

**Application Programming Interface** — interfaces that abstract away the inner workings of complex packages of code so a developer can worry only about input and output.

Example: When you call `Math.sin()`, you don't need to worry about the inner workings, just the input and output.

## Application API vs Web API

- `Math.sin()` is an **application API**
- A **web API** works on the same principle but over the internet
  - Most commonly used to store, share, and update data
  - Programmer uses documentation to learn how to access

## Summary

A web API is an API accessed over the internet instead of by importing a library. Web APIs provide access to data and functionality without requiring the developer to know the implementation details.
