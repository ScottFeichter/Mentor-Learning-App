# Chrome Shortcuts

&nbsp;

Utilize these keyboard shortcuts to enhance your experience using **Chrome**

## Browsing Keyboard Shortcuts

&nbsp;

<div class="center">

| Action | Mac | Win/Linux |
|---|---|---|
| New tab | `Cmd+T` | `Ctrl+T` |
| Close tab | `Cmd+W` | `Ctrl+W` |
| Reopen closed tab | `Cmd+Shift+T` | `Ctrl+Shift+T` |
| Reload | `Cmd+R` | `Ctrl+R` |
| Hard reload | `Cmd+Shift+R` | `Ctrl+Shift+R` |
| Bookmark page | `Cmd+D` | `Ctrl+D` |
| Find on page | `Cmd+F` | `Ctrl+F` |
| Zoom in | `Cmd++` | `Ctrl++` |
| Zoom out | `Cmd+-` | `Ctrl+-` |
| Reset zoom | `Cmd+0` | `Ctrl+0` |
| Full screen | `Cmd+Ctrl+F` | `F11` |


</div>



## DevTools Keyboard Shortcuts

<div class="center">

| Action | Mac | Win/Linux |
|---|---|---|
| Open DevTools | `Cmd+Option+I` | `Ctrl+Shift+I` |
| Open Console panel | `Cmd+Option+J` | `Ctrl+Shift+J` |
| Open Elements panel | `Cmd+Shift+C` | `Ctrl+Shift+C` |
| Toggle DevTools | `Cmd+Option+I` | `Ctrl+Shift+I` |
| Run command | `Cmd+Shift+P` | `Ctrl+Shift+P` |
| Search across files | `Cmd+Option+F` | `Ctrl+Shift+F` |
| Clear console | `Ctrl+L` | `Ctrl+L` |

</div>
