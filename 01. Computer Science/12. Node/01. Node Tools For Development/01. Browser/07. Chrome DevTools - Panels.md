# Chrome DevTools - Panels

&nbsp;

**Chrome** DevTools has several panels that provide differing functionality.

## The Panels

<div class="indent">

### Console

The Console is the most frequently used panel.

It serves as an output window for logs and errors.

It is also an interactive JavaScript environment.

You can run JavaScript directly in the console.

### Elements

Inspect and live-edit the HTML and CSS of any page.

Changes are reflected instantly in the browser but are not saved to source files.

### Sources

View and debug the source files of a page.

Set breakpoints, step through code, and inspect variables at runtime.

### Network

Monitor all network requests made by the page.

Includes fetch calls, images, scripts, and stylesheets.

Will track their status codes, timing, and payloads.

### Performance

Record and analyze runtime performance.

Identify bottlenecks, long tasks, and rendering issues.

### Memory

Profile memory usage to understand how objects are being allocated and retained.

### Application

Inspect storage as well as service workers and manifest files.

Storage includes cookies, localStorage, sessionStorage, IndexedDB, and cache.

### Security

View the security status of the page, including certificate details and mixed content warnings.

### Lighthouse

Run automated audits on a page for performance, accessibility, SEO, and best practices.

Generate a scored report with recommendations.

</div>
