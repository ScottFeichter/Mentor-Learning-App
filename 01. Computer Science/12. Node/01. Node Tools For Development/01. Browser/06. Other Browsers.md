# Other Browsers

&nbsp;

While **Chrome** is the most widely used browser for development there are other browsers.

## Why Other Browsers Matter

<div class="indent">

### Cross-Browser Testing

A web page may look and behave differently across browsers due to differences in rendering engines and CSS support.

Testing in multiple browsers is an important part of development.

### Market Share Awareness

Different users use different browsers.

Understanding the landscape helps you make informed decisions about what to support.

### Each Has Its Own DevTools

Every major browser ships with its own developer tools, all of which are worth knowing.

</div>

## Other Browsers

<div class="indent">

### Firefox

<div class="indent">

#### Overview

Developed by Mozilla, Firefox is open source and privacy-focused.

It is a strong choice for development due to its excellent DevTools.

#### Engine

Firefox uses the **Gecko** rendering engine and the **SpiderMonkey** JavaScript engine.

#### Why Use It

Firefox DevTools has strong CSS tooling and can be more visual and intuitive than others.

It includes a grid inspector and flexbox inspector to help manage page element positions.

#### DevTools Shortcut

`Cmd+Option+I` (Mac) or `Ctrl+Shift+I` (Win/Linux)
</div>


### Safari

<div class="indent">

#### Overview

Developed by Apple, Safari is the default browser on Mac and iOS devices.

It is important to test in Safari because its behavior can differ, particularly on mobile.

#### Engine

Safari uses the **WebKit** rendering engine and the **JavaScriptCore** engine.

#### Why Use It

Safari is the only browser available on iOS.

Any web app targeting iPhone or iPad users must be tested in Safari.

It also tends to be more energy efficient on Mac hardware.

#### DevTools Shortcut

##### Enable DevTools
Safari > Settings > Advanced > Show features for web developers

##### Shortcut
`Cmd+Option+I`.

</div>


### Edge

<div class="indent">

#### Overview

Developed by Microsoft, Edge is the default browser on Windows. Since 2020 it has been rebuilt on the same Chromium engine as **Chrome**, making it very similar to **Chrome** from a development perspective.

#### Engine

Edge uses the **Blink** rendering engine and the **V8** JavaScript engine — the same as **Chrome**.

#### Why Use It

Edge is the default on Windows and has a significant share of corporate and enterprise users. It also includes some unique features like built-in PDF tools and vertical tabs.

#### DevTools Shortcut

`Cmd+Option+I` (Mac) or `Ctrl+Shift+I` (Win/Linux)
</div>


### Opera

<div class="indent">

#### Overview

Opera is a Chromium-based browser with a focus on speed and built-in features like a VPN, ad blocker, and sidebar tools.

#### Engine

Opera uses the **Blink** rendering engine and the **V8** JavaScript engine — the same as **Chrome**.

#### Why Use It

Opera is less commonly used for development but is worth knowing as it shares **Chrome**'s engine, meaning pages that work in **Chrome** will generally work in Opera.
</div>


### Brave

<div class="indent">

#### Overview

Brave is a Chromium-based browser with a strong focus on privacy, blocking ads and trackers by default.

#### Engine

Brave uses the **Blink** rendering engine and the **V8** JavaScript engine — the same as **Chrome**.

#### Why Use It

Brave is growing in popularity among privacy-conscious users and developers. Because it is Chromium-based, **Chrome** extensions work in Brave and its DevTools are nearly identical to **Chrome**'s.
</div>

</div>

## Browser Engine Summary

&nbsp;

<div class="center">

| Browser | Engine | JS Engine | Based On |
|---|---|---|---|
| Chrome | Blink | V8 | Chromium |

| Safari | WebKit | JavaScriptCore | Independent |
| Edge | Blink | V8 | Chromium |
| Opera | Blink | V8 | Chromium |
| Brave | Blink | V8 | Chromium |
