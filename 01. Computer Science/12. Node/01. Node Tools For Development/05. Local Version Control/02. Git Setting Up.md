# Setting Up Git And GitHub

&nbsp;

After installing Git and signing up for a GitHub account, you need to configure Git and connect it to GitHub.

---

&nbsp;


## Git does not have a GUI

To use it we must issue commands in a terminal.

We must use the base command **```git```** followed by a space.

```bash
git -version
```

This tells computer the command is for Git rather than for Shell.

---

&nbsp;

## Initial Git Configuration

Set your identity — this is used in every commit:

```bash
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
```

&nbsp;

---

&nbsp;

## Connect Git to GitHub via SSH

**1. Generate an SSH key:**

```bash
ssh-keygen -t ed25519 -C "your@email.com"
```

Press Enter to accept the defaults.

&nbsp;

**2. Copy your public key:**

```bash
cat ~/.ssh/id_ed25519.pub
```

&nbsp;

**3. Add it to GitHub:**

- Go to GitHub → Settings → SSH and GPG Keys → New SSH Key
- Paste the key and save

&nbsp;

**4. Test the connection:**

```bash
ssh -T git@github.com
```

You should see: `Hi username! You've successfully authenticated...`

&nbsp;

---

&nbsp;

## Optional but Recommended

Set your default branch name to match GitHub's default:

```bash
git config --global init.defaultBranch main
```

Set VSCode as your default Git editor:

```bash
git config --global core.editor "code --wait"
```

&nbsp;

---

&nbsp;

## Verify Your Config

```bash
git config --list
```

After this setup, you can clone, push, and pull from GitHub without entering a password each time.
