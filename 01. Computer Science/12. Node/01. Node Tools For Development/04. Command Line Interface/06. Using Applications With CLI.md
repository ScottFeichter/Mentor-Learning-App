# Using Applications With CLI

&nbsp;

When you type a command in a terminal to use another app you are using both the shell and the app.

The shell receives and dispatches the command but the actual work is done by the target program.

---

## Roles Of The Shell And The App

The shell receives your command, interprets it, and figures out what to run.

It handles things like the prompt, environment variables, and passing arguments.

### The Flow Looks Like This:

- You open a terminal application window →
- The cursor waits at the command line prompt →
- You type the app specific base command →
- After a space you type the sub command →
- You type (if needed) arguments or flags separated by spaces →
- You press Enter →
- Shell receives command →
- Shell finds & launches application →
- Application does the work

### Anatomy Of A Command:

```bash
git commit -m "my message"
```
- program: ```git```
- utility: ```commit```
- flag: ```-m```
- argument: ```"my message"```

*Notice the program tells the shell this is for the git application.*
