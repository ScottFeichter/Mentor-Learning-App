# CLI vs. GUI

&nbsp;

Using a mouse to point and click on screen is an example of using a **Graphical User Interface (GUI)**.

Using text commands in a terminal window is an example of using a **Command Line Interface (CLI)**.

---

## Vocabulary Clarification

- **Shell** — the program running inside the terminal that interprets your commands
- **Terminal** — the application/window you type in
- **Command Line** — the text interface itself (the prompt where you type)
- **Command** — the text that a shell understands to do a task

### Operating System Tasks

Some operating system tasks can be done with **CLI** or **GUI**.

For example on macOS you can manage files via Finder or via Bash commands in Terminal.app.

However, some **GUI** maneuvers (like drag-and-drop) have no direct **CLI** equivalent.


### Application Tasks

Consumer and creative apps tend to be **GUI**-first because their users expect visual interaction.

Development apps tend to have strong **CLI** support because developers need automation and scripting.

Many apps used in development have no **GUI** at all.
