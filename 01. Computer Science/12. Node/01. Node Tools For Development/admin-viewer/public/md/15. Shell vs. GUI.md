# Shell vs. GUI

&nbsp;

A shell and a graphical user interface (GUI) are both ways to tell your computer what to do.

Using a mouse to point and click items on the screen is an example of using a GUI.

## Common Shells

- **Bash** — default on most Linux distros, available everywhere
- **Zsh** — default on macOS, superset of Bash with extra features
- **Command Prompt (cmd)** — legacy default shell for Windows with its own syntax
- **PowerShell** — newer Windows shell with enhanced logic capabilities
- **WSL** — runs a real Linux shell inside Windows

## Shell vs Terminal vs Command Line

- **Shell** — the program running inside the terminal that interprets your commands
- **Terminal** — the application/window you type in
- **Command Line** — the text interface itself (the prompt where you type)
- **Command** - the text that a shell understand to do a task

### Example Bash Shell Commands

Common commands include `cd`, `ls`, `mkdir`, `rm`, `cp`, and `mv`.

You will use the shell constantly as a developer.
