# Editors Explained

&nbsp;

There are different kinds of editors you can use to write code.

We recommend you use **VSCode**.

---

&nbsp;

## Text Editors

A text editor is a simple program for editing plain text files.

**Examples:** Notepad (Windows), TextEdit (macOS).

They have no special features for coding — no syntax highlighting, no autocomplete.

&nbsp;

---

&nbsp;

## Terminal Editors

A terminal editor runs inside the shell.

**Examples:** Vim, Nano, Emacs.

They are useful for quick edits on a server or when you only have terminal access.

```bash
nano myFile.js
vim myFile.js
```

&nbsp;

---

&nbsp;

## IDEs (Integrated Development Environments)

An IDE is a code editor with built-in tools for development.

**Examples:** VSCode, WebStorm, IntelliJ.

They provide syntax highlighting, autocomplete, debugging, integrations, extensions, and more.

VSCode is the most popular free IDE for JavaScript development:

https://code.visualstudio.com
