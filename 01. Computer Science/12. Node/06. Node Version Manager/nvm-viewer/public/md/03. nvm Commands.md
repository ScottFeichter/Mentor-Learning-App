# nvm Commands

&nbsp;

`nvm` is the base command needed for anything you do with **Node Version Manager**

---

## Commonly Used Commands

&nbsp;

```bash
nvm install <node_version_number>
```
Installs the version of Node specified.

<!-- --- -->

&nbsp;
```bash
nvm install --lts
```
Installs the most current long-term supported version of Node.

<!-- --- -->
&nbsp;
```bash
nvm ls
```
Lists all versions of Node on your machine.

<!-- --- -->
&nbsp;
```bash
nvm alias default <node_version_number>
```
Specifies the default version of Node to use.

<!-- --- -->
&nbsp;
```bash
nvm use <node_version>
```
Tells your machine which version of Node to use during this session.

<!-- --- -->
&nbsp;
```bash
node -v
```
Not an **nvm** command but a Node command - displays Node version currently in use.
