# What is Node?

&nbsp;

Node is an application:

- Photoshop is for editing photos.
- Browsers are for exploring the Internet.
- Node is for running JavaScript.

## Node does not have a GUI

To use it we must issue commands in a terminal.

We must use the base command **```node```** followed by a space.

```bash
node -version
```
This tells computer the command is for Node rather than for Shell.
