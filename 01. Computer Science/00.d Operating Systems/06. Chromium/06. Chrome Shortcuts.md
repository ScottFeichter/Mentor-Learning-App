# Chrome Shortcuts

## Windows and Tabs

- **⌘N** — Open new window
- **⌘`** — Cycle through Chrome windows
- **⌘T** — Open new tab and jump to it
- **⌘⌥→** — Go to next tab
- **⌘⌥←** — Go to previous tab
- **⌘W** — Close active tab/window

## Navigation

- **⌘L** — Select the address/search field
- **Space** — Scroll down
- **⇧Space** — Scroll up

## Developer Tools

- **⌘⌥J** — Open/close Dev Tools (Console)
- **⌘⌥C** — Open Elements panel
- **⌘⌥I** — Open last used panel
- **⌘⇧C** — Toggle Inspect Element mode
- **⌘]** — Focus next panel
- **⌘[** — Focus previous panel

## Other Useful

- **⌘⌥⇧I** — Open document explorer
- **⌃⌥F/E/V/I/O/T/N** — Enter menu items (use arrows to navigate between menus)
- **⌘Z** — Undo
- **⌘Y** or **⇧⌘Z** — Redo
