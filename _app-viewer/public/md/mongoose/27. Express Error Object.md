
## Express Error Object

Express extends JavaScript errors with additional properties for HTTP handling.

### Express Error Properties
- **status** or **statusCode**: HTTP status code
- **message**: Error message
- **stack**: Stack trace

### Express Error Handling
```javascript
// Creating Express errors
const createError = require('http-errors');

// Method 1: Using http-errors package
const error = createError(404, 'Page not found');

// Method 2: Manual error creation
const error = new Error('Unauthorized');
error.status = 401;

// Error middleware
app.use((err, req, res, next) => {
  res.status(err.status || 500);
  res.json({
    message: err.message,
    error: process.env.NODE_ENV === 'production' ? {} : err
  });
});
```

### Common Express Error Patterns
```javascript
// Async error handling
const asyncWrapper = (fn) => {
  return async (req, res, next) => {
    try {
      await fn(req, res, next);
    } catch (error) {
      next(error);
    }
  };
};

// Route with error
app.get('/users/:id', asyncWrapper(async (req, res) => {
  const user = await User.findById(req.params.id);
  if (!user) {
    const error = new Error('User not found');
    error.status = 404;
    throw error;
  }
  res.json(user);
}));
```
