# Node Standard Library vs Globals

## Globals

Available everywhere without importing anything. You just use them.

```js
console.log(process.version);
console.log(__dirname);
setTimeout(() => console.log("hi"), 1000);
```

Examples: `process`, `console`, `Buffer`, `setTimeout`, `setInterval`, `__dirname`, `__filename`, `require`, `module`, `exports`

## Standard Library (Core Modules)

Ship with Node (no `npm install`), but you still have to import them before you can use them.

```js
const fs = require("fs");
fs.readFileSync("file.txt");

const path = require("path");
path.join(__dirname, "data");

const http = require("http");
http.createServer((req, res) => res.end("hi"));
```

Examples: `fs`, `path`, `http`, `https`, `os`, `crypto`, `events`, `stream`, `url`, `util`, `child_process`, `readline`, `zlib`

## The Distinction

- **Globals** → available automatically, no import needed
- **Standard library / core modules** → ship with Node, but you must import them

Built-in modules like `fs`, `path`, `http` are not globals. They are part of Node's standard library.
