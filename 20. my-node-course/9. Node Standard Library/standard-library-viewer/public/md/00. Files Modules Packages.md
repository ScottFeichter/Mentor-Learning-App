# Files, Modules, Packages

## File

A single `.js`, `.mjs`, `.cjs`, or `.json` file on disk. The smallest unit of code.

```
app.js
utils.js
config.json
```

## Module

A file that exports something.

In Node, every file is treated as its own module with its own scope.

A module can be a single file or a directory with an index file.

```js
// greet.js — this file is a module because it exports something
module.exports = function greet(name) {
  return `Hello, ${name}`;
};
```

## Package

A directory with a `package.json` file.

A package contains one or more modules.

It's the unit of distribution — what you publish to npm or install with `npm install`.

```
my-package/
  package.json
  index.js
  utils.js
```
