# The global Object

Node has a global object named "global".

It represents the global scope of the Node environment.

This is the top level scope and provides a shared space.

Everything you do with Node exists in "global".

Within "global" are other globals.

They are not truly global but for practical purposes are called global.

This topic can get very confusing — just think big picture.

```
global {

    process {
        properties...
        methods...
    }

    console {
        properties...
        methods...
    }

    <all the code you create...>

}
```
