# Debugging

A **bug** is a flaw in code that throws an error or makes the program behave unintentionally.

To **debug** means to find and fix problems (bugs) in code.



## Two Scenarios For Bugs

### 1. Bug: Error Is Thrown

- **Error message** is generated by program to help understand the problem.

- **Stack trace** lists function calls that were active when the error occurred.


### 2. Bug: Error Is NOT Thrown

- **Silent failure** when a problem occurs but no error is thrown.




# Debugging Tools

**Logging**
- Logging To A File
- Logging To A Console (*console.log()*)

**Debugger**
- Pause Execution (breakpoints)
- Step Through

## Putting It Together:
- A bug is a problem in code that causes an error to be thrown or a silent fail.
- A silent fail might be showing the wrong data or skipping an instruction step.
- A console.log() displays a message to the console to help understand code execution.
- A debugger is a tool to run code step by step and stop at breakpoints.
- When an error is thrown the program tries to give a helpful error message and stack trace.
- We view a stack trace to help find where and why an error it happened.
- A try catch finally block are ways to handle an error without program crashing.
