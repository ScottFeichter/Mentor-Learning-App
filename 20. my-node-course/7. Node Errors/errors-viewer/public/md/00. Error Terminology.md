# Error Terminology

An **error** is any unexpected condition that prevents a program from running as intended.

**Throw** means the program has hit an error and is announcing it.

**Catch** means the program handles the error to avoid crashing.

**Crash** is when a program stops running entirely and any work in progress is lost.

## Putting It Together:
- The program encounters a problem.
- A thrown error halts execution of the current code.
- The program looks for something to catch the error.
- If nothing catches it, the program crashes.
