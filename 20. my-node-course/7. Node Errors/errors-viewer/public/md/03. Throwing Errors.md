# Throwing Errors

**Throw** — a keyword in JS that halts program execution to signal a problem.

```javascript
function divide(a, b) {
  if (b === 0) {
    throw new Error('Cannot divide by zero');
  }
  return a / b;
}

divide(10, 0); // Throws error, stops execution
```

## You Can Throw Anything

JS lets you throw any value, not just Error objects:

```js
throw "something went wrong";  // string
throw 404;                     // number
throw { message: "oops" };    // plain object
```

However, you should always throw actual Error objects.

This is because they include a **stack trace** which is critical for debugging.

```js
throw new Error("There was an error...");
```
