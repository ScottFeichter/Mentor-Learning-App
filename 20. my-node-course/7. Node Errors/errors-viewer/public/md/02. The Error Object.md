# Error Object

## What Is An Error Object?

The `Error` class is built-in to JavaScript and used to represent runtime errors.

You instantiate an `Error Object` from the `Error` class constructor.

## Instantiating an Error Object

```javascript
const myErrorObject = new Error('Something went wrong');
```
You can instantiate and throw an Error object for when something goes wrong in your code.

Sometimes the program itself creates the Error object and throws it.

## Error Properties

**message**: The error description
```javascript
const error = new Error('File not found');
console.log(error.message); // 'File not found'
```

**name**: The type of error
```javascript
const error = new Error('Something broke');
console.log(error.name); // 'Error'
```

**stack**: Stack trace showing where the error occurred
```javascript
const error = new Error('Oops');
console.log(error.stack);
// Error: Oops
//     at <anonymous>:1:15
//     at ...
```
