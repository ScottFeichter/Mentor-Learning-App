## Error vs Exception

In JS, "error" and "exception" are related but not the same thing:

- An **Error** is:
    - a JS object
    - instantiated with the `new` keyword
    - and the `Error("some message")` constructor or one of its subclasses

- An **Exception** is:
    - the event that occurs
    - when an error is **thrown**
    - and disrupts normal program flow.


An Error becomes an Exception when you `throw` it

```js
const err = new Error("oops"); // This is just an Error object — no exception yet

throw err;                     // NOW it's an exception
```

## Loose Language

- They're officially called **Errors** in JavaScript.
- But people often say "exceptions" out of habit.

Both terms refer to the same concept in practice.
