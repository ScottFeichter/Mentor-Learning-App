# JS Errors

## Do Errors Block in JavaScript?

**Yes, uncaught errors are blocking** - they stop execution:

```javascript
console.log('Before error');

throw new Error('Something broke');

console.log('This never runs'); // Blocked by the error
```

**But caught errors don't block:**

```javascript

console.log('Before error');

try {
  throw new Error('Something broke');
} catch (err) {
  console.log('Caught:', err.message);
}

console.log('This runs!'); // Not blocked
```
