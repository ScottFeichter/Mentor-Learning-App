# I/O

"I/O" stands for Input/Output - it's the process of reading data in (input) and writing data out (output).

"I/O" also refers primarily to interaction with the system's disk and network supported by libuv.

## What is libuv?

libuv is a C library that Node uses under the hood to handle these I/O operations efficiently. It manages things like:

- File system operations

- Network connections

- Child processes


## In the context of Node.js:

Disk I/O: Reading/writing files on your computer's hard drive

Network I/O: Sending/receiving data over the internet (HTTP requests, database queries, etc.)


## The key point:

I/O operations are typically slow (waiting for disk reads, network responses),

so Node uses libuv to handle them asynchronously without blocking your code from running other tasks.
