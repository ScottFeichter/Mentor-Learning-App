# async/await vs .then()

## When to Use async/await

### 1. You want cleaner, more readable code

```javascript
// async/await - reads like synchronous code
async function getUser() {
  const response = await fetch('/api/user');
  const data = await response.json();
  return data;
}
```

vs

```javascript
// .then() - more nested/chained
function getUser() {
  return fetch('/api/user')
    .then(response => response.json())
    .then(data => data);
}
```

### 2. You need sequential operations

```javascript
async function processData() {
  const user = await getUser();
  const posts = await getPosts(user.id);
  const comments = await getComments(posts[0].id);
  return comments;
}
```

### 3. You want easier error handling

```javascript
async function getData() {
  try {
    const data = await fetch('/api/data');
    return data;
  } catch (error) {
    console.error('Failed:', error);
  }
}
```

## When to Use .then()

### 1. You need parallel operations

```javascript
// Better with .then()
Promise.all([
  fetch('/api/user'),
  fetch('/api/posts'),
  fetch('/api/comments')
]).then(([user, posts, comments]) => {
  // All fetched in parallel
});
```

### 2. You're in a non-async context and want to avoid making it async

```javascript
// Top-level code (before top-level await)
fetch('/api/data')
  .then(data => console.log(data));

// vs requiring an IIFE
(async () => {
  const data = await fetch('/api/data');
  console.log(data);
})();
```

### 3. You want to chain transformations

```javascript
fetch('/api/data')
  .then(response => response.json())
  .then(data => data.filter(x => x.active))
  .then(active => active.map(x => x.name))
  .then(names => console.log(names));
```

## Modern Best Practice

**Use async/await by default** - it's cleaner and easier to read.

Use .then() only when:
- You need parallel execution (Promise.all)
- You're in a context where async isn't available
- You have a simple one-off promise

## They're Interchangeable

```javascript
// These do the same thing
async function example1() {
  return await fetch('/api/data');
}

function example2() {
  return fetch('/api/data');
}
```

Both return a Promise. async/await is just syntactic sugar over .then().
