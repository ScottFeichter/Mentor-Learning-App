# Benchmarking

In Node, use `Ctrl + C` to stop execution.

**FATAL ERROR** means the process was killed (probably due to running out of memory).

## Timing Benchmarks

Two methods for determining how long a function takes:

### console.time()

Use with `console.timeLog()` and `console.timeEnd()` to measure how long an operation takes:

```javascript
console.time("addNums");
addNums(1000000);
console.timeEnd("addNums");
```

### Date.now()

Use the Unix Epoch (time since Jan 1, 1970). Take two measurements and subtract:

```javascript
const start = Date.now();
addNums(1000000);
const end = Date.now();
console.log(`Time: ${end - start}ms`);
```

You can paste values in Google Sheets and do Insert → Chart to make a graph.
