# Prisma Error Codes

## Overview

Prisma throws specific error codes when database operations fail. Each code starts with `P` followed by a 4-digit number. Understanding these codes helps you return appropriate HTTP responses.

## Common Error Codes

### P2002 — Unique Constraint Violation

A record with that value already exists for a unique field.

```javascript
// Trying to create a user with an email that already exists
try {
  await prisma.user.create({ data: { email: 'existing@email.com', name: 'John' } });
} catch (error) {
  if (error.code === 'P2002') {
    // error.meta.target contains the field(s): ['email']
    res.status(400).json({ error: `${error.meta.target[0]} already exists` });
  }
}
```

**HTTP Response:** 400 Bad Request

### P2025 — Record Not Found

The record you're trying to update or delete doesn't exist.

```javascript
try {
  await prisma.user.update({ where: { id: 999 }, data: { name: 'New' } });
} catch (error) {
  if (error.code === 'P2025') {
    res.status(404).json({ error: 'Record not found' });
  }
}
```

**HTTP Response:** 404 Not Found

### P2003 — Foreign Key Constraint Violation

The related record doesn't exist (e.g., creating a task with a userId that doesn't exist).

```javascript
try {
  await prisma.task.create({ data: { title: 'Task', userId: 999 } });
} catch (error) {
  if (error.code === 'P2003') {
    res.status(400).json({ error: 'Related record not found' });
  }
}
```

**HTTP Response:** 400 Bad Request

### P2014 — Relation Violation

The change would violate a required relation (e.g., deleting a user that has tasks when cascade isn't set).

**HTTP Response:** 400 Bad Request

### P2021 — Table Does Not Exist

The table doesn't exist in the database. Usually means migrations haven't been run.

**HTTP Response:** 500 Internal Server Error

### P2022 — Column Does Not Exist

A column referenced in the query doesn't exist. Usually means the schema is out of sync.

**HTTP Response:** 500 Internal Server Error

## Error Handling Pattern

```javascript
const { Prisma } = require('@prisma/client');

app.post('/api/users', async (req, res, next) => {
  try {
    const user = await prisma.user.create({
      data: req.body
    });
    res.status(201).json(user);
  } catch (error) {
    if (error instanceof Prisma.PrismaClientKnownRequestError) {
      switch (error.code) {
        case 'P2002':
          return res.status(400).json({
            error: `Duplicate value for: ${error.meta.target.join(', ')}`
          });
        case 'P2025':
          return res.status(404).json({ error: 'Record not found' });
        case 'P2003':
          return res.status(400).json({ error: 'Related record does not exist' });
        default:
          return res.status(400).json({ error: `Database error: ${error.code}` });
      }
    }

    if (error instanceof Prisma.PrismaClientValidationError) {
      return res.status(400).json({ error: 'Invalid data provided' });
    }

    next(error);
  }
});
```

## Error Types

| Error Class | When It Occurs |
|-------------|----------------|
| `PrismaClientKnownRequestError` | Database constraint violations (has `.code`) |
| `PrismaClientValidationError` | Invalid query (wrong field names, types) |
| `PrismaClientUnknownRequestError` | Unexpected database errors |
| `PrismaClientInitializationError` | Connection failures |
| `PrismaClientRustPanicError` | Internal Prisma engine crash |

## Reusable Error Handler Middleware

```javascript
const { Prisma } = require('@prisma/client');

function prismaErrorHandler(error, req, res, next) {
  if (error instanceof Prisma.PrismaClientKnownRequestError) {
    switch (error.code) {
      case 'P2002':
        return res.status(400).json({ error: 'Duplicate entry', field: error.meta?.target });
      case 'P2025':
        return res.status(404).json({ error: 'Not found' });
      case 'P2003':
        return res.status(400).json({ error: 'Invalid reference' });
      default:
        return res.status(400).json({ error: 'Database error' });
    }
  }

  if (error instanceof Prisma.PrismaClientValidationError) {
    return res.status(400).json({ error: 'Validation error' });
  }

  next(error);
}

// Use as middleware
app.use(prismaErrorHandler);
```
