# Prisma Client and Studio

## Prisma Client

### What Is It?

Prisma Client is an auto-generated, type-safe database client. It's generated from your schema.prisma file and provides methods for all CRUD operations.

### Generating the Client

```bash
npx prisma generate
```

Run this every time you change your schema. It reads `schema.prisma` and generates a client tailored to your models.

### Using the Client

```javascript
const { PrismaClient } = require('@prisma/client');
const prisma = new PrismaClient();

// Now prisma.user, prisma.task, etc. are available
// based on the models in your schema
```

### What Gets Generated

For each model in your schema, Prisma Client provides:

| Method | Purpose |
|--------|---------|
| `findMany()` | Get multiple records |
| `findUnique()` | Get one record by unique field |
| `findFirst()` | Get first matching record |
| `create()` | Create a record |
| `createMany()` | Create multiple records |
| `update()` | Update a record |
| `updateMany()` | Update multiple records |
| `delete()` | Delete a record |
| `deleteMany()` | Delete multiple records |
| `upsert()` | Create or update |
| `count()` | Count records |
| `aggregate()` | Aggregation operations |
| `groupBy()` | Group by operations |

### Client Options

```javascript
const prisma = new PrismaClient({
  log: ['query', 'info', 'warn', 'error'],  // Enable logging
  errorFormat: 'pretty',                      // Readable errors
});
```

## Prisma Studio

### What Is It?

Prisma Studio is a visual database browser that lets you view and edit data in your database through a GUI.

### Running Studio

```bash
npx prisma studio
```

Opens in your browser at `http://localhost:5555`

### Features

- View all your models/tables
- Browse records with pagination
- Filter and sort data
- Create, edit, and delete records
- View relations between records
- No SQL required

### When to Use Studio

- Quick data inspection during development
- Manually adding test data
- Debugging — checking what's actually in the database
- Verifying migrations worked correctly

## Other Prisma CLI Commands

| Command | Purpose |
|---------|---------|
| `npx prisma init` | Initialize Prisma in a project |
| `npx prisma generate` | Generate Prisma Client |
| `npx prisma migrate dev` | Create and apply migrations |
| `npx prisma migrate deploy` | Apply migrations in production |
| `npx prisma migrate reset` | Reset database and reapply migrations |
| `npx prisma db push` | Push schema without migration files |
| `npx prisma db pull` | Pull existing database schema into Prisma |
| `npx prisma db seed` | Run the seed script |
| `npx prisma studio` | Open visual database browser |
| `npx prisma validate` | Validate the schema file |
| `npx prisma format` | Format the schema file |
