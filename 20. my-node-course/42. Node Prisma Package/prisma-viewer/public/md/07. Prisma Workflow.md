# Prisma Workflow

## Adding Prisma Support to Your App

```
1. Define Schema → 2. Generate Client → 3. Use in Code → 4. Database Operations
```

## Step 1: Schema Definition

Define your database structure in `schema.prisma`.

- Specify models, fields, relationships, and database connection
- This file is the single source of truth for your database structure

```prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

generator client {
  provider = "prisma-client-js"
}

model User {
  id    Int     @id @default(autoincrement())
  email String  @unique
  name  String?
  posts Post[]
}
```

## Step 2: Client Generation

Prisma reads your schema and generates a TypeScript client.

- Run `npx prisma generate`
- Provides type-safe methods for all database operations
- Regenerate every time you change the schema

## Step 3: Code Integration

Import and use the generated client in your application.

```javascript
const { PrismaClient } = require('@prisma/client');
const prisma = new PrismaClient();
```

- Enjoy autocomplete and type checking
- All models from your schema become available as methods

## Step 4: Database Operations

Prisma translates your method calls to optimized SQL.

```javascript
// Create
const user = await prisma.user.create({ data: { email: 'john@example.com', name: 'John' } });

// Read
const users = await prisma.user.findMany();

// Update
const updated = await prisma.user.update({ where: { id: 1 }, data: { name: 'Jane' } });

// Delete
const deleted = await prisma.user.delete({ where: { id: 1 } });
```

- Handles connections, transactions, and error handling automatically
