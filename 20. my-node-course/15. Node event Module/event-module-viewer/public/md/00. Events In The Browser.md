# Events In The Browser

## Browser Events

In the browser, DOM elements emit events (clicks, key presses, page loads). You register listeners to respond to these events:

```javascript
button.addEventListener('click', () => {
  console.log('Button clicked!');
});
```

When the user clicks the button, the browser emits the 'click' event and executes all registered listeners.

## Node's EventEmitter

Node doesn't have a DOM, but it mimics this pattern with the EventEmitter class. You create custom events and emit them programmatically:

```javascript
const EventEmitter = require('events');
const myEmitter = new EventEmitter();

myEmitter.on('customEvent', () => {
  console.log('Custom event fired!');
});

myEmitter.emit('customEvent');
```

**Key similarity**: Both use the same pattern - register listeners with `on()`/`addEventListener()`, then trigger them with `emit()`/user actions.

**Key difference**: Browser events are triggered by user interactions; Node events are triggered by your code calling `emit()`.
