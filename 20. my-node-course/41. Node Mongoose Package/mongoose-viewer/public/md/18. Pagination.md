# Pagination

Pagination is a technique used to divide large datasets into smaller, manageable chunks or "pages" for display and navigation.

## Why Use Pagination?

- **Performance**: Loading thousands of records at once can slow down applications
- **User Experience**: Easier to navigate through smaller sets of data
- **Memory Management**: Reduces memory usage on both client and server
- **Network Efficiency**: Smaller data transfers over the network

## How It Works

Instead of loading all data at once, pagination loads a specific number of items per page:

- **Page Size**: Number of items per page (e.g., 10, 25, 50)
- **Page Number**: Current page being viewed (1, 2, 3...)
- **Total Count**: Total number of items in the dataset
- **Navigation**: Previous/Next buttons or page numbers

## Common Implementation

```
Page 1: Items 1-10
Page 2: Items 11-20  
Page 3: Items 21-30
```

## Types

- **Offset-based**: Uses page numbers and limits
- **Cursor-based**: Uses unique identifiers for continuous scrolling
- **Infinite scroll**: Automatically loads more content as user scrolls

Pagination is essential for handling large datasets efficiently in web applications, databases, and APIs.
