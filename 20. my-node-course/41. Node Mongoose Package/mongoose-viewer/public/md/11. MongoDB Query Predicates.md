# MongoDB Query Predicates

## What is a Query Predicate?

A query predicate in MongoDB is a condition or set of conditions used to filter documents in a collection.

It defines the criteria that documents must match to be included in query results.

## Mongoose Compatibility

Query predicates in Mongoose (Node.js) use identical syntax to native MongoDB queries.

The same operators and structure work in both:

```javascript
// Native MongoDB
db.users.find({ name: "John", age: { $gt: 18 } })

// Mongoose
User.find({ name: "John", age: { $gt: 18 } })
```

## Basic Syntax

```javascript
db.collection.find({ field: value })
```

## Common Query Predicates

### Equality
```javascript
db.users.find({ name: "John" })
db.users.find({ age: 25 })
```

### Comparison Operators
```javascript
db.users.find({ age: { $gt: 18 } })     // greater than
db.users.find({ age: { $gte: 18 } })    // greater than or equal
db.users.find({ age: { $lt: 65 } })     // less than
db.users.find({ age: { $lte: 65 } })    // less than or equal
db.users.find({ age: { $ne: 25 } })     // not equal
```

### Logical Operators
```javascript
// AND (implicit)
db.users.find({ name: "John", age: 25 })

// OR
db.users.find({ $or: [{ name: "John" }, { name: "Jane" }] })

// NOT
db.users.find({ age: { $not: { $gt: 65 } } })
```

### Array and Element Queries
```javascript
db.users.find({ hobbies: "reading" })           // array contains value
db.users.find({ hobbies: { $in: ["reading", "gaming"] } })  // array contains any of these values
db.users.find({ address: { $exists: true } })   // field exists
```

## Complex Predicates

```javascript
// Multiple conditions
db.users.find({
  age: { $gte: 18, $lt: 65 },
  status: "active",
  $or: [
    { department: "engineering" },
    { department: "design" }
  ]
})
```

Query predicates are essential for precise data retrieval and form the foundation of MongoDB's flexible querying capabilities.
