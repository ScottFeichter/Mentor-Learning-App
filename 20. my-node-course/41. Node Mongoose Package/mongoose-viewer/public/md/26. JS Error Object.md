## JavaScript Built-in Error Object

The **Error** object represents runtime errors in JavaScript.

### Properties
- **name**: Type of error (e.g., "Error", "TypeError")
- **message**: Human-readable error description
- **stack**: Stack trace showing where error occurred

### Basic Usage
```javascript
const error = new Error("Something went wrong");
console.log(error.name);     // "Error"
console.log(error.message);  // "Something went wrong"
console.log(error.stack);    // Stack trace
```

### JavaScript Error Types

| Error Type | Description | Example |
|------------|-------------|---------|
| **Error** | Generic error | `new Error("General error")` |
| **SyntaxError** | Invalid syntax | `eval("invalid syntax")` |
| **TypeError** | Wrong data type | `null.someMethod()` |
| **ReferenceError** | Undefined variable | `console.log(undefinedVar)` |
| **RangeError** | Number out of range | `new Array(-1)` |
| **URIError** | Invalid URI | `decodeURI("%")` |

### Custom Errors
```javascript
class CustomError extends Error {
  constructor(message) {
    super(message);
    this.name = "CustomError";
  }
}

throw new CustomError("Custom error occurred");
```
