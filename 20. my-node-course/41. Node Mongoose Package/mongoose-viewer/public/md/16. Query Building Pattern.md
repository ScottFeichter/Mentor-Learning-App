# Query Building Pattern with Delayed Await

## What is This Technique?

This pattern is called **Query Building** or **Deferred Execution**. It allows you to construct a database query step-by-step before executing it with `await`.

## The Pattern

```javascript
// Step 1: Create query object (not executed yet)
let result = Product.find(queryObject);

// Step 2: Conditionally modify the query
if (sort) {
  const sortList = sort.split(',').join(' ');
  result = result.sort(sortList);
} else {
  result = result.sort('createdAt');
}

// Step 3: Execute the query
const products = await result;
```

## Why This Works

### Mongoose Query Objects
```javascript
// This returns a Query object, NOT the actual data
let query = Product.find({ category: 'electronics' });
console.log(query); // Query object, not products

// The query is only executed when you await it
const products = await query; // NOW it hits the database
```

### Method Chaining
```javascript
// Each method returns a new Query object
let query = Product.find({ price: { $lt: 100 } });
query = query.sort('name');
query = query.limit(10);
query = query.select('name price');

// Still no database call until:
const products = await query;
```

## Alternative Names for This Pattern

- **Query Builder Pattern**
- **Deferred Execution**
- **Lazy Evaluation**
- **Method Chaining with Delayed Execution**
- **Query Construction Pattern**

## Complete Example

```javascript
const getProducts = async (req, res) => {
  const { category, sort, fields, limit } = req.query;
  
  // Step 1: Start building the query
  let query = Product.find();
  
  // Step 2: Add filters conditionally
  if (category) {
    query = query.where('category').equals(category);
  }
  
  // Step 3: Add sorting conditionally
  if (sort) {
    const sortList = sort.split(',').join(' ');
    query = query.sort(sortList);
  } else {
    query = query.sort('createdAt');
  }
  
  // Step 4: Add field selection conditionally
  if (fields) {
    const fieldList = fields.split(',').join(' ');
    query = query.select(fieldList);
  }
  
  // Step 5: Add limit conditionally
  if (limit) {
    query = query.limit(parseInt(limit));
  }
  
  // Step 6: Execute the query
  const products = await query;
  
  res.json({ products, count: products.length });
};
```

## Benefits of This Pattern

### Conditional Query Building
```javascript
let query = User.find();

// Add conditions based on user input
if (req.query.age) {
  query = query.where('age').gte(req.query.age);
}

if (req.query.active) {
  query = query.where('status').equals('active');
}

if (req.query.search) {
  query = query.where('name').regex(new RegExp(req.query.search, 'i'));
}

// Single database call with all conditions
const users = await query;
```

### Performance Optimization
```javascript
// BAD: Multiple database calls
const users = await User.find({ age: { $gte: 18 } });
const sortedUsers = await User.find({ age: { $gte: 18 } }).sort('name');
const limitedUsers = await User.find({ age: { $gte: 18 } }).sort('name').limit(10);

// GOOD: Single database call
let query = User.find({ age: { $gte: 18 } });
query = query.sort('name');
query = query.limit(10);
const users = await query;
```

## Common Patterns

### Sort Parameter Processing
```javascript
// Convert "name,-price,createdAt" to "name -price createdAt"
if (sort) {
  const sortList = sort.split(',').join(' ');
  query = query.sort(sortList);
}
```

### Field Selection
```javascript
// Convert "name,price,category" to "name price category"
if (fields) {
  const fieldList = fields.split(',').join(' ');
  query = query.select(fieldList);
}
```

### Pagination
```javascript
const page = parseInt(req.query.page) || 1;
const limit = parseInt(req.query.limit) || 10;
const skip = (page - 1) * limit;

query = query.skip(skip).limit(limit);
```

## Alternative Syntax

### Object-Based Approach
```javascript
const queryOptions = {};

if (sort) {
  const sortList = sort.split(',').join(' ');
  queryOptions.sort = sortList;
}

const products = await Product.find(queryObject, null, queryOptions);
```

### Immediate Chaining
```javascript
const products = await Product
  .find(queryObject)
  .sort(sort ? sort.split(',').join(' ') : 'createdAt')
  .limit(limit || 10)
  .select(fields ? fields.split(',').join(' ') : '');
```

## Key Concepts

- **Query objects** are returned by Mongoose methods, not data
- **Method chaining** allows building complex queries step-by-step
- **Deferred execution** means the database is only hit when you `await`
- **Conditional building** enables dynamic queries based on user input
- **Single database call** improves performance over multiple queries

This pattern is fundamental to building flexible, efficient APIs with MongoDB and Mongoose.
