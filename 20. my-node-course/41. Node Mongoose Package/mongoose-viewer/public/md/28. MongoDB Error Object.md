# MongoDB Error Object

MongoDB provides specific error types for database operations.

### MongoDB Error Properties
- **name**: Error type (e.g., "MongoError", "ValidationError")
- **message**: Error description
- **code**: MongoDB-specific error code
- **codeName**: Human-readable error code name

### Common MongoDB Errors

| Error Type | Code | Description |
|------------|------|-------------|
| **DuplicateKeyError** | 11000 | Unique constraint violation |
| **ValidationError** | - | Schema validation failed |
| **CastError** | - | Invalid data type for field |
| **DocumentNotFoundError** | - | Document not found |
| **MongoNetworkError** | - | Connection issues |

### MongoDB Error Examples
```javascript
// Mongoose validation error
const userSchema = new mongoose.Schema({
  email: { type: String, required: true, unique: true }
});

try {
  await User.create({ name: 'John' }); // Missing required email
} catch (error) {
  console.log(error.name);    // "ValidationError"
  console.log(error.errors);  // Detailed validation errors
}

// Duplicate key error
try {
  await User.create({ email: 'existing@email.com' });
} catch (error) {
  if (error.code === 11000) {
    console.log('Email already exists');
  }
}

// Cast error
try {
  await User.findById('invalid-id');
} catch (error) {
  console.log(error.name); // "CastError"
}
```
