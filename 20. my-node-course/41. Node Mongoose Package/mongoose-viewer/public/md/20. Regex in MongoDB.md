# Regular Expressions in MongoDB

## Basic Regex Syntax

MongoDB supports regular expressions using the `$regex` operator or JavaScript regex literals.

```javascript
// Using $regex operator
db.users.find({ name: { $regex: "john", $options: "i" } })

// Using regex literal
db.users.find({ name: /john/i })
```

## Mongoose Usage

Regex syntax is identical in Mongoose:

```javascript
// Mongoose
User.find({ name: /john/i })
User.find({ email: { $regex: "gmail", $options: "i" } })
```


## Common Patterns

### Case-Insensitive Search
```javascript
// Using regex literal
db.users.find({ name: /john/i })
// Using $regex operator
db.users.find({ name: { $regex: "john", $options: "i" } })

// Email example
db.users.find({ email: /gmail/i })
db.users.find({ email: { $regex: "gmail", $options: "i" } })
```

### Starts With
```javascript
// Using regex literal
db.users.find({ name: /^John/ })
db.users.find({ email: /^admin/ })

// Using $regex operator
db.users.find({ name: { $regex: "^John" } })
db.users.find({ email: { $regex: "^admin" } })
```

### Ends With
```javascript
// Using regex literal
db.users.find({ email: /\.com$/ })
db.users.find({ name: /son$/ })

// Using $regex operator
db.users.find({ email: { $regex: "\.com$" } })
db.users.find({ name: { $regex: "son$" } })
```

### Contains
```javascript
// Using regex literal
db.users.find({ name: /smith/ })
db.users.find({ description: /mongodb/i })

// Using $regex operator
db.users.find({ name: { $regex: "smith" } })
db.users.find({ description: { $regex: "mongodb", $options: "i" } })
```

## Regex Options

| Option | Description |
|--------|-------------|
| `i` | Case-insensitive |
| `m` | Multiline |
| `x` | Extended (ignore whitespace) |
| `s` | Dot matches newline |

```javascript
db.posts.find({
  content: {
    $regex: "javascript",
    $options: "im"
  }
})
```

## Advanced Patterns

### Character Classes
```javascript
db.users.find({ phone: /^[0-9]{3}-[0-9]{3}-[0-9]{4}$/ })  // phone format
db.users.find({ username: /^[a-zA-Z0-9_]+$/ })            // alphanumeric + underscore
```

### Wildcards and Quantifiers
```javascript
db.products.find({ sku: /^ABC.{3}$/ })     // ABC followed by exactly 3 characters
db.users.find({ name: /Jo+hn/ })           // "John", "Joohn", "Jooohn", etc.
```

## Performance Considerations

- Use indexes on regex fields when possible
- Anchor patterns with `^` for better performance
- Avoid leading wildcards (`.*pattern`) as they can't use indexes

```javascript
// Good - can use index
db.users.find({ email: /^admin/ })

// Poor performance - can't use index efficiently
db.users.find({ email: /admin/ })
```
