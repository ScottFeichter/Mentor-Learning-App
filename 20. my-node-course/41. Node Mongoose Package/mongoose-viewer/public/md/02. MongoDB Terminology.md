# MongoDB Terminology Map

A quick reference for translating common database terms to MongoDB equivalents.

## Database Terms

| Common Term | MongoDB Term |
|-------------|--------------|
| Database | Database |
| Table | Collection |
| Record/Row | Document |
| Column/Field | Field |
| Primary Key | _id (ObjectId) |
| Index | Index |
| Join | $lookup (aggregation) |
| Foreign Key | Reference/DBRef |
| Schema | Document Structure |
| View | View |
| Stored Procedure | Server-side JavaScript |
| Transaction | Transaction |
| Cursor | Cursor |
| Cluster | Cluster |

## SQL vs MongoDB Operations

| SQL Operation | MongoDB Operation |
|---------------|-------------------|
| SELECT | find() |
| INSERT | insertOne()/insertMany() |
| UPDATE | updateOne()/updateMany() |
| DELETE | deleteOne()/deleteMany() |
| WHERE | filter/query |
| ORDER BY | sort() |
| GROUP BY | $group (aggregation) |
| HAVING | $match (aggregation) |
| LIMIT | limit() |
| OFFSET | skip() |

## Key Differences

- **Document**: Can contain nested objects and arrays (unlike flat SQL rows)
- **Collection**: Schema-flexible (documents can have different structures)
- **_id**: Automatically generated unique identifier for each document
- **Embedded Documents**: Replace many SQL joins with nested data
