# Test DB Connection

In the shell invoke:

```bash
npm run dev
```

This will run the server.js file which will call the startServer function.

This is an async function that first awaits the connectDB function to return without errors.

Then it runs SERVER.listion and a console.log() will appear in the console for either success or error.

If success it will indicate the server is running on the desired port.

If failure examine the error message and trouble shoot.

Upon success check in MongoDB Atlas to see the new db was properly created.
