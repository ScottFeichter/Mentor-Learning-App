# Create connect.js

## Purpose

Create a `connect.js` file in the `database` folder.

This will be a function built with Mongoose that connects to MongoDB Atlas.

We need to:

- import mongoose
- create the connectDB function
- give it url parameter
- return mongoose.connect method passing url and options
- export the function 

## Implementation

```javascript
const mongoose = require('mongoose')

const connectDB = (url) => {
  return mongoose.connect(url, {
    useNewUrlParser: true,
    useCreateIndex: true,
    useFindAndModify: false,
    useUnifiedTopology: true,
  })
}

module.exports = connectDB
```
