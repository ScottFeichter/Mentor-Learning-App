# Query, Filter, Sort, Select, Limit, Skip

Used in MongoDB/Mongoose

## What is a Query?

A **query** is a request to retrieve data from a database. It's the overall operation that asks the database to find and return documents that match certain criteria.

```javascript
// MongoDB query - asking for user documents
db.users.find()

// Mongoose query - same concept
User.find()
```

## What is a Filter?

A **filter** is the criteria or conditions that determine which documents to include in the query results. It's the "WHERE" clause equivalent in SQL.

```javascript
// MongoDB filter - only users with age greater than 18
db.users.find({ age: { $gt: 18 } })

// Mongoose filter - same logic
User.find({ age: { $gt: 18 } })
```

## What is Sorting?

**Sorting** determines the order in which the filtered results are returned. It doesn't change which documents are returned, only their sequence.

```javascript
// MongoDB sort - alphabetical by name
db.users.find().sort({ name: 1 })

// Mongoose sort - same ordering
User.find().sort({ name: 1 })
```

## What is Select?

**Select** (also called projection) determines which fields are included in the returned documents. It controls what data is sent back, reducing bandwidth and improving performance.

```javascript
// MongoDB select - only return name and email fields
db.users.find({}, { name: 1, email: 1 })

// Mongoose select - same field selection
User.find().select('name email')
User.find().select({ name: 1, email: 1 })
```

## What is Limit?

**Limit** restricts the maximum number of documents returned by a query. It's essential for pagination and performance optimization.

```javascript
// MongoDB limit - return only 10 documents
db.users.find().limit(10)

// Mongoose limit - same functionality
User.find().limit(10)
```

## What is Skip?

**Skip** bypasses a specified number of documents before returning results. Combined with limit, it enables pagination.

```javascript
// MongoDB skip - skip first 20 documents
db.users.find().skip(20)

// Mongoose skip - same functionality
User.find().skip(20)
```

## How They Work Together

### Complete Example
```javascript
// MongoDB: Query with all operations
db.users.find(
  { age: { $gte: 18 }, status: "active" },  // Filter
  { name: 1, email: 1, age: 1 }             // Select
).sort({ name: 1 })                         // Sort
 .skip(20)                                  // Skip
 .limit(10)                                 // Limit

// Mongoose: Same operation
User.find({ age: { $gte: 18 }, status: "active" })
    .select('name email age')
    .sort({ name: 1 })
    .skip(20)
    .limit(10)
```

### Step-by-Step Process
1. **Query**: "Find user documents"
2. **Filter**: "Where age >= 18 AND status = 'active'"
3. **Select**: "Only return name, email, and age fields"
4. **Sort**: "Order results by name A-Z"
5. **Skip**: "Skip the first 20 results"
6. **Limit**: "Return maximum 10 documents"

## Filter Examples

### Basic Filters
```javascript
// Equality
User.find({ name: "John" })
User.find({ age: 25 })

// Comparison
User.find({ age: { $gt: 18 } })        // Greater than
User.find({ price: { $lte: 100 } })    // Less than or equal

// Multiple conditions (AND)
User.find({ age: { $gte: 18 }, status: "active" })

// OR conditions
User.find({ $or: [{ age: { $lt: 18 } }, { status: "inactive" }] })
```

### Advanced Filters
```javascript
// Array contains
User.find({ hobbies: "reading" })

// Field exists
User.find({ email: { $exists: true } })

// Regex pattern
User.find({ name: /^John/i })

// In array
User.find({ status: { $in: ["active", "pending"] } })
```

## Select Examples

### Basic Field Selection
```javascript
// Include specific fields
User.find().select('name email')
User.find().select({ name: 1, email: 1 })

// Exclude specific fields
User.find().select('-password -__v')
User.find().select({ password: 0, __v: 0 })
```

### Advanced Selection
```javascript
// Include all except certain fields
User.find().select('-password -createdAt -updatedAt')

// Nested field selection
User.find().select('name profile.avatar profile.bio')

// Array field selection
User.find().select('name hobbies')
```

## Limit and Skip Examples

### Basic Pagination
```javascript
// Page 1: First 10 users
User.find().limit(10)

// Page 2: Skip 10, take next 10
User.find().skip(10).limit(10)

// Page 3: Skip 20, take next 10
User.find().skip(20).limit(10)
```

### Pagination Formula
```javascript
const page = 2;        // Current page (1-based)
const limit = 10;      // Items per page
const skip = (page - 1) * limit;  // Calculate skip value

User.find().skip(skip).limit(limit)
```

### Combined with Other Operations
```javascript
// Filter, sort, then paginate
User.find({ status: 'active' })
    .sort({ createdAt: -1 })
    .skip(20)
    .limit(10)
```

## Sort Examples

### Basic Sorting
```javascript
// Ascending (1 or 'asc')
User.find().sort({ name: 1 })
User.find().sort({ age: 'asc' })

// Descending (-1 or 'desc')
User.find().sort({ createdAt: -1 })
User.find().sort({ price: 'desc' })
```

### Multiple Field Sorting
```javascript
// Sort by category first, then price descending
Product.find().sort({ category: 1, price: -1 })

// String syntax (Mongoose only)
Product.find().sort('category -price')
```

## REST API Integration

### Express Route Example
```javascript
app.get('/api/users', async (req, res) => {
  try {
    // Extract query parameters
    const { age, status, sort, fields, page, limit } = req.query;

    // Build filter object
    let filter = {};
    if (age) filter.age = { $gte: parseInt(age) };
    if (status) filter.status = status;

    // Build sort object
    let sortObject = {};
    if (sort) {
      const sortFields = sort.split(',');
      sortFields.forEach(field => {
        if (field.startsWith('-')) {
          sortObject[field.substring(1)] = -1;
        } else {
          sortObject[field] = 1;
        }
      });
    }

    // Build select string
    let selectFields = '';
    if (fields) {
      selectFields = fields.split(',').join(' ');
    }

    // Pagination
    const pageNum = parseInt(page) || 1;
    const limitNum = parseInt(limit) || 10;
    const skip = (pageNum - 1) * limitNum;

    // Execute query with all operations
    let query = User.find(filter);
    if (selectFields) query = query.select(selectFields);
    const users = await query
      .sort(sortObject)
      .skip(skip)
      .limit(limitNum);

    // Get total count for pagination info
    const total = await User.countDocuments(filter);

    res.json({
      users,
      pagination: {
        page: pageNum,
        limit: limitNum,
        total,
        pages: Math.ceil(total / limitNum)
      }
    });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});
```

### URL Examples
```
GET /api/users                                    // Query all users
GET /api/users?page=2&limit=5                     // Pagination
GET /api/users?age=18&sort=name&fields=name,email&page=1&limit=10  // All operations
```

## Query Operations Summary

| Component | Purpose | Example |
|-----------|---------|---------|
| **Query** | Request data from database | `User.find()` |
| **Filter** | Specify which documents to return | `{ age: { $gte: 18 } }` |
| **Sort** | Order the returned documents | `{ name: 1, createdAt: -1 }` |
| **Select** | Choose which fields to include/exclude | `'name email'` or `{ password: 0 }` |
| **Skip** | Bypass a number of documents | `.skip(20)` |
| **Limit** | Restrict maximum documents returned | `.limit(10)` |

## MongoDB vs Mongoose Syntax

### MongoDB Shell
```javascript
db.users.find({ age: { $gte: 18 } }, { name: 1, email: 1 }).sort({ name: 1 }).limit(10)
```

### Mongoose
```javascript
User.find({ age: { $gte: 18 } }).select('name email').sort({ name: 1 }).limit(10)

// Or method chaining
User.find()
    .where('age').gte(18)
    .select('name email')
    .sort('name')
    .limit(10)
```

## Key Concepts

- **Query**: The overall database operation
- **Filter**: Conditions that determine which documents match
- **Sort**: Ordering applied to the matching documents
- **Select**: Field projection to control returned data
- **Chaining**: Operations can be combined for complex data retrieval
- **Performance**: Filters reduce data, sorting organizes results, select reduces bandwidth

These four concepts work together to provide precise, ordered, and optimized data retrieval from MongoDB collections.
