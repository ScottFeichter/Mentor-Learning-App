# MySQL

## What Is MySQL?

**MySQL** is an open-source relational database management system owned by Oracle Corporation. It's one of the most widely deployed databases in the world, known for its speed, reliability, and ease of use. It powers much of the web, including WordPress, Facebook, and Twitter.

## History

- **1995**: Created by Michael Widenius and David Axmark at MySQL AB (Sweden)
- **2000**: Released under GPL open-source license
- **2008**: Sun Microsystems acquired MySQL AB for $1 billion
- **2010**: Oracle Corporation acquired Sun Microsystems (and MySQL with it)
- **2010**: MariaDB forked from MySQL due to concerns about Oracle's stewardship
- **Today**: Still one of the most popular databases, especially for web applications

## Key Features

- Fast read performance (optimized for web workloads)
- Full ACID compliance (with InnoDB engine)
- Multiple storage engines (InnoDB, MyISAM, Memory)
- Replication (master-slave, master-master)
- Partitioning for large tables
- JSON data type support (since 5.7)
- Full-text search
- Stored procedures and triggers
- Views and cursors
- Large community and ecosystem

## Running Locally (mysql Shell)

### Connect to MySQL

```bash
# Connect as root
mysql -u root -p

# Connect to a specific database
mysql -u username -p mydb

# Connect with host and port
mysql -h localhost -P 3306 -u username -p
```

### Basic Shell Commands

```sql
-- List all databases
SHOW DATABASES;

-- Use a database
USE mydb;

-- List all tables
SHOW TABLES;

-- Describe a table
DESCRIBE users;

-- Show current user
SELECT USER();

-- Show current database
SELECT DATABASE();

-- Quit mysql
EXIT;
-- or
\q
```

### Basic SQL Operations

```sql
-- Create a database
CREATE DATABASE myapp;

-- Create a table
CREATE TABLE users (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL,
  age INT CHECK (age >= 0),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB;

-- Insert data
INSERT INTO users (name, email, age) VALUES ('John', 'john@example.com', 30);

-- Query data
SELECT * FROM users WHERE age > 21 ORDER BY name;

-- Update data
UPDATE users SET age = 31 WHERE email = 'john@example.com';

-- Delete data
DELETE FROM users WHERE id = 1;

-- Drop a table
DROP TABLE users;

-- Drop a database
DROP DATABASE myapp;
```

### User Management

```sql
-- Create a user
CREATE USER 'myuser'@'localhost' IDENTIFIED BY 'mypassword';

-- Grant privileges
GRANT ALL PRIVILEGES ON myapp.* TO 'myuser'@'localhost';
FLUSH PRIVILEGES;

-- List users
SELECT user, host FROM mysql.user;
```

## MySQL vs PostgreSQL

| Aspect | MySQL | PostgreSQL |
|--------|-------|-----------|
| Speed | Faster for simple reads | Faster for complex queries |
| Standards | Partial SQL compliance | Full SQL compliance |
| Data Types | Fewer advanced types | Rich type system (JSON, arrays, etc.) |
| Replication | Built-in, mature | Streaming replication |
| Extensibility | Limited | Highly extensible |
| Use Case | Web apps, CMS, e-commerce | Analytics, complex apps, GIS |

## When to Use MySQL

- Simple web applications
- WordPress or PHP-based projects
- Read-heavy workloads
- When you need mature replication
- E-commerce platforms
- When team already knows MySQL
