# Installing Node Version Manager

&nbsp;

https://github.com/nvm-sh/nvm

https://github.com/nvm-sh/nvm?tab=readme-ov-file#installing-and-updating

## Windows

Go to the NVM for Windows releases page on GitHub and download the nvm-setup.zip or nvm-setup.exe file.

Extract the contents if you downloaded a zip file, and then run the nvm-setup.exe file.

Follow the installation wizard, accepting the default settings for most users.

Restart your command prompt or terminal after the installation is complete.

Verify the installation by typing `nvm -v` and pressing Enter. If successful, the version number will be displayed.

## macOS and Linux

Run the installation script using curl or wget as shown on the official NVM GitHub repository.

After installation, verify by opening a new terminal and typing `nvm -v`.
