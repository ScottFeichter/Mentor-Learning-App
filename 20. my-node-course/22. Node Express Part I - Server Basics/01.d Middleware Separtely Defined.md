# Defining Middleware Function Separately

You don't have to define the middlware function inside the argument list. 

You can define the middleware function separately in your code.

Then pass the function identifier as the argument because it is a reference to the function definition.

```js

function someMiddleware(req, res, next) {
  // logic
  next();
}


app.use(someMiddleware);
```

This is a callback function because we are not calling the function in our code.

We are giving the function definition to app.use() so that app.use() can call someMiddleware() in its body.
