# Engines

&nbsp;

A JS Engine implements ECMAScript. It parses and executes JavaScript.

There are several engines available.

## Browser Based Engines

- Chrome uses V8
- Mozilla uses SpiderMonkey (the first JS engine ever invented)
- Safari uses JavaScriptCore (aka SquirrelFish/Nitro)

### Previous Browser Engines

- Carakan was used by Opera
- Chakra was used in Internet Explorer
- Chakra was used in Edge

## Non-Browser Engines

- Node uses V8
- React Native uses Hermes
- Mozilla uses Rhino
- Oracle uses GraalJS
- IoT/embedded systems can use Moddable XS
- QuickJS is a lightweight embeddable engine
