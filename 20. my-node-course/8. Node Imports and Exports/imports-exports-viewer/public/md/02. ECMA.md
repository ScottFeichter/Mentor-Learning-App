# ECMA and ECMAScript

## What is ECMA?

**ECMA** = European Computer Manufacturers Association (now just "Ecma International")

- Standards organization founded in 1961
- Creates standards for information and communication systems
- Based in Geneva, Switzerland
- No longer an acronym - officially just "Ecma"

## What is ECMAScript?

**ECMAScript** is the official specification/standard for JavaScript.

- **ECMA-262** is the standard number for ECMAScript
- JavaScript is the most popular implementation of ECMAScript
- Other implementations: JScript (Microsoft), ActionScript (Adobe)

## History

### 1995: JavaScript is Born
- Brendan Eich creates JavaScript at Netscape in 10 days
- Originally called "Mocha", then "LiveScript", finally "JavaScript"

### 1996: Standardization Begins
- Netscape submits JavaScript to Ecma International
- Needed standardization due to browser wars (Netscape vs Microsoft)

### 1997: ECMAScript 1 (ES1)
- First official standard released

### 1998: ECMAScript 2 (ES2)
- Minor editorial changes

### 1999: ECMAScript 3 (ES3)
- Regular expressions, try/catch, more string methods
- Widely adopted, stable for years

### 2009: ECMAScript 5 (ES5)
- Strict mode, JSON support, array methods
- ES4 was abandoned due to disagreements

### 2015: ECMAScript 6 (ES6 / ES2015)
- **MAJOR UPDATE**
- Arrow functions, classes, modules, promises
- let/const, template literals, destructuring
- Changed naming to year-based (ES2015)

### 2016+: Yearly Releases
- **ES2016 (ES7)**: Array.includes, exponentiation operator
- **ES2017 (ES8)**: async/await, Object.entries
- **ES2018 (ES9)**: Rest/spread properties, async iteration
- **ES2019 (ES10)**: Array.flat, Object.fromEntries
- **ES2020 (ES11)**: Optional chaining, nullish coalescing
- **ES2021 (ES12)**: Logical assignment operators
- **ES2022 (ES13)**: Top-level await, class fields
- **ES2023 (ES14)**: Array methods (toSorted, toReversed)
- **ES2024 (ES15)**: Ongoing...

## Why It Matters

- **Standardization**: Ensures JavaScript works consistently across browsers
- **Evolution**: New features added regularly through TC39 process
- **Compatibility**: Developers need to know which features are supported
- **Transpilation**: Tools like Babel convert newer ES versions to older ones

## TC39 Process

**TC39** = Technical Committee 39 (maintains ECMAScript)

**Proposal Stages**:
- Stage 0: Strawperson
- Stage 1: Proposal
- Stage 2: Draft
- Stage 3: Candidate
- Stage 4: Finished (added to next ES version)

## Common Terminology

- **JavaScript**: The language we write
- **ECMAScript**: The specification/standard
- **ES6/ES2015**: Often used interchangeably for the 2015 version
- **Modern JavaScript**: Generally refers to ES6+
