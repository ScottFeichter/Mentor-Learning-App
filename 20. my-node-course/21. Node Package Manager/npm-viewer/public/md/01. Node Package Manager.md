# Node Package Manager (npm)

**Node Package Manager (npm)** is a program for managing Node packages in a project.

- It is a separate entity from Node though they are often installed together
- It handles downloading, installing, and managing third-party code
- It uses the terminal (command line) - there is no GUI

## What Does npm Do?

- **Installs packages** from the npm registry into your project
- **Manages dependencies** so your project knows what code it needs
- **Runs scripts** defined in your `package.json`
- **Publishes packages** so others can use your code
