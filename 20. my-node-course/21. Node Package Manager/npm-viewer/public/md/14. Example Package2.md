# Example Package 2

A more realistic package that has **dependencies** installed via npm. This package includes:

- A `package.json` with dependencies (express, nodemon)
- A `package-lock.json` that locks dependency versions
- A `node_modules/` folder containing all installed packages
- Application code (`index.js` and `myCode.js`)

## Key Points

- Running `npm install` reads `package.json` and installs dependencies into `node_modules/`
- The `node_modules/` folder can contain hundreds of packages (dependencies of dependencies)
- `package-lock.json` ensures everyone on the team gets the exact same versions
- You never edit `node_modules/` directly - npm manages it for you
