# package.json

The `package.json` file provides information about the code in a directory.

## What It May Include

- **Project Name** - the name of your package
- **Author** - who wrote it
- **Date Established** - when it was created
- **License** - how others can use your code
- **Scripts** - terminal commands used to run the project and do other things
- **Dependencies** - imported code needed by the project
- **Dev Dependencies** - imported code needed only in the development environment

## Key Point

A directory can be called a **package** when it has a `package.json` file in it.
