# Node Files, Modules, and Packages

The terms File, Module, and Package are often used in a loose manner. There are technical differences but they are only minimally helpful to the new learner.

## Node File

- A single JS file (e.g., `myScript.js`)
- Can be loaded using `require()` (CJS) or `import` (ESM)

## Node Module

- One or multiple JS files in a directory
- Usually self-contained code of related functionality
- Can be loaded using `require()` (CJS) or `import` (ESM)

## Node Package

- One or multiple Modules in a directory with a `package.json` file
- Distributed through a package manager (npm)
- Can be installed as dependencies in your project

## The Big Picture

It's all about getting the code you need where you need it.

This can be code you wrote or code someone else wrote.
