# Example Module

A **module** is simply a single JavaScript file. It's the smallest unit of reusable code in Node.js.

This example shows a module - just two JS files sitting in a folder. No `package.json`, no `node_modules`, no configuration. Just code files.

## Key Point

A module doesn't need any special setup. Any `.js` file is a module that can be imported by another file using `require()` or `import`.
