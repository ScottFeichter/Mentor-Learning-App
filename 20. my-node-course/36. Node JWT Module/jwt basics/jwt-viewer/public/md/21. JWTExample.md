# JWT Example - Building a JWT Step by Step

## What is a JWT?

A JWT (JSON Web Token) consists of three parts separated by dots:
```
header.payload.signature
```

## Setup

```javascript
const crypto = require('crypto');
```

---

## Step 1: Create the Header

The header describes the token type and signing algorithm.

```javascript
// Header object
const header = {
  alg: 'HS256',  // Algorithm: HMAC SHA-256
  typ: 'JWT'     // Type: JWT
};

// Convert to JSON string
const headerJSON = JSON.stringify(header);
console.log('Header JSON:', headerJSON);
// Output: {"alg":"HS256","typ":"JWT"}

// Base64URL encode
const headerBase64 = Buffer.from(headerJSON).toString('base64url');
console.log('Header Base64URL:', headerBase64);
// Output: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9
```

---

## Step 2: Create the Payload

The payload contains the claims (data) you want to store.

```javascript
// Payload object
const payload = {
  userId: 123,
  email: 'user@example.com',
  iat: Math.floor(Date.now() / 1000),  // Issued at (timestamp)
  exp: Math.floor(Date.now() / 1000) + (60 * 60)  // Expires in 1 hour
};

// Convert to JSON string
const payloadJSON = JSON.stringify(payload);
console.log('Payload JSON:', payloadJSON);
// Output: {"userId":123,"email":"user@example.com","iat":1234567890,"exp":1234571490}

// Base64URL encode
const payloadBase64 = Buffer.from(payloadJSON).toString('base64url');
console.log('Payload Base64URL:', payloadBase64);
// Output: eyJ1c2VySWQiOjEyMywiZW1haWwiOiJ1c2VyQGV4YW1wbGUuY29tIiwiaWF0IjoxMjM0NTY3ODkwLCJleHAiOjEyMzQ1NzE0OTB9
```

---

## Step 3: Create the Signature

The signature ensures the token hasn't been tampered with.

```javascript
// Secret key (keep this secure!)
const secret = 'my-secret-key';

// Combine header and payload
const data = headerBase64 + '.' + payloadBase64;
console.log('Data to sign:', data);

// Create HMAC SHA-256 signature
const signature = crypto
  .createHmac('sha256', secret)
  .update(data)
  .digest('base64url');

console.log('Signature:', signature);
// Output: SflKxwRJSMeKKF2QT4fwpMeJf36POk6yJV_adQssw5c
```

---

## Step 4: Combine All Parts

```javascript
// Final JWT
const jwt = headerBase64 + '.' + payloadBase64 + '.' + signature;

console.log('Complete JWT:', jwt);
// Output: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VySWQiOjEyMywiZW1haWwiOiJ1c2VyQGV4YW1wbGUuY29tIiwiaWF0IjoxMjM0NTY3ODkwLCJleHAiOjEyMzQ1NzE0OTB9.SflKxwRJSMeKKF2QT4fwpMeJf36POk6yJV_adQssw5c
```

## Complete Example

```javascript
const crypto = require('crypto');

function createJWT(payload, secret) {
  // Step 1: Create header
  const header = {
    alg: 'HS256',
    typ: 'JWT'
  };
  const headerBase64 = Buffer.from(JSON.stringify(header)).toString('base64url');
  
  // Step 2: Create payload
  const payloadBase64 = Buffer.from(JSON.stringify(payload)).toString('base64url');
  
  // Step 3: Create signature
  const data = headerBase64 + '.' + payloadBase64;
  const signature = crypto
    .createHmac('sha256', secret)
    .update(data)
    .digest('base64url');
  
  // Step 4: Combine
  return headerBase64 + '.' + payloadBase64 + '.' + signature;
}

// Usage
const token = createJWT(
  {
    userId: 123,
    email: 'user@example.com',
    iat: Math.floor(Date.now() / 1000),
    exp: Math.floor(Date.now() / 1000) + (60 * 60)
  },
  'my-secret-key'
);

console.log('JWT:', token);
```

## Verifying a JWT

```javascript
function verifyJWT(token, secret) {
  // Split the token
  const [headerBase64, payloadBase64, signature] = token.split('.');
  
  // Recreate the signature
  const data = headerBase64 + '.' + payloadBase64;
  const expectedSignature = crypto
    .createHmac('sha256', secret)
    .update(data)
    .digest('base64url');
  
  // Compare signatures
  if (signature !== expectedSignature) {
    throw new Error('Invalid signature');
  }
  
  // Decode payload
  const payload = JSON.parse(Buffer.from(payloadBase64, 'base64url').toString());
  
  // Check expiration
  if (payload.exp && payload.exp < Math.floor(Date.now() / 1000)) {
    throw new Error('Token expired');
  }
  
  return payload;
}

// Usage
try {
  const decoded = verifyJWT(token, 'my-secret-key');
  console.log('Decoded payload:', decoded);
} catch (err) {
  console.error('Verification failed:', err.message);
}
```

## Key Points

1. **Header** - Metadata about the token (algorithm, type)
2. **Payload** - Your data (claims)
3. **Signature** - Ensures integrity (prevents tampering)

**Important:**
- JWT is **encoded**, not encrypted (anyone can decode and read it)
- The signature prevents **modification**, not **viewing**
- Never put sensitive data (passwords, credit cards) in JWT
- Always verify the signature before trusting the payload

## Using the jsonwebtoken Library

In production, use the `jsonwebtoken` library instead of manual creation:

```javascript
const jwt = require('jsonwebtoken');

// Create token
const token = jwt.sign(
  { userId: 123, email: 'user@example.com' },
  'my-secret-key',
  { expiresIn: '1h' }
);

// Verify token
try {
  const decoded = jwt.verify(token, 'my-secret-key');
  console.log(decoded);
} catch (err) {
  console.error('Invalid token');
}
```

This handles all the encoding, signing, and verification automatically!
