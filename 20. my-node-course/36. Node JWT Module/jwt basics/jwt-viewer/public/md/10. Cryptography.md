# Cryptography

## What is Cryptography?

Cryptography is the practice of **securing information** by transforming it into an unreadable format (encryption) that can only be converted back to readable format (decryption) by authorized parties.

## Core Concepts

### Plaintext vs Ciphertext
- **Plaintext**: Original, readable data
- **Ciphertext**: Encrypted, unreadable data
- **Key**: Secret value used to encrypt/decrypt

```
Plaintext: "Hello World"
    ↓ (encrypt with key)
Ciphertext: "X7$9mK#2pQ@"
    ↓ (decrypt with key)
Plaintext: "Hello World"
```

## Types of Cryptography

### 1. Symmetric Encryption
**Same key** for encryption and decryption.

```javascript
const crypto = require('crypto');

// Encrypt
function encrypt(text, key) {
  const iv = crypto.randomBytes(16);
  const cipher = crypto.createCipheriv('aes-256-cbc', Buffer.from(key), iv);
  let encrypted = cipher.update(text, 'utf8', 'hex');
  encrypted += cipher.final('hex');
  return iv.toString('hex') + ':' + encrypted;
}

// Decrypt
function decrypt(encryptedText, key) {
  const parts = encryptedText.split(':');
  const iv = Buffer.from(parts[0], 'hex');
  const encrypted = parts[1];
  const decipher = crypto.createDecipheriv('aes-256-cbc', Buffer.from(key), iv);
  let decrypted = decipher.update(encrypted, 'hex', 'utf8');
  decrypted += decipher.final('utf8');
  return decrypted;
}

// Usage
const key = crypto.randomBytes(32); // 256-bit key
const encrypted = encrypt('Secret Message', key);
const decrypted = decrypt(encrypted, key);

console.log('Encrypted:', encrypted);
console.log('Decrypted:', decrypted);
```

**Use Cases:**
- File encryption
- Database encryption
- Secure communication (when key is shared securely)

**Common Algorithms:** AES, DES, 3DES

---

### 2. Asymmetric Encryption (Public Key Cryptography)
**Two keys**: public key (encrypt) and private key (decrypt).

```javascript
const crypto = require('crypto');

// Generate key pair
const { publicKey, privateKey } = crypto.generateKeyPairSync('rsa', {
  modulusLength: 2048,
});

// Encrypt with public key
const message = 'Secret Message';
const encrypted = crypto.publicEncrypt(publicKey, Buffer.from(message));

// Decrypt with private key
const decrypted = crypto.privateDecrypt(privateKey, encrypted);

console.log('Encrypted:', encrypted.toString('base64'));
console.log('Decrypted:', decrypted.toString('utf8'));
```

**Use Cases:**
- SSL/TLS (HTTPS)
- Digital signatures
- Secure key exchange

**Common Algorithms:** RSA, ECC, Diffie-Hellman

---

### 3. Hashing
**One-way transformation** - cannot be reversed.

```javascript
const crypto = require('crypto');

// Hash a password
const password = 'myPassword123';
const hash = crypto.createHash('sha256').update(password).digest('hex');

console.log('Password:', password);
console.log('Hash:', hash);

// Verify password
const inputPassword = 'myPassword123';
const inputHash = crypto.createHash('sha256').update(inputPassword).digest('hex');

if (hash === inputHash) {
  console.log('Password matches!');
}
```

**Use Cases:**
- Password storage
- Data integrity verification
- Digital signatures

**Common Algorithms:** SHA-256, SHA-512, MD5 (deprecated)

---

### 4. Salted Hashing
Adding **random data (salt)** to prevent rainbow table attacks.

```javascript
const crypto = require('crypto');

// Hash password with salt
function hashPassword(password) {
  const salt = crypto.randomBytes(16).toString('hex');
  const hash = crypto.pbkdf2Sync(password, salt, 1000, 64, 'sha512').toString('hex');
  return { salt, hash };
}

// Verify password
function verifyPassword(password, salt, hash) {
  const hashVerify = crypto.pbkdf2Sync(password, salt, 1000, 64, 'sha512').toString('hex');
  return hash === hashVerify;
}

// Usage
const { salt, hash } = hashPassword('myPassword123');
console.log('Salt:', salt);
console.log('Hash:', hash);

const isValid = verifyPassword('myPassword123', salt, hash);
console.log('Valid:', isValid);
```

**Use Cases:**
- Secure password storage
- User authentication

## Real-World Examples

### Password Storage (bcrypt)
```javascript
const bcrypt = require('bcrypt');

// Hash password
async function signup(password) {
  const saltRounds = 10;
  const hash = await bcrypt.hash(password, saltRounds);
  // Store hash in database
  return hash;
}

// Verify password
async function login(password, storedHash) {
  const match = await bcrypt.compare(password, storedHash);
  return match; // true or false
}
```

### JWT (JSON Web Tokens)
```javascript
const jwt = require('jsonwebtoken');

// Sign (create) token
const token = jwt.sign(
  { userId: 123, email: 'user@example.com' },
  'secret-key',
  { expiresIn: '1h' }
);

// Verify token
try {
  const decoded = jwt.verify(token, 'secret-key');
  console.log('User ID:', decoded.userId);
} catch (err) {
  console.log('Invalid token');
}
```

### HTTPS (SSL/TLS)
```
Browser                          Server
   |                                |
   |------ Public Key Request ----->|
   |<----- Public Key + Cert -------|
   |                                |
   | (Encrypts session key          |
   |  with server's public key)     |
   |                                |
   |------ Encrypted Session Key -->|
   |                                |
   | (Server decrypts with          |
   |  private key)                  |
   |                                |
   |<==== Encrypted Communication ==>|
```

## Key Differences

| Type | Reversible? | Keys | Speed | Use Case |
|------|-------------|------|-------|----------|
| Symmetric | ✅ Yes | 1 (shared) | Fast | Bulk data encryption |
| Asymmetric | ✅ Yes | 2 (public/private) | Slow | Key exchange, signatures |
| Hashing | ❌ No | 0 | Fast | Passwords, integrity |

---

## Security Best Practices

1. **Never store passwords in plaintext** - Always hash with salt
2. **Use bcrypt/argon2 for passwords** - Not plain SHA-256
3. **Use HTTPS** - Encrypts data in transit
4. **Keep keys secret** - Never commit to version control
5. **Use strong keys** - Minimum 256-bit for symmetric, 2048-bit for RSA
6. **Update algorithms** - Avoid MD5, SHA-1 (deprecated)
7. **Use established libraries** - Don't roll your own crypto

---

## Common Pitfalls

```javascript
// ❌ BAD - Storing plain password
user.password = 'myPassword123';

// ❌ BAD - Using weak hash
const hash = crypto.createHash('md5').update(password).digest('hex');

// ❌ BAD - No salt
const hash = crypto.createHash('sha256').update(password).digest('hex');

// ✅ GOOD - Using bcrypt with salt
const hash = await bcrypt.hash(password, 10);
```

---

## Summary

Cryptography protects data through:
- **Encryption** - Makes data unreadable (reversible)
- **Hashing** - Creates unique fingerprints (irreversible)
- **Digital signatures** - Verifies authenticity

Choose the right tool:
- Passwords → bcrypt/argon2
- Data storage → AES (symmetric)
- Communication → RSA/TLS (asymmetric)
- Integrity → SHA-256 (hashing)
