# Hashing

## What is Hashing?

Hashing is a process that converts input data (of any size) into a fixed-size string of characters, called a hash.

The output is typically a unique fingerprint of the input data.

## Key Properties

- **Deterministic**: Same input always produces the same hash
- **Fixed size**: Output is always the same length regardless of input size
- **One-way**: Cannot reverse a hash back to the original input
- **Unique**: Different inputs should produce different hashes (collision-resistant)

## Simple Examples

### Example 1: Password Storage

```javascript
// Instead of storing: "myPassword123"
// Store the hash: "5f4dcc3b5aa765d61d8327deb882cf99"

// When user logs in:
// 1. Hash their entered password
// 2. Compare hashes (not actual passwords)
```

### Example 2: Data Integrity

```python
# Original file hash
file_hash = "a1b2c3d4e5f6"

# After download, hash the file again
downloaded_hash = "a1b2c3d4e5f6"

# If hashes match, file wasn't corrupted
if file_hash == downloaded_hash:
    print("File is intact!")
```

### Example 3: Hash Table (Dictionary)

```python
# Hash function converts keys to array indices
hash_table = {}

# "apple" → hash → index 3
hash_table["apple"] = 5

# "banana" → hash → index 7
hash_table["banana"] = 10

# Fast lookup: O(1) time complexity
print(hash_table["apple"])  # 5
```

## Common Hash Functions

- **MD5**: Fast but not secure (128-bit)
- **SHA-1**: Deprecated for security (160-bit)
- **SHA-256**: Secure, widely used (256-bit)
- **bcrypt**: Designed for passwords (slow by design)

## Real-World Uses

1. **Password storage** - Store hashed passwords, not plain text
2. **File verification** - Check if files were modified
3. **Blockchain** - Link blocks together securely
4. **Hash tables** - Fast data lookup in programming
5. **Digital signatures** - Verify document authenticity


## Is Hashing Encryption?

No, hashing is **NOT encryption**. They are fundamentally different.

### Key Differences

**Hashing**
- **One-way**: Cannot be reversed
- **No key**: No secret needed
- **Same input = same output**: Deterministic
- **Fixed length output**: Always same size
- **Purpose**: Verify integrity, store passwords

**Encryption**
- **Two-way**: Can be decrypted
- **Requires key**: Secret key needed
- **Same input = different output**: With different keys/IVs
- **Variable length output**: Depends on input
- **Purpose**: Hide data temporarily

### Visual Comparison

```javascript
const crypto = require('crypto');

// HASHING - ONE WAY (cannot reverse)
const password = 'myPassword123';
const hash = crypto.createHash('sha256').update(password).digest('hex');
console.log('Hash:', hash);
// Output: ef92b778bafe771e89245b89ecbc08a44a4e166c06659911881f383d4473e94f

// ❌ CANNOT get back "myPassword123" from the hash
// You can only compare hashes:
const inputHash = crypto.createHash('sha256').update('myPassword123').digest('hex');
console.log('Match:', hash === inputHash); // true

// ENCRYPTION - TWO WAY (can decrypt)
const key = crypto.randomBytes(32);
const iv = crypto.randomBytes(16);
const cipher = crypto.createCipheriv('aes-256-cbc', key, iv);
let encrypted = cipher.update(password, 'utf8', 'hex');
encrypted += cipher.final('hex');
console.log('Encrypted:', encrypted);

// ✅ CAN decrypt back to "myPassword123"
const decipher = crypto.createDecipheriv('aes-256-cbc', key, iv);
let decrypted = decipher.update(encrypted, 'hex', 'utf8');
decrypted += decipher.final('utf8');
console.log('Decrypted:', decrypted); // myPassword123
```

### When to Use Each

**Use Hashing For:**
```javascript
// ✅ Password storage
const bcrypt = require('bcrypt');
const hash = await bcrypt.hash(password, 10);
// Store hash in database, never the password

// ✅ Data integrity
const fileHash = crypto.createHash('sha256').update(fileData).digest('hex');
// Verify file hasn't been tampered with
```

**Use Encryption For:**
```javascript
// ✅ Sensitive data that needs to be retrieved
const encryptedCreditCard = encrypt(creditCardNumber, key);
// Can decrypt later when needed

// ✅ Secure communication
const encryptedMessage = encrypt(message, sharedKey);
// Recipient can decrypt with same key
```

### Common Misconception

```javascript
// ❌ WRONG - "Encrypting" a password with hash
const "encrypted" = crypto.createHash('sha256').update(password).digest('hex');
// This is hashing, not encryption!

// ❌ WRONG - Trying to "decrypt" a hash
// Impossible! Hashes cannot be reversed

// ✅ RIGHT - Hashing a password
const hash = await bcrypt.hash(password, 10);
// Later: verify with bcrypt.compare(inputPassword, hash)
```

### Summary Table

| Feature | Hashing | Encryption |
|---------|---------|------------|
| Reversible? | ❌ No | ✅ Yes |
| Key needed? | ❌ No | ✅ Yes |
| Use case | Passwords, integrity | Data protection |
| Example | SHA-256, bcrypt | AES, RSA |

**Bottom line**: 
- **Hash** = One-way transformation (like shredding paper)
- **Encrypt** = Two-way transformation (like locking in a safe)
