# Shell Scripts vs JS/Python Scripts

&nbsp;

Shell scripts (Bash, Zsh) are written for the terminal itself.

They are great for automating system tasks like moving files or running commands.

```bash
#!/bin/bash
echo "Hello from a shell script"
```

JS and Python scripts run inside their own runtime (Node or Python).

They are better suited for building applications, APIs, and complex logic.

```bash
node app.js
python app.py
```

Shell scripts glue commands together. JS and Python scripts build things.
