# MQL Categories

## How MQL Works (The Flow)

1. You write a MQL query (a method call with a filter/update document)
2. The database receives the query
3. The database parses the query and determines the execution plan
4. The database executes the query (using indexes if available)
5. The database returns the results as documents

## MQL Operation Categories

| Category | Purpose | Methods |
|---|---|---|
| **CRUD** | Create, read, update, delete documents | insertOne, find, updateOne, deleteOne |
| **Aggregation** | Data processing and analysis | aggregate (pipeline stages) |
| **Index** | Define and manage indexes | createIndex, dropIndex |
| **Administration** | Manage collections and databases | createCollection, drop, renameCollection |

## Query Operators

| Category | Purpose | Operators |
|---|---|---|
| **Comparison** | Compare values | $eq, $ne, $gt, $gte, $lt, $lte, $in, $nin |
| **Logical** | Combine conditions | $and, $or, $not, $nor |
| **Element** | Check field existence/type | $exists, $type |
| **Array** | Query array fields | $all, $elemMatch, $size |
| **Evaluation** | Pattern matching and expressions | $regex, $expr, $where |

## Update Operators

| Category | Purpose | Operators |
|---|---|---|
| **Field** | Modify field values | $set, $unset, $rename, $inc, $min, $max |
| **Array** | Modify arrays | $push, $pull, $pop, $addToSet |
| **Bitwise** | Bitwise operations | $bit |
