# What Is A Database?

## The Short Answer

A database is an organized collection of data that can be easily accessed, managed, and updated.

## Database as a Computer

In the physical sense, a database is a **dedicated computer** (or set of computers) whose primary job is to store and retrieve data.

These machines are optimized for:

- Fast read/write operations
- Large storage capacity
- High availability (always on)
- Data redundancy and backup

When you hear "database server," think of an actual machine sitting in a data center whose sole purpose is to hold data and respond to requests for that data.
