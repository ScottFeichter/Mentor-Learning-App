# LocalStrategy

LocalStrategy is a Passport.js authentication strategy for authenticating users with a username and password stored in your own database (as opposed to third-party OAuth providers).

## What is LocalStrategy?

LocalStrategy handles the traditional "local" authentication where:
- Credentials are stored in your application's database
- Users log in with username/email and password
- You control the entire authentication process

## How LocalStrategy Relates to Cookie-Based Authentication

LocalStrategy handles **authentication** (verifying credentials), while cookies handle **session persistence** (remembering the user). They work together:

```
1. User submits credentials → LocalStrategy verifies them
2. If valid → Passport serializes user ID into session
3. Session ID stored in cookie → Sent to browser
4. Browser sends cookie with each request → Server deserializes user
5. User stays logged in across requests
```

## Complete Example

```javascript
const passport = require('passport');
const LocalStrategy = require('passport-local').Strategy;
const session = require('express-session');
const bcrypt = require('bcrypt');

// Configure session middleware (creates cookies)
app.use(session({
  secret: 'your-secret-key',
  resave: false,
  saveUninitialized: false,
  cookie: { 
    secure: false, // set true in production with HTTPS
    httpOnly: true,
    maxAge: 24 * 60 * 60 * 1000 // 24 hours
  }
}));

app.use(passport.initialize());
app.use(passport.session());

// Configure LocalStrategy - verifies username/password
passport.use(new LocalStrategy(
  async (username, password, done) => {
    try {
      // Find user in database
      const user = await User.findOne({ username });
      if (!user) {
        return done(null, false, { message: 'Incorrect username' });
      }
      
      // Verify password
      const isValid = await bcrypt.compare(password, user.password);
      if (!isValid) {
        return done(null, false, { message: 'Incorrect password' });
      }
      
      // Success - return user object
      return done(null, user);
    } catch (err) {
      return done(err);
    }
  }
));

// Serialize user to session (stores user.id in cookie)
passport.serializeUser((user, done) => {
  done(null, user.id);
});

// Deserialize user from session (retrieves full user from cookie's user.id)
passport.deserializeUser(async (id, done) => {
  try {
    const user = await User.findById(id);
    done(null, user);
  } catch (err) {
    done(err);
  }
});

// Login route - uses LocalStrategy
app.post('/login', 
  passport.authenticate('local', {
    successRedirect: '/dashboard',
    failureRedirect: '/login',
    failureFlash: true
  })
);

// Or with custom callback
app.post('/login', (req, res, next) => {
  passport.authenticate('local', (err, user, info) => {
    if (err) return next(err);
    if (!user) return res.status(401).json({ message: info.message });
    
    req.login(user, (err) => {
      if (err) return next(err);
      return res.json({ message: 'Logged in', user });
    });
  })(req, res, next);
});

// Protected route - cookie automatically sent, user available
app.get('/dashboard', (req, res) => {
  if (!req.isAuthenticated()) {
    return res.redirect('/login');
  }
  res.send(`Welcome ${req.user.username}`);
});

// Logout - clears session and cookie
app.post('/logout', (req, res) => {
  req.logout((err) => {
    if (err) return next(err);
    res.redirect('/');
  });
});
```

## Configuration Options

LocalStrategy accepts options to customize field names:

```javascript
passport.use(new LocalStrategy(
  {
    usernameField: 'email',    // default is 'username'
    passwordField: 'password',  // default is 'password'
    passReqToCallback: true     // pass req to verify callback
  },
  async (req, email, password, done) => {
    // req is now available
    // use email instead of username
  }
));
```

## Key Points

- **LocalStrategy** = Verifies credentials on login
- **Cookies** = Store session ID to keep user logged in
- **serializeUser** = Converts user object to ID for cookie storage
- **deserializeUser** = Converts ID back to user object on each request
- Together they enable stateful authentication where users stay logged in across requests

## Flow Diagram

```
Login Request
    ↓
LocalStrategy verifies credentials
    ↓
serializeUser(user) → stores user.id in session
    ↓
Session ID saved in cookie → sent to browser
    ↓
Subsequent Requests
    ↓
Cookie sent automatically with request
    ↓
deserializeUser(id) → retrieves full user
    ↓
req.user available in routes
```
