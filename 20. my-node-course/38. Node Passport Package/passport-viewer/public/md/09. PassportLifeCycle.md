# Passport Lifecycle

In the context of Passport.js (the Node.js authentication middleware), the **Passport Lifecycle** refers to the flow of authentication requests through the middleware.

## Authentication Request Lifecycle

1. **User initiates authentication** - User submits credentials (login form, OAuth callback, etc.)

2. **Strategy execution** - Passport invokes the configured strategy (LocalStrategy, OAuth, JWT, etc.)

3. **Verification callback** - Your verify function validates credentials and returns user object or false

4. **Serialization** - `serializeUser()` converts user object to an identifier (usually user ID) stored in session

5. **Session storage** - User ID is saved in the session cookie

6. **Subsequent requests** - On each request, Passport checks for session data

7. **Deserialization** - `deserializeUser()` converts stored ID back to full user object and attaches to `req.user`

8. **Logout** - `req.logout()` clears session data

## Minimal Example

```javascript
// 1. Configure strategy
passport.use(new LocalStrategy((username, password, done) => {
  // 3. Verify credentials
  User.findOne({ username }, (err, user) => {
    if (!user || !user.validPassword(password)) return done(null, false);
    return done(null, user);
  });
}));

// 4. Serialize user to session
passport.serializeUser((user, done) => {
  done(null, user.id);
});

// 7. Deserialize user from session
passport.deserializeUser((id, done) => {
  User.findById(id, (err, user) => {
    done(err, user);
  });
});

// 2. Authenticate route
app.post('/login', passport.authenticate('local'), (req, res) => {
  res.json({ user: req.user });
});

// 6. Protected route - req.user available
app.get('/profile', (req, res) => {
  if (!req.isAuthenticated()) return res.status(401).send('Unauthorized');
  res.json(req.user);
});

// 8. Logout
app.post('/logout', (req, res) => {
  req.logout(() => res.send('Logged out'));
});
```

The key is understanding that serialize/deserialize happen automatically on every request once authentication succeeds, making `req.user` available throughout your app.
