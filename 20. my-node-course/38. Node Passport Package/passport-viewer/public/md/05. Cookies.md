# Cookies

A cookie is a small piece of data (max 4KB) that a server sends to a user's browser. The browser stores it and automatically sends it back with subsequent requests to the same server.

## Why Cookies Exist

HTTP is stateless - each request is independent. Cookies solve this by allowing the server to "remember" information about the client across multiple requests.

## How Cookies Work

```
1. Client makes request → GET /login
2. Server sends response with cookie → Set-Cookie: sessionId=abc123
3. Browser stores cookie
4. Client makes another request → GET /profile
5. Browser automatically includes cookie → Cookie: sessionId=abc123
6. Server reads cookie and knows who the client is
```

## Cookie Structure

```
Set-Cookie: name=value; Domain=example.com; Path=/; Expires=Wed, 16 Jan 2025 10:00:00 GMT; HttpOnly; Secure; SameSite=Strict
```

**Components:**
- **name=value** - The actual data
- **Domain** - Which domain can receive the cookie
- **Path** - Which paths can receive the cookie
- **Expires/Max-Age** - When the cookie expires
- **HttpOnly** - Prevents JavaScript access
- **Secure** - Only sent over HTTPS
- **SameSite** - Controls cross-site sending

## Setting Cookies in Express

```javascript
const express = require('express');
const app = express();

// Simple cookie
app.get('/set-cookie', (req, res) => {
  res.cookie('username', 'john', { maxAge: 900000 });
  res.send('Cookie set');
});

// Cookie with options
app.get('/set-secure-cookie', (req, res) => {
  res.cookie('sessionId', 'abc123', {
    httpOnly: true,      // No JavaScript access
    secure: true,        // HTTPS only
    maxAge: 3600000,     // 1 hour
    sameSite: 'strict'   // CSRF protection
  });
  res.send('Secure cookie set');
});

// Reading cookies (requires cookie-parser)
const cookieParser = require('cookie-parser');
app.use(cookieParser());

app.get('/read-cookie', (req, res) => {
  const username = req.cookies.username;
  res.send(`Username: ${username}`);
});

// Deleting cookies
app.get('/delete-cookie', (req, res) => {
  res.clearCookie('username');
  res.send('Cookie deleted');
});
```

## Cookie Attributes Explained

### httpOnly
Prevents client-side JavaScript from accessing the cookie.

```javascript
res.cookie('token', 'secret', { httpOnly: true });

// In browser console:
document.cookie; // Won't show httpOnly cookies
```

**Use for:** Session IDs, authentication tokens

### secure
Cookie only sent over HTTPS, not HTTP.

```javascript
res.cookie('token', 'secret', { secure: true });
```

**Use in:** Production with HTTPS

### sameSite
Controls when cookies are sent with cross-site requests.

```javascript
// Strict - never sent on cross-site requests
res.cookie('token', 'secret', { sameSite: 'strict' });

// Lax - sent on top-level navigation (default)
res.cookie('token', 'secret', { sameSite: 'lax' });

// None - always sent (requires secure: true)
res.cookie('token', 'secret', { sameSite: 'none', secure: true });
```

**Values:**
- `strict` - Best security, may break some workflows
- `lax` - Good balance (default)
- `none` - Use for cross-domain cookies

### maxAge vs expires

```javascript
// maxAge - milliseconds from now
res.cookie('token', 'secret', { maxAge: 3600000 }); // 1 hour

// expires - specific date
res.cookie('token', 'secret', { 
  expires: new Date(Date.now() + 3600000) 
});
```

### domain and path

```javascript
// Available to all subdomains
res.cookie('token', 'secret', { domain: '.example.com' });

// Only available to /admin paths
res.cookie('token', 'secret', { path: '/admin' });
```

## Types of Cookies

### Session Cookies
Deleted when browser closes (no expiration set).

```javascript
res.cookie('temp', 'value'); // No maxAge or expires
```

### Persistent Cookies
Remain until expiration date.

```javascript
res.cookie('remember', 'value', { maxAge: 30 * 24 * 60 * 60 * 1000 }); // 30 days
```

### First-Party Cookies
Set by the domain you're visiting.

```javascript
// On example.com
res.cookie('user', 'john'); // First-party cookie
```

### Third-Party Cookies
Set by a different domain (ads, analytics).

```javascript
// On example.com, but set by analytics.com
// Being phased out by browsers
```

## Cookie Security

### XSS Protection
Use `httpOnly` to prevent JavaScript access.

```javascript
// Vulnerable
res.cookie('token', 'secret'); // JavaScript can steal this

// Protected
res.cookie('token', 'secret', { httpOnly: true }); // Safe from XSS
```

### CSRF Protection
Use `sameSite` to prevent cross-site requests.

```javascript
res.cookie('sessionId', 'abc', { 
  sameSite: 'strict',  // Prevents CSRF
  httpOnly: true 
});
```

### Man-in-the-Middle Protection
Use `secure` to require HTTPS.

```javascript
res.cookie('token', 'secret', { 
  secure: true,  // Only sent over HTTPS
  httpOnly: true 
});
```

## Signed Cookies

Signed cookies detect tampering.

```javascript
const cookieParser = require('cookie-parser');
app.use(cookieParser('secret-key'));

// Set signed cookie
app.get('/set', (req, res) => {
  res.cookie('user', 'john', { signed: true });
  res.send('Signed cookie set');
});

// Read signed cookie
app.get('/read', (req, res) => {
  const user = req.signedCookies.user; // Use signedCookies, not cookies
  res.send(`User: ${user}`);
});
```

## Cookie Limitations

- **Size limit:** 4KB per cookie
- **Number limit:** ~50 cookies per domain
- **Total limit:** ~4KB total per domain
- **Sent with every request:** Increases bandwidth
- **Browser-specific:** Users can disable cookies

## Common Use Cases

### 1. Session Management
```javascript
res.cookie('sessionId', 'abc123', {
  httpOnly: true,
  secure: true,
  sameSite: 'strict'
});
```

### 2. Personalization
```javascript
res.cookie('theme', 'dark', { maxAge: 365 * 24 * 60 * 60 * 1000 });
res.cookie('language', 'en', { maxAge: 365 * 24 * 60 * 60 * 1000 });
```

### 3. Tracking
```javascript
res.cookie('visitCount', visits, { maxAge: 365 * 24 * 60 * 60 * 1000 });
```

### 4. Remember Me
```javascript
res.cookie('rememberToken', token, { 
  maxAge: 30 * 24 * 60 * 60 * 1000,  // 30 days
  httpOnly: true,
  secure: true
});
```

## Best Practices

1. **Use httpOnly for sensitive data** - Prevents XSS
2. **Use secure in production** - Requires HTTPS
3. **Set sameSite** - Prevents CSRF
4. **Keep cookies small** - 4KB limit
5. **Set appropriate expiration** - Don't keep forever
6. **Use signed cookies** - Detect tampering
7. **Minimize cookie count** - Performance impact
8. **Don't store sensitive data** - Use session IDs instead

## Cookie vs Session vs Token

| Feature | Cookie | Session | Token |
|---------|--------|---------|-------|
| Storage | Client | Server | Client |
| Size | 4KB | Unlimited | Medium |
| Security | Moderate | High | Moderate |
| Auto-sent | Yes | Via cookie | No |
| Stateless | Yes | No | Yes |

## Complete Example

```javascript
const express = require('express');
const cookieParser = require('cookie-parser');

const app = express();
app.use(cookieParser('secret-key'));

// Set multiple cookies
app.get('/login', (req, res) => {
  // Session cookie
  res.cookie('sessionId', 'abc123', {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'strict'
  });
  
  // Preference cookie
  res.cookie('theme', 'dark', {
    maxAge: 365 * 24 * 60 * 60 * 1000
  });
  
  res.send('Logged in');
});

// Read cookies
app.get('/profile', (req, res) => {
  const sessionId = req.cookies.sessionId;
  const theme = req.cookies.theme;
  
  if (!sessionId) {
    return res.status(401).send('Not authenticated');
  }
  
  res.send(`Session: ${sessionId}, Theme: ${theme}`);
});

// Clear cookies
app.get('/logout', (req, res) => {
  res.clearCookie('sessionId');
  res.send('Logged out');
});

app.listen(3000);
```

## Key Takeaways

- Cookies are small data pieces stored by the browser
- Automatically sent with every request to the same domain
- Essential for maintaining state in stateless HTTP
- Security flags (httpOnly, secure, sameSite) are critical
- Used primarily for session management and personalization
- Limited to 4KB per cookie
