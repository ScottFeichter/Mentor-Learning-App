# Common Issues and Troubleshooting

A guide to common authentication problems and their solutions.

## Session Issues

### Issue: req.user is undefined
**Symptoms:** User logs in successfully but req.user is undefined on subsequent requests.

**Causes:**
1. Forgot to configure serialize/deserialize
2. Session middleware not configured
3. passport.session() not called

**Solution:**
```javascript
// Make sure all of these are present
app.use(session({ ... }));
app.use(passport.initialize());
app.use(passport.session());

passport.serializeUser((user, done) => {
  done(null, user.id);
});

passport.deserializeUser(async (id, done) => {
  const user = await User.findById(id);
  done(null, user);
});
```

### Issue: Session not persisting
**Symptoms:** User has to log in on every request.

**Causes:**
1. Cookie not being sent/received
2. Session store not configured properly
3. CORS issues

**Solution:**
```javascript
// Server-side
app.use(session({
  secret: 'secret',
  resave: false,
  saveUninitialized: false,
  cookie: {
    httpOnly: true,
    secure: false, // Set true only with HTTPS
    sameSite: 'lax'
  }
}));

// Client-side (fetch)
fetch('/api/profile', {
  credentials: 'include' // Important!
});
```

### Issue: Session expires immediately
**Causes:**
1. maxAge set too low
2. Clock skew between client/server

**Solution:**
```javascript
app.use(session({
  cookie: {
    maxAge: 24 * 60 * 60 * 1000 // 24 hours, not 24 seconds!
  }
}));
```

## Passport Issues

### Issue: "Failed to serialize user into session"
**Symptoms:** Error after successful authentication.

**Cause:** serializeUser not configured or returning wrong value.

**Solution:**
```javascript
// Make sure this is configured
passport.serializeUser((user, done) => {
  done(null, user.id); // Must call done()
});
```

### Issue: "Failed to deserialize user out of session"
**Symptoms:** Error on subsequent requests after login.

**Causes:**
1. User deleted from database
2. deserializeUser not finding user
3. Error in deserializeUser

**Solution:**
```javascript
passport.deserializeUser(async (id, done) => {
  try {
    const user = await User.findById(id);
    if (!user) {
      return done(null, false); // User not found
    }
    done(null, user);
  } catch (err) {
    done(err); // Handle errors
  }
});
```

### Issue: Authentication always fails
**Causes:**
1. Strategy not configured
2. Wrong field names
3. Password comparison failing

**Solution:**
```javascript
// Check strategy configuration
passport.use(new LocalStrategy(
  {
    usernameField: 'email', // Match your form field names
    passwordField: 'password'
  },
  async (email, password, done) => {
    try {
      const user = await User.findOne({ email });
      if (!user) {
        return done(null, false, { message: 'User not found' });
      }
      
      // Make sure password comparison is correct
      const isValid = await bcrypt.compare(password, user.password);
      if (!isValid) {
        return done(null, false, { message: 'Wrong password' });
      }
      
      return done(null, user);
    } catch (err) {
      return done(err);
    }
  }
));
```

## Password Issues

### Issue: Passwords not hashing
**Symptoms:** Plain text passwords in database.

**Cause:** Forgot to hash before saving.

**Solution:**
```javascript
// Use pre-save hook
userSchema.pre('save', async function(next) {
  if (!this.isModified('password')) return next();
  this.password = await bcrypt.hash(this.password, 10);
  next();
});

// Or hash manually
const hashedPassword = await bcrypt.hash(password, 10);
const user = new User({ username, password: hashedPassword });
```

### Issue: Password comparison always fails
**Causes:**
1. Comparing hashes directly
2. Password not hashed
3. Wrong bcrypt method

**Solution:**
```javascript
// Wrong
if (user.password === password) { }

// Correct
const isValid = await bcrypt.compare(password, user.password);
if (isValid) { }
```

### Issue: bcrypt.compare() returns false for correct password
**Cause:** Password hashed multiple times.

**Solution:**
```javascript
// Check if password is already hashed
userSchema.pre('save', async function(next) {
  if (!this.isModified('password')) return next(); // Important!
  this.password = await bcrypt.hash(this.password, 10);
  next();
});
```

## CORS Issues

### Issue: Cookies not being sent cross-origin
**Symptoms:** Authentication works on same domain but not cross-origin.

**Solution:**
```javascript
// Server-side
const cors = require('cors');

app.use(cors({
  origin: 'http://localhost:3001', // Your frontend URL
  credentials: true // Important!
}));

app.use(session({
  cookie: {
    sameSite: 'none', // Required for cross-origin
    secure: true // Required with sameSite: 'none'
  }
}));

// Client-side
fetch('http://localhost:3000/api/profile', {
  credentials: 'include' // Important!
});
```

## Database Issues

### Issue: "User already exists" on first registration
**Cause:** Unique index on username/email.

**Solution:**
```javascript
// Drop existing indexes if needed
await User.collection.dropIndexes();

// Or handle duplicate key error
try {
  await user.save();
} catch (err) {
  if (err.code === 11000) {
    return res.status(400).json({ message: 'User already exists' });
  }
  throw err;
}
```

### Issue: Cannot connect to MongoDB
**Symptoms:** "MongoNetworkError" or connection timeout.

**Solution:**
```javascript
// Check connection string
mongoose.connect('mongodb://localhost:27017/myapp', {
  useNewUrlParser: true,
  useUnifiedTopology: true
})
.then(() => console.log('Connected'))
.catch(err => console.error('Connection error:', err));

// Make sure MongoDB is running
// mongod --dbpath /path/to/data
```

## Middleware Order Issues

### Issue: req.user undefined in routes
**Cause:** Middleware in wrong order.

**Solution:**
```javascript
// Correct order
app.use(express.json());
app.use(session({ ... }));
app.use(passport.initialize());
app.use(passport.session());
// Then your routes
app.use('/api', routes);
```

### Issue: Session not saving
**Cause:** Session middleware after routes.

**Solution:**
```javascript
// Wrong
app.use('/api', routes);
app.use(session({ ... }));

// Correct
app.use(session({ ... }));
app.use('/api', routes);
```

## Production Issues

### Issue: Secure cookies not working
**Cause:** secure: true without HTTPS.

**Solution:**
```javascript
app.use(session({
  cookie: {
    secure: process.env.NODE_ENV === 'production', // Only in production
    httpOnly: true
  }
}));
```

### Issue: Session store memory leak
**Cause:** Using default memory store in production.

**Solution:**
```javascript
// Use persistent store
const MongoStore = require('connect-mongo');

app.use(session({
  store: MongoStore.create({
    mongoUrl: process.env.MONGODB_URI
  })
}));
```

## Debugging Tips

```javascript

  // ... config

  console.log('Authenticated:', req.isAuthenticated());

```

```bash
  -b cookies.txt
```

## Common Error Messages

### "Cannot read property 'id' of undefined"
**Cause:** req.user is undefined.
**Fix:** Check serialize/deserialize configuration.

### "Secret option required for sessions"
**Cause:** No secret in session config.
**Fix:** Add secret: 'your-secret-key'.

### "req.login is not a function"
**Cause:** passport.initialize() not called.
**Fix:** Add app.use(passport.initialize()).

### "MongoError: E11000 duplicate key error"
**Cause:** Trying to create user with existing username/email.
**Fix:** Check if user exists before creating.

### "UnauthorizedError: No authorization token was found"
**Cause:** JWT token not sent or wrong format.
**Fix:** Send token in Authorization header: "Bearer <token>".

## Getting Help

1. **Check error message carefully**
2. **Console.log req.session and req.user**
3. **Verify middleware order**
4. **Test with curl to isolate frontend issues**
5. **Check browser Network tab for cookies**
6. **Enable debug logging**
7. **Search error message on Stack Overflow**
8. **Check Passport.js documentation**

## Key Takeaways

- Most issues are configuration problems
- Middleware order matters
- Always configure serialize/deserialize
- Use bcrypt.compare() for passwords
- Check cookies in browser dev tools
- Enable debug logging when stuck
- Test with curl to isolate issues
- Read error messages carefully
