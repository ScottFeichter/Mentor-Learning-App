# Back In The Day

## You've Never Seen Raw HTML in the Browser

Even in the early 1990s when the web was created, you never saw the "actual HTML" in the browser window - you've always seen the **rendered version**.

From day one:
- Browser downloaded HTML
- Browser parsed it and rendered it visually
- You saw formatted text, images, links - not the raw `<html>` tags

## What Changed Over Time

### Early Web (1990s)
- Static HTML only
- No JavaScript (or very limited)
- To see changes, you had to reload the entire page from the server
- Still rendered, just simpler
- What you downloaded is what you saw

### Modern Web (2000s - Present)
- HTML + CSS + JavaScript
- DOM manipulation without reloading
- Dynamic, interactive experiences
- Still rendered, just more complex
- JavaScript changes what you see after download

## Viewing Raw HTML

You can view the raw HTML source code:
- Right-click → "View Page Source"
- Or use browser DevTools

But the main browser window has **always** shown the rendered output, never the raw tags.

## The Key Difference

**Early websites**: Mostly static - the rendered page matched the HTML file exactly

**Modern websites**: Dynamic - JavaScript modifies the DOM after download, so what you see differs from the original HTML file
