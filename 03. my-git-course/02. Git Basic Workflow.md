# Git Basic Workflow

## Setup

```bash
which git              # check if git is installed
git --version          # check version
git config --global init.defaultBranch main   # set default branch to main
git config --global user.name "<name>"        # set author name
```

## Help

```bash
git help
git help -a
git help <command>
git help git
```

## View All Repos on Machine

```bash
find ~ -name .git
```

## Basic Workflow

```bash
git init <directory>           # initialize repo (no args = current dir)
git add <directory>            # stage changes (or git add .)
git commit -m "<message>"      # commit staged snapshot
```

## Status and Diff

```bash
git status                     # list staged, unstaged, untracked files
git diff                       # show unstaged changes
git diff --staged              # show staged changes (same as --cached)
git diff --color-words         # show changes with color highlighting
```

## Discard and Unstage

```bash
git restore <file>             # discard changes in working directory
git restore --staged <file>    # unstage changes
git reset HEAD <file>          # unstage (older method)
```

## Amend, Undo, Revert

```bash
git commit --amend -m "message"    # amend most recent commit
git checkout <sha> <file>          # retrieve old version of a file
git revert <sha>                   # revert a commit (creates new commit)
```

> EDITS WHICH UNDO SHOULD BE NEW COMMITS!

## Clean Untracked Files

```bash
git clean -n     # see what would be removed (dry run)
git clean -i     # interactive steps
git clean -f     # force remove untracked files
```

## Ignore Files

Create `.gitignore` in root:
```bash
touch .gitignore
```

Add file/folder names or patterns to ignore.

## Track Empty Directories

```bash
touch .gitkeep   # git doesn't track empty dirs, this makes it non-empty
```

## Stage and Commit Shortcut

```bash
git commit -a -m "message"   # stages and commits all tracked file changes
```
