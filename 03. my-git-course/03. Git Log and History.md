# Git Log and History

## Viewing Commits

```bash
git show              # view most recent commit
git show <sha>        # view any commit
git show HEAD         # reference commit using HEAD
```

## Commit Ancestry

```bash
git show HEAD^        # parent (or HEAD~1)
git show HEAD^^       # grandparent (or HEAD~2)
git show HEAD^^^      # great-grandparent (or HEAD~3)
```

## Viewing the Commit Log

```bash
git log               # display entire commit history
git help log          # learn about options
```

Navigation: `f` forward, `b` backward, `q` quit

## Filtering the Log

```bash
git log -3                        # limit to 3 commits
git log --since=2019-01-01        # by date (--after also works)
git log --until=2019-01-01        # by date (--before also works)
git log --author="Scott"          # by author
git log --grep="Initial"          # by string (regex)
git log <SHA>..<SHA>              # by range
git log <filename>                # by file/directory changes
git log -p                        # show change sets (patches)
git log --stat                    # show statistics
```

## Formatting the Log

```bash
git log --format=oneline          # options: short, medium, full, fuller, email, raw
git log --oneline                 # compact one-line format with SHA
git log --graph                   # show as graph
git log --graph --all --oneline --decorate   # full graph view
```

## Tree-ish

A tree-ish is a directory, commit, or reference:
- SHA-1 hash
- HEAD pointer reference
- Branch reference
- Tag reference
- Ancestry

```bash
git ls-tree <tree-ish>            # list contents of a tree object
git ls-tree HEAD <path>           # specify a path
git help ls-tree                  # learn more
```

> In ls-tree: "tree" = directory, "blob" = file (binary large object)
