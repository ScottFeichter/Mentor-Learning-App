# Git Branches

## Overview

- Branches are cheap, easy to create, and easy to delete
- Try new ideas, isolate features
- ONE working directory — git swaps files to match the branch
- HEAD pointer shows the tip of the current branch

## Create Branches

```bash
git branch                        # list branches (* = current)
git branch <branch_name>          # create a branch
```

## View HEAD

```bash
cat .git/HEAD                     # where HEAD is pointing
ls -la .git/refs/heads/           # directory with references
cat .git/refs/heads/main          # content of reference
```

## Switch Branches

```bash
git checkout <branchname>         # switch to a branch
git checkout -b <newbranchname>   # create and switch
```

## Compare Branches

```bash
git diff <branch1>..<branch2>                    # compare two branches
git diff --color-words <branch1>..<branch2>      # with color
git branch --merged                              # branches merged into current
```

## Rename Branches

```bash
git branch -m [<oldname>] <newname>
```

## Delete Branches

```bash
git branch -d <branchname>       # delete (must not be on it)
git branch -D <branchname>       # force delete (unmerged commits)
```

## Reset Branches

```bash
git reset --soft <tree-ish>      # moves HEAD only
git reset --mixed <tree-ish>     # moves HEAD + changes staging (default)
git reset --hard <tree-ish>      # moves HEAD + changes staging + working dir
```

## Merge Branches

```bash
git merge <branchToBringIn>      # merge while in receiving branch
git branch --merged              # see merged branches
```

> Have a clean working directory before merging.

## Merge Conflicts

```bash
git merge --abort                # abort if conflicts arise
```

Resolve manually using conflict indicators:
```
<<<<<<HEAD
Content in current branch
===========
Content in other branch
>>>>>>><other branch>
```

## Stash Changes

```bash
git stash save <name>            # stash uncommitted changes
git stash list                   # view stash list
git stash show -p <stash@{num}>  # view a specific stash
git stash pop                    # retrieve most recent stash (deletes it)
git stash pop <stash@{num}>      # retrieve specific stash
git stash apply                  # retrieve without deleting
git stash drop <stash@{num}>     # clear specific stash
git stash clear                  # clear all stashes
```

> Use `-u` flag to include untracked files in stash.
