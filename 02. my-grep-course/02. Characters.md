# Literal Characters and Metacharacters

## Literal Characters

- `/car/` matches "car"
- `/car/` matches first three of "carnival"
- Similar to searching a word processor
- Simplest match there is

### Rules

- Searches are **case-sensitive** by default (recommended to always write regex as case sensitive)
- **Spaces are characters!** — `/car/` does NOT match "c a r"

### Standard (non-global) Matching

The earliest (leftmost) match is always preferred:
- `/zz/` matches the **first** set of z's in "pizzazz"

### Global Matching

All matches are found throughout the text:
- `/zz/g` matches **both** sets of z's in "pizzazz"

### How Matching Works

Example: `/cat/` against "The cow, camel, and cat communicated"

1. Searches `c` in first character
2. If match → searches `a` in second character
3. If match → searches `t` in third character
4. If no match → backtracks and resumes search for first character

## Metacharacters

Characters with special meaning that transform literal characters into powerful expressions.

Only a few to learn:

```
\ . * + - {} [] ^ $ | ? () : ! =
```
