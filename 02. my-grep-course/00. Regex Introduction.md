# Regular Expressions Introduction

## What are Regular Expressions?

- A set of symbols representing a text pattern
- A formal language interpreted by a regular expression processor
- Used for matching, searching, and replacing text
- Used by programming languages
- "Regex" for short

## Examples

- Test if an email is in valid format
- Search a document for "Bob" to replace with "Robert"

## Matches

Text and a regex "match" if they correctly describe each other.

## Regular Expression Engines

The regular expression processor:
- Most expressions work on any engine
- Might have added functionality
- JavaScript is a regex engine
- Most text editors have one
- Most languages have a regex engine
