# Notation, Modes, and Grep

## Notation

Regular expressions are usually written inside `//`:

```
/abc/
```

(May not need `//` depending on circumstance.)

## Flags (Modes)

| Flag | Mode | Description |
|------|------|-------------|
| (none) | Standard | `/re/` — find first match |
| g | Global | `/re/g` — find all matches |
| i | Case insensitive | `/re/i` — regardless of case |
| m | Multiline | `/re/m` — stretches across more than one line |

## Grep

`g/re/p` — **G**lobal **R**egular **E**xpression **P**rint

- The "g" used to be the global flag at the beginning
- Often used as a verb ("grep for something")
