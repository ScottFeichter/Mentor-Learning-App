# Prisma Overview

Prisma is an ORM (Object-Relational Mapping) for Node.js that simplifies database access with type safety and auto-generated queries.

## Three Main Tools

Prisma consists of three main tools:

### Prisma Schema

A declarative way to define your database structure.

- Written in a `.prisma` file
- Defines models, fields, relationships, and database connection
- Human-readable and version-controllable

### Prisma Client

An auto-generated, type-safe database client.

- Generated from your schema
- Provides autocomplete and type checking
- Handles all CRUD operations

### Prisma Migrate

Database migration and schema management.

- Tracks schema changes over time
- Generates SQL migrations automatically
- Keeps database in sync with your schema
