# PostgreSQL Terminology

A quick reference for translating common terms between SQL, Prisma, and general database concepts.

## Database Terms

| Common Term | PostgreSQL Term | Prisma Term |
|-------------|----------------|-------------|
| Database | Database | datasource |
| Table | Table | Model |
| Row/Record | Row | Record |
| Column | Column | Field |
| Primary Key | PRIMARY KEY | @id |
| Foreign Key | FOREIGN KEY / REFERENCES | @relation |
| Index | INDEX | @@index |
| Unique Constraint | UNIQUE | @unique |
| Schema | Schema | schema.prisma |
| View | View | (not directly supported) |
| Migration | ALTER TABLE / CREATE TABLE | prisma migrate |
| Seed | INSERT (initial data) | prisma db seed |

## SQL vs Prisma Operations

| SQL Operation | Prisma Method |
|---------------|---------------|
| SELECT | findMany() / findUnique() / findFirst() |
| INSERT | create() / createMany() |
| UPDATE | update() / updateMany() |
| DELETE | delete() / deleteMany() |
| WHERE | where: { } |
| ORDER BY | orderBy: { } |
| GROUP BY | groupBy() |
| LIMIT | take: n |
| OFFSET | skip: n |
| JOIN | include: { } |
| COUNT | count() |
| AVG / SUM | aggregate() |

## Data Types

| PostgreSQL Type | Prisma Type | JavaScript Type |
|-----------------|-------------|-----------------|
| INTEGER / SERIAL | Int | number |
| BIGINT | BigInt | BigInt |
| TEXT / VARCHAR | String | string |
| BOOLEAN | Boolean | boolean |
| TIMESTAMP | DateTime | Date |
| DOUBLE PRECISION | Float | number |
| JSONB | Json | object |
| UUID | String (@default(uuid())) | string |

## Key Differences from MongoDB

- **Table** (not Collection) — structured with fixed columns
- **Row** (not Document) — flat record, same shape as all other rows
- **Column** (not Field) — defined type, enforced by the database
- **Foreign Key** (not Reference) — enforced relationship between tables
- **SQL** (not MQL) — declarative query language
