# Connection Methods

## How Prisma Connects to PostgreSQL

Prisma connects to your database through a connection URL defined in your schema file and typically stored in an environment variable.

## The DATABASE_URL

```prisma
// schema.prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```

```bash
# .env file
DATABASE_URL="postgresql://username:password@host:port/database?schema=public"
```

## Connection URL Format

```
postgresql://USER:PASSWORD@HOST:PORT/DATABASE?schema=SCHEMA
```

| Component | Example | Purpose |
|-----------|---------|---------|
| Protocol | `postgresql://` | Database type |
| User | `myuser` | Database username |
| Password | `mypassword` | Database password |
| Host | `localhost` | Server address |
| Port | `5432` | PostgreSQL default port |
| Database | `myapp` | Database name |
| Schema | `?schema=public` | PostgreSQL schema (default: public) |

## Local Connection Examples

```bash
# Local PostgreSQL with default settings
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/myapp"

# Local with custom user
DATABASE_URL="postgresql://myuser:mypassword@localhost:5432/myapp?schema=public"
```

## Remote Connection Examples

```bash
# Neon
DATABASE_URL="postgresql://user:pass@ep-cool-name-123456.us-east-2.aws.neon.tech/mydb?sslmode=require"

# Supabase
DATABASE_URL="postgresql://postgres:pass@db.abcdefghijk.supabase.co:5432/postgres"

# Railway
DATABASE_URL="postgresql://postgres:pass@containers-us-west-1.railway.app:5432/railway"

# Amazon RDS
DATABASE_URL="postgresql://user:pass@mydb.abc123.us-east-1.rds.amazonaws.com:5432/mydb?sslmode=require"
```

## Connection Pooling

For serverless or high-concurrency environments, use connection pooling:

```bash
# Direct connection (for migrations)
DIRECT_URL="postgresql://user:pass@host:5432/mydb"

# Pooled connection (for application queries)
DATABASE_URL="postgresql://user:pass@host:6543/mydb?pgbouncer=true"
```

```prisma
datasource db {
  provider  = "postgresql"
  url       = env("DATABASE_URL")
  directUrl = env("DIRECT_URL")
}
```

## PrismaClient Instantiation

```javascript
const { PrismaClient } = require('@prisma/client');

// Basic
const prisma = new PrismaClient();

// With logging
const prisma = new PrismaClient({
  log: ['query', 'info', 'warn', 'error']
});

// Singleton pattern (recommended for production)
let prisma;
if (process.env.NODE_ENV === 'production') {
  prisma = new PrismaClient();
} else {
  if (!global.prisma) {
    global.prisma = new PrismaClient();
  }
  prisma = global.prisma;
}
```

## Disconnecting

```javascript
// Graceful shutdown
process.on('beforeExit', async () => {
  await prisma.$disconnect();
});
```

## Testing the Connection

```javascript
async function testConnection() {
  try {
    await prisma.$connect();
    console.log('Database connected successfully');
  } catch (error) {
    console.error('Database connection failed:', error);
    process.exit(1);
  }
}
```
