# Lazy Loading

**Lazy loading** means related data is NOT fetched until you explicitly ask for it.

```javascript
// Only fetches the user - no related data
const user = await User.findByPk(1);

// Related posts are fetched NOW, when you access them
const posts = await user.getPosts();
```

### How It Works

1. Initial query fetches only the requested record
2. Related data is fetched in separate queries only when accessed
3. Each access to related data triggers a new database query

### Pros

- **Faster initial load** - only fetches what you immediately need
- **Less memory usage** - doesn't load data you might never use
- **Simpler initial queries** - no complex joins

### Cons

- **N+1 problem** - if you loop through 100 users and access their posts, that's 101 queries (1 for users + 100 for each user's posts)
- **Unpredictable performance** - hard to know when queries will fire
- **Multiple round trips** - more network calls to the database
