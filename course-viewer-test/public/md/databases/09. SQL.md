# SQL

## What Is SQL?

**SQL** stands for **Structured Query Language**.

It is a language specifically designed to communicate with relational databases.

You use SQL to tell the database what data you want to create, read, update, or delete.

## Key Points About SQL as a Language

- **Declarative** - you describe *what* you want, not *how* to get it (the database figures out the how)
- **Technically NOT a programming language** - no loops, variables, or functions in the traditional sense
- **Standardized** - SQL syntax is mostly the same across different RDBMS (with minor variations)
- **Case insensitive** - `SELECT` and `select` work the same (convention is uppercase for keywords)
- **English-like** - designed to be readable and intuitive

## CRUD Operations

SQL maps directly to the four basic data operations:

| Operation | SQL Command |
|---|---|
| **C**reate | `INSERT` |
| **R**ead   | `SELECT` |
| **U**pdate | `UPDATE` |
| **D**elete | `DELETE` |
