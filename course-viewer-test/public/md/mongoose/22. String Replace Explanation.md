# String Replace with Operator Mapping

## Code
```javascript
let filters = numericFilters.replace(
  regEx,
  (match) => `-${operatorMap[match]}-`
);
```

## Overview
This code transforms HTML-encoded comparison operators in a string by replacing them with mapped values wrapped in dashes.

## How It Works

### `numericFilters.replace(regEx, callback)`
- **`numericFilters`** - Source string containing HTML-encoded operators
- **`regEx`** - Regular expression that matches HTML entities like `&lt;`, `&gt;=`, etc.
- **`callback`** - Function that processes each match

### Callback Function: `(match) => `-${operatorMap[match]}-`
- **`match`** - The matched HTML entity (e.g., `&lt;`, `&gt;=`)
- **`operatorMap[match]`** - Looks up the corresponding value in the `operatorMap` object
- **Template literal** - Wraps the mapped value with dashes: `-value-`

## Example Transformation

Assuming `operatorMap` contains:
```javascript
const operatorMap = {
  '&lt;': '$lt',
  '&gt;': '$gt', 
  '&gt;=': '$gte',
  '&lt;=': '$lte',
  '=': '$eq'
};
```

### Input/Output Examples:
| Input | Match | Mapped Value | Output |
|-------|-------|--------------|--------|
| `price&gt;=100` | `&gt;=` | `$gte` | `price-$gte-100` |
| `age&lt;25` | `&lt;` | `$lt` | `age-$lt-25` |
| `score=90` | `=` | `$eq` | `score-$eq-90` |

## Purpose
Converts HTML-encoded filter expressions into a format suitable for query processing, typically for database operations where operators need specific syntax (like MongoDB query operators).
