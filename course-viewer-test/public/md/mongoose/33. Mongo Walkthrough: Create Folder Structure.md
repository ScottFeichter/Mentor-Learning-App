# Create Folder Structure

## Purpose

Depending on what your project is, you should make some folders you know you will need.

This will be a nice scaffolding to put things in places they can easily be found.

## Recommended Root Level Folders for Web Server API

- src
- dist

## Recommended Folders for Inside the src Folder

- `server`
- `controllers`
- `database`
- `errors`
- `middlewares`
- `models`
- `routers`
- `utils`
- `static`
