# URI Sort Parameter: Built-in vs Custom Implementation

## Common Misconception

Many developers assume that `sort=` is automatically handled by MongoDB/Mongoose, but this is **not correct**.

The sort parameter requires custom implementation to bridge URI parameters and database queries.

## What's Actually Built-In

### Express.js Query Parsing
```javascript
// Built-in: Express automatically parses query strings
app.get('/api/products', (req, res) => {
  console.log(req.query.sort); // "name,-price" from ?sort=name,-price
  console.log(req.query.limit); // "10" from ?limit=10
  console.log(req.query.page); // "2" from ?page=2
});
```

### MongoDB/Mongoose Sort Method
```javascript
// Built-in: MongoDB's sort functionality
db.products.find().sort({ name: 1, price: -1 })

// Built-in: Mongoose sort method
Product.find().sort({ name: 1, price: -1 })
Product.find().sort('name -price') // String syntax also built-in
```

## What You Must Implement

### URI Parameter to Sort Object Conversion
```javascript
// This logic is NOT built-in - you must write it
const parseSortParameter = (sortParam) => {
  if (!sortParam) return {};

  const sortObject = {};
  const fields = sortParam.split(',');

  fields.forEach(field => {
    const trimmedField = field.trim();
    if (trimmedField.startsWith('-')) {
      sortObject[trimmedField.substring(1)] = -1; // Descending
    } else {
      sortObject[trimmedField] = 1; // Ascending
    }
  });

  return sortObject;
};
```

### Complete Route Implementation
```javascript
app.get('/api/products', async (req, res) => {
  try {
    // Built-in: Express parses ?sort=name,-price
    const { sort } = req.query;

    // Custom: Convert URI parameter to MongoDB format
    const sortObject = parseSortParameter(sort);

    // Built-in: Mongoose executes the sort
    const products = await Product.find().sort(sortObject);

    res.json(products);
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});
```

## Why This Confusion Exists

### REST API Conventions
The `sort=` parameter is a widely adopted REST API convention, making it seem "standard":

```
GET /api/users?sort=name           // Common pattern
GET /api/products?sort=-price      // Industry standard
GET /api/posts?sort=date,-views    // Expected behavior
```

### Framework Similarities
Some frameworks do provide automatic sorting:

```javascript
// Django REST Framework (Python) - has built-in sorting
// Laravel (PHP) - has query parameter handling
// Rails (Ruby) - has parameter parsing helpers
```

But Node.js/Express/MongoDB requires manual implementation.

## Third-Party Solutions

### Mongoose Plugins
```javascript
// mongoose-paginate-v2 handles sorting automatically
const mongoosePaginate = require('mongoose-paginate-v2');
ProductSchema.plugin(mongoosePaginate);

// Now sorting is handled automatically
const options = {
  sort: req.query.sort || '-createdAt',
  page: req.query.page || 1,
  limit: req.query.limit || 10
};

const result = await Product.paginate({}, options);
```

### API Query Libraries
```javascript
// api-query-params library
const aqp = require('api-query-params');

app.get('/api/products', async (req, res) => {
  const { filter, skip, limit, sort } = aqp(req.query);
  const products = await Product
    .find(filter)
    .skip(skip)
    .limit(limit)
    .sort(sort);

  res.json(products);
});
```

## Best Practices

### Validation and Security
```javascript
const allowedSortFields = ['name', 'price', 'createdAt', 'category'];

const validateAndParseSortParameter = (sortParam) => {
  if (!sortParam) return {};

  const sortObject = {};
  const fields = sortParam.split(',');

  fields.forEach(field => {
    const trimmedField = field.trim();
    const fieldName = trimmedField.startsWith('-')
      ? trimmedField.substring(1)
      : trimmedField;

    // Security: Only allow whitelisted fields
    if (allowedSortFields.includes(fieldName)) {
      sortObject[fieldName] = trimmedField.startsWith('-') ? -1 : 1;
    }
  });

  return sortObject;
};
```

### Default Sorting
```javascript
app.get('/api/products', async (req, res) => {
  const sortObject = parseSortParameter(req.query.sort) || { createdAt: -1 };
  const products = await Product.find().sort(sortObject);
  res.json(products);
});
```

## Summary

- **URI parsing**: Built-in to Express
- **Sort parameter convention**: Industry standard, not automatic
- **Parameter conversion**: Must be implemented manually
- **Database sorting**: Built-in to MongoDB/Mongoose
- **Complete solution**: Requires custom glue code

The `sort=` parameter represents the gap between HTTP APIs and database queries that developers must bridge with custom implementation.
