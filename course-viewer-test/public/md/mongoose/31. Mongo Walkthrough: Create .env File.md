# Create .env File

Create a `.env` file in the project root.

## JWT_SECRET Variable

- Use `openssl rand -hex 64` to generate a random string in the shell
- Set `JWT_SECRET` to the generated string

## DB_CONNECT Variable

- Set `DB_CONNECT` to your MongoDB Atlas connection string
- Ensure the end of the string uses the name of your new project

## PORT Variable

- Set `PORT` to your desired port number
- It can be helpful to set it to a port not in use by other projects
