# Create server.js

In the server folder create a file server.js

Run dotenv.config() on import.
Import express.
Import the startServer function.

Instantiate a variable PORT from process.env.PORT or default.

Instatiate a variable MONGO_URI from process.env.MONGO_URI.

Instantiate the SERVER object from express() constructor.

Call the startServer function passing in the appropriate arguments.

```javascript
require('dotenv').config();

const express = require('express');
const startServer = require('./startServer');


const PORT = process.env.PORT || 3000;
const MONGO_URI = process.env.MONGO_URI;



const SERVER = express();

startServer(SERVER, PORT, MONGO_URI);
```
