# Establish Git

## Create .gitignore File

In the project root create a `.gitignore` file with the following:

```
node_modules/
.env
```

## Initialize Local Repository

Establish a local git repo by running these commands from project root:

```bash
git init
git add .
git commit -m "Initial commit"
```

## Connect to Remote Repository

- Create a new remote GitHub repo in your account on github.com
- Copy the repository URL
- Connect the local repo to the remote:

```bash
git remote add origin <repository-url>
git push -u origin main
```
