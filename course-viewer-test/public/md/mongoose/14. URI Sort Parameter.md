# URI Sort Parameter in MongoDB/Mongoose

## What is the sort= Parameter?

The `sort=` URI parameter is used in REST APIs to specify how query results should be ordered.

It's commonly passed as a query string parameter in HTTP requests.

## Basic Syntax

```
GET /api/users?sort=name
GET /api/products?sort=-price
GET /api/posts?sort=createdAt,-views
```

## Sort Parameter Format

### Ascending Order
```
sort=fieldName
sort=name          // Sort by name A-Z
sort=price         // Sort by price low to high
```

### Descending Order
```
sort=-fieldName
sort=-name         // Sort by name Z-A
sort=-price        // Sort by price high to low
```

### Multiple Fields
```
sort=category,-price,name
// 1. Sort by category (ascending)
// 2. Then by price (descending)
// 3. Then by name (ascending)
```

## MongoDB/Mongoose Implementation

### Express Route Handler
```javascript
app.get('/api/products', async (req, res) => {
  const { sort } = req.query;

  let sortObject = {};

  if (sort) {
    const sortFields = sort.split(',');
    sortFields.forEach(field => {
      if (field.startsWith('-')) {
        sortObject[field.substring(1)] = -1; // Descending
      } else {
        sortObject[field] = 1; // Ascending
      }
    });
  }

  const products = await Product.find().sort(sortObject);
  res.json(products);
});
```

### MongoDB Sort Values
```javascript
// MongoDB sort object format
{
  name: 1,      // Ascending (A-Z, 1-10)
  price: -1,    // Descending (Z-A, 10-1)
  createdAt: -1 // Descending (newest first)
}
```

## Mongoose Examples

### Single Field Sort
```javascript
// URI: ?sort=name
Product.find().sort({ name: 1 })

// URI: ?sort=-price
Product.find().sort({ price: -1 })
```

### Multiple Field Sort
```javascript
// URI: ?sort=category,-price,name
Product.find().sort({
  category: 1,
  price: -1,
  name: 1
})
```

### Dynamic Sorting
```javascript
const buildSortObject = (sortParam) => {
  if (!sortParam) return {};

  return sortParam.split(',').reduce((sortObj, field) => {
    if (field.startsWith('-')) {
      sortObj[field.substring(1)] = -1;
    } else {
      sortObj[field] = 1;
    }
    return sortObj;
  }, {});
};

// Usage
const sortObject = buildSortObject(req.query.sort);
const results = await Model.find().sort(sortObject);
```

## Common Use Cases

```javascript
// Recent posts first
GET /api/posts?sort=-createdAt

// Alphabetical product listing
GET /api/products?sort=name

// Price high to low, then by rating
GET /api/products?sort=-price,-rating

// Category grouping with newest first
GET /api/products?sort=category,-createdAt
```

The `sort=` parameter provides a clean, RESTful way to control result ordering that maps directly to MongoDB's sort functionality.
