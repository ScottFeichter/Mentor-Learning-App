# Initiate Node

## Initialize Package

Create node modules and generate `package.json` with the `-y` flag to avoid questions:

```bash
npm init -y
```

## Install Dependencies

```bash
npm install \
    express \
    mongoose \
    dotenv \
    bcrypt \
    helmet \
    cors \
    csurf \
    cross-env \
    jsonwebtoken \
    express-rate-limit \
    express-validator \
    cookie-parser \
    compression \
    express-mongo-sanitize \
    http-status-codes \
    winston \
    morgan \
    swagger-jsdoc \
    swagger-ui-express
```

- Include as many dependencies as you know you will use
- You probably won't know all of them, but include as many as you can
- You can always add more later

## Install Dev Dependencies

```bash
npm install -D nodemon
```
