# Regular Expressions (Regex)

## What is Regex?

Regular expressions (regex or regexp) are patterns used to match character combinations in strings.

They provide a powerful and flexible way to search, match, and manipulate text.

## What Regex Does

- **Pattern matching**: Find specific text patterns in strings
- **Text validation**: Check if input matches required format (email, phone, etc.)
- **Text extraction**: Pull specific parts from larger text
- **Text replacement**: Find and replace text based on patterns
- **Text splitting**: Break strings into parts based on patterns

## History

**1950s**: Mathematician Stephen Kleene developed the concept of "regular sets"

**1960s**: Ken Thompson implemented regex in the QED text editor

**1970s**: Regex became part of Unix tools (grep, sed, awk)

**1980s**: Henry Spencer created widely-used regex library

**1990s**: Perl popularized advanced regex features

**2000s**: Regex became standard in most programming languages

## Basic Syntax

### Literal Characters
```javascript
/hello/        // Matches exactly "hello"
/123/          // Matches exactly "123"
```

### Special Characters (Metacharacters)
```javascript
.              // Matches any single character
^              // Start of string
$              // End of string
*              // Zero or more of preceding
+              // One or more of preceding
?              // Zero or one of preceding
[]             // Character class
()             // Grouping
|              // OR operator
\              // Escape character
```

## Character Classes

```javascript
[abc]          // Matches a, b, or c
[a-z]          // Matches any lowercase letter
[A-Z]          // Matches any uppercase letter
[0-9]          // Matches any digit
[a-zA-Z0-9]    // Matches alphanumeric characters
[^abc]         // Matches anything except a, b, or c
```

### Predefined Character Classes
```javascript
\d             // Digit [0-9]
\w             // Word character [a-zA-Z0-9_]
\s             // Whitespace [ \t\n\r\f]
\D             // Non-digit [^0-9]
\W             // Non-word character [^a-zA-Z0-9_]
\S             // Non-whitespace [^ \t\n\r\f]
```

## Quantifiers

```javascript
*              // Zero or more
+              // One or more
?              // Zero or one
{n}            // Exactly n times
{n,}           // n or more times
{n,m}          // Between n and m times
```

## JavaScript Usage

### Creating Regex
```javascript
// Literal notation
const regex1 = /pattern/flags;

// Constructor
const regex2 = new RegExp('pattern', 'flags');
```

### Common Methods

#### test() - Check if pattern exists
```javascript
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
console.log(emailRegex.test('user@email.com')); // true
console.log(emailRegex.test('invalid-email'));  // false
```

#### match() - Extract matches
```javascript
const text = 'Phone: 123-456-7890';
const phoneRegex = /\d{3}-\d{3}-\d{4}/;
console.log(text.match(phoneRegex)); // ['123-456-7890']
```

#### replace() - Replace matches
```javascript
const text = 'Hello World';
const newText = text.replace(/World/, 'JavaScript');
console.log(newText); // 'Hello JavaScript'
```

#### split() - Split by pattern
```javascript
const text = 'apple,banana;orange:grape';
const fruits = text.split(/[,;:]/);
console.log(fruits); // ['apple', 'banana', 'orange', 'grape']
```

## Flags

```javascript
/pattern/g     // Global - find all matches
/pattern/i     // Case insensitive
/pattern/m     // Multiline - ^ and $ match line breaks
/pattern/s     // Dotall - . matches newlines
/pattern/u     // Unicode
/pattern/y     // Sticky - match from lastIndex
```

## Common Patterns

### Email Validation
```javascript
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
```

### Phone Number (US)
```javascript
const phoneRegex = /^\(\d{3}\)\s\d{3}-\d{4}$/; // (123) 456-7890
const phoneRegex2 = /^\d{3}-\d{3}-\d{4}$/;     // 123-456-7890
```

### Password (8+ chars, letter + number)
```javascript
const passwordRegex = /^(?=.*[A-Za-z])(?=.*\d)[A-Za-z\d]{8,}$/;
```

### URL
```javascript
const urlRegex = /^https?:\/\/(www\.)?[-a-zA-Z0-9@:%._\+~#=]{1,256}\.[a-zA-Z0-9()]{1,6}\b([-a-zA-Z0-9()@:%_\+.~#?&//=]*)$/;
```

### Credit Card (basic)
```javascript
const creditCardRegex = /^\d{4}[\s-]?\d{4}[\s-]?\d{4}[\s-]?\d{4}$/;
```

## Grouping and Capturing

### Capturing Groups
```javascript
const nameRegex = /^(\w+)\s+(\w+)$/;
const match = 'John Doe'.match(nameRegex);
console.log(match[1]); // 'John'
console.log(match[2]); // 'Doe'
```

### Non-Capturing Groups
```javascript
const regex = /(?:Mr|Mrs|Ms)\.\s+(\w+)/;
const match = 'Mr. Smith'.match(regex);
console.log(match[1]); // 'Smith'
```

## Lookaheads and Lookbehinds

### Positive Lookahead
```javascript
const regex = /\d+(?=px)/;  // Numbers followed by 'px'
console.log('100px'.match(regex)); // ['100']
```

### Negative Lookahead
```javascript
const regex = /\d+(?!px)/;  // Numbers not followed by 'px'
console.log('100em'.match(regex)); // ['100']
```

## Practical Examples

### Extract All Email Addresses
```javascript
const text = 'Contact us at info@company.com or support@company.com';
const emailRegex = /[^\s@]+@[^\s@]+\.[^\s@]+/g;
const emails = text.match(emailRegex);
console.log(emails); // ['info@company.com', 'support@company.com']
```

### Clean Phone Numbers
```javascript
const phone = '(123) 456-7890';
const cleanPhone = phone.replace(/[\(\)\s-]/g, '');
console.log(cleanPhone); // '1234567890'
```

### Validate Form Input
```javascript
function validateInput(input) {
  const patterns = {
    email: /^[^\s@]+@[^\s@]+\.[^\s@]+$/,
    phone: /^\d{3}-\d{3}-\d{4}$/,
    zipCode: /^\d{5}(-\d{4})?$/
  };

  return {
    email: patterns.email.test(input.email),
    phone: patterns.phone.test(input.phone),
    zipCode: patterns.zipCode.test(input.zipCode)
  };
}
```

### Extract Data from Text
```javascript
const logEntry = '2023-12-01 14:30:25 ERROR User login failed for user123';
const logRegex = /^(\d{4}-\d{2}-\d{2})\s+(\d{2}:\d{2}:\d{2})\s+(\w+)\s+(.+)$/;
const match = logEntry.match(logRegex);

if (match) {
  console.log('Date:', match[1]);     // '2023-12-01'
  console.log('Time:', match[2]);     // '14:30:25'
  console.log('Level:', match[3]);    // 'ERROR'
  console.log('Message:', match[4]);  // 'User login failed for user123'
}
```

## Best Practices

### Keep It Simple
```javascript
// ❌ Complex, hard to maintain
const regex = /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&])[A-Za-z\d@$!%*?&]{8,}$/;

// ✅ Break into smaller, testable parts
const hasLowercase = /[a-z]/;
const hasUppercase = /[A-Z]/;
const hasNumber = /\d/;
const hasSpecial = /[@$!%*?&]/;
const minLength = /.{8,}/;
```

### Use Comments
```javascript
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
// Matches: start ^ + non-whitespace/@ + @ + non-whitespace/@ + . + non-whitespace/@ + end $
```

### Test Thoroughly
```javascript
const phoneRegex = /^\d{3}-\d{3}-\d{4}$/;

// Test valid cases
console.log(phoneRegex.test('123-456-7890')); // true

// Test invalid cases
console.log(phoneRegex.test('123-456-789'));  // false
console.log(phoneRegex.test('abc-def-ghij')); // false
```

## Common Pitfalls

### Greedy vs Non-Greedy
```javascript
const text = '<div>Hello</div><div>World</div>';

// ❌ Greedy - matches too much
const greedy = /<div>.*<\/div>/;
console.log(text.match(greedy)[0]); // '<div>Hello</div><div>World</div>'

// ✅ Non-greedy - matches correctly
const nonGreedy = /<div>.*?<\/div>/;
console.log(text.match(nonGreedy)[0]); // '<div>Hello</div>'
```

### Escaping Special Characters
```javascript
// ❌ Wrong - . matches any character
const regex1 = /file.txt/;

// ✅ Correct - \. matches literal dot
const regex2 = /file\.txt/;
```
