# Common Shortcuts

## Modifier Keys

| Symbol | Key |
|--------|-----|
| ⌘ | Command (Cmd) |
| ⇧ | Shift |
| ⌥ | Option (Alt) |
| ⌃ | Control (Ctrl) |
| ⇪ | Caps Lock |
| Fn | Function |

On Windows keyboards: Alt = Option, Windows logo = Command.

## Cut, Copy, Paste

- **⌘X** — Cut selected item to Clipboard
- **⌘C** — Copy selected item to Clipboard
- **⌘V** — Paste contents of Clipboard
- **⌘Z** — Undo previous command
- **⇧⌘Z** — Redo (reverse the undo)
- **⌘A** — Select All

## Find and Navigate

- **⌘F** — Find items in a document or open Find window
- **⌘G** — Find Again (next occurrence)
- **⇧⌘G** — Find previous occurrence
- **⌘Tab** — Switch to next most recently used app

## Window Management

- **⌘H** — Hide front app windows
- **⌥⌘H** — Hide all other apps
- **⌘M** — Minimize front window to Dock
- **⌥⌘M** — Minimize all windows of front app
- **⌘W** — Close front window
- **⌥⌘W** — Close all windows of app
- **⌃⌘F** — Full screen (if supported)

## Files and Apps

- **⌘O** — Open selected item
- **⌘P** — Print current document
- **⌘S** — Save current document
- **⌘T** — Open a new tab
- **⌥⌘Esc** — Force quit an app
- **⌘Space** — Show/hide Spotlight search
- **⇧⌘N** — Create new folder in Finder
- **⌘,** — Open preferences for front app

## Screenshots

- **⇧⌘5** — Screenshot or screen recording (Mojave+)
- **⇧⌘3** — Full screenshot
- **⇧⌘4** — Selection screenshot
