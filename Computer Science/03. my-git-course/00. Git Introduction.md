# Git Introduction

## What is Git?

Git is version control software useful for tracking changes in files and directories over time.

The word "Git" does not really mean anything in particular, according to the inventor.

## Interfacing with Git

- Git does not have a GUI — it is utilized via CLI
- Third party GUIs exist but are not very useful as of writing
- Git is usually factory installed on Unix-like machines (Mac, Linux)
- Can be installed on most any machine and accessed in various CLI shells

> NOTE: Git branches are not seen in Finder.
> NOTE: Directories that are git repos are seen in Finder but indistinguishable.

### The GitHub CLI

- Git is only local. However, it is often used with GitHub
- GitHub is a storage place in the cloud for repositories
- Others exist: GitLab, etc.
- Usually a local repo is mirrored in the cloud for collaboration
- GitHub CLI requires download and learning the commands

## Git is Distributed VCS

- Can be used locally only (single user, single machine)
- Can be used in a distributed manner with remote repositories
- Each user has a working copy AND the full change history
- Uses parallel branches on different computers for collaborative development

## Git Syntax

Basic syntax: `program | utility | flag | argument`

```bash
git add .                    # git | add | .
git commit -m "message"     # git | commit | -m | "message"
git status                   # git | status
```

> NOTE: The flag is not always needed.
> NOTE: When no destination is specified, it uses the current directory.
