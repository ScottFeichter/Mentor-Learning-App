# Two Types of Globals

## The Distinction

JavaScript has two types of global objects that behave very differently:

## 1. Global Constructors (Error, Array, Object)

- `Error` is a constructor function
- You create instances: `new Error('message')`
- Many error objects can exist
- It's a template/blueprint

```javascript
const error1 = new Error('First error');
const error2 = new Error('Second error');
// Two different error objects

typeof Error // 'function'
new Error('oops') // Creates an instance
```

## 2. Global Singleton Objects (process, console)

- `process` is a single object instance
- Only one exists
- You use it directly: `process.env`
- Not a constructor

```javascript
console.log(process); // The one process object
// You can't do: new process()

typeof process // 'object'
new process() // TypeError: process is not a constructor
```

## The Key Difference

**Constructors create multiple instances:**
```javascript
const arr1 = new Array(1, 2, 3);
const arr2 = new Array(4, 5, 6);
// Two separate arrays
```

**Singletons are single objects:**
```javascript
process.env.NODE_ENV = 'development';
// There's only one process object
// Everyone accessing process sees the same object
```

## Examples

**Global Constructors (many instances):**
- `Error`
- `Array`
- `Object`
- `String`
- `Number`
- `Date`
- `Promise`
- `RegExp`

**Global Singleton Objects (one instance):**
- `process` (Node.js only)
- `console`
- `Math`
- `JSON`
- `globalThis`

## Summary

- **Error** is a global constructor - you create instances with `new Error()`
- **process** is a global singleton object - only one exists, use it directly
- Both are "globals" but serve different purposes
