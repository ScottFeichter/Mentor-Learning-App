# Route Handlers and Static Assets

## Route Handlers in Node http

Use conditionals to branch different route handlers:

```javascript
const server = http.createServer((req, res) => {
  if (req.method === 'GET' && req.url === '/') {
    res.statusCode = 200;
    res.setHeader('Content-Type', 'text/plain');
    return res.end('Splash Page');
  }
});
```

For multiple routes, use more conditionals.

## Static Assets

A **static asset** is a resource that doesn't change no matter how many times you ask the server for it.

The URL usually includes the file extension: `/images/dog.jpg`

## Serving Static Assets in Node http

Use `fs` (built-in node library) to find and read files:

```javascript
const fs = require('fs');
const fileContents = fs.readFileSync('./file-name.txt', 'utf-8');
```

- First argument: file path (relative or absolute)
- If file not found: method throws an error
- Second argument: `'utf-8'` to read as string

## HTML Templating

### The Problem
How to insert data into a static HTML resource?

### The Solution
Use a template and insert data into it.

### Templating Engines
- Node: Pug, Handlebars
- Python: Genshi, Jinja

### Basic HTML Templating
- In JS: `${}`
- In HTML templates: `#{}`

### Using a Template
1. Use `fs` to read file contents to a string
2. Use `String.replace` on variables with user info
