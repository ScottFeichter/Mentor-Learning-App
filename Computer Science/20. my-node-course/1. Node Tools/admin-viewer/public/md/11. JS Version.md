# JS Version

&nbsp;

JavaScript doesn't come with Node — it's the other way around.

Node is a runtime that executes JS. Node bundles the V8 engine which implements a specific version of ECMAScript.

## Which ECMAScript Version Am I Using?

It depends on your Node version.

Each Node release supports a specific set of ES features. For example, Node 18+ supports nearly all of ES2022.

You can check your Node version with:

```bash
node -v
```

Then look up what ES features it supports at:

https://node.green

## In The Browser

In the browser, it depends on which browser and version your user has.

That's why tools like Babel exist — to transpile newer ES syntax down to older versions for compatibility.

## ES Modules vs CommonJS

If you're using a `package.json` with `"type": "module"`, you're using ES modules (ESM / import / export).

Without it, Node defaults to CommonJS (require / module.exports).

## Key Point

You don't really "choose" an ECMAScript version — you just use features, and your runtime either supports them or doesn't.

If it doesn't, you get a syntax error.
