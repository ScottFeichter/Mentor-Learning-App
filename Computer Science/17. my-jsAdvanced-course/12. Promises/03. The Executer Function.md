# The Executor Function

The executor function is the callback function passed to the Promise constructor.

The programmer is responsible for creating the executor function based on the required structure.

## What You Give to the Promise Constructor

You provide an **executor function** that follows this pattern:

```javascript
function executor(resolve, reject) {
  // Asynchronous logic of your choosing goes here
  // Call to resolve goes here
  // Call to reject goes here
}
```

## For The Purposes Of Learning

For the purpose of learning:

- First we will define the executor callback function as a separate entity.
- Then we will pass it as a callback to the Promise() constructor.

Later we will practice defining it inline inside the constructor argument list.


## Key Points

The Promise exists specifically because the operation won't finish right away.

That's why Promises are useful - they handle the "waiting" for you.

Meanwhile your code continues running.
