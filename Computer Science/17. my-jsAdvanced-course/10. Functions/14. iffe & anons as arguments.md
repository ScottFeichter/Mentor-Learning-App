## Anonymous vs Immediately Invoked Function Expression (IIFE)

**Anonymous function as callback:**
```javascript
processCallback(function() {
  console.log("I'm passed as reference");
}); // No extra parentheses - just passed as reference
```

**Immediately Invoked Function Expression (IIFE):**
```javascript
(function() {
  console.log("I run immediately!");
})(); // Extra parentheses make it run immediately
```

## Key Differences

- **Anonymous callback**: `function() { ... }` - passed as reference, called later
- **IIFE**: `(function() { ... })()` - executed immediately when defined
