# Network Types

## LAN (Local Area Network)

- Based on **802.3 Ethernet** standards
- Designated as *x*BASE-*Y* (x = data rate, Y = cable type)
- Operates at a single site

## WLAN (Wireless LAN)

- Uses radios and antennas for data transmission/reception
- Based on IEEE **802.11** (brand name: **Wi-Fi**)

## WAN (Wide Area Network)

- Spans multiple geographic locations
- Example: the Internet (global network of networks)
- **ISP** — Internet Service Provider, facilitates access to the Internet

## MAN (Metropolitan Area Network)

- Covers an area equivalent to a city
- Larger than a LAN but smaller than a WAN

## SOHO (Small Office Home Office)

- Business-oriented network
- Often uses a single networking appliance ("SOHO router" / "broadband router")
- May use a centralized server plus client devices and printers

## SAN (Storage Area Network)

- Within enterprise LAN or datacenter
- Provisions access to a configurable pool of storage devices
- Used by application servers

## PAN (Personal Area Network)

- Wireless connectivity at a range of a few meters
- Connects PC to mobile devices and wearable technology

## Client-Server Model

- **Server** — dedicated to running network applications and hosting shared resources
- **Client** — allows end users to access applications and resources
- **Datacenter** — whole site dedicated to provisioning server resources
