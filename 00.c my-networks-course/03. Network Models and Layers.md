# Network Models and Layers

## TCP/IP Model

| Layer | Name |
|-------|------|
| 4 | Application Layer |
| 3 | Transport Layer |
| 2 | Internet Layer |
| 1 | Network Access Layer |

## OSI Model

| Layer | Name |
|-------|------|
| 7 | Application Layer |
| 6 | Presentation Layer |
| 5 | Session Layer |
| 4 | Transport Layer |
| 3 | Network Layer |
| 2 | Data Link Layer |
| 1 | Physical Layer |

- MAC Addresses are Layer 2
- IP Addresses are Layer 3

## The Ethernet Frame

| Component | Purpose |
|-----------|---------|
| Preamble | Gets the receiving card in sync with the bits |
| Start Frame Delimiter | Indicates actual information follows |
| Destination MAC Address | The destination device |
| Source MAC Address | The sending device |
| Length/Type | Length in bytes or type of data (IPv4/IPv6 packet) |
| Data | The actual data packet being delivered |
| Frame Check Sequence | Checks for no loss of data |

## Encapsulation

The process of placing one message format (the letter) inside another message format (the envelope).

- De-encapsulation is when the process is reversed by the recipient
- Each message is encapsulated in a specific form called a **frame**
- The frame provides the addresses (like an envelope)
- If not correctly formatted, it is not successfully delivered

## Ethernet Switches

- Operate at Layer 2 (Data Link) of OSI
- Use MAC address tables
- Take in messages on a port based on the sending MAC
- Use an address table to send out a different port based on destination MAC

## MAC Address Tables

- Switch looks at source MAC — if not in table, adds it
- Checks destination MAC — if unknown, floods to ALL ports except incoming (**unknown unicast**)
- Known addresses check if frame is for them; if not, they ignore it
- MAC entries kept for ~5 minutes

## Ports

A port is a **logical** connection (not physical) used by programs to exchange information.

- Determines which program on a computer to use
- Always associated with an IP address
- Range: 0–65535, assigned by IANA

| Category | Range | Usage |
|----------|-------|-------|
| System (Well-known) | 0–1023 | Server side |
| User (Registered) | 1024–49151 | Registered by companies |
| Dynamic (Private) | 49152–65535 | Client side, self-assigned |
