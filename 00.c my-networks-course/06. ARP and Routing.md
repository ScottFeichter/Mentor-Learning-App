# ARP and Routing

## Address Types

- **Physical Address (MAC)** — used for NIC-to-NIC on same Ethernet network (Layer 2)
- **Logical Address (IP)** — used to send from source to destination across networks (Layer 3)

## ARP (Address Resolution Protocol)

For IPv4: associates IP addresses with MAC addresses on each link along the path.

### ARP Process (3 steps)

1. Sending host broadcasts a frame addressed to broadcast MAC, containing the IPv4 of the intended destination
2. Each host receives and compares — the match replies back with its MAC
3. Sending host stores the MAC and IPv4 in its **ARP table**

## ND (Neighbor Discovery)

For IPv6: same purpose as ARP but for IPv6 addresses.

## Broadcast Containment

- An Ethernet Broadcast = destination MAC is all `FF:FF:FF:FF:FF:FF`
- Switch floods broadcast to all ports except incoming
- Router receives broadcast but does NOT forward it
- A NIC only accepts frames addressed to broadcast MAC or its own MAC

## Routing Between Networks

A router is a networking device that connects multiple Layer 3 (IP) networks.

### Messages Within Same Network

1. Host checks destination IP against subnet mask
2. If same network → uses MAC address directly (via switch)
3. If MAC unknown → sends ARP to obtain it

### Messages Between Different Networks

1. Host checks destination IP — determines it's on a different network
2. Host sends frame to Default Gateway (router) MAC
3. Router de-encapsulates, reads destination IP, checks routing table
4. Router re-encapsulates with new MAC addresses and forwards

**If no default gateway is configured, the host cannot communicate with remote networks.**

## Routing Table Entries

- Not concerned with individual host addresses
- Contain network addresses and the best path to reach them
- Entries made **dynamically** (from other routers) or **manually** (by admin)
- If router cannot determine where to forward → **drops the packet**
- Admins configure a **static default route** to prevent drops

## Routing vs Switching

| | Routing | Switching |
|---|---------|-----------|
| Where | WAN (Internet) | LAN |
| Uses | IP addresses | MAC addresses |
| Layer | Layer 3 | Layer 2 |
