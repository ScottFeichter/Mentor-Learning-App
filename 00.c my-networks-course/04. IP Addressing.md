# IP Addressing

## IPv4 Address Structure

- 32 bits grouped into 4 octets: `209.165.200.1`
- Each IP has a **network component** and a **host component**
- The **subnet mask** identifies which portion is the network portion (represented by 255)
- This allows multiple logical networks to exist on one physical network

## IPv4 Unicast, Broadcast, and Multicast

| Type | Description | Range |
|------|-------------|-------|
| Unicast | Single source → single destination | 1.1.1.1 to 223.255.255.255 |
| Broadcast | Single source → all destinations on network | 255.255.255.255 |
| Multicast | Single source → multiple (not all) destinations | 224.0.0.0 to 239.255.255.255 |

**Broadcast Domain** — all hosts on the same network segment. Broadcasts are NOT forwarded by routers.

## Types of IPv4 Addresses

**Public** — globally routed between ISP routers

**Private (RFC 1918)** — cannot be used on the internet, only internal:
- `10.0.0.0/8` → 10.0.0.0 – 10.255.255.255
- `172.16.0.0/12` → 172.16.0.0 – 172.31.255.255
- `192.168.0.0/16` → 192.168.0.0 – 192.168.255.255

**Reserved/Special Use:**
- Loopback: `127.0.0.0/8` (127.0.0.1 – 127.255.255.254)
- Link-Local (APIPA): `169.254.0.0/16` (169.254.0.1 – 169.254.255.254)

## Legacy Classful Addressing (Deprecated)

| Class | Range | Use |
|-------|-------|-----|
| A | 0.0.0.0/8 to 127.0.0.0/8 | Extremely large networks (16M+ hosts) |
| B | 128.0.0.0/16 to 191.255.0.0/16 | Moderate to large (up to 65K hosts) |
| C | 192.0.0.0/24 to 223.255.255.0/24 | Small networks (max 254 hosts) |
| D | 224.0.0.0 to 239.0.0.0 | Multicast |
| E | 240.0.0.0 to 255.0.0.0 | Experimental |

## Classless Addressing

Network addresses and subnet masks allocated based on the number of addresses that can be justified.

## Network Segmentation (Subnetting)

- Switches broadcast out all interfaces except incoming
- Routers do NOT propagate broadcasts
- Each router interface connects to a broadcast domain
- Subnetting reduces broadcast domain size

Benefits:
- Reduces overall network traffic
- Improves network performance
- Allows security policies between subnets
- Reduces devices affected by abnormal broadcast traffic

## IPv6

- 128-bit address space
- Uses hexadecimal notation in 8 hextets: `2001:0db8:85a3:0000:0000:8a2e:0370:7334`
- **Rule 1**: Remove leading zeros
- **Rule 2**: Replace one all-zero segment with `::` (only once)

Migration techniques:
- **Dual Stack** — IPv4 and IPv6 coexist on same segment
- **Tunneling** — transport IPv6 packet over IPv4 network
- **NAT64** — allows IPv6 to communicate with IPv4
