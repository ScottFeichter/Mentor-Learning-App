# Internet Protocol (IP)

## What is IP?

The Internet Protocol opened the door for an internetworked model in computing by providing a framework for networks to communicate with one another. It's a shared language that everyone can "speak" and understand.

The Internet can be loosely defined as "a series of internetworked systems" — a series of interconnected networks sharing data.

## History

By 1974, two researchers working for DARPA proposed the *Transmission Control Program*. It was:
- **Fault tolerant** — data can be cached and re-sent if it fails
- **End-to-end** — no single central systems that can take the whole network down

The Transmission Control Program was later divided into:
- **TCP (Transmission Control Protocol)** — responsible for fault-tolerance
- **IP (Internet Protocol)** — responsible for end-to-end connectivity

## Packet-Switching

IP data is transmitted in **packets** — metadata in headers, and a body with content.

A message is split into separate packets, delivered to a destination, and reassembled. IP isn't concerned about whether packets arrive in sequential order. It can even withstand some situations where packets are lost in transit.

## IPv4

- Composed of 4 **octets** (8-bit binary numbers)
- Represented in decimal: `192.168.1.1`
- Same as `11000000.10101000.00000001.00000001` in binary
- Supports ~4 billion unique addresses

## IPv6

- Uses 128 bits (vs IPv4's 32 bits)
- Supports ~350 undecillion (3.5×10³⁸) addresses
- Uses "eight colon-ed hexadecimal" notation:

```
2600:6c5e:157f:d48c:138f:e0ba:6fa7:d859
```

## Special Addresses

| Address | IPv4 | IPv6 | Purpose |
|---------|------|------|---------|
| Loopback (localhost) | 127.0.0.1 | ::1 | Traffic to your own machine |
| All interfaces | 0.0.0.0 | :: | Catch any incoming requests |

The loopback and "all interfaces" address are **not interchangeable**.
