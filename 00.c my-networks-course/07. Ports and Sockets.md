# Transport Layer Ports and Sockets

## Common Port Numbers

| Port | Service |
|------|---------|
| 21 | FTP |
| 22 | SSH |
| 23 | Telnet |
| 25 | SMTP (Mail) |
| 53 | DNS |
| 67 | DHCP Server |
| 68 | DHCP Client |
| 69 | TFTP |
| 80 | HTTP |
| 110 | POP3 |
| 143 | IMAP |
| 161 | SNMP |
| 443 | HTTPS |
| 3128 | Proxy |

## Port Ranges

| Category | Range | Usage |
|----------|-------|-------|
| Well-Known | 1–1023 | Common network applications (destination) |
| Registered | 1024–49151 | Organizations register specific apps (source or destination) |
| Private | 49152–65535 | Any application, client-side (source) |

Web servers listen on various destination ports simultaneously, allowing many services to run at once.

## Sockets

**Socket** — the combination of IP address + port number:

```
192.168.1.7:80
```

**Socket Pair** — source socket + destination socket:

```
192.168.1.7:80, 192.168.1.7:1099
```

## The netstat Command

- Shows active TCP connections on a networked host
- Unexplained connections can pose a security threat
- The `-n` option displays IP addresses and port numbers in numerical form
- Works on Mac/Linux/Windows
