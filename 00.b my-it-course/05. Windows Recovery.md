# Windows Recovery (Core 2)

## Boot Repair Commands

- `bootrec` — CLI command to try to fix the boot sector
- `bcdedit` — CLI command to try to fix the BCD
- **Startup Repair** — will do both of these automatically

## Restore Points

- Windows makes automatic restore points
- You should also make your own
- Use the **Create Restore Point** wizard
- Turn **System Protection** on
- Create a new restore point and give it a name
- Makes a snapshot of the registry
- Can restore from Safe Mode
- Good practice: make a restore point before a major change
- Restore points are backups of the **registry**, not of data

## Recovery Image

- Use to back up, restore, or create a system image

## Rolling Back

- **Drivers** — roll back in Device Manager
- **Updates** — roll back in Programs and Features
