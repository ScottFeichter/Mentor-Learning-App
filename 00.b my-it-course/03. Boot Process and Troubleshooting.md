# Boot Process and Hardware Troubleshooting

## When You Press Power

1. PSU sends 12V to fans and HDD
2. Checks 5V and 3V power — if good, sends "power good" signal
3. Firmware performs **POST** to check hardware components are present and working
4. If POST passes, firmware searches devices for boot sector
5. Two ways of formatting boot sector: **MBR** and **GPT**
6. Methods of booting: **BCD**, **GRUB**, **LILO**

## System Clock

- **RTC (Real Time Clock)** — part of chipset, keeps calendar date/time
- Runs on battery when computer is off
- Uses a coin cell lithium battery (often called "CMOS battery")
- On current motherboards, config data stored in **NVRAM** (flash memory), not CMOS RAM

## RAID Failure

Two main scenarios:
- **Device failure** — volume listed as "degraded" but data still accessible
- **Whole array/volume failure** — complete loss

## Common Troubleshooting Symptoms

Symptoms like lockups, intermittent shutdowns, continuous rebooting, blue screen/kernel panic, and application crashes are difficult to diagnose. Most likely causes:
- Software issues
- Disk/file corruption
- Malware

## Performance Issues

- Hardest type of problem to diagnose
- Use a structured approach to compartmentalize the source
- **Bottleneck** — an underpowered component that slows the whole system
  - Example: fast CPU + lots of RAM + HDD = slow performance
