# Compile Time vs Run Time

## Key Concepts

- **Compile time** — when the compiler converts source code to byte code (or machine code)
- **Run time** — when the program is actually executing
- **Compile** — does whole program simultaneously
- **Interpret** — does program line by line
- **Errors** — problems during compile time
- **Exceptions** — used to handle errors so execution is not interrupted

## Java

```
Source Code → Compiler → ByteCode → Interpreter → Binary Executable → OS → Shell → Kernel → Hardware
```

## C++

```
Source Code → Compiler → Binary Executable
```

## Python

```
Source Code → Interpreter → Byte Code → Python Compiler → Binary Executable
```

## JavaScript

```
Source Code → Parser/Compiler → ...
```
