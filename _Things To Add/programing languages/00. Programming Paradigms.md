# Programming Paradigms

## Scripting Language

- Interpreted by a program (e.g., web browser), not compiled to low-level code
- You are making the engine do things

## Imperative Programming

Programs describe *how* to do something step by step.

## Functional (aka Procedural) Programming

- Based on functions
- Doesn't matter if you use normal or applicative order
- Sequence doesn't matter but function must be created before it is called
- Very easy to adapt to multi-thread and multi-core (parallelization)

## Object Oriented Programming

- Based on objects
- Easy to implement API and keep code tidy

## Logic Programming

Programs describe *what* to compute using logical rules.

## Declarative Programming

Programs describe *what* the result should be, not how to get there.
