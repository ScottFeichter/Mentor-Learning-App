# Why Certain Languages Were Born

## Java (1995)

- Developed by Sun Microsystems
- Main purpose: run on any platform and is fully OOP
- At the time it was difficult to run things on different OS platforms

## JavaScript

- Main purpose: interact with browsers
- At the time it was not easy to interact with browsers in other languages

## Python (1989)

- Developed by Guido van Rossum
- Object-oriented programming language

## C (1972)

- Developed at Bell Labs from a previous language named B
- First major software written in C was the Unix operating system

## C++ (1979)

- Developed by Bell Labs
- Used especially in projects where performance comes at a premium

## Go (2007)

- Developed by Google
- Intended to have syntax loosely based on C but more streamlined than C++

## History of Languages

| Year | Language | Origin |

| 1972 | C | Bell Labs, from B |
| 1979 | C++ | Bell Labs |
| 1989 | Python | Guido van Rossum |
| 1995 | Java | Sun Microsystems |
| 2007 | Go | Google |
