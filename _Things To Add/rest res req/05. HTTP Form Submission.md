# HTTP Form Submission

## Submission Request

```html
<form method="" action="">
```

- **method** — CAN ONLY BE `POST` (in native HTML forms)
- **action** — URL path of the request
- **Content-Type** — automatically set to `application/x-www-form-urlencoded`
- The body will contain the form input data

## Server Response

- Server should parse the body of the request
- Do some CRUD action with the data
- Redirect user to another page

Typical response components:
- Status code: **302** (Found/Redirect)
- **Location** header — path to redirect the user to
- Body — none

## Form Submission Flow

1. Form is submitted
2. Browser makes request to the server
3. Server parses the request body and does some CRUD action with the data
4. Server sends a redirection response
5. Browser receives response
6. Browser redirects user to the path specified in the Location header
