# HTTP Request Components

## Example Request

```
POST / HTTP/1.0
Host: appacademy.io
Content-Length: 31
Content-Type: application/x-www-form-urlencoded
Connection: keep-alive
User-Agent: Mozilla/5.0 (Macintosh; Intel Mac OS X 10_14_5)
Accept: text/html,application/xhtml+xml,application/xml;q=0.9
Accept-Encoding: gzip, deflate
Accept-Language: en-US,en;q=0.9

username=azure&password=hunter2
```

## Request-Line

`POST / HTTP/1.0` — made up of 3 parts:

### 1. Method (HTTP Verbs)

| Method | Purpose | Body? |
|--------|---------|-------|
| GET | Retrieving resources from server | Never |
| POST | Creating new resources | Yes |
| PUT | Update a resource (whole resource) | Yes |
| PATCH | Update a resource (partial) | Yes |
| DELETE | Destroys resources on the server | Recommended not |

### 2. URI (Uniform Resource Indicator)

- Typical resources: users, posts, likes, or root (`/`)
- URI = URL + URN

### 3. HTTP Version

- Usually `HTTP/1.1` or `HTTP/2`

## Headers

Key:value pairs that define metadata needed to process the request. Key is NOT case sensitive.

### Common Request Headers

**Host** — the root path for the URI (usually the domain):
```
Host: appacademy.io
```

**Content-Length** — size of the body:
```
Content-Length: 31
```

**Content-Type** — format of request body data (MIME types):
```
Content-Type: application/x-www-form-urlencoded
```

| MIME Type | Meaning |
|----------|---------|
| application/x-www-form-urlencoded | Info from an HTML web form |
| application/json | JSON data format |
| multipart/form-data | HTML form with multiple media types |

> Content headers only appear on requests that support body content. GET requests should NEVER have content headers.

**User-Agent** — browser information:
```
User-Agent: Mozilla/5.0 (Macintosh; Intel Mac OS X 10_14_5) ...
```

**Accept** — what the client can receive:
```
Accept: text/html,application/xhtml+xml,application/xml;q=0.9
Accept-Encoding: gzip, deflate
Accept-Language: en-US,en;q=0.9
```

**Referer** — the URL the sender is coming from (note: misspelled in the spec).

## Body

Any data that cannot go in the header (e.g., form data or a file).

URL encoding format:
```
username=azure&password=hunter2
```
