# HTTP Response Components

An HTTP response contains either the content requested or an explanation of why it couldn't be delivered.

## Status-Line

```
HTTP/1.1 200 OK
```

- HTTP version the server is responding with
- **Status Code** — numeric representation of response
- **Reason Phrase** — short phrase explaining why

### Status Code Ranges

| Range | Category | Examples |
|-------|----------|----------|
| 100–199 | Informational | |
| 200–299 | Successful | 200 OK, 201 Created |
| 300–399 | Redirection | 301 Moved Permanently, 302 Found |
| 400–499 | Client Error | 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found |
| 500–599 | Server Error | 500 Internal Server Error, 503 Service Unavailable, 504 Gateway Timeout |

## Headers

Key:value pairs that define metadata needed to process the response. Key is NOT case sensitive.

### Common Response Headers

**Content-Type** — format of the response body:
```
Content-Type: text/html; charset=utf-8
```

**Set-Cookie** — sends data back to the client to set on the cookie:
```
Set-Cookie: _session=BAh7CEkiD3Nlc3Npb25faWQ...; path=/; secure; HttpOnly
```
- Cookie is a set of key:value pairs associated with the server's domain
- Needed since HTTP is stateless

**Location** — used by the client for redirection (contains the redirect URL)

**Expires** — when the response should be considered stale (enables caching)

**Content-Disposition** — how to display the response (visible or download)

### Reference

- [MDN HTTP Headers](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers)

## Body

- Assuming a successful request, the body contains the resource requested
- For a website: the HTML of the page
- Format is dictated by the Content-Type header

```html
<!DOCTYPE html>
<html>
...
</html>
```
