# Express Setup

## What is Express?

A framework built on Node http.

## Initialize an Express Server

### 1. Create Project Directory

```bash
mkdir <project-name>
cd <project-name>
touch README.md
```

### 2. Track with Git

```bash
git init
git add .
git commit -m "initial"
```

### 3. Create .gitignore

```bash
touch .gitignore
# Add: node_modules/
git add .
git commit -m ".gitignore"
```

### 4. Create and Link Remote on GitHub

```bash
gh repo create <repo-name> --public
git remote add origin https://github.com/<profile>/<repo-name>
git branch -M main
git push -u origin main
```

### 5. Establish Dependencies

```bash
mkdir server
cd server
npm init -y
npm install express
npm install -D nodemon
```

Add to `package.json` scripts:
```json
"start": "node app.js",
"dev": "nodemon app.js"
```

### 6. Create Server (app.js)

```javascript
const express = require("express");
const app = express();

app.get('/status', (req, res) => {
  res.send('Hello from the app!');
});

const port = 5001;
app.listen(port, console.log(`Server is listening on port ${port}...`));
```

Test with:
- Terminal: `npm start`
- Browser: `localhost:5001/status`
- Postman: `GET localhost:5001/status`
