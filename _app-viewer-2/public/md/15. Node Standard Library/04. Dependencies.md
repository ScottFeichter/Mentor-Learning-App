- **Dependency** — a package your project needs to run. Listed in `package.json` under `dependencies` or `devDependencies`.


## Summary

| Term | What It Is |
|------|-----------|
| File | A single `.js` file |
| Module | A file that exports something |
| Package | A directory with `package.json` containing one or more modules |
| Dependency | A package your project relies on |
| Core module | Ships with Node, import only |
| Third-party module | Installed from npm |
| Library | You call it |
| Framework | It calls you |
