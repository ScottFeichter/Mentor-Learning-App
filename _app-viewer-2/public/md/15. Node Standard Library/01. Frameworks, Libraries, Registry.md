- **Library** — a package that provides utility functions you call in your code. You control the flow. (e.g. `lodash`, `axios`)

- **Framework** — a package that provides structure and calls your code. It controls the flow. (e.g. `express`, `next`)

- **Registry** — where packages are hosted. npm's registry is at npmjs.com.


## Installing a Library

```bash
npm install lodash
```

## Using a Library

```javascript
const lodashLibrary = require('lodash');

lodashLibrary.capitalize('hello'); // 'Hello'
lodashLibrary.shuffle([1, 2, 3, 4]); // [3, 1, 4, 2]
```

## Library vs Framework

A library is a tool you reach for.

A framework is a structure you build within.

**You call a library. A framework calls you.**


## Using a Framework

```bash
npm install express
```

```javascript
const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('Hello World');
});

app.listen(3000);
```

Notice you define the handler, but Express decides when to call it. That's the framework pattern.

## Framework vs Library

**You call a library. A framework calls you.**

This is known as **Inversion of Control**.

The framework is in charge of the flow, you just fill in the pieces.
