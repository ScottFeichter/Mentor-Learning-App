# Function Anatomy

## Parts of a Function

Here's a breakdown of all the parts that make up a function:

```javascript
function greetUser(name, greeting = "Hello") {
  let message = greeting + " " + name + "!";
  console.log(message);
  return message;
}
```

### 1. Function Keyword
- **`function`** - Declares that this is a function definition
- Tells JavaScript to create a function

### 2. Function Name
- **`greetUser`** - The identifier used to call the function
- Optional (can be anonymous)
- Must follow JavaScript naming rules

### 3. Parameters
- **`(name, greeting = "Hello")`** - Input variables the function accepts
- Enclosed in parentheses
- Separated by commas
- Can have default values (ie greeting = "Hello")
- Can be a function reference (callback)
- Can be a function call
- Optional (can be empty `()`)

### 4. Function Body
- **`{ ... }`** - The code that runs when function is called
- Enclosed in curly braces
- Contains all the function's logic

### 5. Local Variables
- **`let message`** - Variables declared inside the function
- Only accessible within the function scope
- Optional

### 6. Statements
- **`console.log(message);`** - Code that performs actions
- Can be any valid JavaScript code
- Optional

### 7. Return Statement
- **`return message;`** - Specifies what value the function gives back
- **Explicit return**: Uses `return` keyword with a value
- **Implicit return**: Returns `undefined` if no `return` statement
- Optional

## Return Statements
- **Explicit return**: Function explicitly returns a value with `return` keyword

```javascript
function greet(name) {
  console.log("Hello " + name);
  return "Greeting complete";
}
```

- **Implicit return**: Function returns `undefined` when no `return` statement is present

``` javascript
function sayHello() {
  console.log("Hello!");
}
```

## Minimal Function

A very simple function:

```javascript
function minimal() {
  // Empty body - implicitly returns undefined
}
```

**Required parts:** Function keyword, name (for declarations), parentheses, braces

**Optional parts:** Parameters, body statements, return statement
