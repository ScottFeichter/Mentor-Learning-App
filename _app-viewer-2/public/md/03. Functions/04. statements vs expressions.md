# Function Statements vs Function Expressions

In JavaScript, functions exists as either a statement or an expression.

## Function Statement
```javascript
function myFunction() {
  console.log("I'm a statement");
}
```

## Function Expression
```javascript
let myFunction = function() {
  console.log("I'm an expression");
};
```

## Key Differences

### 1. Standalone vs Part of Something
- **Statement**: Stands alone as a complete statement
- **Expression**: Part of a larger expression (assignment, argument, etc.)

### 2. Hoisting
- **Statement**: Fully hoisted - can be called before definition
- **Expression**: Not hoisted - cannot be called before assignment

```javascript
// This works
myStatement(); // "Hello from statement"

function myStatement() {
  console.log("Hello from statement");
}

// This doesn't work
myExpression(); // Error: Cannot access before initialization

let myExpression = function() {
  console.log("Hello from expression");
};
```

### 3. Context Usage
- **Statement**: Creates a named function in the current scope
- **Expression**: Creates a function value that must be used somewhere

**Function statements** are declarations that create named functions, while **function expressions** create function values that are used as part of other operations.

## All Forms of Function Statements

### 1. Basic Function Declaration
```javascript
function myFunction() {
  console.log("Basic declaration");
}
```

### 2. Function Declaration with Parameters
```javascript
function greet(name, greeting = "Hello") {
  console.log(greeting + " " + name);
}
```

## All Forms of Function Expressions

### 1. Anonymous Function Expression
```javascript
let myFunc = function() {
  console.log("Anonymous expression");
};
```

### 2. Named Function Expression
```javascript
let myFunc = function namedFunc() {
  console.log("Named expression");
};
```

### 3. Arrow Function Expression
```javascript
let myFunc = () => {
  console.log("Arrow function");
};

// Short form
let add = (a, b) => a + b;
```

### 4. Function Expression as Argument (Callback)
```javascript
processCallback(function() {
  console.log("Callback expression");
});
```

### 5. Immediately Invoked Function Expression (IIFE)
```javascript
(function() {
  console.log("IIFE");
})();
```

### 6. Function Expression in Return Statement
```javascript
function createFunction() {
  return function() {
    console.log("Returned expression");
  };
}
```
