# Why Functions?

## What is the Purpose of Functions in Programming?

Functions serve several key purposes in programming:

## 1. Code Reusability
Avoid writing the same code multiple times:
```javascript
function greet(name) {
  console.log("Hello " + name);
}

greet("Alice");
greet("Bob");
greet("Charlie");
```

## 2. Organization and Structure
Break large programs into smaller, manageable pieces:
```javascript
function calculateTax(income) { ... }
function processPayment(amount) { ... }
function generateReport() { ... }
```

## 3. Abstraction
Hide complex implementation details:
```javascript
function sendEmail(to, subject, body) {
  // Complex email logic hidden inside
}

sendEmail("user@example.com", "Welcome", "Hello!");
```

## 4. Modularity
Create independent, testable units:
```javascript
function add(a, b) {
  return a + b;
}

function multiply(a, b) {
  return a * b;
}
```

## 5. Maintainability
Change logic in one place affects everywhere it's used:
```javascript
function formatCurrency(amount) {
  return "$" + amount.toFixed(2);
}
```

## 6. Readability
Make code self-documenting:
```javascript
if (isValidEmail(email) && isPasswordStrong(password)) {
  createAccount();
}
```

Functions make code **DRY** (Don't Repeat Yourself), organized, and easier to understand and maintain.
