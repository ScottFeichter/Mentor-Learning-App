
## What is a Function Declaration?

A **function declaration** is a specific type of function definition that:
- Stands alone as a complete statement
- Always has a name
- Gets hoisted (can be called before it's defined in the code)

```javascript
// Function declaration
function myFunction() {
  console.log("I'm a declaration");
}

// Can be called before it's defined due to hoisting
sayHello(); // This works!

function sayHello() {
  console.log("Hello!");
}
```

## Function Expression vs Function Declaration

**Function Declaration** (statement):
```javascript
function myFunction() {
  console.log("I'm a declaration");
}
```

**Function Expression** (part of an expression):
```javascript
processCallback(function() {
  console.log("I'm a function expression used as argument!");
});
```

## Why is it a Function Expression and Not Just a Function Definition?

It's a **function expression** because of **where and how** it's used, not just how it looks.

**Why it's an expression:**
- It's **part of a larger expression** (the function call `processCallback(...)`)
- It's used as a **value** being passed to another function
- It's **not a standalone statement** - it's embedded within another operation

**Other function expressions:**
```javascript
let myFunc = function() { ... };  // Expression (assignment)
return function() { ... };        // Expression (return statement)
(function() { ... })();           // Expression (IIFE)
```

**The test:** If you can use it as a value (assign it, pass it, return it), it's an expression. If it stands alone as a statement, it's a declaration.

So it's called a function expression because it's functioning as a **value** within a larger expression, not as a standalone function definition.
