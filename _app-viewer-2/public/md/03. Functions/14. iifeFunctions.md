# Immediately Invoked Function Expressions (IIFE)

## What is an IIFE?

An **IIFE** (Immediately Invoked Function Expression) is a function that runs immediately when it's defined.

```javascript
(function() {
  console.log("I run immediately!");
})(); // Extra parentheses invoke the function
```

## IIFE Syntax

The key is the parentheses at the end that immediately invoke the function:

```javascript
// Standard function - does NOT run automatically - waits to be called
function myFunction() {
  console.log("I need to be called");
}

// IIFE - runs immediately
(function() {
  console.log("I run right away!");
})();
```

## What if Missing the Parentheses?

Without the parentheses at the end, it's **not an IIFE** - it's just a **function expression** that doesn't execute:

```javascript
// Missing parentheses - NOT an IIFE, just a function expression
(function() {
  console.log("I don't run!");
});

// With parentheses - IS an IIFE
(function() {
  console.log("I run immediately!");
})();
```

**What happens without the parentheses:**
- The function is created but never called
- No output occurs
- It's essentially useless code since the function has no name and can't be called later

**The parentheses are what make it "immediately invoked":**
- `()` at the end = function call = IIFE
- No `()` = just a function expression that sits there doing nothing

## Are All IIFEs Anonymous?

No! IIFEs can be named too:

```javascript
// Anonymous IIFE
(function() {
  console.log("Anonymous IIFE");
})();

// Named IIFE
(function myIIFE() {
  console.log("Named IIFE");
})();
```

The name in a named IIFE is only visible inside the function itself.

## Why Use IIFEs?

- **Avoid global pollution**: Variables inside IIFE don't leak to global scope
- **Run code immediately**: Execute initialization code right away
- **Create private scope**: Keep variables contained

```javascript
(function() {
  let privateVariable = "I'm private!";
  console.log(privateVariable); // Works here
})();

// console.log(privateVariable); // Error - not accessible outside
```

## Key Point

IIFEs are **function calls**, not function references. They execute immediately, unlike callbacks which are passed as references to be called later.
