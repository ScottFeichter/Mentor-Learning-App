# XSS Prevention Strategies

## Defense in Depth

XSS prevention requires multiple layers of protection. No single technique is sufficient.

## 1. Input Sanitization

Remove or escape dangerous characters before storing data.

```javascript
const { xss } = require('express-xss-sanitizer');
app.use(xss());
```

## 2. Output Encoding

Encode data when rendering it in HTML, JavaScript, or URLs.

```javascript
// In templates, use encoding functions
const escaped = text
  .replace(/&/g, '&amp;')
  .replace(/</g, '&lt;')
  .replace(/>/g, '&gt;')
  .replace(/"/g, '&quot;')
  .replace(/'/g, '&#x27;');
```

## 3. Content Security Policy (CSP)

Use Helmet to set CSP headers that restrict script sources.

```javascript
const helmet = require('helmet');
app.use(helmet.contentSecurityPolicy({
  directives: {
    defaultSrc: ["'self'"],
    scriptSrc: ["'self'"],  // Only allow scripts from same origin
    styleSrc: ["'self'", "'unsafe-inline'"]
  }
}));
```

## 4. HTTPOnly Cookies

Prevent JavaScript from accessing sensitive cookies.

```javascript
res.cookie('session', token, { httpOnly: true });
```

## 5. Validate Input Types

Reject input that doesn't match expected formats.

```javascript
const { body, validationResult } = require('express-validator');

app.post('/user',
  body('email').isEmail(),
  body('age').isInt({ min: 0, max: 150 }),
  (req, res) => {
    const errors = validationResult(req);
    if (!errors.isEmpty()) {
      return res.status(400).json({ errors: errors.array() });
    }
    // Process valid input
  }
);
```

## 6. Use Frameworks That Auto-Escape

React, Angular, and Vue automatically escape output by default.

```jsx
// React auto-escapes this — safe!
<p>{userInput}</p>

// This is DANGEROUS — bypasses escaping
<p dangerouslySetInnerHTML={{__html: userInput}} />
```

## Summary

| Layer | Technique | Protects Against |
|-------|-----------|-----------------|
| Input | Sanitization | Stored XSS |
| Output | Encoding | Reflected XSS |
| Headers | CSP | All XSS types |
| Cookies | httpOnly | Cookie theft |
| Validation | Type checking | Malformed input |
| Framework | Auto-escaping | DOM XSS |
