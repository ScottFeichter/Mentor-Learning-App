# express-xss-sanitizer

## What is express-xss-sanitizer?

express-xss-sanitizer is an Express middleware that sanitizes user input to prevent Cross-Site Scripting (XSS) attacks. It cleans `req.body`, `req.query`, and `req.params` by removing or escaping malicious scripts.

## What is XSS?

Cross-Site Scripting (XSS) is an attack where malicious scripts are injected into trusted websites. When other users visit the page, the script executes in their browser.

### Types of XSS

- **Stored XSS** — Malicious script is saved in the database and served to other users
- **Reflected XSS** — Script is reflected off a web server in error messages or search results
- **DOM-based XSS** — Script manipulates the DOM directly in the browser

## Installation

```bash
npm install express-xss-sanitizer
```

## Basic Usage

```javascript
const express = require('express');
const { xss } = require('express-xss-sanitizer');

const app = express();
app.use(express.json());
app.use(xss());

app.post('/comment', (req, res) => {
  // req.body is already sanitized
  console.log(req.body.text); // Safe!
  res.send('Comment saved');
});
```

## What It Sanitizes

### Before Sanitization
```javascript
req.body = {
  name: '<script>alert("hacked")</script>John',
  bio: '<img src=x onerror=alert("xss")>Hello'
};
```

### After Sanitization
```javascript
req.body = {
  name: 'John',
  bio: 'Hello'
};
```

## Configuration Options

### Allow Specific Tags
```javascript
app.use(xss({
  allowedTags: ['b', 'i', 'em', 'strong', 'a'],
  allowedAttributes: {
    'a': ['href']
  }
}));
```

### Selective Sanitization
```javascript
// Only sanitize body
app.use(xss({
  allowedKeys: ['body']
}));
```

## Common XSS Attack Vectors

| Attack | Example |
|--------|---------|
| Script injection | `<script>steal(document.cookie)</script>` |
| Event handlers | `<img onerror="malicious()">` |
| URL injection | `javascript:alert('xss')` |
| CSS injection | `<div style="background:url(javascript:alert('xss'))">` |

## Summary

- **XSS attacks** inject malicious scripts into web pages
- **express-xss-sanitizer** automatically cleans user input
- Sanitizes `req.body`, `req.query`, and `req.params`
- Configure allowed tags if you need some HTML (like rich text editors)
- Always sanitize on the server — never trust client-side validation alone
