# Type Module

## Node.js (package.json)

You declare `"type": "module"` in **package.json** to enable ES6 module syntax in Node.js.

### Without `"type": "module"`:
```javascript
// CommonJS (default)
const express = require('express');
module.exports = something;
```

### With `"type": "module"`:
```javascript
// ES6 modules
import express from 'express';
export default something;
```

### Key differences:

- **CommonJS** (default): Uses `require()` and `module.exports`
- **ES Modules**: Uses `import`/`export` statements
- You need `"type": "module"` to use `import`/`export` in Node.js
- Without it, Node.js defaults to CommonJS

### When to use:
- Modern projects often use ES modules for consistency with frontend code
- If you're using `import`/`export`, you must add `"type": "module"` to package.json
- If you're using `require()`, you don't need it (CommonJS is default)

## File Extension Alternative (.mjs / .cjs)

In Node.js, you can use file extensions instead of declaring `"type": "module"` in package.json.

### File extension approach:

- **`.mjs`** - Always treated as ES6 module (use `import`/`export`)
- **`.cjs`** - Always treated as CommonJS (use `require`/`module.exports`)
- **`.js`** - Depends on `"type"` in package.json (defaults to CommonJS)

### Example:

```javascript
// app.mjs - automatically an ES6 module
import express from 'express';
export default something;
```

```javascript
// app.cjs - automatically CommonJS
const express = require('express');
module.exports = something;
```

### When to use:

- **`.mjs`**: Mix ES6 modules in a CommonJS project without changing package.json
- **`"type": "module"`**: Convert entire project to ES6 modules
- **`.cjs`**: Keep some CommonJS files in an ES6 module project

Most projects choose one approach and stick with it. Using `"type": "module"` with `.js` files is more common than using `.mjs`.

## Browser (HTML script tag)

For browsers, you specify the module type in the **HTML script tag**:

```html
<!-- ES6 module -->
<script type="module" src="app.js"></script>

<!-- Regular script (default) -->
<script src="app.js"></script>
```

### Key points:

- **`type="module"`** tells the browser to treat the JS file as an ES6 module
- Enables `import`/`export` statements in the browser
- Modules are automatically in strict mode
- Modules are deferred by default
- Each module has its own scope (not global)

### Example:

```html
<!-- index.html -->
<script type="module" src="main.js"></script>
```

```javascript
// main.js - can now use imports
import { something } from './utils.js';
```

The JS files themselves don't need any special declaration - it's all controlled by the HTML `<script>` tag's `type` attribute.
