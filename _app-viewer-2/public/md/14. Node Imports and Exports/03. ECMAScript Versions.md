# ECMAScript Versions

&nbsp;

JavaScript doesn't come with Node — it's the other way around.

Node bundles the V8 engine which implements a specific version of ECMAScript.

## Which ECMAScript Version Am I Using?

It depends on your Node version.

Each Node release supports a specific set of ES features.

For example, Node 18+ supports nearly all of ES2022.

### How To Check Your Node Version

Once installed you can check your Node version with:

```bash
node -v
```

Then look up what ES features it supports at: https://node.green

## In The Browser

In the browser, it depends on which browser and version you have installed.

Tools like Babel exist to transpile newer ES syntax down to older versions for compatibility.

## Key Point

You don't really "choose" an ECMAScript version.

You just use features, and your runtime either supports them or doesn't.

If it doesn't, you get a syntax error.
