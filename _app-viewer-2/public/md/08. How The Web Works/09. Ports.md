# Ports

&nbsp;

A port is NOT a physical connection but rather a logical connection used by programs to exchange information.

It determines which program on a computer is going to be used. A port has a unique number (e.g. `80` for HTTP).

A port is always associated with an IP address. The port number is added to the IP address so the receiver knows which program to use.

The range for ports is `0 - 65535`, assigned by IANA.

&nbsp;

---

&nbsp;

## Port Categories

- **System / Well-known ports**: `0 - 1023` (server side)
- **User / Registered ports**: `1024 - 49151` (registered by companies for services, server side)
- **Dynamic / Private ports**: `49152 - 65535` (free to use, client side — self assigned)
