# Bandwidth and Throughput

&nbsp;

## Rate Of Data Transfer

The terms bandwidth and throughput describe the rate of data transfer — aspects of the speed of transmitting and receiving bits across a distance.

&nbsp;

---

&nbsp;

## Bandwidth

Bandwidth is the capacity of a medium to carry data.

Digital bandwidth is measured by the theoretical amount of bits that can be sent across the medium in a second (bps).

- bps — bits per second
- kbps — thousand (Kilobit) bits per second
- Mbps — million (Megabit) bits per second
- Gbps — billion (Gigabit) bits per second
- Tbps — trillion (Terabit) bits per second

&nbsp;

---

&nbsp;

## Throughput

Throughput is the actual measure of the transfer of bits across the medium over a given period of time.

Due to a number of factors, throughput does not usually match the specified bandwidth.

Factors that influence throughput include:

- Amount of data being sent and received over the connection
- Types of data being transmitted
- Latency created by the number of network devices encountered between source and destination

&nbsp;

---

&nbsp;

## Note

Bits are used to measure data speed whereas bytes are used to measure storage or file size. A gigabit and gigabyte are not the same amount and are not used to measure the same concepts.
