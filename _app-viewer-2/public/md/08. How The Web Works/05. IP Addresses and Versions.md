# IP Addresses and Versions

&nbsp;

A computer has a permanent, unique **MAC address** built into its hardware — this is the physical address. The hardware piece containing the MAC is called the **Network Interface Card (NIC)**.

An **IP address** is assigned (not permanent) and identifies a device on a network — this is the logical address.

## IPv4 Address Types

### Unicast
A packet with a single source and single destination.

- Range: `1.1.1.1` to `223.255.255.255`

### Broadcast
A packet from a single source to all destinations on the network. Not forwarded by routers by default.

- Range: `255.255.255.255`

### Multicast
A packet from a single source to multiple (but not all) destinations.

- Range: `224.0.0.0` to `239.255.255.255`

## IPv4 Public vs Private

**Public** — globally routed between ISP routers.

**Private** — cannot be used on the internet, only for internal hosts (RFC 1918):

- `10.0.0.0/8` → `10.0.0.0 - 10.255.255.255`
- `172.16.0.0/12` → `172.16.0.0 - 172.31.255.255`
- `192.168.0.0/16` → `192.168.0.0 - 192.168.255.255`
