# Globals

These are standard built ins that have global scope

## What Are Globals Made Of?

Globals can be objects, value properties, functions and more. 

Some examples of globals in JS:

**NaN** - a global value property

**isNaN()** - a global function

## Three Layers of Globals

JavaScript has globals, the browser has globals, and Node.js has globals. There's overlap between them.

## 1. JavaScript Core Globals (everywhere)

Available in all JavaScript environments (browsers, Node.js, Deno, etc.):

**Constructors:**
- `Error`, `Array`, `Object`, `String`, `Number`, `Boolean`, `Date`, `Promise`, `RegExp`, `Map`, `Set`

**Singleton objects:**
- `Math`, `JSON`

**Functions:**
- `parseInt()`, `parseFloat()`, `isNaN()`, `setTimeout()`, `setInterval()`

**Values:**
- `undefined`, `null`, `NaN`, `Infinity`

## 2. Browser-Only Globals

Only available in web browsers:

**Singleton objects:**
- `window` (the global object itself)
- `document` (the DOM)
- `navigator` (browser info)
- `location` (URL info)
- `localStorage`, `sessionStorage`
- `history`

**Constructors:**
- `HTMLElement`, `XMLHttpRequest`, `Blob`, `File`

**Functions:**
- `alert()`, `confirm()`, `prompt()`
- `fetch()` (now also in Node.js 18+)

## 3. Node.js-Only Globals

Only available in Node.js:

**Singleton objects:**
- `process` (Node process info)
- `global` (the global object, like `window` in browsers)
- `console` (enhanced version)

**Variables (not truly global, but available in every module):**
- `__dirname` (current directory path)
- `__filename` (current file path)
- `require()` (module loading)
- `module`, `exports`

**Functions:**
- `Buffer` (binary data handling)
- `setImmediate()`, `clearImmediate()`

## Why This Matters

**Code that uses only JavaScript core globals works everywhere:**
```javascript
const arr = [1, 2, 3];
const sum = arr.reduce((a, b) => a + b);
// Works in browser, Node.js, Deno, etc.
```

**Code that uses browser globals only works in browsers:**
```javascript
document.getElementById('button'); // Only in browsers
```

**Code that uses Node globals only works in Node:**
```javascript
process.env.NODE_ENV; // Only in Node.js
```

## Summary

Three layers of globals:
1. **JavaScript Core** - available everywhere
2. **Browser** - only in web browsers
3. **Node.js** - only in Node.js environment

Understanding which globals come from where helps you write portable code and understand compatibility issues.
