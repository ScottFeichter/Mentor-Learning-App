# __filename

The absolute path to the current file, including the filename.

```js
console.log(__filename);
// /Users/username/project/src/app.js
```

## __filename vs __dirname

```js
console.log(__filename); // /Users/username/project/src/app.js
console.log(__dirname);  // /Users/username/project/src
```

`__filename` = `__dirname` + the file's name.

## Key Points

- Includes the full path AND the filename
- Not truly a global — Node injects it per module at runtime
- Always an absolute path
- Only available in CommonJS (`require`). In ES modules (`import`), use `import.meta.filename` (Node 21.2+) or:

```js
import { fileURLToPath } from "url";

const __filename = fileURLToPath(import.meta.url);
```
