# SVG.js

**npm:** `@svgdotjs/svg.js`

Lightweight library for creating and manipulating SVG graphics. Chainable API for drawing shapes, paths, text, gradients, and animations.

**Use cases:**
- Generating SVG graphics programmatically
- Creating data visualizations
- Manipulating existing SVG documents
- Animated vector graphics

**Install:**
```bash
npm install @svgdotjs/svg.js
```
