# Canvas (Compositing & Batch)

**npm:** `canvas`

Using Node Canvas for complex compositing workflows. Full programmatic layout control — position images, draw shapes, render text with custom fonts, and export the final composition.

**Use cases:**
- Complex multi-element compositions (InDesign-like layouts)
- Dynamic image generation with precise text placement
- Certificate/badge generation with custom fonts and logos
- Combining data-driven content with visual templates

**Note:** Same package as Node Canvas (Canvas Drawing) — this documents its compositing and layout capabilities specifically.
