# OpenCV4NodeJS

**npm:** `@u4/opencv4nodejs`

Full OpenCV bindings for Node.js. Computer vision operations including face detection, contour detection, perspective transforms, optical flow, feature matching, and image segmentation.

**Use cases:**
- Face/object detection
- Document scanning (perspective correction)
- Motion detection and tracking
- Image stitching (panoramas)
- OCR preprocessing

**Install:**
```bash
npm install @u4/opencv4nodejs
# Requires OpenCV installed on the system
```
