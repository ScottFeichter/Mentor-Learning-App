# Sharp

**npm:** `sharp`

The fastest Node.js image processing library. Built on libvips. Resize, crop, rotate, composite, format conversion, and color manipulation. Significantly faster than ImageMagick or Jimp for most operations.

**Use cases:**
- Resizing/cropping uploaded images
- Format conversion (PNG → WebP, JPEG → AVIF)
- Image compositing (layering images)
- Thumbnail generation

**Install:**
```bash
npm install sharp
```
