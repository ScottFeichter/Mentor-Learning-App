# PSD.js

**npm:** `psd.js`

Parse Adobe Photoshop .psd files in JavaScript. Extract layer data, read metadata, flatten to image, and access individual layer pixels. Read-only — does not write .psd files.

**Use cases:**
- Extracting layers from .psd uploads
- Reading PSD metadata (dimensions, color mode, etc.)
- Flattening PSD to PNG/JPEG
- Inspecting layer structure programmatically

**Install:**
```bash
npm install psd.js
```
