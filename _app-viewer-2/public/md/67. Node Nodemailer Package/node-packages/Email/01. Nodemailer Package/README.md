# Nodemailer

**npm:** `nodemailer`

The standard Node.js email sending library. Supports SMTP, Gmail, Outlook, AWS SES, and custom transports. Handles HTML/plain text bodies, attachments, embedded images, and OAuth2 authentication.

**Use cases:**
- Sending transactional emails (reports, notifications)
- Attaching files (e.g., spreadsheet reports)
- Bulk email with templates

**Install:**
```bash
npm install nodemailer
npm install @types/nodemailer  # TypeScript
```
