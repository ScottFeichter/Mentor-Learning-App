# Docxtemplater

**npm:** `docxtemplater`

Template-based Word document generation. Create a .docx template with `{placeholder}` tags, then fill in data programmatically. Supports loops, conditionals, and images via plugins.

**Use cases:**
- Mail merge workflows
- Filling in form templates with data
- Generating personalized documents from a master template

**Install:**
```bash
npm install docxtemplater pizzip
```
