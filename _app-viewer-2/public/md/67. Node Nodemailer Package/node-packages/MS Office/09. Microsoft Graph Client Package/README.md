# Microsoft Graph Client

**npm:** `@microsoft/microsoft-graph-client`

Official SDK for Microsoft Graph API. Access Outlook mail, Calendar, OneDrive, Teams, SharePoint, and all Microsoft 365 services programmatically.

**Use cases:**
- Sending emails via Outlook
- Managing calendar events
- Accessing OneDrive/SharePoint files
- Teams messaging integration

**Install:**
```bash
npm install @microsoft/microsoft-graph-client
```
