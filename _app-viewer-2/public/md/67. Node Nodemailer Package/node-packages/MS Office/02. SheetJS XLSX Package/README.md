# SheetJS (xlsx)

**npm:** `xlsx`

Fast spreadsheet parser and writer. Supports .xlsx, .xls, .ods, .csv, and many other formats. The free Community Edition handles data but not styles. Excellent for parsing and data extraction.

**Use cases:**
- Parsing uploaded spreadsheets
- Converting between formats (.ods → .xlsx, .csv → .xlsx)
- Fast bulk data extraction

**Install:**
```bash
npm install xlsx
```
