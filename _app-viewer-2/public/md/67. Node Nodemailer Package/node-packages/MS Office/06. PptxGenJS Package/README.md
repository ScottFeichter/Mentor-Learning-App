# PptxGenJS

**npm:** `pptxgenjs`

Create PowerPoint .pptx presentations from scratch. Supports slides, text, images, charts, tables, shapes, and media. Works in Node.js and browsers.

**Use cases:**
- Generating slide decks from data
- Automated report presentations
- Chart/data visualization in PowerPoint format

**Install:**
```bash
npm install pptxgenjs
```
