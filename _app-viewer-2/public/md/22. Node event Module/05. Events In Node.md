# Events In Node

Node doesn't have a DOM or UI and therefore doesn't not have the same concerns of browsers.

The architecture that Node utilizes is fundementally different from that of a browser.

Node utilizes EDA to handle asynchronous operations in a way that is non blocking.

## Comparisions

Nevertheless tutorials often try to match a pattern with browser events to the EventEmitter class used in Node.

An instance of Node's EventEmitter is the functional equivalent of a DOM element (like an HTML <button>) in the browser.

However, EventEmitter "events" are not very much like browser events and this attempt to pattern match causes more harm than good.

## Node's EventEmitter

 You create custom emitters and trigger them programmatically:

```javascript
const EventEmitter = require('events'); // import the module that has access to EventEmitter class

const myEmitter = new EventEmitter(); // programatically instantiate the EventEmitter

myEmitter.on('customEvent', () =>  {  // use the .on() method to add a listener to an event emitter
  console.log('Custom event fired!');
});

myEmitter.emit('customEvent'); // use .emit() to programatically trigger the listening target to execute the handler
```
