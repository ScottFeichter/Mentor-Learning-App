# Browser Events
Browser event driven architecture refers to how web development is oriented around interactivity.

This interactivity is facilitated via the browser rendering engine processing events.

## Events
Rather than code running from top to bottom and finishing, a web application stays active in memory.

It waits for specific triggers to occur so it can react to them, a process expressed programmatically as an **event**.

## Core Concepts

* **Event Type** (The Trigger): Some action such as a mouse click.
* **Event Target** (The Component): The element receiving the trigger such as an HTML button.
* **Event Listener** (The Flag): A method attached to a target that tells the browser engine the event is meaningful.
* **Event Handler** (The Reaction): A function that runs in response to the browser engine detecting the listener on the target.
