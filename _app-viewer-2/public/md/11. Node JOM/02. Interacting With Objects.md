# Interacting With Objects

&nbsp;

We can interact programatically with objects using syntactic notation in two styles:

## Dot Notation
```js
myObject.someProperty = "adding a new property";
```

## Bracket Notation
```js
myObject["someOtherProperty"] = "adding yet another property";
```

## Built In JS Object Methods

We can also interact with objects using methods that are built in to the language:

- ```Object.keys(obj)```
- ```Object.values(obj)```
- ```Object.entries(obj)```

### Example

```js
let keysOfMyObject = Object.keys(myObject);

console.log(keysOfMyObject)

// [
//  'someKey',
//  'anotherKey',
//  'thisKeyHasAFunctionForItsValue',
//  'someProperty',
//  'someOtherProperty'
// ]
```
