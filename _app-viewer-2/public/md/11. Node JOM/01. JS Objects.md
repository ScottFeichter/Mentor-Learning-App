# JS Objects

&nbsp;

An **object** is a very useful and important data structure in JS.

## Review

Recall that an object in JS is:
- a container for multiple **properties**
- **properties** are <span class="red-bold">key</span> **:** <span class="blue-bold">value</span> pairs
- <span class="red-bold">keys</span> are always strings
- <span class="blue-bold">values</span> can be any primitive data type, an array, an object, or a function
- a **property** whose <span class="blue-bold">value</span>  is a function is called a <span class="subheading-highlight">method</span>.

```js

let myObject = {
    "someKey": "someValue",
    "anotherKey": "anotherValue",
    "thisKeyHasAFunctionForItsValue": function() {
        return `we refer to functions as methods when a property of an object`
    }
}
```
