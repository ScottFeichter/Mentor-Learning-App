# Regular Expression Explanation

## Code
```javascript
const regEx = /\b(&lt;|&gt;|&gt;=|=|&lt;|&lt;=)\b/g;
```

## Overview
This regular expression matches HTML-encoded comparison operators within word boundaries.

## Pattern Breakdown

### `/\b(...)\b/g`
- **`\b`** - Word boundary anchors that ensure the pattern matches complete operators, not parts of larger strings
- **`g`** - Global flag that finds all matches in the string, not just the first one

### `(&lt;|&gt;|&gt;=|=|&lt;|&lt;=)`
This is a capturing group with alternation (`|`) that matches any of these HTML entities:

| Pattern | HTML Entity | Decoded Symbol | Meaning |
|---------|-------------|----------------|---------|
| `&lt;` | `&lt;` | `<` | Less than |
| `&gt;` | `&gt;` | `>` | Greater than |
| `&gt;=` | `&gt;=` | `>=` | Greater than or equal |
| `=` | `=` | `=` | Equal |
| `&lt;=` | `&lt;=` | `<=` | Less than or equal |

## What It Matches
- HTML-encoded comparison operators surrounded by word boundaries
- Examples: `&lt;`, `&gt;=`, `&lt;=` when they appear as complete tokens

## What It Doesn't Match
- Raw symbols like `<`, `>`, `>=` (these are the decoded versions)
- Partial matches within larger strings
- HTML entities that aren't comparison operators

## Use Case
Typically used to find and process comparison operators in HTML content where `<` and `>` have been encoded to prevent HTML parsing issues.
