# Error Objects

Understanding error objects helps build robust applications that handle failures gracefully and provide meaningful feedback to users and developers.

## Error Categories

### Runtime Errors
- Occur during code execution
- Examples: TypeError, ReferenceError
- Can be caught with try/catch

### Syntax Errors
- Occur during code parsing
- Examples: Missing brackets, invalid syntax
- Cannot be caught with try/catch

### Logic Errors
- Code runs but produces wrong results
- Examples: Incorrect calculations, wrong conditions
- Hardest to detect and debug

### Network Errors
- Connection or communication failures
- Examples: Database connection lost, API timeout
- Often require retry logic
