# URL Parameters, Query Parameters, and HTTP Request Parameters

## URL Parameters (Path Parameters)

URL parameters are part of the URL path, defined by placeholders in the route.

**Example:**
```
/users/:id/posts/:postId
/users/123/posts/456
```

- `:id` = 123
- `:postId` = 456

**Express.js:**
```javascript
app.get('/users/:id', (req, res) => {
  const userId = req.params.id; // "123"
});
```

## Query Parameters

Query parameters come after the `?` in the URL, separated by `&`.

**Example:**
```
/search?q=nodejs&category=tutorial&limit=10
```

- `q` = "nodejs"
- `category` = "tutorial" 
- `limit` = "10"

**Express.js:**
```javascript
app.get('/search', (req, res) => {
  const query = req.query.q;        // "nodejs"
  const category = req.query.category; // "tutorial"
  const limit = req.query.limit;    // "10"
});
```

## HTTP Request Parameters

### 1. Request Body (POST/PUT)
Data sent in the request body, typically JSON.

```javascript
// Client sends
fetch('/api/users', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: 'John', email: 'john@email.com' })
});

// Server receives
app.post('/api/users', (req, res) => {
  const name = req.body.name;   // "John"
  const email = req.body.email; // "john@email.com"
});
```

### 2. Headers
Metadata sent with the request.

```javascript
app.get('/api/data', (req, res) => {
  const auth = req.headers.authorization;
  const contentType = req.headers['content-type'];
});
```

### 3. Form Data
Data from HTML forms or multipart uploads.

```javascript
app.post('/upload', (req, res) => {
  const formData = req.body; // form fields
  const files = req.files;   // uploaded files
});
```

## Summary

- **URL Parameters**: Part of the path (`/users/:id`)
- **Query Parameters**: After `?` in URL (`?name=value&foo=bar`)
- **Request Body**: JSON/form data in POST/PUT requests
- **Headers**: Metadata like authentication tokens
- **Form Data**: HTML form submissions and file uploads

Each serves different purposes for passing data between client and server.
