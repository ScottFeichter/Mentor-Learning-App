# MongoDB Query API 

## MongoDB Query API

The **MongoDB Query API** is a set of methods and operators used to retrieve, filter, and manipulate documents in MongoDB collections.

### Core Query Methods

- **find()**: Retrieve documents matching criteria
- **findOne()**: Retrieve single document
- **countDocuments()**: Count matching documents
- **distinct()**: Get unique values for a field

### Query Operators

```javascript
// Comparison operators
db.users.find({ age: { $gte: 18, $lt: 65 } })

// Logical operators
db.users.find({ $and: [{ age: { $gte: 18 } }, { status: "active" }] })

// Element operators
db.users.find({ email: { $exists: true } })

// Array operators
db.users.find({ tags: { $in: ["premium", "vip"] } })
```

### Query Features

- **Projection**: Select specific fields to return
- **Sorting**: Order results by field values
- **Limiting**: Restrict number of results
- **Skipping**: Pagination support

```javascript
db.users.find(
  { age: { $gte: 18 } },           // filter
  { name: 1, email: 1, _id: 0 }    // projection
).sort({ name: 1 }).limit(10)      // sort and limit
```
