# pnpm

## What Is pnpm?

pnpm (Performant npm) is a fast, disk-space-efficient package manager for Node.js. It stores packages in a global content-addressable store and uses hard links and symlinks to create `node_modules`, avoiding duplicate copies of the same package across projects.

## Installation

```bash
# Via npm
npm install -g pnpm

# Via corepack (Node 16+)
corepack enable
corepack prepare pnpm@latest --activate

# Via Homebrew (macOS)
brew install pnpm
```

## Basic Commands

| npm | pnpm |
|-----|------|
| `npm install` | `pnpm install` |
| `npm install pkg` | `pnpm add pkg` |
| `npm install -D pkg` | `pnpm add -D pkg` |
| `npm uninstall pkg` | `pnpm remove pkg` |
| `npm run script` | `pnpm run script` or `pnpm script` |
| `npm init` | `pnpm init` |
| `npx command` | `pnpm dlx command` |

## How pnpm Works

### Content-Addressable Store

All packages are stored once in a global store (usually `~/.pnpm-store`). When a project needs a package, pnpm creates a hard link to the store instead of copying files.

```
~/.pnpm-store/
  v3/
    files/
      ab/cdef1234...  (actual package files)

project/node_modules/
  .pnpm/
    express@4.18.2/
      node_modules/
        express -> hard link to store
```

### Strict node_modules

Unlike npm's flat `node_modules`, pnpm creates a nested structure that prevents accessing packages you haven't explicitly declared as dependencies (no phantom dependencies).

## Key Features

- **Fast** — Installs are up to 2x faster than npm
- **Disk efficient** — Packages stored once, linked everywhere
- **Strict** — No phantom dependencies
- **Monorepo support** — Built-in workspace support
- **Lockfile** — Uses `pnpm-lock.yaml`

## Configuration

### .npmrc for pnpm

```ini
# Hoist packages (for compatibility)
shamefully-hoist=true

# Set store location
store-dir=~/.pnpm-store

# Auto-install peers
auto-install-peers=true
```

## Summary

- pnpm is a drop-in replacement for npm
- Saves disk space via content-addressable storage
- Faster installs through hard linking
- Stricter dependency resolution prevents bugs
- Great for monorepos with workspace support
