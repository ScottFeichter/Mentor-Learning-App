# Analyzing Time Complexity

## Rules

When determining algorithm time complexity:

- Constants **do not** matter — O(2n) simplifies to O(n)
- Smaller terms **do not** matter — O(n + 10) simplifies to O(n)
- Always make sure you can answer: **what is n?** (String? Array? Number? etc.)

## Helpful Hints

- Arithmetic operations are **constant time**
- Variable assignments are **constant time**
- Accessing elements in an array (by index) or object (by key) is **constant time**
- Loops: length of the loop × complexity of whatever happens inside the loop

## Examples

```javascript
// O(1) — constant
function addUp(n) {
  return n * (n + 1) / 2;
}

// O(n) — linear
function addUpLoop(n) {
  let total = 0;
  for (let i = 1; i <= n; i++) {
    total += i;
  }
  return total;
}

// O(n²) — quadratic
function printPairs(arr) {
  for (let i = 0; i < arr.length; i++) {
    for (let j = 0; j < arr.length; j++) {
      console.log(arr[i], arr[j]);
    }
  }
}
```
