# Git Remotes and Collaboration

## Set Up a Remote

```bash
git remote                        # view remote repos
git remote -v                     # view with URLs (fetch and push)
git remote add origin <URL>       # add remote repository
git remote rm origin              # delete remote
```

> "Origin" is the naming convention for a local branch that references the remote server branch.

## Push to Remote

```bash
git push -u origin <branchname>   # create/push remote branch (-u = track)
git push                          # push changes (if tracking)
git push origin main              # push to specific branch
```

## Clone a Remote

```bash
git clone <repo-url>              # download remote repo to local
```

## Fetch and Merge

```bash
git fetch                         # fetch changes from remote
git merge origin/main             # merge fetched changes into local main
```

> `git pull` does fetch + merge in one command.
> Fetch often: first thing of day, before push, last thing of day.

## Delete Remote Branches

```bash
git push origin --delete <branch>   # delete remote branch
git push origin :<branch>           # old syntax (colon = delete)
```

## Track Remote Branches

```bash
git branch -u <upstream>/branchname branchname
git checkout <branchname> <target>   # checkout remote branch
```

## Collaboration Workflow

1. Add collaborators on GitHub
2. Fork repos to become a collaborator
3. Clone, branch, commit, push
4. Create pull requests on GitHub

## A Practice Routine

```bash
open -a "Chrome"                          # open browser
# Create new repo on GitHub
git clone <SSH-URL>                       # clone to local
cd <repo>                                 # enter repo
git remote -v                             # verify remote
touch hello_world.txt                     # create file
git status                                # check status
git add hello_world.txt                   # stage
git commit -m "Add hello_world.txt"       # commit
git status                                # verify
git log                                   # view history
```

## Cheatsheet

**Remote commands:**
```bash
git clone git@github.com:USER-NAME/REPOSITORY-NAME.git
git push origin main
```

**Workflow commands:**
```bash
git add .
git commit -m "A message describing the snapshot"
```

**Status/log commands:**
```bash
git status
git log
```
