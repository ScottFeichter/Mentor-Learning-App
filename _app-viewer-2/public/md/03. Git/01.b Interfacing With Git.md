# Interfacing with Git

&nbsp;

Git does not have a GUI — it is utilized via CLI.

Third party GUIs exist but are not very useful as of writing.

## Command Syntax

The syntax to use Git follows the usual CLI pattern:

`program | utility | flag | argument`

### Example

```bash
git commit -m "message"
```
