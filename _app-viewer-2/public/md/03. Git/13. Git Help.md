### GIT HELP {#git-help}

**Open git help:** git help

**Open git help \-a:** git help \-a

**Open git help \-g:** git help \-g

**Open git help \<command\>:** git help \<command\>

**Open git help \<concept\>:** git help \<concept\>

**Open git help git:** git help git
