# HTML Basics

## Three Components

- **Tags** — tell the browser how to display content
- **Elements** — tags and the content between them
- **Attributes** — `name="value"` pairs that define additional information

## Comments

```html
<!-- comment -->
```

## Whitespace

Browsers ignore whitespace in HTML source code.

## Learning Objectives

- Appropriately structure an HTML page
- Identify, utilize, and distinguish common semantic HTML tags

## Compare and Contrast Similar Tags

| Comparison | Difference |
|-----------|-----------|
| `div` vs `span` vs `p` | Block container vs inline container vs paragraph |
| `h1` vs `h2` vs `h3` | Heading hierarchy (importance/size) |
| `ol` vs `ul` | Ordered (numbered) vs unordered (bulleted) list |
| `br` vs `hr` | Line break vs horizontal rule (thematic break) |
| `link` vs `a` | External resource link (in head) vs anchor/hyperlink |
| `head` vs `header` | Document metadata vs page/section header |
| `head` vs `body` vs `footer` | Metadata vs content vs footer |
