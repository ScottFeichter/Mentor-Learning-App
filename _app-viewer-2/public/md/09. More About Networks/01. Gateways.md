# Gateways

&nbsp;

## Gateway

A gateway is the way traffic leaves a LAN and goes to other networks — like the exit door.

## Default Gateway

The first gateway a host will try. Often the router is the default gateway for all hosts on its network.

Each interface on a router is connected to a separate network. The IPv4 address assigned to the interface identifies which local network is directly connected to it. Each host must know the IPv4 address of the router interface connected to its network — this is the default gateway.

## Router as DHCP Server

It is common for the router to also be the DHCP server. It provides:

- Its own internal IPv4 address as the default gateway to DHCP clients
- The client's own IPv4 address and subnet mask

The default IPv4 address on the router is usually the first host address and it provides hosts with addresses within the same network and within a configurable range.

## ISP and External Network

Many ISPs use DHCP servers to provide IPv4 addresses to the internet side of routers. In this case the router is in the role of DHCP client to receive the correct external network IPv4 address.

The router is therefore the boundary between the local network and the external internet — acting as both DHCP server and client.
