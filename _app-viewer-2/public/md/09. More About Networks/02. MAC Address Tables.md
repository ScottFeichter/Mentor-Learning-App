# MAC Address Tables

&nbsp;

A switch makes its forwarding decision based on Layer 2 information — the Ethernet header of the Ethernet Frame.

&nbsp;

---

&nbsp;

## How It Works

1. The switch looks at the **source MAC address** and checks if it already exists in its table. If not, it adds it.
2. It then checks for the **destination MAC address**. If not found, it sends the frame out every port except the incoming port — this is called an **unknown unicast**.
3. Devices that receive it check if it matches their MAC. If not, they ignore it.
4. As the switch receives unknown source MACs it adds them to its table (kept for about 5 minutes).
