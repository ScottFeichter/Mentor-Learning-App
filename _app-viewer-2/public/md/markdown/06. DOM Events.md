# DOM Events and Event Listeners

## Event Types

**UI Events:** load, unload, error, resize, scroll

**Focus/Blur:** focus, blur, focusin, focusout

**Mouse:** click, dblclick, mousedown, mouseup, mouseover, mouseout, mousemove

**Keyboard:** input, keydown, keypress, keyup

**Form:** submit, change, input

**HTML5:** DOMContentLoaded, hashchange, beforeunload

**CSS:** transitionend, animationstart, animationiteration, animationend

## Event Listeners

```javascript
element.addEventListener(type, listener)
element.addEventListener(type, listener, options)
element.addEventListener(type, listener, useCapture)
```

- **type** — case-sensitive string (e.g., "click")
- **listener** — callback function, object with handleEvent(), or null
- **options** — `{ capture: bool, once: bool, passive: bool, signal: abort() }`
- **useCapture** — boolean (default false = bubbling, true = capturing)

### Example

```javascript
const button = document.querySelector("button");

button.addEventListener("click", (e) => {
  console.log(`Event fired: ${e}`);
}, false);
```

## Event Objects

Created when an event is triggered. Passed to the handler callback.

### event.target

Returns the element where the event occurred (read-only).

### event.preventDefault()

Cancels the default action (e.g., prevent form submission, prevent link navigation):

```javascript
document.getElementById("myAnchor").addEventListener("click", function(event) {
  event.preventDefault();
});
```

### event.stopPropagation()

Prevents the event from bubbling/capturing through the DOM:

```javascript
event.stopPropagation();
```

## Propagation

- **Bubbling** (default) — inner element first, then outer
- **Capturing** — outer element first, then inner
