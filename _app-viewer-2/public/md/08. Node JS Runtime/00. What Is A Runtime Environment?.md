# What Is A Runtime Environment?

&nbsp;

The full software ecosystem required to compile, execute, and manage a program while it runs.

Sometimes referred to simply as a runtime.

## What Is Runtime Environment Concerned With?

### Code Execution
  - the engine
  - task flow management
  - thread management
  - memory management?

  ## Additional Capabilities
- external APIs
- memory management?
- task queues, stacks, and loops
