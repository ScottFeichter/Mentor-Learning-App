# Sorting Concepts

## Swapping

Using a temp variable:

```javascript
let tmp = arr[1];
arr[1] = arr[2];
arr[2] = tmp;
```

Using destructuring:

```javascript
[arr[4], arr[6]] = [arr[6], arr[4]];
```

## Shifting

When shifting to right you must shift BACK TO FRONT:

```javascript
for (let i = arr.length - 1; i > 0; i--) {
  arr[i] = arr[i - 1];
}
```

## Bubble Sort

- flagSwap = true
- While (flagSwap)
  - for (let i = 0 ...)
    - Compare adjacent pair
    - Swap if needed → Swap = true
    - Continue to next pair
- If no swap occurs exit, else run again

## Insertion Sort

- Split the array into sorted and unsorted
- Pick and remove a value from the unsorted
- Insert it into the correct place in the sorted
- Repeat until unsorted is empty and sorted is full

Variants:
- **Out of Place** — start by creating an empty array
- **In Place** — use a divider index

## Selection Sort

- Split the array into sorted and unsorted
- Find and remove the smallest (or largest) value from the unsorted
- Add this value to the end (beginning) of the sorted array
- Repeat until unsorted is empty and sorted is full

## Recursive Sorting

- Base case: `arr.length <= 1` (any array of length 1 is sorted)
- The step is removing the largest (or smallest), reducing arr.length
- Use splice and push to do in place
- Can use Math.min or Math.max then indexOf
- Time: ~O(n²)

## Divide and Conquer

- Improves time complexity by reducing depth of calls
- Instead of reducing array by one each call, split it in half
  - Check base case, return if length <= 1
  - Split array in half to get log n recursive steps to reach base
  - Recursive sort each half
  - Put left half and right half together and return
- Quicksort and Mergesort are examples
- Time: O(n log n)

## Merge Sort Notes

- Out of Place Recursive
  1. Split unsorted in half
  2. Sort halves
  3. Merge sorted halves
- Can use a pointer to improve Time to O(n)
- Space complexity can vary by implementation

## Quicksort Notes

- Uses divide and conquer
  1. Pick a value to be pivot
  2. Partition array with smaller values on left of pivot
  3. Sort each partition
  4. Return an array with left, pivot, and right values
- Depending on how the pivot is set: Time O(log n) to O(n²)
- Space: O(1) to O(n log n)

## Funky Sorting

- May be asked to sort for many different things (e.g. all zeros to the left)
- Think about: Out of place vs In place, Divide and conquer, Space/Time Complexity, shift/unshift/push/pop/splice

## Built-in Sorts

- Each browser runs their own sorting implementation
  - Chrome V8 uses mergesort
- `Array.sort()` sorts numbers in *alphabetical* order (treats them as strings)
- You can define a custom sorting predicate:

```javascript
arr.sort((a, b) => a - b); // numerical sort
```
