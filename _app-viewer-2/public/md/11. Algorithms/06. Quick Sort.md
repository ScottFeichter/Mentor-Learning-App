# Quick Sort

Time: O(n²) worst case, O(n log n) average
Space: O(n) or O(log n)

```javascript
function quicksort(arr) {
  if (arr.length <= 1) return arr;

  const pivot = arr[0];
  const smaller = [];
  const bigger = [];

  for (let i = 1; i < arr.length; i++) {
    if (arr[i] < pivot) {
      smaller.push(arr[i]);
    } else {
      bigger.push(arr[i]);
    }
  }

  return [...quicksort(smaller), pivot, ...quicksort(bigger)];
}
```
