# What Is The DOM?

## DOM = Document Object Model

The DOM is **not** part of JavaScript itself. It's a **Web API** provided by the browser.

## What It Is

The DOM is a tree-like representation of an HTML document, exposed as JavaScript objects. When a browser loads an HTML page, it:

1. Parses the HTML
2. Creates a tree structure in memory
3. Provides JavaScript objects to interact with that structure

## Accessing the DOM

The browser gives you global objects to access the DOM:

```javascript
document.querySelector('button')  // returns a button element object
document.getElementById('myDiv')  // returns a div element object
window.alert('Hello!')            // window is also part of the Web API
```

These objects (`document`, `window`, element objects) are **JavaScript objects**, but they're created and provided by the **browser**, not by JavaScript itself.

## Browser Events

In the browser, DOM elements emit events (clicks, key presses, page loads). You register listeners to respond to these events:

```javascript
button.addEventListener('click', () => {
  console.log('Button clicked!');
});
```

When the user clicks the button, the browser emits the 'click' event and executes all registered listeners.
