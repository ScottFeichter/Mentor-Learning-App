# The Russian Doll: Browser Hierarchy

## The Nesting Structure

The browser environment is hierarchical, like Russian nesting dolls. Each layer contains the next:

```
Browser Application
  └── Window (browser tab/window)
      └── Document (the loaded HTML page)
          └── HTML Element (<html>)
              └── Body Element (<body>)
                  └── Child Elements (<div>, <button>, etc.)
                      └── Nested Children...
```

## Layer by Layer

### 1. Browser Application
The actual program running on your computer (Chrome, Firefox, Safari).

### 2. Window Object
Represents a browser tab or window. The global object in browser JavaScript.
- Contains: `document`, `console`, `alert()`, `setTimeout()`, etc.
- One window per tab

### 3. Document Object
Represents the loaded HTML page within that window.
- The entry point to the DOM
- Access via `window.document` or just `document`

### 4. DOM Tree
The hierarchical structure of HTML elements:
- Starts with `<html>` (root element)
- Contains `<head>` and `<body>`
- Each element can contain child elements
- Each element is a JavaScript object with properties and methods

## How It's Generated

1. **Browser loads HTML** → Parses the text
2. **Creates DOM tree** → Converts HTML tags into element objects in memory
3. **Renders to screen** → Uses DOM + CSS to paint pixels
4. **Exposes to JavaScript** → Provides `window` and `document` objects to interact with it

## In Code

```javascript
window                          // The browser window/tab
  └── window.document           // The HTML document
      └── document.documentElement  // <html> element
          └── document.body     // <body> element
              └── document.querySelector('button')  // A button element
```

Each level is a JavaScript object that contains/references the objects below it.
