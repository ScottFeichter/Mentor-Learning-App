# Data Containers

## Types

- **Literal** — a fixed value written directly in code
- **Primitive** — basic data types (number, string, boolean, etc.)
- **Reference** — objects, arrays (stored by reference)
- **Variable** — has one value
- **Array** — multiple values, usually same type
- **Structure** — multiple values but no functions
- **Class/Object** — multiple key-value pairs (may include methods)
- **List** — multiple values, can be different types
- **Dictionary** — key:value pairs, ordered, changeable, no duplicates
- **Tuple** — a constant (immutable) list
- **Set** — items are unchangeable, but you can remove/add items
- **Pointer** — a reference to a memory address
