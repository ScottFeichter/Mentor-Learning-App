# Graphs

## Intro to Graphs

[Seven Bridges of Königsberg](https://en.wikipedia.org/wiki/Seven_Bridges_of_K%C3%B6nigsberg)

Node-and-pointer structures (all forms of graphs):
- Linked List
- Doubly Linked List
- Binary Tree
- Binary Search Tree

## What is a Graph?

- An abstract data type representing a collection of nodes and edges
- Each node contains one or more values and any number of edges
- Edges point to other nodes
- Graphs represent relationships between objects
- Graphs do not necessarily start from a root node

## Graph Properties

- **Directed**: one-way edges (arrows)
- **Undirected**: two-way edges (no arrows)
- **Bidirected**: two arrows (explicit two-way)
- **Cyclic**: contains circles, can lead to loops, must track visited
- **Acyclic**: no circles
- **Weighted**: edges have different weights
- **Unweighted**: every edge has a weight of 1

## Adjacency List

An object of keyed vertices where each vertex value is an associated set of connections:

```javascript
const adjList = {
  1: [2, 5],
  2: [1, 3, 5],
  3: [2, 4],
  4: [3, 5, 6],
  5: [1, 2, 4],
  6: [4],
};
```

*Vertex is synonymous with node.*

## Breadth-First Traversal (Graph)

- Similar to tree BFT but must keep track of visited nodes
- Visits nodes from nearest to furthest, level by level

Algorithm:
1. Create a queue and enqueue the starting node
2. Create a set to store visited nodes
3. While the queue is not empty:
4. Dequeue the first node
5. Do the thing you need to do
6. For each unvisited neighbor, add it to visited and to the back of the queue

## Depth-First Traversal (Graph)

Same as BFT but use a stack instead of a queue.

## Data Structures and Algorithms

- A **data structure** is a format for storing and managing more than one piece of data
- Two fundamental ways of storing information:
  - In **arrays**
  - With **nodes**

### What is a Node?

An individual part of a larger data structure:
- Contains data
- Has links to one or more other nodes

## Asymptotic Notation

Used to describe the running time of an algorithm.

Three kinds:
- **Big O** — upper bound (worst case)
- **Big Theta Θ** — tight bound (average case)
- **Big Omega Ω** — lower bound (best case)

## Algorithm Types

- **Greedy**: makes locally optimal choices at each step
- **Brute Force**: tries all possibilities
- **Recursive**: calls itself with smaller input
- **Divide and Conquer**: splits problem in half recursively
- **Dynamic Programming**: stores results of subproblems
- **Backtracking**: explores and abandons paths that don't work
- **Branch & Bound**: systematic enumeration with pruning
