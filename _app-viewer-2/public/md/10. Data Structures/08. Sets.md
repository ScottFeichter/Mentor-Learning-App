# Sets

A set is an abstract data type that stores a collection of **unique**, **unordered** values.

- No duplicate values allowed
- Items are inserted based on the hash-valued index
- Lookup time using `set.has()` is O(1)
- Implemented using hash tables to achieve O(1) search
- O(n) space complexity (dynamically resizes at 0.7 load capacity)
- Niche use, but capable of massive performance gains when used appropriately

## JavaScript Built-in Set

```javascript
const mySet = new Set();

mySet.add(value);
mySet.has(value);    // O(1)
mySet.delete(value);
```

## Time Complexity of Common Set Methods

| Operation | Complexity |
|-----------|-----------|
| retrieval | O(1) |
| .has() | O(1) |
| .add() | O(1) *unless resizing needed then O(n) |
| .delete() | O(1) |
