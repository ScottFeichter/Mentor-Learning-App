# Doubly Linked Lists

Each node contains a pointer to the **previous** node as well as the **next** node.

There will be a null at both ends.

## Benefits

- Improves the efficiency of removeFromTail() to O(1)
- Can traverse in both directions

## Costs

- Space increase from O(1) per node to O(1) extra pointer per node
- Increased code complexity — all other methods must be updated to accommodate the previous pointer

## Is the cost worth it?

It depends on the circumstances. If you frequently need to remove from the tail or traverse backwards, the tradeoff is worthwhile.
