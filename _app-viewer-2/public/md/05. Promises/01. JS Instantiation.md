# JS Instantiation

Promise instantiation follows previously learned JS instantiation patterns.

First let's review JS instantiation.

## Basic JS Instantiation Syntax
```javascript
let myObject = new ClassName();
```

### The **new** Keyword
The new keyword creates a new object instance from a constructor.

  - Creates a new empty object
  - Calls the constructor function.
  - Sets **this** to point to the new object
  - Returns the new object

### **Constructor**
A constructor is a special method that runs when you create a new object from a class.

  - Defined in the class
  - Initializes the new object's properties
  - Sets up the object's initial state
  - Accepts parameters to customize the object
