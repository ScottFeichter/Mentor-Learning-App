# Does a Promise Get Consumed When Resolved?

## The Question

When a promise is resolved and the status changes, does the promise object get consumed and all that remains is the resultant value?

## The Answer

No, the **Promise object remains** - it doesn't get consumed or destroyed.

```javascript
let myPromise = new Promise(function(resolve, reject) {
  resolve("success data");
});

console.log(myPromise); // Still exists - shows Promise object
// Promise { <fulfilled>: "success data" }

myPromise.then(value => {
  console.log(value); // "success data"
});

console.log(myPromise); // Still the same Promise object
// Promise { <fulfilled>: "success data" }
```

## What Actually Happens

- Promise object **stays alive** with its internal state and value
- State changes from `pending` to `fulfilled`
- Value gets stored inside the Promise object
- You access the value **through** the Promise using `.then()`
- The Promise object itself persists and can be used multiple times

## Multiple Usage

You can call `.then()` multiple times:

```javascript
myPromise.then(value => console.log("First:", value));
myPromise.then(value => console.log("Second:", value));
// Both work because the Promise object still exists
```

## Key Point

The Promise object is a **container** that holds the resolved value - it doesn't disappear when resolved.
