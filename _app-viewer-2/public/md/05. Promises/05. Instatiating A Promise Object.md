
# Instantiating A Promise Object

## Syntax to Instantiate a Promise Object

As with other objects built from a class we use the **new** keyword and **constructor** to instantiate a Promise object:

```javascript
let myPromise = new Promise(executor);
```

For Promises we need to pass a callback function called the **executor** to the **constructor** during instantiation.


## Steps To Instantiate A Promise

To instantiate a Promise object:
 - Use a declaration keyword (var, let, or const)
 - Choose an identifier (whatever name you want to give it)
 - Use the assignment operator
 - Use the **new** keyword
 - Call the Promise() **constructor**
 - Pass an **executor function** as a **callback**

```javascript
let myPromise = new Promise(executor);
```
