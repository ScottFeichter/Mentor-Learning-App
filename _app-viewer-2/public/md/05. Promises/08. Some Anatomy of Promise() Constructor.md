# Some Anatomy Of The Promise() constructor

If we imagine what the Promise() constructor looks like in code we might think of this:

```javascript
class Promise {
  constructor(executor) {
    this.state = "pending";
    this.value = undefined;


    const resolve = (value) => {
      if (this.state !== "pending") return;
      this.state = "fulfilled";
      this.value = value;
    };

    const reject = (reason) => {
      if (this.state !== "pending") return;

      this.state = "rejected";
      this.value = reason;
    };

    try {
      executor(resolve, reject);
    } catch (error) {
      reject(error);
    }
  }
}
  ```
This is a simplified imaginary version of the Promise() constructor as defined in the Promise class.

## Promise() Constructor Has Parameter For Executor Function

As we can see, the Promise() constructor when invoked takes an argument.

The argument is the executor function we provide it.

The constructor immediately invokes the executor function in a try block.
