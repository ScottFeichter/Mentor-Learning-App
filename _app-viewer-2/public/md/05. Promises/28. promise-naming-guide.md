# Promise Naming Guide

## What names are bananable

### You CAN rename:

- **The executor function**: `function executor` → `function bananaExecutor`
- **The resolve parameter**: `resolve` → `bananaResolveParam`
- **The reject parameter**: `reject` → `bananaRejectParam`
- **Your variable names**: `myPromise` → `myBananaPromise`

```javascript
let myBananaPromise = new Promise(function bananaExecutor(bananaResolveParam, bananaRejectParam) {
  if (Math.random() > 0.5) {
    bananaResolveParam("success");
  } else {
    bananaRejectParam("error");
  }
});
```

### You CANNOT rename:

- `Promise` (the class name)
- `.then()`, `.catch()`, `.finally()` (method names)
- The internal state names (`"pending"`, `"fulfilled"`, `"rejected"`)

**The Promise API is fixed, but your function and parameter names are completely up to you!**
