# Promise Class - Simple - Custom Promise Implementation

This is a simplified implementation of JavaScript's Promise functionality.

We create a class called `Promise` to give an idea of what the Promise class might look like.

## The Complete Code

```javascript
class Promise {
  constructor(executor) {
    this.state = "pending";
    this.value = undefined;
    this.handlers = [];

    const resolve = (value) => {
      if (this.state !== "pending") return;

      this.state = "fulfilled";
      this.value = value;

      this.handlers.forEach(handler => {
        if (handler.onFulfilled) {
          handler.onFulfilled(value);
        }
      });
    };

    const reject = (reason) => {
      if (this.state !== "pending") return;

      this.state = "rejected";
      this.value = reason;

      this.handlers.forEach(handler => {
        if (handler.onRejected) {
          handler.onRejected(reason);
        }
      });
    };

    try {
      executor(resolve, reject);
    } catch (error) {
      reject(error);
    }
  }

  // Instance methods

  then(onFulfilled, onRejected) {
    if (this.state === "fulfilled") {
      if (onFulfilled) {
        onFulfilled(this.value);
      }
    } else if (this.state === "rejected") {
      if (onRejected) {
        onRejected(this.value);
      }
    } else {
      // Still pending, queue the handlers
      this.handlers.push({
        onFulfilled,
        onRejected
      });
    }
  }

  catch(onRejected) {
    return this.then(null, onRejected);
  }
}

// Example usage:
let myPromise = new Promise(function executor(resolve, reject) {
  let randomNumber = Math.random();

  if (randomNumber > 0.5) {
    resolve("Success! Number was: " + randomNumber);
  } else {
    reject("Failed! Number was: " + randomNumber);
  }
});

myPromise.then(function(value) {
  console.log("Success:", value);
});

myPromise.catch(function(error) {
  console.log("Error:", error);
});
```

## How It Works

### Core Components

**Instance Properties:**
- `state`: Tracks promise state (`"pending"`, `"fulfilled"`, `"rejected"`)
- `value`: Stores the resolved value or rejection reason
- `handlers`: Array of `.then()` and `.catch()` callbacks waiting to execute

**Local Functions (Closures):**
- `resolve(value)`: Changes state to "fulfilled" and executes success handlers
- `reject(reason)`: Changes state to "rejected" and executes error handlers

### The Flow

1. **Creation**: `new Promise(executor)` creates instance with "pending" state
2. **Function references passed**: `executor(resolve, reject)` passes function references (not called functions)
3. **Executor runs**: The provided executor function runs immediately with access to `resolve` and `reject`
4. **State change**: Executor decides when to call `resolve(value)` or `reject(reason)` with parameters
5. **Handler execution**: When state changes, queued `.then()` or `.catch()` handlers run
6. **One-time only**: Once resolved or rejected, state cannot change again

### Key Point: Function References vs Function Calls

```javascript
// We pass function references (no parentheses)
executor(resolve, reject);

// The executor later calls them with parameters
resolve("success data");  // Now the function executes
reject("error message");  // Now the function executes
```

The executor receives the functions and decides when and how to call them.

### Key Features

- **State management**: Prevents multiple resolutions
- **Handler queuing**: Stores callbacks if promise is still pending
- **Error handling**: Catches executor errors and auto-rejects
- **Immediate execution**: Handlers run immediately if promise already settled

This demonstrates the core mechanics of how JavaScript Promises work internally!
