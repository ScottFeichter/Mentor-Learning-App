# APIs Available

&nbsp;

API means Application Programming Interface. 

## API Comparison

| Feature | Node.js | Browser |
|---------|---------|---------|
| File System | ✅ `fs` module | ❌ (limited File API) |
| HTTP Server | ✅ `http` module | ❌ |
| DOM Manipulation | ❌ | ✅ `document` |
| Fetch API | ✅ (Node 18+) | ✅ |
| WebSockets | ✅ (via libraries) | ✅ Native |
| Crypto | ✅ `crypto` module | ✅ Web Crypto API |
