# package-lock.json

The `package-lock.json` file is not a file you will have to worry about.

It is a file **automatically generated** by npm that further specifies package versions.

## What It Does

- Locks the exact version of every installed dependency
- Ensures everyone on the team gets the same versions
- Includes the full dependency tree (dependencies of dependencies)

## Key Points

- **Never edit it manually** - npm manages it for you
- **Do commit it to Git** - so your team gets consistent installs
- **Regenerated automatically** when you run `npm install`
