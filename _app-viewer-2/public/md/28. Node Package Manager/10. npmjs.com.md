# npmjs.com

## The npm Registry

[https://www.npmjs.com/](https://www.npmjs.com/)

This is the website where all public npm packages are hosted.

## What You Can Do There

- **Search** for packages by name or keyword
- **View** package documentation, version history, and download stats
- **Check** dependencies and bundle size
- **Publish** your own packages for others to use

## How It Connects to npm

When you run `npm install express`, npm downloads the package from this registry.

```bash
npm install express
# Downloads from https://www.npmjs.com/package/express
```

## Tips

- Check weekly downloads to gauge package popularity
- Look at "Last publish" date to see if it's maintained
- Read the README for usage instructions
- Check the "Dependencies" tab to see what else gets installed
