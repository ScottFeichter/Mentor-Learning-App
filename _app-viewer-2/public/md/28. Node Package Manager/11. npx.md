# npx

## What Is npx?

**npx** is a command-line tool that comes bundled with npm (since npm 5.2+).

It executes Node packages without permanently installing them.

## npx vs npm

| | npm | npx |
|---|---|---|
| **Purpose** | Install and manage packages | Execute packages |
| **Installation** | Installs packages to your project or globally | Doesn't install permanently |
| **Usage** | `npm install package-name` | `npx package-name` |

## How It Works

1. Checks if the package exists locally in `node_modules/.bin`
2. If found locally, runs it
3. If not found locally, temporarily downloads it, runs it, then removes it

## Common Use Cases

### Run a package without installing it

```bash
npx create-react-app my-app
npx prisma migrate dev
npx eslint .
```

### Run a specific version of a package

```bash
npx node@16 --version
npx create-react-app@5 my-app
```

### Run locally installed packages

```bash
# Instead of:
./node_modules/.bin/eslint .

# You can use:
npx eslint .
```

### One-time commands

```bash
npx prisma generate
npx prisma studio
npx nodemon server.js
```

## Why Use npx?

- **No global installs** - keeps your system clean
- **Always latest version** - downloads fresh each time (unless installed locally)
- **Convenience** - shorter than typing full path to `node_modules/.bin`
- **One-time tools** - perfect for generators and setup scripts you only run once

## Key Takeaway

Use `npm` to install packages your project depends on.

Use `npx` to execute packages — especially one-time commands or tools you don't need permanently installed.
