# npm Commands

Node Package Manager is just an application. However it does not have a GUI. To utilize it we need to use commands in the terminal.

## Basic Commands

| Command | What It Does |
|---|---|
| `npm` | The base command prefix for anything you want to do with npm |
| `npm init` | Creates a new or updates an existing `package.json` |
| `npm init -y` | Runs `npm init` and answers yes to all prompts |
| `npm install` | Reads `package.json` and installs any dependencies not already installed |
| `npm install [package]` | Installs a specific package |
| `npm run [scriptname]` | Executes a custom script defined in the scripts section of `package.json` |

## Examples

```bash
# Initialize a new project
npm init -y

# Install express
npm install express

# Install nodemon as a dev dependency
npm install nodemon --save-dev

# Run the "dev" script from package.json
npm run dev
```

These are the basic commands for npm a beginner should know.
