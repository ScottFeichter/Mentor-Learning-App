# Naming Cases in Programming

## Rust Naming Conventions (snake_case)

Rust follows strict naming conventions using **snake_case** for most identifiers.

### File Names
```rust
// Correct
main.rs
user_service.rs
database_connection.rs

// Incorrect
Main.rs
userService.rs
DatabaseConnection.rs
```

### Variable Names
```rust
let user_name = "Alice";
let total_count = 42;
let is_valid = true;
```

### Function Names
```rust
fn calculate_total() -> i32 { }
fn get_user_by_id(id: u32) -> User { }
fn is_email_valid(email: &str) -> bool { }
```

### Module Names
```rust
mod user_management;
mod database_utils;
mod error_handling;
```

### Constants (SCREAMING_SNAKE_CASE)
```rust
const MAX_USERS: usize = 1000;
const API_BASE_URL: &str = "https://api.example.com";
```

### Types and Structs (PascalCase)
```rust
struct UserAccount { }
enum PaymentStatus { }
trait DatabaseConnection { }
```

## Other Naming Cases

### camelCase
**Description**: First word lowercase, subsequent words capitalized
**Languages**: JavaScript, Java (variables/methods), C# (variables/methods)

```javascript
// JavaScript
let userName = "Alice";
function calculateTotal() { }
```

### PascalCase (UpperCamelCase)
**Description**: All words capitalized, no separators
**Languages**: C# (classes), Java (classes), Pascal, C++ (classes)

```csharp
// C#
class UserAccount { }
interface IPaymentProcessor { }
```

### kebab-case
**Description**: All lowercase with hyphens
**Languages**: CSS, HTML attributes, Lisp dialects

```css
/* CSS */
.user-profile { }
.navigation-menu { }
```

### SCREAMING_SNAKE_CASE
**Description**: All uppercase with underscores
**Languages**: Constants in C, C++, Rust, Python

```c
// C
#define MAX_BUFFER_SIZE 1024
const int DEFAULT_TIMEOUT = 30;
```

### flatcase
**Description**: All lowercase, no separators
**Languages**: Some package names, domains

```
// Package names
numpy
tensorflow
```

### Train-Case
**Description**: Capitalized words with hyphens
**Languages**: HTTP headers, some configuration files

```
Content-Type: application/json
Accept-Language: en-US
```

## Language-Specific Examples

| Language | Variables | Functions | Classes | Constants |
|----------|-----------|-----------|---------|-----------|
| **Rust** | snake_case | snake_case | PascalCase | SCREAMING_SNAKE_CASE |
| **JavaScript** | camelCase | camelCase | PascalCase | SCREAMING_SNAKE_CASE |
| **Python** | snake_case | snake_case | PascalCase | SCREAMING_SNAKE_CASE |
| **Java** | camelCase | camelCase | PascalCase | SCREAMING_SNAKE_CASE |
| **C#** | camelCase | PascalCase | PascalCase | PascalCase |
| **Go** | camelCase | PascalCase* | PascalCase | PascalCase |

*Go uses PascalCase for exported (public) functions, camelCase for unexported (private)
