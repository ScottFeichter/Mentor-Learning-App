# Rust Formatter (rustfmt)

## Overview

**rustfmt** is an automatic code formatter tool that formats Rust code according to a standard style.

It's included with the standard Rust distribution alongside rustc, so it's already installed on your computer when you install Rust.

## Why Use rustfmt?

### Consistency
- Maintains uniform code style across all Rust projects
- Eliminates debates about formatting preferences
- Makes code reviews focus on logic, not style

### Productivity
- Automatic formatting saves time
- No need to manually adjust indentation or spacing
- Consistent style improves code readability

## Basic Usage

### Format a Single File
```bash
rustfmt src/main.rs
```

### Format All Files in Project
```bash
cargo fmt
```

### Check Formatting (Don't Modify)
```bash
cargo fmt -- --check
```

### Format with Verbose Output
```bash
cargo fmt -- --verbose
```

## Configuration

### Default Configuration
rustfmt works out of the box with sensible defaults that follow Rust's official style guide.

### Custom Configuration (rustfmt.toml)
Create a `rustfmt.toml` file in your project root:

```toml
# rustfmt.toml
max_width = 100
hard_tabs = false
tab_spaces = 4
newline_style = "Unix"
use_small_heuristics = "Default"
```

### Common Configuration Options
```toml
# Line width
max_width = 100

# Indentation
hard_tabs = false
tab_spaces = 4

# Import formatting
imports_granularity = "Crate"
group_imports = "StdExternalCrate"

# Function formatting
fn_single_line = false
where_single_line = false

# Array and struct formatting
array_width = 60
struct_field_align_threshold = 0
```

## IDE Integration

### VS Code
- Install Rust Analyzer extension
- Enable "Format on Save" in settings
- rustfmt runs automatically

### Other Editors
- Most Rust-aware editors support rustfmt integration
- Can be configured to run on save or manually triggered

## CI/CD Integration

### GitHub Actions
```yaml
- name: Check formatting
  run: cargo fmt -- --check
```

### Pre-commit Hook
```bash
#!/bin/sh
cargo fmt -- --check
if [ $? -ne 0 ]; then
    echo "Code is not formatted. Run 'cargo fmt' to fix."
    exit 1
fi
```

## What rustfmt Formats

### Code Structure
- Indentation and spacing
- Line breaks and wrapping
- Bracket and brace placement

### Imports
- Sorting and grouping imports
- Removing unused imports (with additional tools)

### Function Signatures
- Parameter alignment
- Return type formatting
- Where clause formatting

### Example: Before and After

**Before:**
```rust
fn calculate_total(items:Vec<Item>,tax_rate:f64)->Result<f64,Error>{
let mut total=0.0;
for item in items{total+=item.price;}
Ok(total*(1.0+tax_rate))
}
```

**After:**
```rust
fn calculate_total(items: Vec<Item>, tax_rate: f64) -> Result<f64, Error> {
    let mut total = 0.0;
    for item in items {
        total += item.price;
    }
    Ok(total * (1.0 + tax_rate))
}
```

## Best Practices

### Team Workflow
1. **Commit rustfmt.toml**: Include configuration in version control
2. **CI checks**: Fail builds on formatting issues
3. **Pre-commit hooks**: Catch issues before they reach CI
4. **Editor integration**: Format on save for immediate feedback

### Configuration Management
- Start with defaults
- Only customize when team agrees on changes
- Document any non-standard choices
- Keep configuration minimal and focused

## Advanced Features

### Stable vs Nightly
- **Stable**: Basic formatting features
- **Nightly**: Additional experimental options

### Skip Formatting
```rust
#[rustfmt::skip]
fn manually_formatted() {
    // This function won't be reformatted
}
```

### Format Specific Items
```bash
rustfmt --config-path rustfmt.toml src/lib.rs
```

## Benefits for Rust Ecosystem

- **Consistency**: All Rust code looks similar
- **Onboarding**: New developers don't need to learn project-specific styles
- **Maintenance**: Easier to read and maintain any Rust codebase
- **Community**: Shared formatting standards across the ecosystem
