# Prisma Query Operators

## What Are Query Operators?

Query operators are the conditions you use inside `where` clauses to filter records. They translate to SQL WHERE conditions.

## Comparison Operators

```javascript
// Equals (implicit)
prisma.user.findMany({ where: { name: "John" } })

// Equals (explicit)
prisma.user.findMany({ where: { name: { equals: "John" } } })

// Not equals
prisma.user.findMany({ where: { status: { not: "inactive" } } })

// Greater than
prisma.user.findMany({ where: { age: { gt: 18 } } })

// Greater than or equal
prisma.user.findMany({ where: { age: { gte: 18 } } })

// Less than
prisma.user.findMany({ where: { age: { lt: 65 } } })

// Less than or equal
prisma.user.findMany({ where: { age: { lte: 65 } } })
```

## String Operators

```javascript
// Contains (LIKE '%value%')
prisma.user.findMany({ where: { name: { contains: "john" } } })

// Contains case-insensitive (ILIKE)
prisma.user.findMany({ where: { name: { contains: "john", mode: "insensitive" } } })

// Starts with (LIKE 'value%')
prisma.user.findMany({ where: { name: { startsWith: "J" } } })

// Ends with (LIKE '%value')
prisma.user.findMany({ where: { email: { endsWith: "@gmail.com" } } })
```

## List Operators

```javascript
// In (value is one of these)
prisma.user.findMany({ where: { status: { in: ["active", "pending"] } } })

// Not in
prisma.user.findMany({ where: { status: { notIn: ["banned", "deleted"] } } })
```

## Logical Operators

```javascript
// AND (implicit — multiple conditions)
prisma.user.findMany({
  where: { age: { gte: 18 }, status: "active" }
})

// AND (explicit)
prisma.user.findMany({
  where: {
    AND: [
      { age: { gte: 18 } },
      { status: "active" }
    ]
  }
})

// OR
prisma.user.findMany({
  where: {
    OR: [
      { email: { endsWith: "@gmail.com" } },
      { email: { endsWith: "@yahoo.com" } }
    ]
  }
})

// NOT
prisma.user.findMany({
  where: {
    NOT: { status: "banned" }
  }
})
```

## Combining Operators

```javascript
// Complex filter: active users aged 18-65 with gmail or yahoo email
prisma.user.findMany({
  where: {
    AND: [
      { age: { gte: 18, lte: 65 } },
      { status: "active" },
      {
        OR: [
          { email: { endsWith: "@gmail.com" } },
          { email: { endsWith: "@yahoo.com" } }
        ]
      }
    ]
  }
})
```

## Null Checks

```javascript
// Field is null
prisma.user.findMany({ where: { phone: null } })

// Field is not null
prisma.user.findMany({ where: { phone: { not: null } } })
```

## Date Operators

```javascript
// After a date
prisma.user.findMany({
  where: { createdAt: { gt: new Date('2024-01-01') } }
})

// Between dates
prisma.user.findMany({
  where: {
    createdAt: {
      gte: new Date('2024-01-01'),
      lte: new Date('2024-12-31')
    }
  }
})
```

## Relation Filters

```javascript
// Users who have at least one task
prisma.user.findMany({
  where: { tasks: { some: {} } }
})

// Users who have no tasks
prisma.user.findMany({
  where: { tasks: { none: {} } }
})

// Users where ALL tasks are completed
prisma.user.findMany({
  where: { tasks: { every: { isCompleted: true } } }
})

// Users who have a task with specific title
prisma.user.findMany({
  where: { tasks: { some: { title: { contains: "urgent" } } } }
})
```

## Operator Reference

| Operator | SQL Equivalent | Example |
|----------|---------------|---------|
| `equals` | `=` | `{ age: { equals: 25 } }` |
| `not` | `!=` | `{ status: { not: "inactive" } }` |
| `gt` | `>` | `{ age: { gt: 18 } }` |
| `gte` | `>=` | `{ age: { gte: 18 } }` |
| `lt` | `<` | `{ age: { lt: 65 } }` |
| `lte` | `<=` | `{ age: { lte: 65 } }` |
| `in` | `IN (...)` | `{ status: { in: ["a", "b"] } }` |
| `notIn` | `NOT IN (...)` | `{ status: { notIn: ["x"] } }` |
| `contains` | `LIKE '%x%'` | `{ name: { contains: "john" } }` |
| `startsWith` | `LIKE 'x%'` | `{ name: { startsWith: "J" } }` |
| `endsWith` | `LIKE '%x'` | `{ email: { endsWith: ".com" } }` |
| `AND` | `AND` | `{ AND: [{...}, {...}] }` |
| `OR` | `OR` | `{ OR: [{...}, {...}] }` |
| `NOT` | `NOT` | `{ NOT: {...} }` |
| `some` | `EXISTS (subquery)` | `{ tasks: { some: {...} } }` |
| `none` | `NOT EXISTS` | `{ tasks: { none: {...} } }` |
| `every` | `ALL match` | `{ tasks: { every: {...} } }` |
