# Prisma Query API

## Overview

The Prisma Query API is the set of methods available on each model through the generated Prisma Client. These methods translate to optimized SQL queries.

## Read Methods

### findMany — Get Multiple Records

```javascript
// All users
const users = await prisma.user.findMany();

// With filtering
const activeUsers = await prisma.user.findMany({
  where: { status: 'active' }
});

// With sorting, pagination, and field selection
const users = await prisma.user.findMany({
  where: { age: { gte: 18 } },
  select: { id: true, name: true, email: true },
  orderBy: { name: 'asc' },
  skip: 10,
  take: 5
});
```

### findUnique — Get One Record by Unique Field

```javascript
// By primary key
const user = await prisma.user.findUnique({ where: { id: 1 } });

// By unique field
const user = await prisma.user.findUnique({ where: { email: 'john@example.com' } });

// Returns null if not found
```

### findFirst — Get First Matching Record

```javascript
// First user matching criteria
const user = await prisma.user.findFirst({
  where: { status: 'active' },
  orderBy: { createdAt: 'desc' }
});

// Returns null if not found
```

### count — Count Records

```javascript
// Total count
const total = await prisma.user.count();

// Filtered count
const activeCount = await prisma.user.count({
  where: { status: 'active' }
});
```

## Write Methods

### create — Create One Record

```javascript
const user = await prisma.user.create({
  data: {
    name: 'John',
    email: 'john@example.com',
    age: 30
  }
});
```

### createMany — Create Multiple Records

```javascript
const result = await prisma.user.createMany({
  data: [
    { name: 'John', email: 'john@example.com' },
    { name: 'Jane', email: 'jane@example.com' }
  ],
  skipDuplicates: true
});
// Returns: { count: 2 }
```

### update — Update One Record

```javascript
const user = await prisma.user.update({
  where: { id: 1 },
  data: { name: 'Updated Name' }
});
```

### updateMany — Update Multiple Records

```javascript
const result = await prisma.user.updateMany({
  where: { status: 'inactive' },
  data: { status: 'archived' }
});
// Returns: { count: 15 }
```

### upsert — Create or Update

```javascript
const user = await prisma.user.upsert({
  where: { email: 'john@example.com' },
  update: { name: 'John Updated' },
  create: { name: 'John', email: 'john@example.com' }
});
```

### delete — Delete One Record

```javascript
const user = await prisma.user.delete({
  where: { id: 1 }
});
```

### deleteMany — Delete Multiple Records

```javascript
const result = await prisma.user.deleteMany({
  where: { status: 'archived' }
});
// Returns: { count: 10 }
```

## Aggregation Methods

### aggregate

```javascript
const stats = await prisma.user.aggregate({
  _count: { id: true },
  _avg: { age: true },
  _min: { age: true },
  _max: { age: true },
  _sum: { age: true }
});
```

### groupBy

```javascript
const grouped = await prisma.user.groupBy({
  by: ['status'],
  _count: { id: true }
});
// Returns: [{ status: 'active', _count: { id: 25 } }, ...]
```

## Query Options Summary

| Option | Purpose | Example |
|--------|---------|---------|
| `where` | Filter records | `{ age: { gt: 18 } }` |
| `select` | Choose fields to return | `{ name: true, email: true }` |
| `include` | Include related records | `{ tasks: true }` |
| `orderBy` | Sort results | `{ name: 'asc' }` |
| `take` | Limit results | `10` |
| `skip` | Offset results | `20` |
| `distinct` | Unique values only | `['status']` |
