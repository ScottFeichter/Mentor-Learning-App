# Rate Limiting Strategies

## Why Rate Limit?

- **Brute-force protection** — Prevent password guessing attacks
- **DDoS mitigation** — Reduce impact of distributed attacks
- **API abuse prevention** — Stop scrapers and bots
- **Cost control** — Limit expensive operations
- **Fair usage** — Ensure all users get equal access

## Common Patterns

### Tiered Rate Limiting

```javascript
const rateLimit = require('express-rate-limit');

// Tier 1: General API (generous)
const generalLimiter = rateLimit({
  windowMs: 60 * 1000,
  max: 60
});

// Tier 2: Authenticated endpoints (moderate)
const authLimiter = rateLimit({
  windowMs: 60 * 1000,
  max: 30
});

// Tier 3: Sensitive operations (strict)
const sensitiveLimiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 5
});

app.use('/api/', generalLimiter);
app.use('/api/auth/', authLimiter);
app.post('/api/auth/login', sensitiveLimiter);
app.post('/api/auth/reset-password', sensitiveLimiter);
```

### Sliding Window vs Fixed Window

**Fixed Window** (default behavior):
- Resets at fixed intervals
- Can allow burst at window boundaries

**Sliding Window** (with store):
- Smoother rate limiting
- Requires external store (Redis)

```javascript
const RedisStore = require('rate-limit-redis');
const Redis = require('ioredis');

const client = new Redis();

const limiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 100,
  store: new RedisStore({
    sendCommand: (...args) => client.call(...args)
  })
});
```

## Production Considerations

### Behind a Proxy

If behind nginx, load balancer, or reverse proxy:

```javascript
// Trust the X-Forwarded-For header
app.set('trust proxy', 1);

const limiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 100
});
```

### Multiple Servers

Use Redis store to share rate limit state across instances:

```javascript
const RedisStore = require('rate-limit-redis');

const limiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 100,
  store: new RedisStore({ /* redis config */ })
});
```

### Graceful Responses

```javascript
const limiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 100,
  handler: (req, res) => {
    const retryAfter = Math.ceil((req.rateLimit.resetTime - Date.now()) / 1000);
    res.set('Retry-After', retryAfter);
    res.status(429).json({
      error: 'Too many requests',
      retryAfter: retryAfter,
      message: `Please try again in ${retryAfter} seconds`
    });
  }
});
```
