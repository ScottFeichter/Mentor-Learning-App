# Function Reference vs. Function Call

It is easy to get confused between a reference to a function defintion and a function call

## What Do They Do?

- **Function reference**: `functionName` - gives the function definition to be called later

- **Function call**: `functionName()` - invokes and executes the function immediately

## Which Is Actually a Callback?

Only the **function reference** is a callback:

```javascript
greet("John", sayGoodbye);  // sayGoodbye is a callback

greet("John", sayGoodbye()); // sayGoodbye() is NOT a callback
```

## What's The Difference?

**Function reference**:
- The receiving function gets the actual function and can call it later

**Function call**:
- The receiving function only gets the return value (string, number, undefined, etc.)
