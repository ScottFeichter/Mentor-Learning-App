# Summary of Authentication Tools

## Overview

Authentication in Node.js typically involves three key tools, each with a specific purpose:

1. **bcrypt** - Password hashing and salting
2. **crypto** - Secret key generation
3. **jsonwebtoken** - Token signing and verification

---

## bcrypt

**Purpose:** Hash and salt passwords for secure storage in the database

**What it does:**
- Hashes passwords with automatic salting
- Stores hashed passwords in the database
- Verifies passwords during login

**Installation:**
```bash
npm install bcrypt
```

**Usage:**
```javascript
const bcrypt = require('bcrypt');

// Registration - Hash password for storage
const hashedPassword = await bcrypt.hash(password, 10); // 10 = salt rounds
await saveUser({ email, password: hashedPassword });

// Login - Verify password
const user = await findUser(email);
const isValid = await bcrypt.compare(password, user.password);
```

**Key Points:**
- Never store plain text passwords
- The salt is automatically included in the hash
- Higher salt rounds = more secure but slower (10-12 is typical)

---

## crypto (Node.js Built-in)

**Purpose:** Generate cryptographically secure random strings for secret keys

**What it does:**
- Creates random, secure strings
- Generates JWT secret keys
- Can also create tokens, IDs, and other random values

**Usage:**
```javascript
const crypto = require('crypto');

// Generate a secure secret key for JWT
const secret = crypto.randomBytes(64).toString('hex');
// Result: 'a1b2c3d4e5f6...' (128 character hex string)

// Store in .env file
// JWT_SECRET=a1b2c3d4e5f6...
```

**Key Points:**
- Built into Node.js (no installation needed)
- Use 32-64 bytes for JWT secrets
- Never hardcode secrets in your code
- Store secrets in environment variables

---

## jsonwebtoken

**Purpose:** Sign and verify tokens for authentication

**What it does:**
- Creates signed tokens containing user data
- Uses HMAC-SHA256 hashing to create signatures
- Verifies tokens haven't been tampered with
- Does NOT hash passwords (that's bcrypt's job)

**Installation:**
```bash
npm install jsonwebtoken
```

**Usage:**
```javascript
const jwt = require('jsonwebtoken');

// Create token after successful login
const token = jwt.sign(
  { userId: user.id, email: user.email },
  process.env.JWT_SECRET,
  { expiresIn: '24h' }
);

// Verify token in protected routes
const decoded = jwt.verify(token, process.env.JWT_SECRET);
```

**Key Points:**
- Uses hashing to create token signatures (not for passwords)
- Payload is base64-encoded (readable by anyone)
- Always set expiration times
- Requires the secret key generated by crypto

## Complete Authentication Flow

```javascript
const bcrypt = require('bcrypt');
const crypto = require('crypto');
const jwt = require('jsonwebtoken');

// 1. Generate secret key (do this once, store in .env)
const JWT_SECRET = crypto.randomBytes(64).toString('hex');

// 2. Registration - bcrypt hashes password
app.post('/register', async (req, res) => {
  const { email, password } = req.body;
  const hashedPassword = await bcrypt.hash(password, 10);
  await saveUser({ email, password: hashedPassword });
  res.json({ message: 'User created' });
});

// 3. Login - bcrypt verifies, JWT signs token
app.post('/login', async (req, res) => {
  const { email, password } = req.body;
  const user = await findUser(email);
  
  const isValid = await bcrypt.compare(password, user.password);
  
  if (isValid) {
    const token = jwt.sign(
      { userId: user.id },
      process.env.JWT_SECRET,
      { expiresIn: '24h' }
    );
    res.json({ token });
  } else {
    res.status(401).json({ error: 'Invalid credentials' });
  }
});

// 4. Protected route - JWT verifies token
app.get('/protected', (req, res) => {
  const token = req.headers.authorization?.split(' ')[1];
  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    res.json({ data: 'Protected data', user: decoded });
  } catch (error) {
    res.status(401).json({ error: 'Unauthorized' });
  }
});
```

## Quick Reference

| Tool | Purpose | When Used |
|------|---------|-----------|
| **bcrypt** | Hash passwords | Registration & Login |
| **crypto** | Generate secret keys | Setup (once) |
| **jsonwebtoken** | Sign/verify tokens | Login & Protected Routes |

---

## Summary

- **bcrypt**: Hashes + salts passwords → database storage
- **crypto**: Generates secret keys → JWT signing
- **jsonwebtoken**: Signs tokens using secret key → authentication

Each tool has a specific role, and all three work together to create a secure authentication system.
