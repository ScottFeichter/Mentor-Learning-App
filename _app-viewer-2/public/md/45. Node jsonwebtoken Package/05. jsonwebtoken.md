# JSON Web Token (JWT)

## What It Is
A compact, URL-safe token that securely transmits information between parties as a JSON object.

Contains three parts: Header, Payload, and Signature.

## How It Works
1. User logs in with credentials
2. Server verifies credentials and creates JWT
3. JWT sent to client (stored in cookies/localStorage)
4. Client includes JWT in subsequent requests
5. Server verifies JWT signature and extracts user data

## Installation
```bash
npm install jsonwebtoken
```

## Creating a JWT
```javascript
const jwt = require('jsonwebtoken');

// Login route
app.post('/login', async (req, res) => {
  const user = await authenticateUser(req.body);

  const token = jwt.sign(
    { id: user.id, email: user.email },  // Payload
    process.env.JWT_SECRET,               // Secret key
    { expiresIn: '7d' }                   // Options
  );

  res.json({ token });
});
```

## Verifying a JWT
```javascript
// Auth middleware
const authenticateToken = (req, res, next) => {
  const token = req.headers.authorization?.split(' ')[1];

  if (!token) {
    return res.status(401).json({ message: 'No token provided' });
  }

  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.user = decoded;  // Attach user data to request
    next();
  } catch (err) {
    res.status(403).json({ message: 'Invalid token' });
  }
};

// Protected route
app.get('/profile', authenticateToken, (req, res) => {
  res.json({ user: req.user });
});
```

## Key Points
- Never store sensitive data in JWT (it's encoded, not encrypted)
- Keep secret key secure in environment variables
- Set appropriate expiration times
- JWT is stateless (server doesn't store it)
