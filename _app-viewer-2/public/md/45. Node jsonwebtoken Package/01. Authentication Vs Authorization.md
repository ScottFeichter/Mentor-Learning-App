# Authentication vs Authorization

## Authentication
**Who are you?**
- Verifies user identity
- Login process (username/password, biometrics, tokens)
- Confirms you are who you claim to be
- Happens first

## Authorization
**What can you do?**
- Determines user permissions
- Controls access to resources/actions
- Checks what authenticated user is allowed to do
- Happens after authentication

## Comparison
| Authentication | Authorization |
|---|---|
| Identity verification | Permission verification |
| Login credentials | Access rights |
| "Are you John?" | "Can John edit this?" |
| Required first | Depends on authentication |
| Example: Password check | Example: Admin role check |

## Example Flow
1. User logs in (Authentication)
2. System verifies credentials
3. User tries to delete a post (Authorization)
4. System checks if user has delete permission
