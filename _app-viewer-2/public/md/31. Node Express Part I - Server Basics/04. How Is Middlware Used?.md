## How Is It Used?

Middleware functions run **in order**, forming a chain. Each one can:

- **Read or modify** the request (`req`) or response (`res`)
- **End the request-response cycle** by sending a response
- **Pass control** to the next middleware by calling `next()`

If a middleware doesn't call `next()` and doesn't send a response, the request hangs — it never reaches the next middleware or the route handler.

---

## Common Uses

- **Parsing** — reading JSON or form data from the request body
- **Logging** — recording information about each request
- **Authentication** — verifying who the user is
- **Authorization** — checking if the user has permission
- **Security** — setting headers to protect against attacks
- **Error handling** — catching and responding to errors
- **Serving static files** — returning images, CSS, or HTML files
