# Different Ways to Implement Middleware in Express

---

## 1. Application-Level — All Routes

```js
app.use(someMiddleware);
```

This applies the middleware to **all incoming requests**, but it will only do work if that request actually needs it.

For example, `app.use(express.json())` runs on every request, but not all requests have JSON to parse — it just passes through quietly when there's nothing to do.

---

## 2. Application-Level — Path-Specific

```js
app.use('/tasks', someMiddleware);
```

This applies the middleware **only to requests that hit the `/tasks` path**.

It runs for **all HTTP methods** — GET, POST, PUT, DELETE, etc. — on that path.

---

## 3. Route Level — Route and Method-Specific

```js
app.get('/tasks', someMiddleware);
```

This also applies the middleware only to the `/tasks` path, but notice:

- It is in the route definition instead of using `app.use`
- It only applies to **GET** requests on `/tasks` — not POST, PUT, DELETE, etc.

This is the most granular way to apply middleware — locked to a specific path **and** a specific HTTP method.
