# Defining Middleware Function Inline

You can define the callback function in app.use or app.get.

Here the middleware function is defined right in the argument.

```js
app.use(function someMiddleware(req, res, next) {
  // logic
  next();
});
```

This is a callback function because we are not calling the function in our code.

We are giving the function definition to app.use() so that app.use() can call someMiddleware() in its body.
