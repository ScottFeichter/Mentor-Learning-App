# Other Ways to Implement Middleware in Express

---

## 1. Router-Level Middleware

Same as `app.use` but scoped to an `express.Router()` instance:

```js
const router = express.Router();
router.use(someMiddleware);
```

---

## 2. Error-Handling Middleware

Has **four** parameters instead of three — Express recognizes it as an error handler because of the `err` parameter:

```js
app.use(function errorHandler(err, req, res, next) {
  // handle error
});
```

---

## 3. Chaining Multiple Middleware on a Single Route

```js
app.get('/tasks', middlewareOne, middlewareTwo, (req, res) => {
  // logic
});
```

Each middleware runs in order, passing control to the next via `next()`.

---

## 4. Array of Middleware on a Single Route

```js
app.get('/tasks', [middlewareOne, middlewareTwo], (req, res) => {
  // logic
});
```

Same behavior as chaining — just organized in an array instead of separate arguments.
