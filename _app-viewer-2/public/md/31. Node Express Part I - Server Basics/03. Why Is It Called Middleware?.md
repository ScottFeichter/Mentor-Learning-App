## Why Is It Called "Middleware"?

It's called middleware because it runs **in the middle** — after the client sends a request but before the server sends back a response.

It sits in between, intercepting and processing the request as it flows through the application.

The term comes from software architecture more broadly, where "middleware" refers to any software that acts as a bridge between two systems.

In Express, it bridges the gap between the raw incoming request and your route handler's final response.

---


## The Flow

```
Client Request
     ↓
Middleware 1 → Middleware 2 → Middleware 3 → Route Handler
     ↓
Server Response
```

Each middleware does its job and calls `next()` to hand off to the next one.

The route handler at the end typically sends the final response.

However, some middleware will send the response in certain situations.
