# Express Validator

## What is Express Validator?

Express Validator is a middleware library for Express.js that validates and sanitizes user input data from requests (body, query parameters, headers, etc.).

## What it Does

- **Validates** input data (checks if email is valid, password meets requirements, etc.)
- **Sanitizes** data (trims whitespace, converts to lowercase, escapes HTML, etc.)
- **Provides error messages** for invalid data
- **Prevents security vulnerabilities** like XSS and injection attacks

## Installation

```bash
npm install express-validator
```

## Basic Usage

### 1. Import and Setup
```javascript
const { body, validationResult } = require('express-validator');
```

### 2. Create Validation Rules
```javascript
const validateUser = [
  body('email').isEmail().normalizeEmail(),
  body('password').isLength({ min: 6 }).trim(),
  body('name').notEmpty().trim().escape()
];
```

### 3. Apply to Route
```javascript
app.post('/register', validateUser, (req, res) => {
  const errors = validationResult(req);

  if (!errors.isEmpty()) {
    return res.status(400).json({ errors: errors.array() });
  }

  // Process valid data
  const { email, password, name } = req.body;
  // Create user...
});
```

## Common Validation Methods

### String Validation
```javascript
body('name').notEmpty()           // Required field
body('email').isEmail()           // Valid email format
body('phone').isMobilePhone()     // Valid phone number
body('url').isURL()               // Valid URL
```

### Number Validation
```javascript
body('age').isInt({ min: 18, max: 100 })  // Integer between 18-100
body('price').isFloat({ min: 0 })         // Positive decimal
```

### Custom Validation
```javascript
body('username').custom(async (value) => {
  const user = await User.findOne({ username: value });
  if (user) {
    throw new Error('Username already exists');
  }
});
```

## Sanitization Methods

```javascript
body('name').trim().escape()      // Remove whitespace, escape HTML
body('email').normalizeEmail()    // Standardize email format
body('text').stripLow()           // Remove control characters
```

## Query and Param Validation

```javascript
const { query, param } = require('express-validator');

// Validate query parameters: /search?q=term&limit=10
app.get('/search', [
  query('q').notEmpty().trim(),
  query('limit').optional().isInt({ min: 1, max: 100 })
], handler);

// Validate URL parameters: /users/:id
app.get('/users/:id', [
  param('id').isMongoId()
], handler);
```

## Error Handling

### Basic Error Response
```javascript
const errors = validationResult(req);
if (!errors.isEmpty()) {
  return res.status(400).json({
    success: false,
    errors: errors.array()
  });
}
```

### Custom Error Messages
```javascript
body('email')
  .isEmail()
  .withMessage('Please provide a valid email')
  .normalizeEmail();

body('password')
  .isLength({ min: 6 })
  .withMessage('Password must be at least 6 characters');
```

## Complete Example

```javascript
const express = require('express');
const { body, validationResult } = require('express-validator');

const app = express();
app.use(express.json());

const userValidation = [
  body('email')
    .isEmail()
    .withMessage('Invalid email')
    .normalizeEmail(),
  body('password')
    .isLength({ min: 6 })
    .withMessage('Password must be at least 6 characters')
    .trim(),
  body('name')
    .notEmpty()
    .withMessage('Name is required')
    .trim()
    .escape()
];

app.post('/users', userValidation, (req, res) => {
  const errors = validationResult(req);

  if (!errors.isEmpty()) {
    return res.status(400).json({
      success: false,
      errors: errors.array()
    });
  }

  // Valid data - create user
  const { email, password, name } = req.body;
  res.json({ success: true, message: 'User created' });
});
```

## Why Use Express Validator Instead of Built-in JavaScript?

### Built-in JavaScript Limitations

**Manual validation is verbose and error-prone:**
```javascript
// Built-in JS approach
app.post('/users', (req, res) => {
  const { email, password, name } = req.body;

  // Manual email validation
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  if (!email || !emailRegex.test(email)) {
    return res.status(400).json({ error: 'Invalid email' });
  }

  // Manual password validation
  if (!password || password.length < 6) {
    return res.status(400).json({ error: 'Password too short' });
  }

  // Manual name validation
  if (!name || name.trim().length === 0) {
    return res.status(400).json({ error: 'Name required' });
  }

  // Manual sanitization
  const cleanName = name.trim().replace(/[<>"'&]/g, '');

  // Process data...
});
```

**Express Validator approach:**
```javascript
// Clean, declarative, and secure
const validateUser = [
  body('email').isEmail().normalizeEmail(),
  body('password').isLength({ min: 6 }).trim(),
  body('name').notEmpty().trim().escape()
];

app.post('/users', validateUser, (req, res) => {
  const errors = validationResult(req);
  if (!errors.isEmpty()) {
    return res.status(400).json({ errors: errors.array() });
  }
  // Process clean, validated data...
});
```

### Key Advantages

**1. Security by Default**
- Built-in XSS protection with `.escape()`
- Proper email normalization
- SQL injection prevention
- Built-in JS has no security features

**2. Comprehensive Validation**
- 100+ built-in validators (email, phone, credit card, etc.)
- Built-in JS requires writing regex for everything
- Handles edge cases you might miss

**3. Consistent Error Handling**
- Standardized error format
- Multiple validation errors collected together
- Built-in JS requires manual error aggregation

**4. Maintainability**
- Declarative syntax is easier to read
- Reusable validation chains
- Less code duplication

**5. International Support**
- Locale-aware validation (phone numbers, postal codes)
- Built-in JS has no internationalization

**6. Performance**
- Optimized validation algorithms
- Lazy evaluation
- Built-in caching

### Real-World Comparison

**Validating a phone number with built-in JS:**
```javascript
// Incomplete - doesn't handle international formats
const phoneRegex = /^\d{10}$/;
if (!phoneRegex.test(phone)) {
  // Error handling...
}
```

**With Express Validator:**
```javascript
// Handles international formats, mobile vs landline, etc.

```

**The Bottom Line:**
Built-in JavaScript validation requires you to:
- Write and maintain complex regex patterns
- Handle security concerns manually
- Implement error collection and formatting
- Deal with internationalization yourself
- Test edge cases extensively

Express Validator provides battle-tested, secure validation with minimal code.
