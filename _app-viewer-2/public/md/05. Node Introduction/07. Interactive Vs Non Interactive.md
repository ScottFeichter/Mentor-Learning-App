# Interactive Vs. Non Interactive

&nbsp;

This refers to how script code gets executed.

## Interactive

Typing a command directly in shell and pressing Enter to run it

### Example

Open a terminal window and at the prompt type this command:

```bash
pwd
```
After pressing **```Enter```** you should see directory path you are currently in.

This command is **print working directory**.

## Non Interactive

Calling a file containing pre written scripts.

### Basic File Types

- .sh
- .js
- .py
