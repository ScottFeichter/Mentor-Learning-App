# Shell Scripts vs JS/Python Scripts

&nbsp;

A common question when learning is why do we need different languages?

## Shell Scripts

Shell scripts (Bash, Zsh) are written for the terminal itself.

They are great for automating system tasks like moving files or run commands.

```bash
#!/bin/bash
echo "Hello from a shell script"
```

## General Purpose Scripting Languages

JS and Python scripts execute inside their own runtime environment (Node or Python).

They are better suited for building applications, APIs, and complex logic.

```js
console.log("Hello from a JS script");
```



## Which To Use When?

Shell scripts glue commands together.

JS and Python scripts build things.
