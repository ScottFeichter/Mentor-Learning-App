# Query, Filter, Sort, Select, Limit, Skip

Used in SQL Databases/Sequelize

## What is a Query?

A **query** is a request to retrieve data from a database. It's the overall operation that asks the database to find and return records that match certain criteria.

```javascript
// SQL query - asking for user records
SELECT * FROM users;

// Sequelize query - same concept
User.findAll()
```

## What is a Filter?

A **filter** is the criteria or conditions that determine which records to include in the query results. It's the "WHERE" clause in SQL.

```javascript
// SQL filter - only users with age greater than 18
SELECT * FROM users WHERE age > 18;

// Sequelize filter - same logic
const { Op } = require('sequelize');
User.findAll({ where: { age: { [Op.gt]: 18 } } })
```

## What is Sorting?

**Sorting** determines the order in which the filtered results are returned. It doesn't change which records are returned, only their sequence.

```javascript
// SQL sort - alphabetical by name
SELECT * FROM users ORDER BY name ASC;

// Sequelize sort - same ordering
User.findAll({ order: [['name', 'ASC']] })
```

## What is Select?

**Select** (also called projection) determines which fields are included in the returned records. It controls what data is sent back, reducing bandwidth and improving performance.

```javascript
// SQL select - only return name and email fields
SELECT name, email FROM users;

// Sequelize select - same field selection
User.findAll({ attributes: ['name', 'email'] })
```

## What is Limit?

**Limit** restricts the maximum number of records returned by a query. It's essential for pagination and performance optimization.

```javascript
// SQL limit - return only 10 records
SELECT * FROM users LIMIT 10;

// Sequelize limit - same functionality
User.findAll({ limit: 10 })
```

## What is Skip?

**Skip** (called "offset" in Sequelize) bypasses a specified number of records before returning results. Combined with limit, it enables pagination.

```javascript
// SQL skip - skip first 20 records
SELECT * FROM users OFFSET 20;

// Sequelize skip - same functionality
User.findAll({ offset: 20 })
```

## How They Work Together

### Complete Example
```javascript
// SQL: Query with all operations
SELECT name, email, age FROM users
WHERE age >= 18 AND status = 'active'
ORDER BY name ASC
LIMIT 10 OFFSET 20;

// Sequelize: Same operation
const { Op } = require('sequelize');

User.findAll({
  where: { age: { [Op.gte]: 18 }, status: 'active' },
  attributes: ['name', 'email', 'age'],
  order: [['name', 'ASC']],
  offset: 20,
  limit: 10
})
```

### Step-by-Step Process
1. **Query**: "Find user records"
2. **Filter**: "Where age >= 18 AND status = 'active'"
3. **Select**: "Only return name, email, and age fields"
4. **Sort**: "Order results by name A-Z"
5. **Skip**: "Skip the first 20 results"
6. **Limit**: "Return maximum 10 records"

## Filter Examples

### Basic Filters
```javascript
const { Op } = require('sequelize');

// Equality
User.findAll({ where: { name: "John" } })
User.findAll({ where: { age: 25 } })

// Comparison
User.findAll({ where: { age: { [Op.gt]: 18 } } })        // Greater than
User.findAll({ where: { price: { [Op.lte]: 100 } } })    // Less than or equal

// Multiple conditions (AND - implicit)
User.findAll({ where: { age: { [Op.gte]: 18 }, status: "active" } })

// OR conditions
User.findAll({
  where: {
    [Op.or]: [
      { age: { [Op.lt]: 18 } },
      { status: "inactive" }
    ]
  }
})
```

### Advanced Filters
```javascript
const { Op } = require('sequelize');

// String contains (LIKE)
User.findAll({ where: { name: { [Op.like]: '%john%' } } })

// Case-insensitive contains (ILIKE - PostgreSQL only)
User.findAll({ where: { name: { [Op.iLike]: '%john%' } } })

// Starts with
User.findAll({ where: { name: { [Op.startsWith]: 'John' } } })

// In array of values
User.findAll({ where: { status: { [Op.in]: ["active", "pending"] } } })

// NOT conditions
User.findAll({ where: { status: { [Op.ne]: "inactive" } } })

// Null check
User.findAll({ where: { email: { [Op.not]: null } } })

// Between
User.findAll({ where: { age: { [Op.between]: [18, 65] } } })
```

## Select Examples

### Basic Field Selection
```javascript
// Include specific fields
User.findAll({ attributes: ['name', 'email'] })

// Exclude specific fields
User.findAll({ attributes: { exclude: ['password', 'createdAt', 'updatedAt'] } })
```

### Advanced Selection
```javascript
// Rename fields with aliases
User.findAll({
  attributes: [
    'name',
    ['email', 'userEmail'],  // Rename email to userEmail
    [sequelize.fn('COUNT', sequelize.col('id')), 'totalCount']  // Aggregation
  ]
})

// Include with computed fields
User.findAll({
  attributes: {
    include: [
      [sequelize.fn('COUNT', sequelize.col('Tasks.id')), 'taskCount']
    ]
  },
  include: [{ model: Task, attributes: [] }],
  group: ['User.id']
})
```

## Limit and Skip Examples

### Basic Pagination
```javascript
// Page 1: First 10 users
User.findAll({ limit: 10 })

// Page 2: Skip 10, take next 10
User.findAll({ offset: 10, limit: 10 })

// Page 3: Skip 20, take next 10
User.findAll({ offset: 20, limit: 10 })
```

### Pagination Formula
```javascript
const page = 2;        // Current page (1-based)
const limit = 10;      // Items per page
const offset = (page - 1) * limit;  // Calculate offset value

User.findAll({ offset, limit })
```

### Combined with Other Operations
```javascript
// Filter, sort, then paginate
User.findAll({
  where: { status: 'active' },
  order: [['createdAt', 'DESC']],
  offset: 20,
  limit: 10
})
```

## Sort Examples

### Basic Sorting
```javascript
// Ascending
User.findAll({ order: [['name', 'ASC']] })

// Descending
User.findAll({ order: [['createdAt', 'DESC']] })
```

### Multiple Field Sorting
```javascript
// Sort by category first, then price descending
Product.findAll({
  order: [
    ['category', 'ASC'],
    ['price', 'DESC']
  ]
})
```

### Sorting by Associated Model
```javascript
// Sort by associated model's field
User.findAll({
  include: [{ model: Task }],
  order: [[Task, 'createdAt', 'DESC']]
})
```

## REST API Integration

### Express Route Example
```javascript
const { Op } = require('sequelize');

app.get('/api/users', async (req, res) => {
  try {
    // Extract query parameters
    const { age, status, sort, fields, page, limit } = req.query;

    // Build filter object
    let where = {};
    if (age) where.age = { [Op.gte]: parseInt(age) };
    if (status) where.status = status;

    // Build order array
    let order = [['createdAt', 'DESC']];
    if (sort) {
      order = sort.split(',').map(field => {
        if (field.startsWith('-')) {
          return [field.substring(1), 'DESC'];
        }
        return [field, 'ASC'];
      });
    }

    // Build attributes array
    let attributes = undefined;
    if (fields) {
      attributes = fields.split(',').map(f => f.trim());
    }

    // Pagination
    const pageNum = parseInt(page) || 1;
    const limitNum = parseInt(limit) || 10;
    const offset = (pageNum - 1) * limitNum;

    // Execute query with all operations
    const { count: total, rows: users } = await User.findAndCountAll({
      where,
      attributes,
      order,
      offset,
      limit: limitNum
    });

    res.json({
      users,
      pagination: {
        page: pageNum,
        limit: limitNum,
        total,
        pages: Math.ceil(total / limitNum)
      }
    });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});
```

### URL Examples
```
GET /api/users                                    // Query all users
GET /api/users?page=2&limit=5                     // Pagination
GET /api/users?age=18&sort=name&fields=name,email&page=1&limit=10  // All operations
```

## Query Operations Summary

| Component | Purpose | Example |
|-----------|---------|---------|
| **Query** | Request data from database | `User.findAll()` |
| **Filter** | Specify which records to return | `{ where: { age: { [Op.gte]: 18 } } }` |
| **Sort** | Order the returned records | `{ order: [['name', 'ASC']] }` |
| **Select** | Choose which fields to include/exclude | `{ attributes: ['name', 'email'] }` |
| **Skip** | Bypass a number of records | `{ offset: 20 }` |
| **Limit** | Restrict maximum records returned | `{ limit: 10 }` |

## SQL vs Sequelize Syntax

### Raw SQL
```sql
SELECT name, email FROM users WHERE age >= 18 ORDER BY name ASC LIMIT 10 OFFSET 20;
```

### Sequelize
```javascript
const { Op } = require('sequelize');

User.findAll({
  where: { age: { [Op.gte]: 18 } },
  attributes: ['name', 'email'],
  order: [['name', 'ASC']],
  offset: 20,
  limit: 10
})
```

## Sequelize Operators Reference

```javascript
const { Op } = require('sequelize');

// Comparison
Op.eq    // = (equal)
Op.ne    // != (not equal)
Op.gt    // > (greater than)
Op.gte   // >= (greater than or equal)
Op.lt    // < (less than)
Op.lte   // <= (less than or equal)

// Range
Op.between      // BETWEEN value1 AND value2
Op.notBetween   // NOT BETWEEN

// Array
Op.in       // IN (value1, value2, ...)
Op.notIn    // NOT IN

// Pattern
Op.like     // LIKE '%value%'
Op.iLike    // ILIKE '%value%' (PostgreSQL only, case-insensitive)
Op.startsWith  // LIKE 'value%'
Op.endsWith    // LIKE '%value'

// Logical
Op.and   // AND
Op.or    // OR
Op.not   // NOT

// Null
Op.is    // IS NULL
Op.not   // IS NOT NULL
```

## Key Concepts

- **Query**: The overall database operation
- **Filter**: Conditions that determine which records match (`where` with `Op` operators)
- **Sort**: Ordering applied to the matching records (`order`)
- **Select**: Field projection to control returned data (`attributes`)
- **Offset/Limit**: Pagination controls for skip and limit
- **Performance**: Filters reduce data, sorting organizes results, attributes reduce bandwidth

These concepts work together to provide precise, ordered, and optimized data retrieval from SQL databases using Sequelize.
