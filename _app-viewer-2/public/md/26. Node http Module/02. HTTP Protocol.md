# Hypertext Transfer Protocol

## History

- 1980s — Tim Berners-Lee — World Wide Web concept

## Key Terms

- **HyperText** — content with references to other content
- **HyperLinks** — the references between hypertext resources
- **Transfer Protocol** — guidelines for the transmission of data

## What is HTTP?

A transfer protocol that defines the expectations for both ends of the transfer and defines some ways it might fail.

- It is a **request/response** protocol
- Defines the process of exchanging hypertext between systems:
  - **Clients** (aka user agent) — the browser
  - **Servers** (aka the origin) — some application

## Key Properties

- **Reliable connections** — messages sacrifice some speed for trust, ensuring each message arrives in order
- **Stateless transfer** — doesn't store any information between requests
- **Intermediaries** — other servers or devices that pass your request along:
  - **Proxies** — modify so it appears to come from a different source
  - **Gateways** — pretend to be the resource server you requested
  - **Tunnels** — simply pass your request along

## The Request-Response Cycle

**Browser's role:**
- Parse HTML, CSS, JS
- Render info to user by constructing DOM tree
