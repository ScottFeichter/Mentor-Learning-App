
## Basic Syntax

**Read data:**
```sql
SELECT name, email FROM users WHERE age > 21;
```

**Create data:**
```sql
INSERT INTO users (name, email, age) VALUES ('John', 'john@example.com', 25);
```

**Update data:**
```sql
UPDATE users SET email = 'newemail@example.com' WHERE id = 1;
```

**Delete data:**
```sql
DELETE FROM users WHERE id = 1;
```

## Creating Tables

```sql
CREATE TABLE users (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  email TEXT UNIQUE,
  age INTEGER
);
```

## Filtering and Sorting

```sql
-- Filter with WHERE
SELECT * FROM users WHERE age > 21 AND name = 'John';

-- Sort with ORDER BY
SELECT * FROM users ORDER BY name ASC;

-- Limit results
SELECT * FROM users LIMIT 10;
```

## Relationships (Joins)

```sql
-- Get users with their orders
SELECT users.name, orders.product, orders.total
FROM users
JOIN orders ON users.id = orders.user_id;
```

## Key Takeaway

SQL is the universal language for talking to relational databases. Learn SQL once and you can work with PostgreSQL, MySQL, SQLite, and most other relational databases with minimal syntax differences.
