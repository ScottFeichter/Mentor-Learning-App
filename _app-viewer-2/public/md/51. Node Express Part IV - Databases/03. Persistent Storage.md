# Persistent Storage

## What Is Persistent Storage?

**Persistent storage** means data that survives after a program stops running or a computer restarts. Unlike variables in memory (RAM) that disappear when the process ends, persistent data is written to disk and remains available.

Examples of persistent storage:
- Files on a hard drive
- Databases
- Cloud storage

Without persistent storage, every time you restart your server, all data would be gone.

## Why Not Just Use Files?

You could store data in plain files, but databases provide:

- **Speed** - optimized for searching and retrieving data
- **Integrity** - rules that prevent bad data from being stored
- **Concurrency** - multiple users can read/write without conflicts
- **Security** - control over who can access what data
- **Scalability** - handles growing amounts of data efficiently
