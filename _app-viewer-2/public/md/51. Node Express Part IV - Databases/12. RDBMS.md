# RDBMS

## What Is an RDBMS?

**RDBMS** stands for **Relational Database Management System**.

It is software that manages a relational database.

It manages data in **tables** with **rows** and **columns**.

It allows you to define **relationships** between those tables.

## Key Characteristics

- Data stored in tables (rows and columns)
- Tables have defined schemas (column names, data types)
- Relationships between tables using foreign keys
- Uses SQL (Structured Query Language) to interact with data
- Enforces data integrity through constraints
- Supports transactions (all-or-nothing operations)

## Examples

| RDBMS | Notes |
|---|---|
| **PostgreSQL** | Open source, feature-rich, highly reliable |
| **MySQL** | Open source, widely used, powers many web apps |
| **SQLite** | Lightweight, file-based, no separate server needed |
| **Microsoft SQL Server** | Enterprise-level, integrates with Microsoft ecosystem |
| **Oracle Database** | Enterprise-level, used in large corporations |
| **MariaDB** | Open source fork of MySQL |
| **Amazon Aurora** | AWS cloud-native, compatible with PostgreSQL/MySQL |
