# Eager Loading

**Eager loading** means related data IS fetched at the same time as the initial query.

```javascript
// Fetches user AND their posts in one query
const user = await User.findByPk(1, {
  include: [{ model: Post }]
});

// No additional query needed
console.log(user.Posts);
```

### How It Works

1. Initial query uses JOINs or multiple queries to fetch everything at once
2. Related data is immediately available without additional queries
3. All data arrives in one round trip

### Pros

- **No N+1 problem** - all data fetched upfront
- **Predictable performance** - you know exactly what queries run
- **Fewer round trips** - less network overhead

### Cons

- **Slower initial load** - fetches more data than you might need
- **More memory usage** - loads everything even if unused
- **Larger queries** - complex joins can be expensive
