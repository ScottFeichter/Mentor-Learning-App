# ORMs and ODMs

## What Is an ORM?

**ORM** stands for **Object-Relational Mapping**.

It's a library that lets you interact with a relational database using JavaScript objects instead of writing raw SQL.

```javascript
// Without ORM (raw SQL)
const result = await pool.query('SELECT * FROM users WHERE id = $1', [1]);
const user = result.rows[0];

// With ORM (Sequelize)
const user = await User.findByPk(1);
```

## What Is an ODM?

**ODM** stands for **Object-Document Mapping**.

Same concept as an ORM, but for document databases (like MongoDB) instead of relational databases.

```javascript
// With ODM (Mongoose)
const user = await User.findById('64a1b2c3d4e5f6');
```

## ORM vs ODM

| | ORM | ODM |
|---|---|---|
| **For** | Relational databases (SQL) | Document databases (NoSQL) |
| **Maps to** | Tables and rows | Collections and documents |
| **Examples** | Sequelize, Prisma, Knex | Mongoose |

## How an ORM Works

You define a **model** (a JavaScript class) that maps to a database table:

```javascript
// Define model
const User = sequelize.define('User', {
  name: DataTypes.STRING,
  email: DataTypes.STRING,
  age: DataTypes.INTEGER
});

// Create
await User.create({ name: 'John', email: 'john@example.com', age: 25 });

// Read
const users = await User.findAll({ where: { age: { [Op.gt]: 21 } } });

// Update
await User.update({ name: 'Jane' }, { where: { id: 1 } });

// Delete
await User.destroy({ where: { id: 1 } });
```

## Popular Node.js ORMs/ODMs

| Library | Type | Database |
|---|---|---|
| **Sequelize** | ORM | PostgreSQL, MySQL, SQLite |
| **Prisma** | ORM | PostgreSQL, MySQL, SQLite, MongoDB |
| **Knex** | Query Builder | PostgreSQL, MySQL, SQLite |
| **Mongoose** | ODM | MongoDB |

## Pros

- Write JavaScript instead of SQL
- Database-agnostic (switch databases with minimal code changes)
- Built-in validation and type checking
- Handles relationships and joins for you
- Prevents SQL injection by default

## Cons

- Adds abstraction (harder to debug complex queries)
- Performance overhead for simple operations
- Generated SQL may not be optimal
- Learning curve for the ORM itself
- Can hide what's actually happening at the database level

## Key Takeaway

ORMs and ODMs are tools that translate between your JavaScript code and the database. They simplify common operations but add a layer of abstraction. Understanding raw SQL is still important for debugging and optimization.
