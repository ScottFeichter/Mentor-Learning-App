# MongoDB

## What Is MongoDB?

**MongoDB** is a **NoSQL document database management system**.

It is software that manages a document-oriented database.

It manages data in **collections** of **documents** (JSON-like objects).

It allows you to define **references** or **embed** related data within documents.

## Key Characteristics

- Data stored in documents (JSON-like BSON format)
- Documents grouped into collections (analogous to tables)
- Flexible schema (documents in the same collection can have different fields)
- Uses MQL (MongoDB Query Language) to interact with data
- Supports optional validation rules for data integrity
- Supports transactions (multi-document, multi-collection)
- Horizontally scalable (sharding across multiple servers)

## MongoDB vs RDBMS

| Aspect | RDBMS | MongoDB |
|---|---|---|
| Data Model | Tables with rows and columns | Collections with documents |
| Schema | Fixed (defined upfront) | Flexible (per-document) |
| Query Language | SQL | MQL |
| Relationships | Foreign keys and JOINs | Embedding or references with $lookup |
| Scaling | Vertical (bigger server) | Horizontal (more servers) |
| Transactions | Native, mature | Supported (since v4.0) |
| Best For | Complex relationships, strict consistency | Rapid development, flexible data, scale |
