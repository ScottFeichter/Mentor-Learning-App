# MQL

## What Is MQL?

**MQL** stands for **MongoDB Query Language**.

It is the language used to communicate with MongoDB databases.

You use MQL to tell the database what data you want to create, read, update, or delete.

## Key Points About MQL as a Language

- **Imperative** - you call methods and pass JSON-like objects describing what you want
- **Not a standalone language** - MQL is expressed through method calls, not standalone statements like SQL
- **JavaScript-based** - uses JavaScript syntax and JSON/BSON document structures
- **Case sensitive** - field names and values are case sensitive (`Name` and `name` are different)
- **Document-oriented** - operates on JSON-like documents rather than rows and columns
- **Expressive** - operators use a `$` prefix (`$gt`, `$in`, `$set`, etc.)

## CRUD Operations

MQL maps directly to the four basic data operations:

| Operation | MQL Method |
|---|---|
| **C**reate | `insertOne()` / `insertMany()` |
| **R**ead   | `find()` / `findOne()` |
| **U**pdate | `updateOne()` / `updateMany()` |
| **D**elete | `deleteOne()` / `deleteMany()` |
