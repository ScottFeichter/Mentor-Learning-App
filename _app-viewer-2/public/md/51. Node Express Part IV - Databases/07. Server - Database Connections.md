# Server - Database Connections

## The General Idea

A server connects to a database the same way a browser connects to a server - over a network using an address and a protocol. The server needs to know **where** the database is and **how** to authenticate.

## What a Connection Requires

Regardless of where the database lives, the server needs:

- **Host** - the address of the database machine (IP address or domain name)
- **Port** - which port the database is listening on
- **Database name** - which specific database to use
- **Username** - who is connecting
- **Password** - proof of identity

## Connection String

All of this information is typically combined into a single **connection string** (also called a URI or DSN):

```
postgresql://username:password@host:port/database_name
```

**Examples:**
```
# Local database
postgresql://admin:secret123@localhost:5432/myapp

# Cloud database
postgresql://admin:secret123@my-db.us-east-1.rds.amazonaws.com:5432/myapp

# MongoDB
mongodb+srv://admin:secret123@cluster0.abc123.mongodb.net/myapp
```
