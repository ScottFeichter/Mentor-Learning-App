# MQL Syntax

## Basic Syntax

**Read data:**
```javascript
db.users.find({ age: { $gt: 21 } }, { name: 1, email: 1 })
```

**Create data:**
```javascript
db.users.insertOne({ name: "John", email: "john@example.com", age: 25 })
```

**Update data:**
```javascript
db.users.updateOne({ _id: ObjectId("...") }, { $set: { email: "newemail@example.com" } })
```

**Delete data:**
```javascript
db.users.deleteOne({ _id: ObjectId("...") })
```

## Creating Collections

Collections are created implicitly when you first insert a document, or explicitly:

```javascript
db.createCollection("users")

// With validation rules
db.createCollection("users", {
  validator: {
    $jsonSchema: {
      bsonType: "object",
      required: ["name", "email"],
      properties: {
        name: { bsonType: "string" },
        email: { bsonType: "string" },
        age: { bsonType: "int" }
      }
    }
  }
})
```

## Filtering and Sorting

```javascript
// Filter with query document
db.users.find({ age: { $gt: 21 }, name: "John" })

// Sort with .sort()
db.users.find().sort({ name: 1 })  // 1 = ascending, -1 = descending

// Limit results
db.users.find().limit(10)

// Combine
db.users.find({ age: { $gt: 21 } }).sort({ name: 1 }).limit(10)
```

## Relationships (Lookup)

```javascript
// Get users with their orders (aggregation pipeline)
db.users.aggregate([
  {
    $lookup: {
      from: "orders",
      localField: "_id",
      foreignField: "user_id",
      as: "orders"
    }
  }
])
```

## Key Takeaway

MQL is the language for talking to MongoDB databases. It uses JavaScript syntax and JSON-like documents to express queries. Learn MQL and you can work with MongoDB through the shell, native drivers, or ODMs like Mongoose.
