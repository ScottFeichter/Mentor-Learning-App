# Retrieval

## What Is Retrieval?

**Retrieval** is the act of reading data from a database. In SQL, this is done with the `SELECT` statement.

## Basic Select

```sql
-- Get all rows and all columns
SELECT * FROM users;

-- Get specific columns
SELECT name, email FROM users;

-- Get one row
SELECT * FROM users WHERE id = 1;
```

## Filtering with WHERE

```sql
SELECT * FROM users WHERE age > 21;
SELECT * FROM users WHERE name = 'John' AND age > 18;
SELECT * FROM users WHERE email LIKE '%@gmail.com';
```

## Sorting with ORDER BY

```sql
SELECT * FROM users ORDER BY name ASC;   -- A to Z
SELECT * FROM users ORDER BY age DESC;   -- Highest first
```

## Limiting Results

```sql
SELECT * FROM users LIMIT 10;           -- First 10 rows
SELECT * FROM users LIMIT 10 OFFSET 20; -- Rows 21-30 (pagination)
```

## In Node.js

```javascript
// Get all users
const result = await pool.query('SELECT * FROM users');
console.log(result.rows);

// Get one user by id
const result = await pool.query('SELECT * FROM users WHERE id = $1', [1]);
console.log(result.rows[0]);

// Filter with parameters
const result = await pool.query(
  'SELECT * FROM users WHERE age > $1 ORDER BY name ASC LIMIT $2',
  [21, 10]
);
```

## What Happens During Retrieval

1. Database receives the query
2. Query optimizer determines the fastest way to find the data
3. Database scans the table (or uses an index if available)
4. Matching rows are collected
5. Results are sorted/limited as requested
6. Data is returned to the caller

## Key Takeaway

Retrieval is the most common database operation. Writing efficient queries with proper filtering, sorting, and limiting keeps your application fast as data grows.
