# Launchpad and Mission Control

## Launchpad

- **⌘Space** — Enter Launchpad (via Spotlight, type app name)
- **Arrow keys** — Navigate between spaces
- **Enter** — Go into a space / open an app
- **Fn+Esc** — Move out of a space
- **Fn+F4** — Close Launchpad

## Mission Control

- **F3** — Enter/Exit Mission Control
- **⌃↑** — Enter Preview
- **⌃←/→** — Cycle Preview / Cycle Desktops
- **⌃1/2/3/4** — Jump to Desktop 1/2/3/4

## Spotlight

- **⌘Space** — Open Spotlight Search
- Type app name + Enter to open

## Window Tiling (Custom)

Create custom shortcuts in System Preferences → Keyboard → Shortcuts → App Shortcuts:
- Menu Title: "Move Window to Right Side of Screen"
- Suggested shortcut: `⌃⌥⌘→`
- Menu Title: "Move Window to Left Side of Screen"
- Suggested shortcut: `⌃⌥⌘←`
