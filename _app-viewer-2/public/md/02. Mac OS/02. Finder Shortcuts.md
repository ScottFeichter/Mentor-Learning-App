# Finder and System Shortcuts

## File Operations

- **⌘D** — Duplicate selected files
- **⌘E** — Eject selected disk/volume
- **⌘I** — Get Info for selected file
- **⌘Delete** — Move selected item to Trash
- **⇧⌘Delete** — Empty Trash
- **⌥⇧⌘Delete** — Empty Trash without confirmation

## Navigation

- **⇧⌘C** — Open Computer window
- **⇧⌘D** — Open Desktop folder
- **⇧⌘F** — Open Recents window
- **⇧⌘G** — Go to Folder
- **⇧⌘H** — Open Home folder
- **⇧⌘I** — Open iCloud Drive
- **⇧⌘K** — Open Network window
- **⌥⌘L** — Open Downloads folder
- **⇧⌘O** — Open Documents folder
- **⇧⌘U** — Open Utilities folder
- **⇧⌘R** — Open AirDrop window
- **⌘[** — Go to previous folder
- **⌘]** — Go to next folder
- **⌘↑** — Open containing folder
- **⌘↓** — Open selected item

## View Options

- **⌘1** — Icon view
- **⌘2** — List view
- **⌘3** — Column view
- **⌘4** — Gallery view
- **⌘J** — Show View Options
- **⌥⌘P** — Show/hide path bar
- **⌥⌘S** — Show/hide Sidebar
- **⌘/** — Show/hide status bar

## Window Management

- **⌘N** — New Finder window
- **⌘T** — Show/hide tab bar
- **⌥⌘D** — Show/hide Dock
- **⌘K** — Connect to Server

## Drag Operations

- **⌘ + drag** — Move to other volume (instead of copy)
- **⌥ + drag** — Copy dragged item
- **⌥⌘ + drag** — Make alias of dragged item

## Display and Sound

- **⌘ Mission Control** — Show desktop
- **⌃↓** — Show all windows of front app
- **⌥ Volume Up** — Open Sound preferences
- **⌥⇧ Volume** — Adjust volume in smaller steps
