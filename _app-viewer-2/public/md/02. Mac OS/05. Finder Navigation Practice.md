# Finder Navigation Practice

## Switching and Hiding

- **⌘Tab** — Navigate to Finder
- **⌘`** — Cycle through Finder windows
- **⌘H** — Hide all Finder windows
- **⌘⌥H** — Hide all windows except Finder's

## Window Management

- **⌘,** — Open Finder Preferences
- **⌘W** — Close active window
- **⌘N** — Open new Finder window
- **⌘M** — Minimize a Finder window

## Folder Navigation

- **⌘⇧C** — Navigate to top level (Computer)
- **⌘⇧A** — Navigate to Applications
- **⌘⇧U** — Navigate to Utilities
- **⌘⇧D** — Navigate to Desktop
- **⌘⇧G** — Go to folder by address (case sensitive)
- **⌘F** — Search for a folder
- **⌘⇧F** — Open Recents folder

## File Operations

- **⌘⇧N** — Create new folder
- **⌘D** — Duplicate file
- **⌘I** — Get info of selected item
- **⌘⇧.** — Show hidden files
- **⌘P** — Show path bar
- **⌘O** — Open selected item (files, not folders)

## Tabs

- **⌘T** — Open new tab
- **⌃Tab** — Cycle forward through tabs
- **⌃⇧Tab** — Cycle backward through tabs

## View Modes

- **⌘1** — Icon mode
- **⌘2** — List mode
- **⌘3** — Column mode
- **⌘4** — Gallery mode

## Trash

- **⌘Delete** — Move selected item to Trash
- **⌘⇧Delete** — Empty Trash

> NOTE: There is no quitting Finder — ⌘Q does nothing.
