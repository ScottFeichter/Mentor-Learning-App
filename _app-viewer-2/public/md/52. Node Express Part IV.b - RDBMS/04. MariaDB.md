# MariaDB

## What Is MariaDB?

**MariaDB** is an open-source relational database that was forked from MySQL in 2009. It was created by MySQL's original developers after Oracle acquired MySQL, to ensure the database remained truly open-source. MariaDB is designed as a drop-in replacement for MySQL — most MySQL code, tools, and queries work unchanged.

## History

- **2009**: Michael "Monty" Widenius (MySQL co-creator) forked MySQL to create MariaDB
- **2009**: Named after Monty's younger daughter Maria (MySQL was named after his older daughter My)
- **2012**: MariaDB Foundation established to ensure open governance
- **2013**: Major Linux distributions (Fedora, Arch, openSUSE) switched default from MySQL to MariaDB
- **2015**: MariaDB 10.0 introduced features diverging from MySQL
- **Today**: Default database in many Linux distributions, used by Google, Wikipedia, and WordPress.com

## Key Features

- Drop-in MySQL replacement (binary compatible)
- Truly open-source (GPL license, community-governed)
- Additional storage engines (Aria, ColumnStore, Spider, TokuDB)
- Thread pool for better concurrency
- Galera Cluster for synchronous multi-master replication
- Temporal tables (system-versioned tables)
- Oracle compatibility mode
- Faster than MySQL in many benchmarks
- Columnar storage engine for analytics (ColumnStore)

## Installation (macOS)

```bash
# Using Homebrew
brew install mariadb
brew services start mariadb

# Secure the installation
mariadb-secure-installation

# Verify
mariadb --version
```

## Installation (Linux/Ubuntu)

```bash
sudo apt update
sudo apt install mariadb-server
sudo systemctl start mariadb
sudo systemctl enable mariadb

# Secure the installation
sudo mariadb-secure-installation
```

## Running Locally (Shell)

### Connect to MariaDB

```bash
# Connect as root
mariadb -u root -p

# Or use the mysql command (still works)
mysql -u root -p

# Connect to a specific database
mariadb -u username -p mydb
```

### Basic Shell Commands

```sql
-- List all databases
SHOW DATABASES;

-- Use a database
USE mydb;

-- List all tables
SHOW TABLES;

-- Describe a table
DESCRIBE users;

-- Show server version
SELECT VERSION();

-- Quit
EXIT;
```

### Basic SQL Operations

```sql
-- Create a database
CREATE DATABASE myapp;

-- Create a table
CREATE TABLE users (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL,
  age INT CHECK (age >= 0),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB;

-- Insert data
INSERT INTO users (name, email, age) VALUES ('John', 'john@example.com', 30);

-- Query data
SELECT * FROM users WHERE age > 21 ORDER BY name;

-- Update data
UPDATE users SET age = 31 WHERE email = 'john@example.com';

-- Delete data
DELETE FROM users WHERE id = 1;
```

### Connecting from Node.js

```javascript
// Uses the same mysql2 driver as MySQL
const mysql = require('mysql2/promise');

const connection = await mysql.createConnection({
  host: 'localhost',
  user: 'myuser',
  password: 'mypassword',
  database: 'mydb'
});

const [rows] = await connection.execute('SELECT * FROM users');
```

## Default Port

**3306** (same as MySQL)

## MariaDB vs MySQL

| Aspect | MariaDB | MySQL |
|--------|---------|-------|
| License | GPL (truly open-source) | GPL + proprietary editions |
| Governance | Community foundation | Oracle Corporation |
| Compatibility | MySQL-compatible | N/A |
| Storage Engines | More options (Aria, ColumnStore) | InnoDB, MyISAM |
| Performance | Often faster | Good performance |
| Features | Adds features MySQL lacks | Some features MariaDB lacks |

## When to Use MariaDB

- When you want a MySQL-compatible database that's fully open-source
- Linux server deployments (often the default)
- When you need Galera Cluster for multi-master replication
- Analytics workloads (ColumnStore engine)
- When migrating away from MySQL with minimal changes
