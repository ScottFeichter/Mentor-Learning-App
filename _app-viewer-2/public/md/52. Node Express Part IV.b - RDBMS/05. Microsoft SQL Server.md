# Microsoft SQL Server

## What Is SQL Server?

**Microsoft SQL Server** (often called MSSQL or SQL Server) is a proprietary relational database management system developed by Microsoft. It's a cornerstone of the Microsoft enterprise ecosystem, tightly integrated with Windows Server, Azure, and .NET applications.

## History

- **1989**: First version released (co-developed with Sybase)
- **1993**: Microsoft and Sybase split — Microsoft continued SQL Server independently
- **2000**: SQL Server 2000 became dominant in enterprise Windows environments
- **2005**: Major rewrite with SQL Server 2005 (new engine, CLR integration)
- **2016**: SQL Server available on Linux for the first time
- **2017**: SQL Server on Linux officially supported, Docker containers available
- **2019**: Big data clusters, enhanced Linux support
- **Today**: Available on Windows, Linux, Docker, and Azure cloud

## Key Features

- T-SQL (Transact-SQL) — Microsoft's SQL extension with procedural features
- SQL Server Management Studio (SSMS) — powerful GUI
- Integration Services (SSIS) — ETL and data migration
- Analysis Services (SSAS) — OLAP and data mining
- Reporting Services (SSRS) — report generation
- Always On Availability Groups — high availability
- In-memory OLTP (Hekaton)
- Columnstore indexes for analytics
- Full-text search
- CLR integration (run .NET code in the database)
- JSON support

## Installation (macOS/Linux via Docker)

SQL Server doesn't run natively on macOS. Use Docker:

```bash
# Pull the image
docker pull mcr.microsoft.com/mssql/server:2022-latest

# Run the container
docker run -e "ACCEPT_EULA=Y" -e "MSSQL_SA_PASSWORD=YourStrong!Pass" \
  -p 1433:1433 --name mssql \
  -d mcr.microsoft.com/mssql/server:2022-latest

# Verify it's running
docker ps
```

## Installation (Linux/Ubuntu)

```bash
# Add Microsoft repository
curl https://packages.microsoft.com/keys/microsoft.asc | sudo apt-key add -
sudo add-apt-repository "$(curl https://packages.microsoft.com/config/ubuntu/22.04/mssql-server-2022.list)"

# Install
sudo apt update
sudo apt install mssql-server
sudo /opt/mssql/bin/mssql-conf setup

# Install command-line tools
sudo apt install mssql-tools18
```

## Running Locally (sqlcmd Shell)

### Connect to SQL Server

```bash
# Connect locally
sqlcmd -S localhost -U sa -P 'YourStrong!Pass'

# Connect with Azure Data Studio or SSMS (GUI)
# Server: localhost,1433
# Authentication: SQL Server Authentication
# Username: sa
# Password: YourStrong!Pass
```

### Basic Shell Commands

```sql
-- List all databases
SELECT name FROM sys.databases;
GO

-- Use a database
USE mydb;
GO

-- List all tables
SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES WHERE TABLE_TYPE = 'BASE TABLE';
GO

-- Describe a table
EXEC sp_columns 'users';
GO

-- Note: Every command in sqlcmd must be followed by GO
```

### Basic SQL Operations

```sql
-- Create a database
CREATE DATABASE myapp;
GO

-- Create a table
USE myapp;
GO

CREATE TABLE users (
  id INT IDENTITY(1,1) PRIMARY KEY,
  name NVARCHAR(100) NOT NULL,
  email NVARCHAR(255) UNIQUE NOT NULL,
  age INT CHECK (age >= 0),
  created_at DATETIME2 DEFAULT GETDATE()
);
GO

-- Insert data
INSERT INTO users (name, email, age) VALUES ('John', 'john@example.com', 30);
GO

-- Query data
SELECT * FROM users WHERE age > 21 ORDER BY name;
GO

-- Update data
UPDATE users SET age = 31 WHERE email = 'john@example.com';
GO

-- Delete data
DELETE FROM users WHERE id = 1;
GO
```

### T-SQL Specifics

```sql
-- Top N rows (instead of LIMIT)
SELECT TOP 10 * FROM users;

-- Identity (instead of SERIAL/AUTO_INCREMENT)
id INT IDENTITY(1,1) PRIMARY KEY

-- String concatenation
SELECT name + ' - ' + email FROM users;

-- Date functions
SELECT GETDATE();       -- current datetime
SELECT DATEADD(day, 7, GETDATE());  -- add 7 days
```

## Running Remotely

### Connection String Format

```
Server=host,port;Database=mydb;User Id=username;Password=password;Encrypt=true;
```

### Connecting from Node.js

```javascript
// Using tedious (official Microsoft driver)
const { Connection, Request } = require('tedious');

// Using mssql (higher-level wrapper)
const sql = require('mssql');

const pool = await sql.connect({
  server: 'localhost',
  database: 'mydb',
  user: 'sa',
  password: 'YourStrong!Pass',
  options: { encrypt: false, trustServerCertificate: true }
});

const result = await pool.request().query('SELECT * FROM users');
```
