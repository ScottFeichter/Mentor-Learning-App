# Node Version Manager

&nbsp;

**Node Version Manager (nvm)** is an application to manage the <span class="highlight">Node</span> application.

## Why Node Version Manager?

You can have multiple versions of <span class="highlight">Node</span> on your machine.

Use **nvm** to install, uninstall, and manage versions of <span class="highlight">Node</span> on your machine.

## Why Multiple Versions Of Node?

The most common reasons for multiple versions of <span class="highlight">Node</span> on a machine are:

- Legacy code relaint on the <span class="highlight">Node</span> version used when developed
- To include or exclude certain version specific <span class="highlight">Node</span> features

### How To Use NVM

**nvm** does not have a GUI.

To use it we utilize commands in a terminal.
