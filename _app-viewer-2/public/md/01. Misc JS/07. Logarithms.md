# Logarithms

## What is a Logarithm?

The **logarithm** of a number roughly measures the number of times you can divide that number by 2 before you get a value ≤ 1. This is the inverse of exponentiation.

- **Exponent**: multiplying itself by itself n times → 2⁵ = 32
- **Logarithm**: dividing itself by itself n times to reach 1 → log₂(32) = 5

We use base 2 in computers because computers use binary.

## The Binary Logarithm (base-2)

Powers of 2 to memorize:

| log₂(n) | n    | 2^x  |
|----------|------|------|
| 0        | 1    | 2⁰   |
| 1        | 2    | 2¹   |
| 2        | 4    | 2²   |
| 3        | 8    | 2³   |
| 4        | 16   | 2⁴   |
| 5        | 32   | 2⁵   |
| 6        | 64   | 2⁶   |
| 7        | 128  | 2⁷   |
| 8        | 256  | 2⁸   |
| 9        | 512  | 2⁹   |
| 10       | 1024 | 2¹⁰  |

## In JavaScript

```javascript
Math.log2(1024); // 10
```

## Why Logarithms Matter

- O(log n) is very efficient
- Growth is so slow it's almost constant
