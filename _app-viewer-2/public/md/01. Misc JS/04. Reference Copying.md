# Reference Copying and Destructuring

## Copying Arrays

Old way (shallow copy):

```javascript
let copy1 = arr1.slice();
```

New way using spread (shallow copy):

```javascript
let copy2 = [...arr1];
```

## Destructuring Arrays

Basic destructuring:

```javascript
let numArray = [10, 20];
let [firstEl, secondEl] = numArray;
```

Declaring variables before destructuring:

```javascript
let animalArray = ["tiger", "hippo"];
let animal1, animal2;

[animal1, animal2] = animalArray;

console.log(animal1); // "tiger"
console.log(animal2); // "hippo"
```

## Swapping Variables with Destructuring

```javascript
let num1 = 17;
let num2 = 3;

[num1, num2] = [num2, num1];

console.log(num1); // 3
console.log(num2); // 17
```

## Rest/Spread in Destructuring

- To the **right** of `=` → spreading into
- To the **left** of `=` → gathering the rest
