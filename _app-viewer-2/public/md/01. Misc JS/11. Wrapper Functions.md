# Wrapper Functions

## What is a Wrapper Function?

A **wrapper function** is a function that calls another function while adding extra functionality around it. It "wraps" the original function with additional behavior without modifying the original code.

## Basic Structure

```javascript
function wrapper(originalFunction) {
  return function(...args) {
    // Code before original function
    const result = originalFunction(...args);
    // Code after original function
    return result;
  };
}
```

## Why Use Wrapper Functions?

### 1. Add Functionality Without Modification
- Enhance existing functions without changing their code
- Follow the Open/Closed Principle (open for extension, closed for modification)
- Maintain backward compatibility

### 2. Cross-Cutting Concerns
- Logging, timing, authentication, validation
- Apply same behavior to multiple functions
- Separate concerns from business logic

### 3. Error Handling
- Centralize error handling logic
- Add try/catch blocks consistently
- Transform or log errors uniformly

## Common Use Cases

### Logging Wrapper
```javascript
function withLogging(fn) {
  return function(...args) {
    console.log(`Calling ${fn.name} with args:`, args);
    const result = fn(...args);
    console.log(`${fn.name} returned:`, result);
    return result;
  };
}

// Usage
const add = (a, b) => a + b;
const loggedAdd = withLogging(add);
loggedAdd(2, 3); // Logs input and output
```

### Timing Wrapper
```javascript
function withTiming(fn) {
  return function(...args) {
    const start = performance.now();
    const result = fn(...args);
    const end = performance.now();
    console.log(`${fn.name} took ${end - start} milliseconds`);
    return result;
  };
}
```

### Error Handling Wrapper (Express)
```javascript
const asyncWrapper = (fn) => {
  return async (req, res, next) => {
    try {
      await fn(req, res, next);
    } catch (error) {
      next(error); // Pass error to Express error handler
    }
  };
};

// Usage
app.get('/users', asyncWrapper(async (req, res) => {
  const users = await User.find(); // Might throw error
  res.json(users);
}));
```

### Authentication Wrapper
```javascript
function requireAuth(fn) {
  return function(req, res, next) {
    if (!req.user) {
      return res.status(401).json({ error: 'Unauthorized' });
    }
    return fn(req, res, next);
  };
}

// Usage
app.get('/profile', requireAuth((req, res) => {
  res.json(req.user);
}));
```

### Caching Wrapper
```javascript
function withCache(fn) {
  const cache = new Map();
  
  return function(...args) {
    const key = JSON.stringify(args);
    
    if (cache.has(key)) {
      console.log('Cache hit');
      return cache.get(key);
    }
    
    const result = fn(...args);
    cache.set(key, result);
    return result;
  };
}

// Usage
const expensiveCalculation = (n) => {
  // Simulate expensive operation
  return n * n;
};

const cachedCalculation = withCache(expensiveCalculation);
```

### Validation Wrapper
```javascript
function withValidation(fn, validator) {
  return function(...args) {
    if (!validator(...args)) {
      throw new Error('Invalid arguments');
    }
    return fn(...args);
  };
}

// Usage
const divide = (a, b) => a / b;
const safeDivide = withValidation(divide, (a, b) => b !== 0);
```

## Advanced Patterns

### Higher-Order Component (React)
```javascript
function withLoading(Component) {
  return function WrappedComponent(props) {
    if (props.loading) {
      return <div>Loading...</div>;
    }
    return <Component {...props} />;
  };
}

// Usage
const UserList = ({ users }) => <ul>{users.map(...)}</ul>;
const UserListWithLoading = withLoading(UserList);
```

### Decorator Pattern
```javascript
class APIService {
  fetchData() {
    return fetch('/api/data');
  }
}

// Wrapper class
class CachedAPIService {
  constructor(apiService) {
    this.apiService = apiService;
    this.cache = new Map();
  }
  
  fetchData() {
    if (this.cache.has('data')) {
      return Promise.resolve(this.cache.get('data'));
    }
    
    return this.apiService.fetchData()
      .then(data => {
        this.cache.set('data', data);
        return data;
      });
  }
}
```

### Multiple Wrappers (Composition)
```javascript
const enhancedFunction = withTiming(
  withLogging(
    withValidation(originalFunction, validator)
  )
);
```

## Benefits

- **Modularity**: Separate concerns into reusable wrappers
- **Composability**: Combine multiple wrappers
- **Testability**: Test wrappers and original functions independently
- **Maintainability**: Centralize cross-cutting concerns
- **Flexibility**: Apply wrappers selectively

## When to Use Wrappers

- **Cross-cutting concerns**: Logging, timing, caching, validation
- **Legacy code enhancement**: Add features without modification
- **Middleware patterns**: Express middleware, React HOCs
- **Aspect-oriented programming**: Separate business logic from infrastructure
- **API consistency**: Standardize behavior across functions

Wrapper functions are a powerful pattern for extending functionality while maintaining clean, modular code architecture.
