# Control Flow

Control flow is the order in which instructions are executed in a program.

### Sequential Control Flow (default)
  - from top to bottom
  - module resolution and dependency loading

### Conditional Control Flow (branching)
  - if
  - if...else
  - switch
  - ternary  ? :

### Repition Control Flow (loops)
 - for
 - while
 - do...while
 - iterators

### Jump Statements
 - break
 - continue
 - return
 - throw

### Error Control Flow
 - Errors

### Error Handling Control Flow
 - try...catch
 - finally

### Function Control Flow (using previously defined code)
 - Single Threaded
   - One Call Stack
     - Synchronous
       - Blocking

### Asynchronus Flow
  - Events
  - Callbacks
  - Promises
  - Async/Await
  - Fetch
