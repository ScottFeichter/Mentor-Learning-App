# Cookie Options In Depth

## Security Options

### httpOnly

Prevents JavaScript from accessing the cookie via `document.cookie`. Essential for session tokens.

```javascript
res.cookie('session', token, { httpOnly: true });
```

### secure

Cookie is only sent over HTTPS connections.

```javascript
res.cookie('session', token, { secure: true });
```

### sameSite

Controls whether cookies are sent with cross-site requests.

```javascript
// Strict: never sent cross-site
res.cookie('session', token, { sameSite: 'strict' });

// Lax: sent with top-level navigations (default in modern browsers)
res.cookie('session', token, { sameSite: 'lax' });

// None: sent with all cross-site requests (requires secure: true)
res.cookie('session', token, { sameSite: 'none', secure: true });
```

## Expiration Options

### maxAge

Time in milliseconds until the cookie expires.

```javascript
// Expires in 1 hour
res.cookie('session', token, { maxAge: 3600000 });

// Expires in 7 days
res.cookie('remember', 'true', { maxAge: 7 * 24 * 60 * 60 * 1000 });
```

### expires

A specific Date object when the cookie expires.

```javascript
const tomorrow = new Date(Date.now() + 86400000);
res.cookie('session', token, { expires: tomorrow });
```

## Path and Domain

### path

Limits the cookie to a specific URL path.

```javascript
// Only sent for /api routes
res.cookie('apiToken', token, { path: '/api' });
```

### domain

Specifies which domain can receive the cookie.

```javascript
// Available to all subdomains
res.cookie('session', token, { domain: '.myapp.com' });
```

## Production Cookie Configuration

```javascript
const cookieOptions = {
  httpOnly: true,
  secure: process.env.NODE_ENV === 'production',
  sameSite: 'strict',
  maxAge: 24 * 60 * 60 * 1000, // 24 hours
  path: '/'
};

res.cookie('session', token, cookieOptions);
```
