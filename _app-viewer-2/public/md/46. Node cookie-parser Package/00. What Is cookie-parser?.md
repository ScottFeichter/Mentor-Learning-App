# cookie-parser

## What is cookie-parser?

cookie-parser is an Express middleware that parses cookies attached to the client request object. It populates `req.cookies` with an object keyed by cookie names.

## Installation

```bash
npm install cookie-parser
```

## Basic Usage

```javascript
const express = require('express');
const cookieParser = require('cookie-parser');

const app = express();
app.use(cookieParser());

app.get('/', (req, res) => {
  console.log(req.cookies); // { name: 'value' }
  res.send('Cookies parsed!');
});
```

## Setting Cookies

```javascript
app.get('/set', (req, res) => {
  res.cookie('username', 'scott', {
    maxAge: 900000,
    httpOnly: true,
    secure: true,
    sameSite: 'strict'
  });
  res.send('Cookie set!');
});
```

## Reading Cookies

```javascript
app.get('/read', (req, res) => {
  const username = req.cookies.username;
  res.send(`Hello ${username}`);
});
```

## Clearing Cookies

```javascript
app.get('/logout', (req, res) => {
  res.clearCookie('username');
  res.send('Cookie cleared!');
});
```

## Signed Cookies

```javascript
app.use(cookieParser('my-secret-key'));

app.get('/set-signed', (req, res) => {
  res.cookie('token', 'abc123', { signed: true });
  res.send('Signed cookie set!');
});

app.get('/read-signed', (req, res) => {
  console.log(req.signedCookies); // { token: 'abc123' }
  res.send('Signed cookie read!');
});
```

## Cookie Options

| Option | Description |
|--------|-------------|
| `maxAge` | Expiry time in milliseconds |
| `httpOnly` | Prevents client-side JS access |
| `secure` | Only sent over HTTPS |
| `sameSite` | Controls cross-site sending (`strict`, `lax`, `none`) |
| `path` | URL path the cookie is valid for |
| `domain` | Domain the cookie is valid for |
| `signed` | Whether the cookie should be signed |

## Summary

- **cookie-parser** parses cookies from incoming requests
- Populates `req.cookies` and `req.signedCookies`
- Signed cookies provide tamper detection
- Always use `httpOnly` and `secure` for sensitive cookies
