# StatusError

## What It Is
Custom error class that combines error messages with HTTP status codes for structured error handling in Express applications.

## Basic Implementation
```javascript
class StatusError extends Error {
  constructor(message, statusCode) {
    super(message);
    this.statusCode = statusCode;
  }
}
```

## Usage in Routes
```javascript
// Throw errors with specific status codes
if (!user) {
  throw new StatusError('User not found', 404);
}

if (!authorized) {
  throw new StatusError('Unauthorized', 401);
}

if (invalidData) {
  throw new StatusError('Invalid input', 400);
}
```

## Error Handling Middleware
```javascript
app.use((err, req, res, next) => {
  const statusCode = err.statusCode || 500;
  const message = err.statusCode ? err.message : 'Internal Server Error';
  res.status(statusCode).json({ message });
});
```

## Benefits
- Consistent error responses
- Proper HTTP status codes
- Cleaner route code
- Centralized error handling
- Better client-side error handling
