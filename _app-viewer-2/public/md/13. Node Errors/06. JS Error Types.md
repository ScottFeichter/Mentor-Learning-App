
## Built-in Error Types Summary

JS has several built-in error subclasses:

- **Error** — generic base error
- **TypeError** — wrong type (e.g. calling a non-function, accessing property of undefined)
- **ReferenceError** — using a variable that doesn't exist
- **SyntaxError** — invalid code syntax
- **RangeError** — value outside allowed range (e.g. `new Array(-1)`)
- **URIError** — bad use of URI functions like `decodeURI()`
- **EvalError** — related to `eval()` (rarely seen in modern JS)

## A Closer Look At Built-in Error Types

These are specific error types that inherit from Error:

**TypeError**: Wrong type used
```javascript
const num = 5;
num.toUpperCase(); // TypeError: num.toUpperCase is not a function
```

**ReferenceError**: Variable doesn't exist
```javascript
console.log(nonExistentVar); // ReferenceError: nonExistentVar is not defined
```

**SyntaxError**: Invalid syntax
```javascript
eval('const x = ;'); // SyntaxError: Unexpected token ';'
```

**RangeError**: Number outside valid range
```javascript
const arr = new Array(-1); // RangeError: Invalid array length
```

**URIError**: Invalid URI handling
```javascript
decodeURIComponent('%'); // URIError: URI malformed
```
