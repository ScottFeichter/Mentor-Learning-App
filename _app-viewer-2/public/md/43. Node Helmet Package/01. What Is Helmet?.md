# Helmet

## What is Helmet?

Helmet is Express middleware that helps secure your app by setting various HTTP security headers. It's not a silver bullet, but it helps protect against common web vulnerabilities.

## What Helmet Does

Helmet sets security-related HTTP headers to protect against:
- Cross-Site Scripting (XSS) attacks
- Clickjacking attacks
- MIME type sniffing
- Information disclosure
- Content Security Policy violations

## Installation

```bash
npm install helmet
```

## Basic Usage

### Enable All Default Protections
```javascript
const express = require('express');
const helmet = require('helmet');

const app = express();

// Apply all default helmet protections
app.use(helmet());

app.get('/', (req, res) => {
  res.send('Secured with Helmet!');
});
```

## What Headers Helmet Sets

### Default Headers Applied
```javascript
app.use(helmet());
// Sets these headers:
// Content-Security-Policy: default-src 'self'
// Cross-Origin-Embedder-Policy: require-corp
// Cross-Origin-Opener-Policy: same-origin
// Cross-Origin-Resource-Policy: same-origin
// Origin-Agent-Cluster: ?1
// Referrer-Policy: no-referrer
// Strict-Transport-Security: max-age=15552000; includeSubDomains
// X-Content-Type-Options: nosniff
// X-DNS-Prefetch-Control: off
// X-Download-Options: noopen
// X-Frame-Options: SAMEORIGIN
// X-Permitted-Cross-Domain-Policies: none
// X-Powered-By: (removed)
// X-XSS-Protection: 0
```

## Individual Middleware

### Content Security Policy (CSP)
```javascript
app.use(helmet.contentSecurityPolicy({
  directives: {
    defaultSrc: ["'self'"],
    styleSrc: ["'self'", "'unsafe-inline'", "https://fonts.googleapis.com"],
    fontSrc: ["'self'", "https://fonts.gstatic.com"],
    scriptSrc: ["'self'", "https://cdn.jsdelivr.net"],
    imgSrc: ["'self'", "data:", "https:"]
  }
}));
```

### Hide X-Powered-By Header
```javascript
app.use(helmet.hidePoweredBy());
// Removes: X-Powered-By: Express
```

### Prevent Clickjacking
```javascript
app.use(helmet.frameguard({ action: 'deny' }));
// Sets: X-Frame-Options: DENY
```

### HTTPS Strict Transport Security
```javascript
app.use(helmet.hsts({
  maxAge: 31536000,  // 1 year
  includeSubDomains: true,
  preload: true
}));
// Sets: Strict-Transport-Security: max-age=31536000; includeSubDomains; preload
```

## Custom Configuration

### Selective Middleware
```javascript
app.use(helmet({
  contentSecurityPolicy: false,  // Disable CSP
  crossOriginEmbedderPolicy: false  // Disable COEP
}));
```

### Custom CSP for React Apps
```javascript
app.use(helmet({
  contentSecurityPolicy: {
    directives: {
      defaultSrc: ["'self'"],
      scriptSrc: ["'self'", "'unsafe-inline'"],  // React needs inline scripts
      styleSrc: ["'self'", "'unsafe-inline'"],   // CSS-in-JS needs inline styles
      imgSrc: ["'self'", "data:", "https:"],
      connectSrc: ["'self'", "https://api.myapp.com"]
    }
  }
}));
```

### Development vs Production
```javascript
if (process.env.NODE_ENV === 'production') {
  app.use(helmet({
    contentSecurityPolicy: {
      directives: {
        defaultSrc: ["'self'"],
        scriptSrc: ["'self'"],
        styleSrc: ["'self'", "https://fonts.googleapis.com"],
        fontSrc: ["'self'", "https://fonts.gstatic.com"]
      }
    }
  }));
} else {
  // More relaxed CSP for development
  app.use(helmet({
    contentSecurityPolicy: false
  }));
}
```

## Common Configurations

### API Server
```javascript
app.use(helmet({
  crossOriginResourcePolicy: { policy: "cross-origin" },  // Allow API calls
  contentSecurityPolicy: false  // APIs don't need CSP
}));
```

### Static File Server
```javascript
app.use(helmet({
  crossOriginResourcePolicy: { policy: "cross-origin" },
  contentSecurityPolicy: {
    directives: {
      defaultSrc: ["'self'"],
      imgSrc: ["'self'", "data:", "https:"],
      mediaSrc: ["'self'", "https:"]
    }
  }
}));
```

### Web App with External Resources
```javascript
app.use(helmet({
  contentSecurityPolicy: {
    directives: {
      defaultSrc: ["'self'"],
      scriptSrc: [
        "'self'",
        "https://cdn.jsdelivr.net",
        "https://unpkg.com"
      ],
      styleSrc: [
        "'self'",
        "'unsafe-inline'",
        "https://fonts.googleapis.com",
        "https://cdn.jsdelivr.net"
      ],
      fontSrc: [
        "'self'",
        "https://fonts.gstatic.com"
      ],
      imgSrc: ["'self'", "data:", "https:"],
      connectSrc: [
        "'self'",
        "https://api.myapp.com"
      ]
    }
  }
}));
```

## Troubleshooting CSP Issues

### Check Browser Console
CSP violations appear in browser console:
```
Content Security Policy: The page's settings blocked the loading of a resource at https://example.com/script.js
```

### Gradual Implementation
```javascript
// Start with report-only mode
app.use(helmet({
  contentSecurityPolicy: {
    directives: {
      defaultSrc: ["'self'"]
    },
    reportOnly: true  // Only report violations, don't block
  }
}));
```

## Best Practices

### Start Simple
```javascript
// Begin with basic helmet
app.use(helmet());

// Then customize as needed
app.use(helmet({
  contentSecurityPolicy: {
    directives: {
      // Add your specific needs
    }
  }
}));
```

### Environment-Specific Settings
```javascript
const helmetConfig = {
  contentSecurityPolicy: process.env.NODE_ENV === 'production' ? {
    directives: {
      defaultSrc: ["'self'"],
      scriptSrc: ["'self'"]
    }
  } : false
};

app.use(helmet(helmetConfig));
```

## Summary

- **Helmet** sets security HTTP headers automatically
- **Protects against** XSS, clickjacking, MIME sniffing, and more
- **CSP** is the most complex but powerful protection
- **Start simple** and customize based on your app's needs
- **Test thoroughly** as some headers can break functionality
- **Use report-only mode** to test CSP before enforcing

Helmet is essential for production Express applications to improve security posture.
