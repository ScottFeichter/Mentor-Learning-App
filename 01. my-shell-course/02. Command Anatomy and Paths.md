# Command Anatomy and Paths

## Anatomy of Unix Commands

- **Utility** — `ls` is a utility. Often runs by itself without flags or arguments.
- **Flag** — `-l` is a flag. Alters how the utility operates. (aka Option or Switch)
- **Argument** — `~/Desktop` is an argument. What the utility acts upon.
- **Command** — `ls -l ~/Desktop` is a command with a utility, flag, and argument.

## What is $THIS?

`$THIS` — Replace with the actual argument you want to give the computer.

Anything in capital letters starting with `$` represents a non-specific argument.

Example: `ls $DIR` means the utility is `ls` and `$DIR` is a directory path argument.

```bash
ls ~/Desktop    # lists contents of Desktop directory
```

## Directory and File Paths

- "Directory" and "folder" mean the same thing
- **Relative Path** — path relative to current working directory
- **Absolute Path** — full path from root (/)

## Working Directory

The directory you are currently in. Check with `pwd`.

## Redirecting a Command

Often called **piping** — the `|` symbol redirects output of one command to input of another.
