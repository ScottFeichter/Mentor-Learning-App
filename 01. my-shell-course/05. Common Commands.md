# Common Commands

## ZSH Efficiency Shortcuts

- **Up Arrow** — see previously typed command (submit same command or edit it)
- **Tab** — auto-complete file/folder names (type first few letters, press Tab)

## Navigation

```bash
pwd                 # print working directory
cd ~                # change to home directory
cd /                # change to root directory
cd ..               # change to parent directory
cd -                # change to previous directory
cd ../..            # move up two levels
cd Documents        # change to child directory (relative)
cd /Users/name/Documents  # change to directory (absolute)
```

## Listing

```bash
ls                  # list contents of current directory
ls -1               # one entry per line
ls -l               # long format (permissions, owner, size, date)
ls -a               # show hidden files
ls -la              # long format + hidden files
ls -lo              # file names with size, owner, and flags
```

## Creating

```bash
mkdir FolderName              # create a folder
mkdir "Folder Name"           # create folder with spaces in name
mkdir -p L1/L2/L3             # create nested folders
mkdir A B C                   # create multiple folders
touch file.txt                # create a new file
touch a.txt b.txt c.txt       # create multiple files
```

## Moving and Renaming

```bash
mv old_name new_name          # rename file or folder
mv file.txt ../               # move file up one level
mv file.txt destination/      # move file to another folder
```

## Copying

```bash
cp file.txt destination/      # copy file
cp -r folder/ destination/    # copy folder recursively
```

## Deleting

```bash
rm file.txt                   # delete a file (permanent!)
rmdir EmptyFolder             # delete empty folder only
rm -r FolderName              # delete folder and all contents (permanent!)
rm -rf FolderName             # force delete without prompts
```

## Viewing Files

```bash
cat file.txt                  # display entire file contents
less file.txt                 # view file with scrolling (q to quit)
less -p "search" file.txt     # open file at search term
```

## Writing to Files

```bash
echo "text" > file.txt        # write text to file (overwrites)
echo "text" >> file.txt       # append text to file
```

## Opening

```bash
open .                        # open current directory in Finder
open ..                       # open parent directory in Finder
open ~                        # open home directory in Finder
open /                        # open root directory in Finder
open file.txt                 # open file in default app
open -a "Safari" file.txt     # open file in specific app
open -R file.txt              # reveal file in Finder
```

## Help

```bash
man command                   # show manual for command (q to quit)
command -h                    # show help for command
```

## Other

```bash
whoami                        # display current username
echo $USER                    # display current username
clear                         # clear terminal screen
exit                          # end terminal session
pkill AppName                 # quit an app from terminal
```

## DANGER — Never Run These!

```bash
sudo rm -rf /                 # deletes EVERYTHING on computer
:(){ :|:& };:                 # fork bomb — crashes computer
```
