# File Types and System Directories

## Stream Files

Data stored as "one continuous stream of bytes" — a start and end, but nothing else defined. A program can use this string of bytes for any purpose.

## Text File Formats

| Format | Description |
|--------|-------------|
| TXT | Plain text, no formatting (except line breaks/spaces) |
| RTF | Rich text, some formatting, text only |
| DOC/DOCX | Lots of formatting, text and images |
| PDF | Portable document, complicated documents, hard to edit |

## USR vs USER

`usr` is NOT the same as `user`

- **usr** — "user usable programs and data"
- The Mac `/usr` folder contains read-only files that apps require to function

## BIN, USR/BIN, and USR/LOCAL/BIN

| Directory | Purpose |
|-----------|---------|
| `/bin` | Executable programs needed in Single User Mode to bring up or repair the system. Accessible by all users. |
| `/usr/bin` | Pre-installed executable programs. Changes with system upgrades. Most apps used by regular users. |
| `/usr/local/bin` | Default location for user-built/installed executables. System updates won't overwrite these. |

## CLI Text and File Editors

```bash
open file.txt       # default external text editor
nano file.txt       # Nano editor
vi file.txt         # Vim/Vi editor
emacs file.txt      # Emacs editor
```
