# General Definitions

## Operating System
Software installed on a computer's hard drive that enables hardware to communicate with software. Without an OS, a computer and software programs would be useless.

## Kernel
The first section of the OS to load into memory. Must be small, efficient, and loaded into a protected area.

- **Monolithic Kernel** — large program performing most OS functions
- **Micro Kernel** — performs only a small subset, extended with drivers

## Shell
A software interface (often CLI) that enables the user to interact with the computer.

## Common Shells

| Shell | Description |
|-------|-------------|
| sh | Bourne shell — standard command interpreter of Unix |
| bash | Bourne-Again Shell — free replacement for sh (GNU project) |
| zsh | Z shell — default on modern macOS |
| ksh | Korn shell — developed at AT&T |
| csh | C shell — syntax inspired by C programming |
| tcsh | Enhanced C shell with command completion |
| PowerShell | Windows shell using .NET cmdlets |

## Terminal
An interface that allows you to access the command line.

## Script
A computer language with commands in a file that can be executed without being compiled. Examples: Perl, PHP, Python (server-side), JavaScript (client-side).

## Batch File
A collection of commands processed in sequence without user input. On Windows: `.bat` files. On Unix/Linux: shell scripts.

## Git
A distributed revision control system designed by Linus Torvalds for Linux kernel development. First released 2005, now the most widely-used version control system.

## Revision Control
Management of changes made over time to source code and project assets. Also called version control or source control. The collection of revisions and metadata is called a **repository** (repo).

## POSIX
Portable Operating System Interface — a family of standards for maintaining compatibility between operating systems.
