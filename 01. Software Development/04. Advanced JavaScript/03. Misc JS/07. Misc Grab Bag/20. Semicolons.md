# Semicolons

Semicolons terminate statements. Not expressions, not blocks — statements.

---

## Expression Statements Get Semicolons

`console.log('hi')` is an Expression Statement. It gets a semicolon.

```js
console.log('hi');
```

ASI will insert it automatically if you leave it off, but the semicolon is the correct explicit terminator.

---

## Blocks Do Not Get Semicolons

`{}` is a block. Blocks are self-terminating — the `}` is the closing delimiter and the parser knows the statement is done. Nothing left to terminate.

```js
if (x) {
  // ...
}   // no semicolon

function foo() {
  // ...
}   // no semicolon
```

---

## The Exception — Function Expressions

A function expression assigned to a variable does get a semicolon — but it is terminating the assignment statement, not the function block.

```js
const foo = function() {
  // ...
};  // semicolon terminates the const foo = ... assignment
```

The `}` closes the function. The `;` closes the statement.
