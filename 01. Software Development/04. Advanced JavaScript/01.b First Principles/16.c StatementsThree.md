# Statements Three

&nbsp;

The full taxonomy of statement types in JS.

---

## All Statement Types

- <span style="color: var(--heading-h3-color); font-weight: bold;">Expression statement</span>
  - any expression used as a statement — value is discarded
    - `console.log()`, `x++`, `fn()`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Declaration statement</span>
  - introduces an identifier into scope
    - `let`, `const`, `var`, `function`, `class`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Control flow statement</span>
  - directs the path of execution
    - `if` / `else`, `switch` / `case` / `break` / `default`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Loop statement</span>
  - repeats a block of code
    - `for`, `for...in`, `for...of`, `while`, `do...while`, `continue`, `break`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Jump statement</span>
  - transfers control to another point in the program
    - `return` — exits a function
    - `throw` — throws an error
    - `break` — exits a loop or switch
    - `continue` — skips to the next iteration
- <span style="color: var(--heading-h3-color); font-weight: bold;">Block statement</span>
  - groups multiple statements together
    - `{ let x = 1; let y = 2; }`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Error handling statement</span>
  - handles errors thrown during execution
    - `try` / `catch` / `finally`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Import / Export statement</span>
  - shares code between modules — module-level only
    - `import`, `export`

---

## The Full Taxonomy

```
Statement
  ├── Expression statement
  ├── Declaration statement
  ├── Control flow statement
  ├── Loop statement
  ├── Jump statement
  ├── Block statement
  ├── Error handling statement
  └── Import / Export statement
```

---

## How This Relates To StatementsTwo

The two-category split from `16.b StatementsTwo.md` still holds at the top level.

```
Statement
  ├── Expression statement
  └── Non-expression statement
        ├── Declaration
        ├── Control flow
        ├── Loop
        ├── Jump
        ├── Block
        ├── Error handling
        └── Import / Export
```

All the types above are subcategories of non-expression statements — except expression statements, which are their own category.
