# Statements Four

&nbsp;

Every **complete instruction** in JS is a statement.

---

## Complete Instructions vs Building Blocks

Not everything in a JS file is a statement on its own.

Some things are **parts of** statements rather than statements themselves.

- `"101.1"` — not a statement, it is an expression that lives inside one
- `const` — not a statement, it is part of a declaration statement
- `+` — not a statement, it is part of an expression inside a statement

---

## The Distinction

- every **complete instruction** in JS is a statement
- statements are built from smaller parts — expressions, keywords, operators, literals, identifiers
- those smaller parts are not statements themselves — they are the building blocks of statements

---

## The Hierarchy

```
Statement                         ← complete instruction
  └── built from expressions, keywords, operators
        └── expressions built from literals, identifiers, function calls
```

---

## Where Literals Fit

A literal is one of the smaller building blocks.

It is an expression — a piece of a statement that produces a value.

It is never a complete instruction on its own.

```js
"101.1"                 // not a complete instruction — just an expression
let x = "101.1"        // complete instruction — "101.1" is a building block inside it
console.log("101.1")   // complete instruction — "101.1" is a building block inside it
```
