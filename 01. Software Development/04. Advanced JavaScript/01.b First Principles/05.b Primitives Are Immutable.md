## Primitives Are Immutable

You cannot change a primitive value.

You can only replace the binding with a new value.

```js
let station = "101.1"
station = "98.7"  // the binding now holds a new string — "101.1" is unchanged
```

`"101.1"` was not modified.
A new string `"98.7"` was created and the binding was updated to point to it.
