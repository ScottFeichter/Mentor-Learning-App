# Primitives

&nbsp;

A **primitive** is a single, immutable piece of data.

---

## The 7 Primitive Types

- <span style="color: var(--heading-h3-color); font-weight: bold;">`string`</span>
  - a sequence of characters
    - `"101.1"`, `'hello'`, `` `world` ``
- <span style="color: var(--heading-h3-color); font-weight: bold;">`number`</span>
  - an integer or floating point number
    - `42`, `3.14`, `-7`
- <span style="color: var(--heading-h3-color); font-weight: bold;">`boolean`</span>
  - a true or false value
    - `true`, `false`
- <span style="color: var(--heading-h3-color); font-weight: bold;">`undefined`</span>
  - a value that has not been assigned
    - `undefined`
- <span style="color: var(--heading-h3-color); font-weight: bold;">`null`</span>
  - an intentional absence of a value
    - `null`
- <span style="color: var(--heading-h3-color); font-weight: bold;">`symbol`</span>
  - a unique, guaranteed-distinct value
    - `Symbol()`, `Symbol("id")`
- <span style="color: var(--heading-h3-color); font-weight: bold;">`bigint`</span>
  - an integer larger than `Number.MAX_SAFE_INTEGER`
    - `9007199254740991n`, `42n`

---





## Primitives Are Stored By Value

Primitives are stored directly in the binding on the call stack.

Copying a primitive gives you an independent copy.

```js
let a = 5
let b = a

b = 10

console.log(a) // 5 — unchanged
console.log(b) // 10
```
