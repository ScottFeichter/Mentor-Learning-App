# Expressions

&nbsp;

An **expression** is any piece of code that produces a value.

It can be as simple as a single literal or as complex as a chain of function calls.

---

## The Key Distinction

An expression **evaluates to a value**.

A statement **performs an action**.

```js
5 + 3           // expression — evaluates to 8
let x = 5 + 3  // statement — declares x and assigns 8 to it
```

---

## Types Of Expressions

- <span style="color: var(--heading-h3-color); font-weight: bold;">Literal expression</span>
  - a value written directly — always evaluates to itself
    - `42`, `"hello"`, `true`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Identifier expression</span>
  - a name that resolves to its bound value
    - `station`, `volume`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Arithmetic expression</span>
  - produces a number
    - `5 + 3`, `volume * 2`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Comparison expression</span>
  - produces a boolean
    - `volume > 5`, `station === "101.1"`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Logical expression</span>
  - produces a value based on boolean logic
    - `isOn && volume > 0`, `station || "unknown"`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Assignment expression</span>
  - assigns a value and produces that value
    - `x = 5` — performs the assignment and evaluates to `5`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Function call expression</span>
  - invokes a function and evaluates to its return value
    - `getStation()`, `Math.max(1, 2)`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Member expression</span>
  - accesses a property or index and evaluates to its value
    - `radio.station`, `stations[0]`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Ternary expression</span>
  - evaluates one of two values based on a condition
    - `isOn ? "playing" : "off"`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Function expression</span>
  - a function definition used as a value
    - `const greet = function() {}`
    - `const greet = () => {}`
- <span style="color: var(--heading-h3-color); font-weight: bold;">`new` expression</span>
  - creates and evaluates to a new object instance
    - `new Date()`, `new Radio("101.1")`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Template literal expression</span>
  - evaluates to a string with embedded values
    - `` `Station: ${station}` ``

---

## Expressions Can Be Nested

The result of one expression can be the operand of another.

```js
(a + b) * (c + d)       // two expressions nested inside a larger one
getStation().toUpperCase() // function call expression chained with member expression
```

---

## Expression Statements

An expression can be used as a statement.

The value it produces is simply discarded.

```js
console.log("hello")  // the return value (undefined) is discarded
counter++             // the expression produces the old value — discarded
```

This is called an **expression statement**.
