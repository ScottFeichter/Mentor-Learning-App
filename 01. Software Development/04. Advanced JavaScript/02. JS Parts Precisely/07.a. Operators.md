# Operators

&nbsp;

An **operator** is a symbol that performs an operation on one or more values.

---

## Assignment

The assignment operator is what binds a value to an identifier.

The keyword declares the identifier into scope.

The `=` operator binds the value to it.


```js
let station = "101.1"
//  ───────   ─────────
//  keyword   = binds "101.1" to station
```

### Basic Assignment

- `=` binds the value on the right to the identifier on the left


```js
let station = "101.1"
station = "98.7"
```

### Compound Assignment

Shorthand that combines an arithmetic or logical operation with assignment.

- `+=` adds and assigns
- `-=` subtracts and assigns
- `*=` multiplies and assigns
- `/=` divides and assigns
- `%=` modulo and assigns
- `**=` exponentiation and assigns


```js
let volume = 5
volume += 2 // volume = volume + 2 → 7
```

### Logical Assignment

- `&&=` assigns only if the left side is truthy
- `||=` assigns only if the left side is falsy
- `??=` assigns only if the left side is `null` or `undefined`


```js
let station = null
station ??= "101.1" // station = "101.1"
```

### Destructuring Assignment

Binds multiple identifiers at once by unpacking an object or array.


```js
const { station, volume } = radio      // object destructuring
const [first, second] = stations       // array destructuring
```

## Arithmetic

Perform mathematical operations on numbers.

- `+` addition
- `-` subtraction
- `*` multiplication
- `/` division
- `%` modulo (remainder)
- `**` exponentiation


```js
10 % 3  // 1
2 ** 8  // 256
```

---

## Comparison

Compare two values and return a boolean.

- `===` strict equality — same value and same type
- `!==` strict inequality
- `==` loose equality — coerces types before comparing
- `!=` loose inequality
- `<` less than
- `>` greater than
- `<=` less than or equal
- `>=` greater than or equal

Prefer `===` over `==` to avoid unexpected type coercion.


```js
5 === 5       // true
5 === "5"     // false — different types
5 == "5"      // true — loose equality coerces "5" to 5
```

---

## Logical

Evaluate boolean logic.

- `&&` and — true if both operands are truthy
- `||` or — true if at least one operand is truthy
- `!` not — inverts a boolean
- `??` nullish coalescing — returns right side if left is `null` or `undefined`


```js
true && false          // false
true || false          // true
!true                  // false
const station = input ?? "101.1" // use input unless it is null or undefined
```

## Bitwise

Bitwise operators treat numbers as 32-bit integers and operate on their individual bits.

They are rarely used in everyday JS but appear in low-level operations like flags, permissions, and performance-sensitive code.

- `&` bitwise and
- `|` bitwise or
- `^` bitwise xor
- `~` bitwise not
- `<<` left shift
- `>>` right shift
- `>>>` unsigned right shift


```js
5 & 3   // 1  — 0101 & 0011 = 0001
5 | 3   // 7  — 0101 | 0011 = 0111
5 ^ 3   // 6  — 0101 ^ 0011 = 0110
~5      // -6
5 << 1  // 10
5 >> 1  // 2
```

## Type

- `typeof` returns a string describing the type of a value
- `instanceof` checks if an object is an instance of a class


```js
typeof "101.1"       // "string"
typeof 42            // "number"
typeof {}            // "object"
typeof function(){}  // "function"

car instanceof Car   // true
```

## Ternary

A shorthand conditional expression.


```js
condition ? valueIfTrue : valueIfFalse
```


```js
const label = volume > 5 ? "loud" : "quiet"
```

---

## Spread / Rest

`...` does two different things depending on context.

- **Spread** — expands an iterable into individual elements


```js
const all = [...stations, "92.3"]
```

- **Rest** — collects remaining elements into an array


```js
function log(first, ...rest) {
  console.log(first) // first element
  console.log(rest)  // array of remaining
}
```

---

## Optional Chaining

`?.` safely accesses a property or method without throwing if the value is `null` or `undefined`.


```js
const station = radio?.tuner?.station // undefined instead of TypeError
```

---

## Nullish Coalescing

`??` returns the right side only if the left side is `null` or `undefined`.

Also covered in Logical operators.


```js
const station = input ?? "101.1"
```

---

## Parentheses

`()` is not a true operator — it is a **punctuator**.

Syntax that changes how things are parsed and evaluated.

It plays several different roles:

- **Grouping** — controls evaluation order


```js
(2 + 3) * 4 // 20 — addition happens first
2 + 3 * 4   // 14 — multiplication happens first without grouping
```

- **Invocation** — calls a function


```js
greet() // invokes the greet function
```

- **Condition** — wraps the expression in `if`, `while`, `for`
  - `()` does not evaluate to boolean itself
  - the expression inside does


```js
if (x > 5) {} // x > 5 evaluates to boolean — () just wraps it
```

---

## Comma

`,` evaluates multiple expressions and returns the last one.

- Mostly seen in `for` loop headers.


```js
for (let i = 0, j = 10; i < j; i++, j--) {}
```

---

## Void & Delete

- `void` evaluates an expression and returns `undefined`
- `delete` removes a property from an object


```js
void 0              // undefined
delete radio.volume // removes the volume property from radio
```
