# globalThis & Scope

&nbsp;

`globalThis` is the top of the scope chain.

Every scope chain ends here.

---

## The Global Scope Lives on globalThis

Identifiers declared at the top level outside any function, block, or module become properties of `globalThis`.

```js
var greeting = 'hello'

console.log(globalThis.greeting) // 'hello'
```

This only applies to `var` and `function` declarations at the top level.

`let` and `const` at the top level do not become properties of `globalThis`.

```js
let station = "101.1"
const volume = 5

console.log(globalThis.station) // undefined
console.log(globalThis.volume)  // undefined
```

---

## Module Scope vs Global Scope

When a file is treated as a module, top-level declarations are **module scoped**.

They live in the file only — not on `globalThis`.

```js
// script.js (not a module)
var x = 1
console.log(globalThis.x) // 1

// module.js (type="module" or .mjs)
var x = 1
console.log(globalThis.x) // undefined
```

---

## globalThis Is the End of the Chain

If an identifier is not found in any inner scope, the engine reaches `globalThis` last.

If it is not there either, a `ReferenceError` is thrown.

```js
console.log(missing) // ReferenceError: missing is not defined
```

---

## Cross-Environment

`globalThis` is the same concept in every JS environment.

| Environment | Global Object |
| :--- | :--- |
| Browser | `window` |
| Node | `global` |
| JS Spec | `globalThis` |
