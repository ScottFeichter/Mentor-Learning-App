# Scope & Identifiers

&nbsp;

Different identifiers follow different scope rules depending on how they are declared.

## Scope Types

### Block Scope

<span class="olive-bold">let</span> and <span class="olive-bold">const</span> are **block scoped**.

They live in the nearest `{}` block they are declared in.

```js
{
  let a = 1
  const b = 2
}

console.log(a) // ReferenceError
console.log(b) // ReferenceError
```

### Function Scope

<span class="olive-bold">var</span> is **function scoped**.

It lives in the nearest function it is declared in, regardless of any inner blocks.

```js
function example() {
  if (true) {
    var x = 'I am var'
    let y = 'I am let'
  }
  console.log(x) // 'I am var'
  console.log(y) // ReferenceError
}
```

### Module Scope

When <span class="js-yellow">JS</span> files are treated as modules, top-level declarations live in that file only.

They are not added to <span class="purple-bold">globalThis</span>.

```js
// module.js
const secret = 'only in this file'

// other.js
console.log(secret) // ReferenceError
```

### Global Scope

An identifier declared at the top level outside any function or block lives in the global scope.

It becomes a property of <span class="purple-bold">globalThis</span>.

```js
var greeting = 'hello'

console.log(globalThis.greeting) // 'hello'
```

## Identifier Scope Reference

&nbsp;

<div class="center">

| Identifier | Scope Type | Lives In |
|---|:---:|---|
| `var` | Function | Nearest enclosing function or global |
| `let` | Block | Nearest enclosing `{}` block |
| `const` | Block | Nearest enclosing `{}` block |
| `function` declaration | Function | Nearest enclosing function or global |
| `class` declaration | Block | Nearest enclosing `{}` block |
| Arrow function | Block | Nearest enclosing `{}` block |
| Top-level `var` | Global | `globalThis` |
| Top-level `let`/`const` | Module | File only — not `globalThis` |

</div>
