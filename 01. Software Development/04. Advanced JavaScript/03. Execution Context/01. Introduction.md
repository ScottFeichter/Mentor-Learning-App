# Introduction

&nbsp;

**Execution Context** is a complicated topic in programming and in JS in particular.

---

## The Concepts

This section builds up the full picture from the ground up.

- <span style="color: var(--heading-h3-color); font-weight: bold;">Semantic Drift</span> — why terminology in JS is often used loosely
- <span style="color: var(--heading-h3-color); font-weight: bold;">Keywords</span> — reserved words the JS engine treats specially
- <span style="color: var(--heading-h3-color); font-weight: bold;">Operators</span> — symbols that perform operations on values
- <span style="color: var(--heading-h3-color); font-weight: bold;">Operands</span> — the values operators act on
- <span style="color: var(--heading-h3-color); font-weight: bold;">Identifiers</span> — names bound to values
- <span style="color: var(--heading-h3-color); font-weight: bold;">Values</span> — what identifiers point to
- <span style="color: var(--heading-h3-color); font-weight: bold;">Binding</span> — the connection between an identifier and a value
- <span style="color: var(--heading-h3-color); font-weight: bold;">Binding Rules</span> — how keywords control that connection
- <span style="color: var(--heading-h3-color); font-weight: bold;">Changing Value</span> — declaring, assigning, initializing, reassigning, mutating
- <span style="color: var(--heading-h3-color); font-weight: bold;">Execution Context</span> — the environment the JS engine creates to run code
- <span style="color: var(--heading-h3-color); font-weight: bold;">Scope</span> — where an identifier is accessible
- <span style="color: var(--heading-h3-color); font-weight: bold;">Scope Chain</span> — how the engine walks outward to resolve identifiers
- <span style="color: var(--heading-h3-color); font-weight: bold;">Scope & Identifiers</span> — how different keywords affect scope
- <span style="color: var(--heading-h3-color); font-weight: bold;">Scope vs Context</span> — the difference between the two
- <span style="color: var(--heading-h3-color); font-weight: bold;">this</span> — the object binding inside an execution context
- <span style="color: var(--heading-h3-color); font-weight: bold;">this & Context</span> — how call site determines `this`
- <span style="color: var(--heading-h3-color); font-weight: bold;">globalThis</span> — the top of the scope chain and execution context
- <span style="color: var(--heading-h3-color); font-weight: bold;">globalThis & Scope</span> — how globalThis relates to scope specifically
