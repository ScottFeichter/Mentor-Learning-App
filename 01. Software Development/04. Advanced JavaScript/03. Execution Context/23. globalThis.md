# globalThis

`globalThis` sits at the top of both the scope chain and execution context.

---

## Top of the Scope Chain

If an identifier isn't found in any inner scope, the engine walks up to the global scope.

The global scope lives on `globalThis`.

---

## Top Execution Context

The global execution context is the first one created when your script runs.

`this` at the top level points to `globalThis`.

---

## Cross-Environment

`globalThis` is the JS spec's unified name for the top-level global object regardless of environment.

| Environment | Global Object |
| :--- | :--- |
| Browser | `window` |
| Node | `global` |
| JS Spec | `globalThis` |

- In a browser → `globalThis === window`
- In Node → `globalThis === global`

---

## Module Quirk

In a Node module (`.mjs` or `type: "module"`), `this` at the top level is `undefined`.

`globalThis` itself still exists and still holds the global scope.

This is a module-specific quirk, not a change to how execution context works overall.
