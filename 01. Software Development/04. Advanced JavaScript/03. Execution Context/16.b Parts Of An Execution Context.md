# Parts Of An Execution Context

&nbsp;



## What's Inside

Every execution context contains three things:

- **Variable Environment** — where identifiers (variables, functions) are stored
- **Scope Chain** — the chain of outer environments the function has access to
- **`this` binding** — what `this` refers to inside that function

---

## How They Relate

- **Execution context** — the full environment the JS engine creates to run a piece of code
- **Scope** — the part of execution context that controls identifier access
- **`this`** — the part of execution context that controls what object the function is bound to

---

## Note

When people say "context" casually in JS, they usually mean `this`.

But technically, execution context is the broader concept that includes both.
