# Context

&nbsp;

The word **context** is a clear example of semantic drift in JS.

---

## Meanings

**Context** has at least two distinct meanings depending on who is using it:

- **Execution Context**
  - the full environment the JS engine creates to run a piece of code
- **`this` context**
  - the object a function is bound to at call time

These are different things that ideally would be distinguished in speech.

But developers often use "**context**" to mean either one — or both — without distinguishing.

---

## Ideal Usage

Ideally everyone would use the following language precisely:

- **Execution Context**
  - the full environment the JS engine creates to run a piece of code

- **Bound Object Of this (BOOt)**
  - only used when referring to `this`
  - not as a synonym for execution context or scope

---

## Additional Confusion

Related terms that compound the confusion:

### Scope

- **Scope**
  — where an identifier is accessible
  - determined at write time
  - often conflated with context
  - they are set up differently and serve different purposes

### globalThis

**`globalThis`** — the most outer global object
- sits at the top of both the scope chain and execution context
- easily confused with the keyword **this**
- easily confused with global

### this

**`this`** — a keyword
- not a variable
- automatically set by the engine
- the object a function is bound to
- determined at call time

In regular English, **this** is a demonstrative — it points to something nearby or just mentioned.

- As an adjective it modifies a noun: "this car".
- As a pronoun it stands alone: "this is mine".

JS borrowed the word for the same reason — it points to the object in the current context.

#### this Absurdity

The problem is that talking about `this` in conversation becomes immediately absurd.

> "What does this refer to?"
> "This refers to the object the function is called on."
> "Which object is this called on?"
> "This is called on the radio object."
> "So this is radio?"
> "Yes, this is radio."

Every sentence becomes ambiguous — is "this" the JS keyword or the English pronoun?

### What To Do?

Is only escape is to say "`this`" (with air quotes or backticks) when referring to the keyword?

As with any situation of confusion and **Semantic Drift** let's start from first principles.
