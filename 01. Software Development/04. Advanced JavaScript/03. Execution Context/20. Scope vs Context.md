# Scope vs Context

These are two different concepts.

**Scope** — where can I access this identifier?

**Context** — what object does `this` refer to inside this function?

Neither is about objects or return values specifically.

---

## Scope

Scope controls where an identifier is accessible.

It is determined by where you write the declaration.

- inside a block
- inside a function
- inside a module
- at the top level

---

## Context (`this`)

When people say "context" in JS, they almost always mean `this`.

`this` refers to the object a function is bound to when it is called.

It has nothing to do with return values.

---

## Example

```js
const radio = {
  station: "101.1",
  getStation() {
    console.log(this.station); // context — which object is getStation called on?
  }
};

function greet() {
  const message = "hello"; // scope — where can message be accessed?
  return message;
}
```
