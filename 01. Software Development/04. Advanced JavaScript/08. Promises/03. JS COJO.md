# JS COJO

A COJO is a JS object that was made from a class.

**To review our previous example:**

## Creating The Class
```javascript
class BankAccount {
  constructor(accountHolder, initialBalance) {
    this.accountHolder = accountHolder;
    this.balance = initialBalance;
    this.bankName = "Monopoly Bank";
  }
}
```

## Instantiating The Object
```javascript
let account1 = new BankAccount("John", 1000);
```

## Logging The Object
```javascript
console.log(account1);
```

## Console Output
```javascript
BankAccount {
  accountHolder: 'John',
  balance: 1000,
  bankName: 'Monopoly Bank'
}
```
