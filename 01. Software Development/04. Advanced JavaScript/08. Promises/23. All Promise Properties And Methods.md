# Promise Properties and Methods

## Promise Instance Properties

**Internal Properties (not directly accessible):**
- `[[PromiseState]]` - "pending", "fulfilled", or "rejected"
- `[[PromiseResult]]` - the resolved value or rejection reason
- `[[PromiseFulfillReactions]]` - array of fulfillment handlers
- `[[PromiseRejectReactions]]` - array of rejection handlers

## Promise Instance Methods

**Core Methods:**
- `then(onFulfilled, onRejected)` - handles resolved/rejected states
- `catch(onRejected)` - handles rejected state only
- `finally(onFinally)` - executes regardless of outcome

```javascript
promise
  .then(value => console.log(value))
  .catch(error => console.error(error))
  .finally(() => console.log('Done'));
```

## Promise Static Methods

**Creation Methods:**
- `Promise.resolve(value)` - creates fulfilled promise
- `Promise.reject(reason)` - creates rejected promise

**Combination Methods:**
- `Promise.all(iterable)` - waits for all to resolve
- `Promise.allSettled(iterable)` - waits for all to settle
- `Promise.race(iterable)` - resolves with first settled
- `Promise.any(iterable)` - resolves with first fulfilled

```javascript
Promise.all([promise1, promise2, promise3])
  .then(results => console.log(results));
```

## Constructor

- `new Promise(executor)` - creates new promise with executor function

## Key Notes

- Instance properties are internal and not directly accessible
- Use methods like `then()` to access the promise's value/state
- Static methods work on the Promise class itself, not instances
- All methods return new promises (except `finally` in some cases)
