# Insertion Sort Out Of Place

Time: O(n²)
Space: O(1)

Does not modify the original array.

```javascript
function insertionSortOutOfPlace(arr) {
  let arrCopy = [...arr];
  let sorted = [];
  while (arrCopy.length > 0) {
    let val = arrCopy.pop();
    sorted.push(null);
    let i = sorted.length - 1;
    while (i > 0) {
      if (sorted[i - 1] < val) {
        break;
      } else {
        sorted[i] = sorted[i - 1];
        i--;
      }
    }
    sorted[i] = val;
  }
  return sorted;
}
```
