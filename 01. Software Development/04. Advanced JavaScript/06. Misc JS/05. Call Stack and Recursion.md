# Call Stack and Recursion

## Call Stack

- **Call Stack** — a LIFO stack of frames
- **Stack Frames** — individual function calls on the stack
- **Pushing** — adding a frame to the top
- **Popping** — removing a frame from the top
- **Single Thread** — JS has one call stack (single-threaded)

## Stack Trace

The error output showing the sequence of function calls that led to an error.

## Stack Overflow

When the stack reaches its size limit:
- The program halts
- The stack gets wiped
- Results are never achieved
- Error: `RangeError: Maximum Call Stack Size Exceeded`

## Recursion

- **Iteration** — the process of counting through each item in a collection
- **Recursion** — the process of calling a function within itself

### Key Concepts

- **Base case** — data passed into function without any additional recursion (terminating case)
- **Recursive case** — data passed into function in a state that causes it to call itself
- **Recursive step** — the logic that gets closer to the base case

### Types

- **Direct recursion** — function directly calling itself
- **Indirect recursion** — recursive loops across multiple functions calling each other

### Default Parameters

Default parameters can make solving problems using recursion easier.
