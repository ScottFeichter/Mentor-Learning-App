# Keywords

&nbsp;

A **keyword** is a reserved word the JS engine recognizes and treats specially.

---

## What They Are

**Keywords** are a kind of Lexical and a sibling to Punctuators.

### Deterministic Usage

**Keywords** have pre defined and fixed meanings.

Only usable for what the language designates them to do.

### Cannot Be Identifiers

```js
let const; // SyntaxError — const is a keyword
```
Trying to name a variable a reserved word throws an error.

---


## JS Keywords

Grouped in categories by what they do:

### Identifier Declaration

Keywords that introduce an identifier into scope.

- `var` — declares a function-scoped or globally-scoped identifier
- `let` — declares a block-scoped identifier
- `const` — declares a block-scoped identifier with a fixed binding
- `function` — declares a function and binds it to an identifier
- `class` — declares a class and binds it to an identifier
- `import` — declares a read-only binding to a value from another module
- `export` — exposes an identifier from the current module for use in others

---

### Object & Instance Creation

Keywords involved in creating objects and instances.

- `new` — creates an instance of a class or constructor function
- `this` — refers to the current execution context's object binding
- `super` — refers to the parent class

---

### Control Flow

Keywords that direct the path of execution.

- `if` — executes a block if a condition is true
- `else` — executes a block if the preceding `if` condition is false
- `switch` — evaluates an expression and matches it to a `case`
- `case` — defines a branch inside a `switch`
- `break` — exits a `switch` case or loop
- `default` — fallback branch in a `switch` if no `case` matches

---

### Loops

Keywords used to repeat execution.

- `for` — repeats a block a set number of times
- `while` — repeats a block while a condition is true
- `do` — executes a block once then repeats while a condition is true
- `continue` — skips the current iteration and moves to the next
- `in` — iterates over the keys of an object (used in `for...in`)
- `of` — iterates over the values of an iterable (used in `for...of`)

---

### Functions & Return

Keywords related to function execution and output.

- `return` — exits a function and optionally passes back a value
- `yield` — pauses a generator function and returns a value
- `async` — marks a function as asynchronous, returns a Promise
- `await` — pauses execution inside an `async` function until a Promise resolves

---

### Error Handling

Keywords used to handle errors.

- `try` — wraps code that may throw an error
- `catch` — handles the error if one is thrown in the `try` block
- `finally` — runs after `try`/`catch` regardless of outcome
- `throw` — manually throws an error

---

### Type Checking

Keywords used to inspect values and types.

- `typeof` — returns a string describing the type of a value
- `instanceof` — checks if an object is an instance of a class
- `in` — checks if a property exists on an object

---

### Modules

Keywords used to share code between files.

- `import` — brings in an identifier from another module (ESM) — also in Identifier Declaration
- `export` — exposes an identifier to other modules (ESM) — also in Identifier Declaration

---

### Misc

Singleton keywords used for various tasks.

- `delete` — removes a property from an object
- `null` — represents the intentional absence of a value
- `void` — evaluates an expression and returns `undefined`
- `debugger` — pauses execution in the browser devtools debugger
- `with` — extends the scope chain with an object (deprecated)

---


### Operable Keywords

Special keywords that evaluate to a value and can be passed as an argument.

- `this` — fully operable can be used freely as a standalone value anywhere
- `super` — partially operable cannot be used as a standalone value outside class

---

### Often Mistaken As Keywords

These global properties are all fully operable and can be used anywhere an operand is expected.

- `undefined` — the default value of an uninitialized identifier
- `NaN` — stands for Not a Number but ironically of type `number`
- `Infinity` — represents mathematical infinity
- `-Infinity` — represents negative mathematical infinity

They are NOT reserved words and CAN be used as Identifiers:

```js
let undefined = 5;  // valid in non-strict mode, terrible idea
let NaN = 'hello';  // valid in non-strict mode, terrible idea
```
