# Statements

&nbsp;

**Statements** are syntax that tells the engine to *do* something.

---

## Unit Of Instruction

 A **statement** is a complete unit of instruction that performs an action.

### Terminating With `}`

If ending with a block the closing `}` serves as the terminator.

```js
if (x > y) { console.log("x > y"); }
```

### Terminating With `;`

Otherwise **statements** end with a semicolon `;`.

```js
let station = "101.1";
```

---

## Forming Statements

Not everything in a JS file is a **statement** on its own.

### The Distinction

**Statements** are often built from smaller parts that are not **statements** themselves.

In some cases those smaller parts can exist on their own as **statements** too.

### Parts Of Statements

| Part | Statement? | Syntax |
|--------|----------------|---------|
| `let` | never on its own | declaration keyword |
| `station` | not during initialization | variable identifier |
| `=` | never on its own | assignment operator |
| `"101.1"` | not during initialization | string literal |
| `;` | not during initialization | terminating punctuator |
