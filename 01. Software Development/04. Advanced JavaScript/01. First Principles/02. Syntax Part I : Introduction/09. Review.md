# Review

&nbsp;

A summary of the key concepts covered in this topic.

---

## Syntax

**Syntax** is the set of rules that define how code is written.

- syntax is about what you write
- the parser checks syntax before the engine runs anything

---

## Syntactic Parts Of JS

JS code is made up of two main syntactic parts:

- **Statements** — instructions that direct the engine to do something
- **Incidentals** — syntax the engine ignores

---

## Syntax Tree

The **Syntax Tree** is a hierarchical map of how the parts of JS syntax relate to each other.

---

## Statements

A **Statement** is a syntactic unit that directs execution.

- It must tell the engine to do something.
- Made of Lexicals and/or Expressions. 

---

## Lexicals

**Lexicals** are the fixed vocabulary of the language.

- Defined by the language spec.
- Cannot be invented by the programmer.

---

## Punctuators

**Punctuators** are lexicals that provide structure and shape to code.

---

## Keywords

**Keywords** are reserved words the engine recognizes and treats specially.
