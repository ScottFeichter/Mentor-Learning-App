# The Secret Life Of JS Arrays

Arrays in JS are not a separate data structure. They are objects.

```js
typeof [];  // "object"
```

---

## Indexes Are Keys

When you write `arr[0]`, you are not accessing a position in a sequence. You are accessing a property on an object where the key is the string `"0"`.

```js
const arr = ["a", "b", "c"];

arr[0];    // "a"
arr["0"];  // "a" — same thing
```

JS converts the numeric index to a string key behind the scenes. `0` and `"0"` resolve to the same property.

---

## You Can Use Dot Notation

Because arrays are objects, dot notation works on them — for any property that is a valid identifier.

```js
const arr = ["a", "b", "c"];

arr.length;   // 3
```

You cannot use dot notation for numeric keys because numbers are not valid identifiers.

```js
arr.0;   // SyntaxError
arr[0];  // works — bracket notation handles non-identifier keys
```

---

## Arrays Have a Prototype Chain

Arrays inherit from `Array.prototype`, which itself inherits from `Object.prototype`. That means all object methods are available on arrays.

```js
const arr = ["a", "b", "c"];

Object.keys(arr);    // ["0", "1", "2"]
Object.values(arr);  // ["a", "b", "c"]
Object.entries(arr); // [["0", "a"], ["1", "b"], ["2", "c"]]
```

`Object.keys()` reveals what indexes really are — string keys on an object.

---

## Arrays Are Objects With Extra Behavior

What makes an array special is not its structure — it's two things the engine adds on top of the object:

- A `length` property that auto-updates as you add or remove items
- A set of array-specific methods on `Array.prototype` like `push`, `map`, `filter`

Strip those away and you have a plain object.

---

## You Can Even Add Arbitrary Properties

Because arrays are objects, you can add non-numeric properties directly to them.

```js
const arr = ["a", "b", "c"];
arr.label = "my array";

arr.label;   // "my array"
arr.length;  // 3 — length is unaffected, label is not an index
```

This is valid but rarely useful. It illustrates that the array is just an object with numeric-looking keys and some special behavior bolted on.
