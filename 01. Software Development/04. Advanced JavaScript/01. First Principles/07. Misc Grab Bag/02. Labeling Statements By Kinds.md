## Kinds Of Statements

- <span style="color: var(--heading-h3-color); font-weight: bold;">Declaration statement</span>
  - introduces an identifier into scope
    - `let station = "101.1"`
    - `const volume = 5`
    - `function greet() {}`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Assignment statement</span>
  - binds a value to an existing identifier
    - `station = "98.7"`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Expression statement</span>
  - an expression used as a statement — the value it produces is discarded
    - `console.log("hello")`
    - `counter++`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Control flow statement</span>
  - directs the path of execution
    - `if`, `else`, `switch`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Loop statement</span>
  - repeats a block of code
    - `for`, `while`, `do...while`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Return statement</span>
  - exits a function and optionally passes back a value
    - `return station`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Throw statement</span>
  - manually throws an error
    - `throw new Error("not found")`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Block statement</span>
  - groups multiple statements together
    - `{ let x = 1; let y = 2; }`
