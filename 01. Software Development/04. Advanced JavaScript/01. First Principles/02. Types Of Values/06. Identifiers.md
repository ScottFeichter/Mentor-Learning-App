# Identifiers

&nbsp;

In programming an **identifier** refers to the **name** you give something.

---

## Identifiers Are Labels For...

In JS an **identifier** can be bound to:

<div class="indent">

<span style="color: var(--heading-h3-color); font-weight: bold;">Primitive</span>
  - `string`
  - `number`
  - `boolean`
  - `null`
  - `undefined`
  - `symbol`
  - `bigint`

<span style="color: var(--heading-h3-color); font-weight: bold;">Function</span>
  - Function declaration
  - Function expression

<span style="color: var(--heading-h3-color); font-weight: bold;">Object</span>
  - Array `[]` (An object under the hood)
  - POJO `{}` (Plain Old JS Object)
  - CIJO `new` (Class Instantiated JS Object)
    - `Promise`
    - `Date`
    - `Map`, `Set`, `WeakMap`, `WeakRef`
    - `RegExp`
    - `Error`
    - Primitive wrappers
        - `new String()`
        - `new Number()`
        - `new Boolean()`

<span style="color: var(--heading-h3-color); font-weight: bold;">Class definition</span>
  - Declaration — `class Car {}`
  - Expression — `const Car = class {}`

<span style="color: var(--heading-h3-color); font-weight: bold;">Module</span>
  - `import` — ESM
  - `require()` — CJS

</div>
