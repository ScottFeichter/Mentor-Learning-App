# Identifiers and Memory

&nbsp;

An **identifier** has its own place in memory.

---

## On The Call Stack

It lives on the **call stack**, inside the current execution context.

That memory location holds either the value directly, or an address pointing to where the value lives.

```
Stack (execution context)
─────────────────────────
volume → 5
radio  → [address: 0x001]
```

- `volume` lives on the stack and holds its value directly
- `radio` lives on the stack and holds an address



---

## Primitives vs References

This is where primitives and objects differ.

### Primitives

**Primitives** are stored directly in the binding.

The identifier holds the actual value.

```js
let volume = 5
```

- `volume` holds `5` directly
- copying it gives you a copy of the value

### References

**Objects, arrays, and functions** are stored in memory.

The identifier holds a reference to the memory address.

```js
const radio = { station: "101.1" }
const copy = radio
```

- `copy` holds the same reference as `radio`
- both point to the same object in memory
- mutating through either identifier changes the same object

---

## What Scope Controls

Scope does not control the value.

Scope controls where the **name** can be looked up.

If the name is not visible in the current scope, the engine cannot reach the value — even if the value exists in memory.

---

## Identifier vs Variable

The word **variable** only describes one kind of binding — one that can be reassigned.

**Identifier** is the broader term.

It covers:

- variables — `var`, `let`
- constants — `const`
- function names — `function greet() {}`
- class names — `class Car {}`
- any name bound to any value

---

## Not All Bindings Are Identifiers

Object properties and array indices are bindings — but they are not identifiers.

They do not live in scope.

They live on the object or array itself.

```js
const radio = { station: "101.1" } // station is a property key — not an identifier
const stations = ["101.1", "98.7"] // 0 and 1 are indices — not identifiers
```

Scope cannot see `station` or `0` directly.

They are only reachable through the identifier that holds the object or array.
