# Identifiers Have No Type

Identifiers are not a type — they're **syntax**.

An identifier is a name written in source code.
It refers to something, but it is not the thing itself.

```js
let score = 42
```

- `42` — literal (syntax), produces a primitive (`number`) at runtime
- `score` — identifier (syntax), refers to a memory location that holds `42`
- the value stored — a primitive (`number`)

---

**The distinction:**

An identifier is part of the **Syntax** axis — it's what you write.
A type (`number`, `string`, `object`, etc.) is part of the **Values & Types** axis — it describes what is stored.

Identifiers don't have types.
The **values they point to** have types.

---

**Analogy:**

A street address is not a house.
The address is syntax — a label that locates something.
The house is the value — the thing that actually exists.

`score` is the address.
`42` is the house.
