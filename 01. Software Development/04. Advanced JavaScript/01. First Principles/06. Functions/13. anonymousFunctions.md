# Anonymous Functions

## What is an Anonymous Function?

An **anonymous function** is a function with no name after the `function` keyword.

```javascript
// Named function
function sayHello() {
  console.log("Hello!");
}

// Anonymous function (this would be syntax error if by itself)
function() {
  console.log("Hello!");
}
```

## Can Anonymous Functions Exist by Themselves?

No, anonymous functions cannot exist by themselves - they need to be used somewhere:

```javascript
// This would be a syntax error:
function() {
  console.log("Hello!");
}

// Anonymous functions must be:
let myFunc = function() { ... };  // Assigned to variable
processCallback(function() { ... }); // Passed as an argument
(function() { ... })(); // Immediately invoked
```

## Anonymous Function as Callback

Anonymous functions are commonly used as callbacks:

```javascript
function processCallback(callback) {
  console.log("About to call callback");
  callback();
  console.log("Callback finished");
}

// Anonymous function passed as callback - NOT immediately invoked
processCallback(function() {
  console.log("I'm an anonymous callback!");
});

// Output:
// "About to call callback"
// "I'm an anonymous callback!"
// "Callback finished"
```

## In Promise Context

```javascript
new Promise(function(resolve, reject) { // Anonymous function
  // This is NOT immediately invoked
  // Promise constructor will call this when ready
  resolve("success");
});
```

The anonymous executor function is passed as a callback reference to the Promise constructor, which decides when to call it.
