# Incidentals

&nbsp;

**Incidentals** are JS syntax items not parsed or picked up by the engine.

---

## Still Syntax But Incidental

These are real parts of JS syntax but not part of how code is reasoned about.

### Comments

Comments are annotation text in source code.

#### Example

They are stripped out by the parser before execution.

```js
// single line comment
/* multi line comment */
```

Comments are syntactically present in the file but not present at runtime.



### Whitespace

Whitespace includes spaces, tabs, and newlines.

#### Example

JS ignores whitespace except as a separator between tokens.

```js
let x=5      // valid
let x = 5   // valid — whitespace is ignored
```

Whitespace is syntactically present but carries no meaning beyond separation.
