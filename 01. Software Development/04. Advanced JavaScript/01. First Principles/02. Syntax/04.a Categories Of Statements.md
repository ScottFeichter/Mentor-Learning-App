# Statements Two

&nbsp;

In JS there are really only two kinds of statements.

---

## Expression Statement

A statement that consists of an expression.

The expression produces a value.
The statement discards it.

```js
x + 1               // expression statement — produces a value, discards it
console.log(x)      // expression statement — the call is the expression
```

---

## Non-Expression Statement

A statement that performs control flow, declaration, or structure.

It cannot produce a value.
It cannot be used where a value is expected.

```js
let x = 5           // non-expression statement — declaration
if (x > 0) {}       // non-expression statement — control flow
for (let i = 0; i < 3; i++) {} // non-expression statement — loop
```

---

## The Hierarchy

```
Statement
  ├── Expression statement      (contains an expression, produces a value)
  └── Non-expression statement  (declaration, control flow, block, etc.)
```
