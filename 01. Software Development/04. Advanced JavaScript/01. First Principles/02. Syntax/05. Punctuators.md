# Puntuators

&nbsp;

**Punctuators** are structural characters that shape the form of code.

---

## JS Puntuators

Here are all the **Punctuators** in the JS language:

### Curly Braces `{}`

#### Defines conditional bodies:
```js
if (true) { console.log('yes'); }
```

#### Defines loop bodies:
```js
for (let i = 3; i > 0; i++) { console.log('hello from the loop body'); }
```

#### Defines object literals:
```js
const user = { name: 'Alice', age: 30 };
```

#### Defines function bodies:
```js
function greet() { return 'hello'; }
```

&nbsp;

### Parentheses `()`

#### Groups expressions to control evaluation order:
```js
const result = (2 + 3) * 4;
```

#### Wraps parameters in a function declaration:
```js
function greet(name) { return name; }
```

#### Wraps arguments in a function call:
```js
console.log('hello');
```

#### Wraps a condition and coerces truthy/falsy:
```js
if (score > 10) { console.log('high'); }
```

#### Wraps the control expression in a loop:
```js
for (let i = 0; i < 3; i++) { console.log(i); }
```

&nbsp;

### Brackets `[]`

#### Defines array literals:
```js
const colors = ['red', 'green', 'blue'];
```

#### Accesses array items by index:
```js
const first = colors[0];
```

#### Accesses object properties by key:
```js
const val = obj['name'];
```

&nbsp;

### Semicolon `;`

#### Marks the end of a statement:
```js
const x = 5;
```

&nbsp;

### Comma `,`

#### Separates items in an array:
```js
const nums = [1, 2, 3];
```

#### Separates parameters and arguments:
```js
function add(a, b) { return a + b; }
add(1, 2);
```

#### Separates properties in an object:
```js
const point = { x: 0, y: 0 };
```

&nbsp;

### Dot `.`

#### Accesses a property on an object:
```js
const name = user.name;
```

#### Calls a method on an object:
```js
console.log('hello');
```

---

&nbsp;
&nbsp;

**Punctuators** are not operators since they do not act on operands.
