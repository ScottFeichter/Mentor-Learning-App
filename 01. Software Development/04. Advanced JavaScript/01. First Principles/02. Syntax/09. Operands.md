# Operands

&nbsp;

An **operand** is a anything an operator acts on.

---

## What Operands Can Be

An **operand** can be:

- <span style="color: var(--heading-h3-color); font-weight: bold;">Literals</span>
  - a value written directly
    - `1 + 2`, `"hello"`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Identifiers</span>
  - a name bound to a value
    - `a + b`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Expressions</span>
  - the result of one operation used as the operand of another
    - `(a + b) * c`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Function Calls</span>
  - the return value becomes the operand
    - `getCount() + 1`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Property Access</span>
  - the accessed value becomes the operand
    - `radio.volume + 1`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Array Access</span>
  - the value at the index becomes the operand
    - `stations[0]`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Template Literals</span>
  - the whole expression is an operand
    - `` `hello ${name}` ``
- <span style="color: var(--heading-h3-color); font-weight: bold;">Expression Using `new`</span>
  - the resulting instance becomes the operand
    - `new Date()`
- <span style="color: var(--heading-h3-color); font-weight: bold;">Expressions Using `this`</span>
  - `this` itself is an operand in the member expression
    - `this.station`

---

## Two Broad Categories

The broad categories are really just two:

- <span style="color: var(--heading-h3-color); font-weight: bold;">A name that resolves to a value</span>
  - identifiers, `this`, property access, array access
- <span style="color: var(--heading-h3-color); font-weight: bold;">Something that produces a value</span>
  - literals, function calls, expressions, `new`

Anything that resolves to or produces a value can be an operand.

### Example

```js
5 + 3           // literals
volume + 2      // identifier + literal
(a + b) * (c + d) // expressions
```
