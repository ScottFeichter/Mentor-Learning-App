# Statements

&nbsp;

A **statement** is an instruction that performs an action.

```js
let station = "101.1";
```

**Statements** are syntax that tell the engine to *do* something.

---

## Forming Complete Instructions

Not everything in a JS file is a **statement** on its own.

### Parts Of Statements

Some things are parts of **statements** rather than **statements** themselves:

| Part | Statement? | What Is It |
|--------|----------------|---------|
| `let` | never on its own | it is a declaration keyword |
| `station` | not during initialization | it is an identifier |
| `=` | never on its own | it is part of an expression called an operator |
| `"101.1"` | not during initialization | it is a kind of value called a literal |
| `;` | not during initialization | it is a kind of lexical called a punctuator |

### The Distinction

**Statements** are built from smaller parts that are not **statements** themselves.

In some cases those smaller parts can exist on their own as **statements** too.

---

## Complete Unit Of Execution

A **statement** is a complete unit of execution.

### Statements End With Semicolons

The semicolon marks the end of the **statement**.

JS has *Automatic Semicolon Insertion (ASI)*.

### Semicolons Are Not Mandatory

Semicolons are optional in practice because of ASI.

But they are a visual boundary that improve readibility.
