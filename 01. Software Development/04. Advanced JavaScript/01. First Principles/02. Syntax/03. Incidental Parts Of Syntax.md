# Incidental Parts Of Syntax

&nbsp;

Beyond the core syntactic parts, JS source code contains several incidental elements.

They are syntactically present but not the focus of how code is reasoned about.

---

## Comments

**Comments** are text in source code ignored by the engine.

They are stripped out by the parser before execution.

```js
// single line comment
/* multi line comment */
```

Syntactically present in the file — not present at runtime.

---

## Whitespace

**Whitespace** includes spaces, tabs, and newlines.

JS ignores whitespace except as a separator between tokens.

```js
let x=5      // valid
let x = 5   // valid — whitespace is ignored
```

Whitespace is syntactically present but carries no meaning beyond separation.

---

## Why These Are Incidental

These elements are real parts of JS syntax.

But they are not the parts you reason about when thinking through how code works.

They are the structural glue — present everywhere, noticed rarely.
