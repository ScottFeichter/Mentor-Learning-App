# Categorizing Operators By Operands

&nbsp;

Sometimes it is helpful to categorize **operators** by how many **operands** they act upon.

---

## Unary Operators

### One Operand

Some **unary operators** are on left and some on right of operand.

```js
5++     // 5 is the operand ++ is the operator
!true   // ! is the operator true is the operand
```

---

## Binary Operators

### Two Operands

One operand on each side of the **operator**.

```js
5 + 3   // 5 and 3 are the operands
x === y // x and y are the operands
```

---

### Ternary Operators

There is only one **ternary operator** in JS and it takes three operands.

```js
condition ? valueIfTrue : valueIfFalse
```

- `condition` — first operand
- `valueIfTrue` — second operand
- `valueIfFalse` — third operand
