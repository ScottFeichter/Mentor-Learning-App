# Primitives vs References

&nbsp;

In JS, how a value is **stored and copied** depends on its type.

Primitives and objects behave differently.

---

## Primitives Are Copied By Value

When you assign a primitive to another identifier, the value is copied.

```js
let a = 5
let b = a

b = 10

console.log(a) // 5
console.log(b) // 10
```

- `b` gets a copy of `5`
- changing `b` does not affect `a`
- they are independent

Each identifier holds its own copy of the value directly on the stack.

---

## Objects Are Copied By Reference

When you assign an object to another identifier, the reference is copied — not the object.

```js
const radio = { station: "101.1" }
const copy = radio

copy.station = "98.7"

console.log(radio.station) // "98.7"
console.log(copy.station)  // "98.7"
```

- `copy` holds the same reference as `radio`
- both point to the same object in memory
- mutating through either identifier changes the same object

---

## Why This Happens

Primitives are small and fixed in size.

The engine stores them directly in the binding on the call stack.

Objects can be large and variable in size.

The engine stores them on the **heap** and puts the memory address in the binding.

```
Stack                    Heap
─────────────────────    ──────────────────────
a      → 5               
radio  → [0x001]    →    { station: "101.1" }
copy   → [0x001]    →    (same object)
```

---

## Equality Comparison

This also affects how equality works.

### Primitives compare by value

```js
const a = "hello"
const b = "hello"

console.log(a === b) // true — same value
```

### Objects compare by reference

```js
const x = { name: "Ada" }
const y = { name: "Ada" }

console.log(x === y) // false — different objects in memory
```

- `x` and `y` hold different addresses
- the contents look the same but they are not the same object

```js
const z = x

console.log(x === z) // true — same reference
```

---

## Functions Follow The Same Rule

Functions are objects under the hood.

They are also passed by reference.

```js
function greet() {}

const fn = greet

console.log(fn === greet) // true — same reference
```

---

## Key Idea

**Primitive** — the identifier holds the value directly.
Copying it gives you an independent copy.

**Object / Array / Function** — the identifier holds a reference to the value.
Copying it gives you another reference to the same thing.
