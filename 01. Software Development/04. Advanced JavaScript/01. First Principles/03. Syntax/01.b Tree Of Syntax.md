# Tree Of Syntax

```
Syntax
├── Incidentals
│   ├── comments:   // /* */
│   └── whitespace: spaces, tabs, newlines
└── Statements
    ├── Punctuators
    │   ├── Grouping:    ( )
    │   ├── Block:       { }
    │   ├── Array:       [ ]
    │   ├── Terminator:  ;
    │   ├── Accessor:    .
    │   ├── Separator:   ,
    │   ├── Arrow:       =>
    │   └── Colon:       :
    └── Expressions
        ├── Structural Keywords
        │   ├── Declaration:     var let const function class
        │   ├── Conditionals:    if else switch case
        │   ├── Loops:           for while do
        │   ├── Jump:            return break continue
        │   ├── Error Handling:  try catch finally throw
        │   ├── Type:            typeof instanceof void delete
        │   ├── Module:          import export default
        │   └── Async:           async await yield
        ├── Operators
        │   ├── Assignment:        = += -= *= /=
        │   ├── Arithmetic:        + - * / %
        │   ├── Comparison:        == === != !== > < >= <=
        │   ├── Logical:           && || ! ??
        │   ├── Unary:             typeof void delete !
        │   ├── Conditional:       ? :
        │   ├── Spread/Rest:       ...
        │   ├── Optional Chaining: ?.
        │   └── Bitwise:           & | ^ ~ << >>
        └── Operands
            ├── Identifiers
            │   ├── Variable Names:  score, userName
            │   ├── Function Names:  getName, handleClick
            │   ├── Parameter Names: function greet(name)
            │   ├── Class Names:     class Animal
            │   ├── Property Names:  user.name
            │   └── Label Names:     outerLoop:
            └── Values
                ├── Literal Values
                │   ├── Number:   42
                │   ├── String:   "hello"
                │   ├── Boolean:  true false
                │   ├── Null:     null
                │   ├── Regex:    /pattern/flags
                │   ├── Array:    [ contents ]
                │   ├── Object:   { contents }
                │   └── Template: `hello ${name}`
                └── Evaluated Values
                    ├── Calculations
                    │   ├── Logical:     a || b
                    │   ├── Conditional: a ? b : c
                    │   └── Arithmetic:  2 + 2
                    ├── Function Calls
                    │   ├── Regular:     getName()
                    │   ├── Conversion:  Number("42")
                    │   └── Constructor: new Date()
                    ├── Retrievals
                    │   ├── Property Access: user.name
                    │   └── Index Access:    arr[0]
                    └── Operable Keywords
                        ├── this:      resolves to an object at runtime
                        ├── super:     resolves to the parent class
                        ├── undefined: global property, absence of assignment
                        ├── NaN:       global property, failed numeric conversion
                        ├── Infinity:  global property, number beyond max value
                        └── -Infinity: global property, number below min value
```

---

**Notes**

- `this` and `super` appear under both Structural Keywords and Operable Keywords — they are keywords that act as operands
- Incidentals are stripped by the parser before the syntax tree is built — they exist in source code but not in executed code
- `{ }` and `[ ]` appear under both Literal Values and Punctuators — same symbols, different roles depending on context
- Literal Values are fixed in source code — no runtime work needed
- Evaluated Values are produced by the engine at runtime
- `null` is the only special value with genuine literal syntax
- `undefined`, `NaN`, `Infinity`, `-Infinity` are global properties, not literals
