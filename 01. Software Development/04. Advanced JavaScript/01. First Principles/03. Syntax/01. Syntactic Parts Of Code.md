# Syntactic Parts Of Code

&nbsp;

**Syntax** in a programming language refers to what you write.

---

## Syntactic Parts Of JS

What you actually write.

<div class="indent">

<span style="color: var(--heading-h3-color); font-weight: bold;">Keywords</span>
  - what you write to control the engine

<span style="color: var(--heading-h3-color); font-weight: bold;">Operators</span>
  - what you write to perform operations

<span style="color: var(--heading-h3-color); font-weight: bold;">Operands</span>
  - what you write that operators act on

<span style="color: var(--heading-h3-color); font-weight: bold;">Identifiers</span>
  - what you write to name things

<span style="color: var(--heading-h3-color); font-weight: bold;">Values</span>
  - what you write to store data of named items

<span style="color: var(--heading-h3-color); font-weight: bold;">Punctuators</span>
  - what you write to structure and separate code

<span style="color: var(--heading-h3-color); font-weight: bold;">Incidentals</span>
  - what you write that the parser ignores — comments and whitespace

</div>
