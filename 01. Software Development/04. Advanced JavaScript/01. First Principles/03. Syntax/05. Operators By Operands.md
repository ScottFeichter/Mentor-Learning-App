# Categorizing Operators By Operands

Sometimes it is helpful to categorize **operators** by the amount of **operands** they act upon.

### Unary Operators

One **operand**.

```js
5++     // 5 is the operand ++ is the operator
!true   // ! is the operator true is the operand
```

---

### Binary Operators

Two **operands** — one on each side of the operator.

```js
5 + 3   // 5 and 3 are the operands
x === y // x and y are the operands
```

---

### Ternary Operators

Three **operands**.

```js
condition ? valueIfTrue : valueIfFalse
```

- `condition` — first operand
- `valueIfTrue` — second operand
- `valueIfFalse` — third operand
