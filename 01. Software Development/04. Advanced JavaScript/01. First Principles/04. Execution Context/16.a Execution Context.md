# Execution Context

&nbsp;

When the JS engine runs code, it creates an **execution context**.

## Three Kinds Of Execution Context

**Execution Context** is the bigger umbrella concept for 3 flavors.

### Golbal Execution Context

Created when the script first runs and before any function is called.

- There is only one.
- It runs from program start to program end.
- Everything else runs inside it.
- It is not a JS function.
- This is the one exception.
- The one case where code runs outside a JS function.


### Function Execution Context

Created when a function is called on the call stack.

- Each function call creates a new **execution context**.
- When a function call is completely finished the **execution context** ends.

### Eval Execution Context

Created when eval() runs.

- ignore this one
- it's legacy and never used
