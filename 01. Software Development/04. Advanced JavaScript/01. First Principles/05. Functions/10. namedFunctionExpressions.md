# Named Function Expressions

## What is a Named Function Expression?

A **named function expression** is a function expression that has a name, and it must be captured in a variable:

```javascript
let myVariable = function namedFunc() {
  console.log("I'm captured in myVariable");
};

myVariable(); // "I'm captured in myVariable"
```

## Can a Named Function Expression be Captured in a Variable?

Yes! A named function expression **is already captured in a variable** - that's how it's defined.

**Key points:**
- The variable name (`myVariable`) is how you call the function
- The internal name (`namedFunc`) is only accessible inside the function itself
- You **must** assign it to a variable or it would be useless

## Named Function Expressions Must Be Captured

You cannot use a named function expression without capturing it:

```javascript
// This would be a syntax error - can't have a standalone named expression
function namedFunc() {
  console.log("Hello");
}; // This is actually a declaration, not an expression

// Named expressions MUST be part of an assignment or other expression
let captured = function namedFunc() { ... }; // Valid
```

## Two Names, Two Purposes

```javascript
let outerName = function innerName() {
  console.log("Outer name:", outerName);
  console.log("Inner name:", innerName);
};

outerName(); // Both work inside the function
// innerName(); // Error - inner name not accessible outside
```

**Summary:** Named function expressions are always captured in variables - that's the only way they can exist and be useful. The variable is how you access the function from outside, while the internal name is only available inside the function.
