# Syntactic Statements

A Statement is a unit of **compound syntax** — it is made up of Lexicals and/or Expressions.

A Statement must be executable. It must direct the engine to do something.

---

## Two Kinds of Statements

### Lexical Statements

The syntax is driven by a keyword or punctuator. No operator is written by the programmer.

- **Declarations** — keyword-driven. The engine fills in implicit behavior (binding the identifier to `undefined`). The programmer writes no operator and no value, but execution still occurs.
- **Ghost Statements** — a lone punctuator (`;`) with no expression. Syntactically valid, but the engine does nothing.

### Expression Statements

The syntax contains an operator and/or operand written by the programmer.

- **Operable** — the expression produces a value that can be used as an operand in another expression.
- **Inoperable** — initializers (`let x = 5`) and assignments (`x = 5`) produce a value but JS restricts where that value can be used. The restriction is JS-specific, not a property of the expression itself.

---

## Summary

```
Statements
├── Lexical Statements
│   ├── Declarations   (keyword-driven, engine fills implicit value)
│   └── Ghost          (empty, no expression at all)
└── Expression Statements
    ├── Operable       (can be used as operands)
    └── Inoperable     (initializers, assignments — JS-specific restriction)
```

The dividing line is **what is written in source**. Lexical Statements have no operator written by the programmer. Expression Statements do.
