# Statements

&nbsp;

A **statement** is an instruction that performs an action.

```js
let station = "101.1";
```

**Statements** are syntax that tell the engine to *do* something.

---

## Forming Statements

Not everything in a JS file is a **statement** on its own.

### The Distinction

**Statements** are often built from smaller parts that are not **statements** themselves.

In some cases those smaller parts can exist on their own as **statements** too.

### Parts Of Statements

| Part | Statement? | What Is It |
|--------|----------------|---------|
| `let` | never on its own | a declaration keyword |
| `station` | not during initialization | an identifier |
| `=` | never on its own | part of an expression called an operator |
| `"101.1"` | not during initialization | a kind of value called a literal |
| `;` | not during initialization | a kind of lexical called a punctuator |

## Complete Unit Of Execution

A **statement** is a complete unit of execution.

### Statements Terminate With `;` Or `}`

**Statements** end with a semicolon `;` much of the time.

If **statement** ends in a block `{}` the closing `}` serves as the terminator.

### Semicolons Are Not Mandatory

*Automatic Semicolon Insertion* makes semicolons optional in practice.

But they are a visual boundary that improve readibility.
