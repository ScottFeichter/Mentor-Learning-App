# Electron

Electron is a framework that lets you build desktop apps using web technologies (HTML, CSS, JavaScript).

It bundles two things together:

- **Chromium** — the browser engine (handles rendering)
- **Node.js** — the runtime (handles file system, OS access, etc.)

VSCode is built on Electron, which is why it's essentially a web app running as a native desktop application. That's also why VSCode extensions are written in JavaScript/TypeScript.

## VSCode's UTF-8 Decoder

VSCode uses the built-in `TextDecoder` API (part of the WHATWG Encoding Standard, available in Node.js) to decode file bytes into displayable text in the editor.

This is VSCode the app decoding bytes so it can display them — not Node.js running a file.

When Node.js actually *runs* a JS file, there is no `TextDecoder` step. The raw bytes go straight into V8's lexer, which has UTF-8 handling built in. `TextDecoder` is a Node.js API available for your own code when you need to manually decode bytes into a string (e.g. reading a file in binary mode with `fs.readFile`).
