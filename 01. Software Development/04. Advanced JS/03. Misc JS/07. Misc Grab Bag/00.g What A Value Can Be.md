

## What A Value Can Be

In JS, a value can be any of the following:

### Primitive

A single, immutable piece of data.

```js
"101.1"       // string
42            // number
true          // boolean
undefined     // undefined
null          // null
Symbol()      // symbol
9007199254740991n // bigint
```

Primitives are not objects.
They have no properties of their own.

### Data Structure

A collection that holds other values.

```js
{}    // object
[]    // array
```

Objects and arrays are mutable.
They are passed by reference, not by value.

Each property value in an object and each index value in an array is itself a value.

```js
const radio = { station: "101.1", volume: 5 }
// "101.1" is a value bound to the key station
// 5 is a value bound to the key volume

const stations = ["101.1", "98.7"]
// "101.1" is a value bound to index 0
// "98.7" is a value bound to index 1
```

### Function Definition

A function is a value.

It can be bound to an identifier just like any other value.

```js
function greet() {}   // function declaration
const greet = () => {}  // function expression
```

### Object Instance

An object created from a class or constructor function using `new`.

```js
const car = new Car()
```

The instance is a value — an object in memory with its own properties.

### Function Return

The value a function produces when it is called.

```js
function getStation() {
  return "101.1"
}

const station = getStation() // "101.1" is the value
```

The return value can be any of the above — a primitive, object, array, or even another function.

---

## Key Idea

The identifier is just the name.

The value is the thing the name points to.

Scope controls where the name is visible.

The binding rules control how the name can be changed.
