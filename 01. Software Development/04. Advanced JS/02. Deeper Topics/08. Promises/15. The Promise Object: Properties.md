# The Promise Object: Properties

Since a Promise is an object it has properties and methods.

## Internal Properties

A Promise object has several internal properties:

## Internal Properties
- **State**
- **Value**
- **Fulfillment Handlers**
- **Rejection Handlers**


## State Property
The state property of a Promise object be one of 3 strings:

- **Pending**: Initial state, operation not completed yet
- **Fulfilled**: Operation completed successfully
- **Rejected**: Operation failed

When you instantiate a Promise object its state is pending.

#### Tracking State

Though state is a property, you cannot key in to view or change it. The Promise API intentionally hides the internal state.

You're meant to use methods to handle the different outcomes rather than checking the state directly.

  - .then()
  - .catch()
  - .finally()

## Value Property

The resolved value (when fulfilled) or rejection reason (when rejected)

The **value property** (internally `[[PromiseResult]]`) stores the actual data that gets passed when a Promise is resolved or rejected.

## What The Value Property Stores

**When Fulfilled:**
- Stores the data passed to `resolve()`
- This becomes the argument to `.then()` callbacks

**When Rejected:**
- Stores the error/reason passed to `reject()`
- This becomes the argument to `.catch()` callbacks

**When Pending:**
- Contains `undefined` (no value yet)


## Key Points

**1. Immutable Once Set**
- Once `resolve()` or `reject()` is called, the value cannot change
- Multiple calls to `resolve()` are ignored

**2. Any Data Type**
- Can store strings, numbers, objects, arrays, other promises
- Whatever you pass to `resolve()`/`reject()` gets stored

**3. Not Directly Accessible**
- Like state, you can't access it directly with `promise.value`
- Must use `.then()`, `.catch()`, or `.finally()` to get the value

**4. Passed to All Handlers**
- Every `.then()` callback receives this same stored value
- Every `.catch()` callback receives this same stored error

The value property is essentially the "payload" that gets delivered to your callback functions when the Promise settles.


## Handlers

Array of `.then()` callbacks waiting to run


Array of `.catch()` callbacks waiting to run





## How It Works

```javascript
let promise = new Promise((resolve, reject) => {
  if (success) {
    resolve("Hello World"); // Value becomes "Hello World"
  } else {
    reject("Something failed"); // Value becomes "Something failed"
  }
});

promise.then(value => {
  console.log(value); // Logs "Hello World" (the stored value)
});
```
