
## Where Are Callbacks Executed?

If a callback gets used, it's not necessarily called within the body of the receiving function.

### 1. **In the Function Body** (Most Common)
```javascript
function processData(callback) {
  console.log("Processing...");
  callback(); // Called here in the body
}
```

### 2. **Stored and Called Later Outside the Function**
```javascript
let savedCallback;

function storeCallback(callback) {
  savedCallback = callback; // Just stored, not called
}

// Called later, outside the original function
setTimeout(() => savedCallback(), 1000);
```

### 3. **Passed to Another Function**
```javascript
function setupHandler(callback) {
  button.addEventListener('click', callback);
  // Browser calls it later when click happens
}
```

### 4. **Called by Async Operations**
```javascript
function fetchData(callback) {
  fetch('/api/data')
    .then(response => callback(response)); // Called by Promise chain
}
```

## Key Points

**Callback execution can happen:**
- Directly in the receiving function's body
- Stored for later execution
- Passed to other functions/systems
- Registered as event handlers
- Anywhere in the program, not just in the original receiving function

A callback is just a function reference that *could* be called - there's no guarantee it will be, and if it is called, it doesn't have to be within the original function's body.
