# Callback Execution

## Are Callbacks Always Called?

No, a callback is not always called.

The receiving function has complete control over **if** and **when** to call the callback.

### Examples Where Callbacks Are NOT Called:

**1. Conditional Execution:**
```javascript
function maybeCall(callback, shouldCall) {
  if (shouldCall) {
    callback(); // Only called if condition is true
  }
  // If shouldCall is false, callback never gets called
}
```

**2. Stored for Later:**
```javascript
let storedCallback;

function storeCallback(callback) {
  storedCallback = callback; // Stored, not called
}

// Called much later, outside the function
setTimeout(() => storedCallback(), 5000);
```

**3. Event Handlers:**
```javascript
function setupButton(callback) {
  button.addEventListener('click', callback);
  // Callback stored, only called when user clicks
}
```

**4. Error Cases:**
```javascript
function processData(data, callback) {
  if (!data) {
    console.log("No data provided");
    return; // Exit without calling callback
  }
  callback(data);
}
```

## Key Points

**The function receiving the callback decides:**
- **IF** to call it
- **WHEN** to call it
- **HOW MANY TIMES** to call it
- **WITH WHAT ARGUMENTS** to call it
