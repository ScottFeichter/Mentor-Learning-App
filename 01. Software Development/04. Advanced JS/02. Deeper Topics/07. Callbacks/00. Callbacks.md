# What is a Callback?

A **callback** is:
  - A function reference
  - That gets passed as an argument to another function
  - To be called later by the receiving function IF NECESSARY

## Example

In the following example the function sayGoodbye is being used as a callback.

It is being passed as an argument to the receiving function greet().

```javascript
function sayGoodbye() {
  console.log("Goodbye!");
}

function greet(name, callback) {
  console.log("Hello " + name);
  callback(); // The callback gets called here
}

greet("John", sayGoodbye); // Pass sayGoodbye as callback argument


// Output: "Hello John" then "Goodbye!"
```

## What Is A Function Reference?

A **function reference** is a reference to a function DEFINITION.

## Key Point

The receiving function controls when the function gets called.
