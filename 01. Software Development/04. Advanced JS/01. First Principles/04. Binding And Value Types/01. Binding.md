# Binding

&nbsp;

A **binding** is the connection between an identifier and its value.

---

## The Binding

When you declare something, two things exist:

- the **identifier** — the name
- the **value** — what the name is bound to

### Example 1: Variable Identifier

```js
let sum = 10;
```
- `sum` is the identifier
- the value is what it is bound to

### Example 2: Function Identifier

```js
function greet() {}
```
- `greet` is the identifier
- the function definition is what it is bound to

### Example 3: Array Identifier

```js
const stations = ["101.1", "98.7"]
```
- `stations` is the identifier
- the array is what it is bound to


### Example 4: Object Identifier

```js
const radio = {}
```
- `radio` is the identifier
- `{}` is the object it is bound to

### Example 5: Class Identifier

```js
class Car {}
```
- `Car` is the identifier
- the class definition is what it is bound to

---

## Property and Index Bindings

Not all bindings involve identifiers.

Object properties and array indices are bindings.

They live on the object or array — not in scope.

### Object Property

```js
const radio = { station: "101.1" }
```
- `station` is a property key — a string bound to the value `"101.1"`
- it lives on the `radio` object, not in scope

### Array Index

```js
const stations = ["101.1", "98.7"]
```
- `0` is an index — a numeric key bound to `"101.1"`
- `1` is an index — a numeric key bound to `"98.7"`
- indices live on the array, not in scope

`const` locks the **binding**, not the value.

```js
const radio = {}
radio.station = "101.1" // allowed — mutating the object
radio = {}              // TypeError — cannot rebind a const
```

`radio` cannot be pointed at a new value.

But the object it points to can still be changed.

## Redeclaration

```js
var x = 1
var x = 2 // allowed

let y = 1
let y = 2 // SyntaxError

const z = 1
const z = 2 // SyntaxError
```
