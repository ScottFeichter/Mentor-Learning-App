# Key Differences: Function Declaration vs Named Function Expression

## Function Declaration
```javascript
function myFunction() {
  console.log("Declaration");
}
```

## Named Function Expression
```javascript
let myFunction = function namedFunc() {
  console.log("Named expression");
};
```

## Key Differences

### 1. Hoisting
- **Declaration**: Fully hoisted - can be called before it's defined
- **Named Expression**: Not hoisted - cannot be called before assignment

```javascript
// This works
sayHello(); // "Hello!"

function sayHello() {
  console.log("Hello!");
}

// This doesn't work
sayGoodbye(); // Error: Cannot access 'sayGoodbye' before initialization

let sayGoodbye = function goodbye() {
  console.log("Goodbye!");
};
```

### 2. Name Accessibility
- **Declaration**: Name is accessible in the surrounding scope
- **Named Expression**: Internal name only accessible inside the function itself

```javascript
let myFunc = function internalName() {
  console.log(internalName); // Works - name accessible inside
};

// console.log(internalName); // Error - name not accessible outside
```

### 3. Syntax Context
- **Declaration**: Standalone statement
- **Named Expression**: Part of an assignment expression

The main practical difference is hoisting behavior - declarations can be called before they're defined, named expressions cannot.
