# Value

&nbsp;

A **value** is what you write that represents or resolves to actual data in memory.

---

## Two Kinds Of Values

**Values** can be defined in two different ways syntactically.

### Literals

A Literal is a **value** written directly in code and never a complete instruction on its own.

It is a kind of syntax that is translated directly into a *runtime value* without any calculation.

### Evaluations

An Evaluation is syntax that must be resolved to a *runtime value* by the JS Engine.

Its result is a *runtime value*, resolved according to JS operation order rules.
