# Lexicals

&nbsp;

**Lexicals** are what you write using the fixed vocabulary of the language.

---

## What Makes Something A Lexical

**Lexical** syntax belongs to the JS language itself.

### Fixed By The Language

You cannot redefine or invent a new a **Lexical**.

### Restricted Usage

You cannot use them as a variable name or a value.

---

## Parts Of Statements

**Lexicals** are a kind of syntax used as building blocks for Statements.

### Not Expressions

**Lexicals** are not Expressions because they do not produce a value.

### Example

The **Lexicals** `if` `()` `{}` `;` shape the statement but produce nothing.

```js
if (score > 10) { console.log('high'); }
```
---

## Kinds Of Lexicals

There are only two kinds of **Lexicals**.

### Punctuators

Fixed symbols that shape the form of code.

### Keywords

Reserved words the engine recognizes and treats specially.
