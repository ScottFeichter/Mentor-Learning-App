# Common Encoding Schemes

&nbsp;

An encoding scheme is a defined set of rules for representing information as a signal or sequence of values.

## Binary Encoding

All digital data is ultimately encoded as binary — sequences of 0s and 1s.

Every encoding scheme at the digital level is built on top of binary.

## Character Encoding

- <span class="olive-bold">ASCII</span> — 128 characters mapped to 7-bit numbers, covers English letters, digits, and basic symbols
- <span class="olive-bold">UTF-8</span> — variable length encoding covering the full Unicode character set, backward compatible with ASCII
- <span class="olive-bold">UTF-16</span> — uses 16-bit code units, commonly used internally by operating systems

## Line Encoding

Used to represent binary data as electrical signals on a wire.

- <span class="olive-bold">NRZ (Non-Return to Zero)</span> — high voltage = 1, low voltage = 0
- <span class="olive-bold">Manchester Encoding</span> — encodes each bit as a voltage transition, making it self-clocking

## Data Encoding

- <span class="olive-bold">Base64</span> — encodes binary data as ASCII text, commonly used in email attachments and web tokens
- <span class="olive-bold">Hex (Hexadecimal)</span> — represents binary data as base-16 numbers, widely used in debugging and color codes
