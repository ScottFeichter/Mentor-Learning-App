# The Web vs The Internet

&nbsp;

The web and the internet are often used interchangeably but they are not the same thing.

## The Internet

The internet is the infrastructure — the global network of interconnected computers communicating via TCP/IP.

It is the physical and logical system of cables, routers, switches, and protocols that connects devices worldwide.

The internet carries many different services — email, file transfer, voice calls, messaging, and the web.

## The Web

The web (World Wide Web) is one service that runs on top of the internet.

It is the system of documents and resources — web pages, images, videos — that are linked together via hyperlinks and accessed using HTTP.

You access the web through a browser, which sends HTTP requests and renders the responses.

## The Distinction

- <span class="olive-bold">Internet</span> — the network itself
- <span class="olive-bold">Web</span> — a service that uses the network

Sending an email uses the internet but not the web.

Browsing a website uses both — the web for the content and the internet to transport it.

## A Useful Analogy

The internet is like the road network.

The web is like one type of vehicle that uses those roads.

Other vehicles — email, FTP, VoIP — also use the same roads.
