# What Is The Internet?

&nbsp;

The internet is a global network of interconnected computers and devices that communicate using a shared set of protocols.

It is not owned by any single entity — it is a decentralized system of networks operated by governments, companies, universities, and individuals that have agreed to interconnect and use common standards.

## How It Works

Every device on the internet has an IP address — a unique identifier that allows data to be routed to it.

Data is broken into packets, each labeled with a source and destination address.

Routers across the network read those addresses and forward packets toward their destination, hopping from network to network until they arrive.

## What It Is Not

The internet is not the same as the web.

The internet is the infrastructure — the physical cables, routers, and protocols.

The web is one service that runs on top of the internet — the system of pages and resources accessed via HTTP.

## Scale

The internet connects billions of devices across every country in the world.

It carries email, web traffic, video streams, voice calls, file transfers, and countless other services simultaneously.
