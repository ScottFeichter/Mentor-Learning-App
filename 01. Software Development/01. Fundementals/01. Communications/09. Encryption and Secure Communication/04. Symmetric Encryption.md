# Symmetric Encryption

&nbsp;

Symmetric encryption uses the same key to both encrypt and decrypt data.

Both the sender and receiver must have a copy of the same secret key.

## How It Works

The sender encrypts the plaintext using the shared key and sends the ciphertext.

The receiver uses the same key to decrypt the ciphertext back into plaintext.

## Common Algorithms

- <span class="olive-bold">AES (Advanced Encryption Standard)</span> — the current standard, widely used for file encryption, HTTPS, and more
- <span class="olive-bold">DES (Data Encryption Standard)</span> — older standard, now considered insecure due to short key length
- <span class="olive-bold">3DES</span> — applies DES three times, more secure than DES but slower than AES
- <span class="olive-bold">ChaCha20</span> — fast and secure, used in TLS and mobile applications

## Advantages

- Fast — much faster than asymmetric encryption
- Efficient for encrypting large amounts of data

## Limitations

- Key distribution problem — how do you securely share the key with the other party in the first place?
- If the key is compromised, all data encrypted with it is exposed

## In Practice

Symmetric encryption is used for the bulk of data encryption.

Asymmetric encryption is typically used to securely exchange the symmetric key, after which symmetric encryption takes over.
