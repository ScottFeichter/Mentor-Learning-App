# SSH

&nbsp;

SSH (Secure Shell) is a cryptographic network protocol for securely accessing and managing remote systems over an unsecured network.

## What It Does

- Provides an encrypted command line session on a remote machine
- Authenticates both the server and the client
- Protects against eavesdropping, connection hijacking, and other attacks

## How It Works

SSH uses asymmetric encryption to authenticate and establish a session, then switches to symmetric encryption for the data transfer.

The server has a host key pair — the client verifies the server's public key to confirm it is connecting to the right machine.

The client authenticates using either a password or its own key pair.

## Key-Based Authentication

Password authentication is less secure — keys are preferred.

The client generates a key pair and adds the public key to the server's `~/.ssh/authorized_keys` file.

When connecting, the server challenges the client to prove it holds the corresponding private key without transmitting it.

## Common Uses

- Remote server administration
- Secure file transfer (SFTP, SCP)
- Git operations over SSH
- Tunneling other protocols securely

## Port

SSH runs on port 22 by default.
