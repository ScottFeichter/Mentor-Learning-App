# HTTPS

&nbsp;

HTTPS (Hypertext Transfer Protocol Secure) is HTTP running over TLS (Transport Layer Security).

It is the secure version of HTTP — all data exchanged between the browser and server is encrypted.

## What It Adds Over HTTP

- <span class="olive-bold">Encryption</span> — data in transit cannot be read by anyone intercepting the connection
- <span class="olive-bold">Authentication</span> — the server's identity is verified via a digital certificate
- <span class="olive-bold">Integrity</span> — data cannot be tampered with in transit without detection

## How It Works

Before any HTTP data is exchanged, TLS performs a handshake:

1. Browser connects to the server and requests a secure session
2. Server presents its TLS certificate
3. Browser verifies the certificate against trusted Certificate Authorities
4. Both parties establish a shared symmetric session key
5. All HTTP traffic is encrypted with that key

## Why It Matters

Without HTTPS, anyone on the same network can read login credentials, form data, and session tokens in plaintext.

HTTPS is now the standard for all websites — browsers flag HTTP sites as "Not Secure."

## Port

HTTPS uses port 443 by default.
