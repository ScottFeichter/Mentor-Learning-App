# IP

&nbsp;

IP (Internet Protocol) is the network layer protocol responsible for addressing and routing packets across interconnected networks.

It is the foundation of the internet — every device connected to the internet has an IP address.

## What It Does

- Assigns addresses to devices so they can be identified on a network
- Routes packets from source to destination across multiple networks
- Fragments and reassembles packets when necessary

## IP Addresses

An IP address is a unique numerical label assigned to each device on a network.

- <span class="olive-bold">IPv4</span> — 32-bit address, written as four numbers separated by dots <span class="muted">(e.g. 192.168.1.1)</span>
- <span class="olive-bold">IPv6</span> — 128-bit address, written as eight groups of hexadecimal <span class="muted">(e.g. 2001:0db8::1)</span>

IPv4 supports about 4.3 billion addresses — a number that has been exhausted.

IPv6 supports 340 undecillion addresses — effectively unlimited.

## IP is Connectionless and Unreliable

IP does not guarantee delivery, ordering, or error correction.

Those responsibilities belong to the transport layer — TCP adds reliability on top of IP.

## Routing

Routers read the destination IP address of each packet and forward it toward its destination, hopping from network to network until it arrives.
