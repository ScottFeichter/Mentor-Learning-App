# Common Protocols Overview

&nbsp;

The internet runs on a stack of protocols, each responsible for a different layer of communication.

## Application Layer

| Protocol | Purpose | Port |
|---|---|---|
| HTTP | Web content transfer | 80 |
| HTTPS | Secure web content transfer | 443 |
| FTP | File transfer | 20, 21 |
| SMTP | Sending email | 25, 587 |
| IMAP | Receiving email | 143, 993 |
| DNS | Domain name resolution | 53 |
| SSH | Secure remote access | 22 |
| WebSockets | Persistent two-way browser connections | 80, 443 |

## Transport Layer

| Protocol | Purpose |
|---|---|
| TCP | Reliable, ordered, connection-oriented delivery |
| UDP | Fast, connectionless, no delivery guarantee |

## Internet Layer

| Protocol | Purpose |
|---|---|
| IP (IPv4/IPv6) | Addressing and routing packets |
| ICMP | Error reporting and diagnostics (ping) |
