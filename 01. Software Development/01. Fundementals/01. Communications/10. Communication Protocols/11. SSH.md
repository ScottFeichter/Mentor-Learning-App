# SSH

&nbsp;

SSH (Secure Shell) is a cryptographic protocol for securely accessing and managing remote systems over an unsecured network.

## What It Replaces

SSH replaced older insecure protocols like Telnet and rsh that transmitted data including passwords in plaintext.

## How It Works

SSH establishes an encrypted tunnel between the client and server.

The server is authenticated using a host key — the client verifies this on first connection and stores it to detect future changes.

The client authenticates using either a password or a key pair.

## Common Uses

- Remote command line access to servers
- Secure file transfer via SFTP and SCP
- Git operations — pushing and pulling from remote repositories
- Port forwarding and tunneling other protocols

## Key-Based Authentication

The preferred method — more secure than passwords.

The client generates a key pair and registers the public key on the server.

Authentication proves possession of the private key without transmitting it.

```bash
ssh-keygen -t ed25519        # generate a key pair
ssh-copy-id user@server      # register public key on server
ssh user@server              # connect
```

## Port

SSH uses port 22 by default.
