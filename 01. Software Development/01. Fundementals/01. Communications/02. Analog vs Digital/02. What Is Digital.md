# What Is Digital?

&nbsp;

A digital signal is a signal that represents information as a sequence of discrete values.

In most computing contexts those values are binary — 0 or 1, off or on, low voltage or high voltage.

## Examples

- Data stored on a hard drive
- Audio in an MP3 file
- A digital clock displaying numbers
- Text in a document

## How It Works

Instead of a continuously varying wave, a digital signal switches between defined states.

Each state represents a binary value, and sequences of those values encode information.

## Advantages and Limitations

- <span class="olive-bold">Advantage</span> — resistant to noise since only two states need to be distinguished, not an infinite range of values
- <span class="olive-bold">Advantage</span> — easy to copy, store, and transmit without degradation
- <span class="olive-bold">Limitation</span> — requires sampling and quantization to represent real world analog phenomena, which introduces some loss
