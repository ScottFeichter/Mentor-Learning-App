# Sender Receiver Model

&nbsp;

The Sender Receiver Model is the most fundamental model of communication.

It describes communication as a process of transmitting a message from one party to another.

## The Components

- <span class="olive-bold">Sender</span> — the party originating the message
- <span class="olive-bold">Message</span> — the information being communicated
- <span class="olive-bold">Channel</span> — the medium through which the message travels
- <span class="olive-bold">Receiver</span> — the party the message is intended for
- <span class="olive-bold">Noise</span> — anything that distorts or disrupts the message in transit
- <span class="olive-bold">Feedback</span> — the receiver's response back to the sender

## In Technical Communication

- The sender is a computer or application transmitting data
- The message is the data being sent
- The channel is the network or transmission medium
- The receiver is the destination computer or application
- Noise is interference, packet loss, or corruption
- Feedback is acknowledgment packets confirming receipt

## Why It Matters

This model applies at every level of communication — from a person speaking to a friend to a server sending an HTTP response to a browser.
