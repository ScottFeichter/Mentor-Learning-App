# Circuit Components

&nbsp;

Circuit components are the individual parts that make up an electronic circuit.

Each component has a specific function that controls or directs the flow of electricity.

## Common Components

- <span class="olive-bold">Resistor</span> — limits the flow of current to protect other components
- <span class="olive-bold">Capacitor</span> — stores and releases electrical charge, used for filtering and timing
- <span class="olive-bold">Inductor</span> — stores energy in a magnetic field, resists changes in current
- <span class="olive-bold">Diode</span> — allows current to flow in only one direction
- <span class="olive-bold">Transistor</span> — acts as a switch or amplifier, the fundamental building block of digital logic
- <span class="olive-bold">LED</span> — a diode that emits light when current flows through it
- <span class="olive-bold">Switch</span> — manually opens or closes a circuit path

## Why It Matters

Understanding components explains how circuits can be designed to do specific things.

Combining components in different arrangements produces the logic and memory systems that computers are built from.
