# Visual Communications

&nbsp;

The branch of communications concerned with conveying information and meaning through visual elements.

## Subfields

- <span class="olive-bold">Graphic Design</span> — using typography, color, and layout to communicate visually
- <span class="olive-bold">Semiotics</span> — the study of signs, symbols, and how they carry meaning
- <span class="olive-bold">Data Visualization</span> — representing information and data in visual form
- <span class="olive-bold">Photography and Film</span> — communicating through captured and moving images
- <span class="olive-bold">User Interface Design</span> — designing visual systems for interacting with software
- <span class="olive-bold">Illustration</span> — using drawn imagery to explain, persuade, or tell stories
