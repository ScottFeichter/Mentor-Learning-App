# What Is Asynchronous Communication?

&nbsp;

Asynchronous communication is communication where the parties do not need to be present at the same time.

The sender transmits and the receiver responds when ready — there is no requirement for simultaneous engagement.

## In Human Communication

- Email
- Text messages
- Forum posts

## In Computing

Asynchronous refers to operations that do not block — the program continues executing while waiting for the operation to complete.

```javascript
fs.readFile('file.txt', (err, data) => {
  console.log(data); // runs when ready
});
console.log('this runs immediately'); // does not wait
```

In networking, asynchronous transmission means each character or byte is sent independently with its own start and stop bits rather than relying on a shared clock.

## Advantages

- Parties do not need to be available simultaneously
- In computing, non-blocking operations keep programs responsive

## Limitations

- No immediate feedback
- Requires more coordination to handle responses and errors
