**MAC OS SHORTCUT PRACTICE ROUTINE**

Mac OS GUI offers many useful keyboard shortcuts for every program 

These shortcuts will increase the efficiency of workflows

Mouse is great but less use is more efficient

*NOTE: Before beginning be sure to check the “Use keyboard navigation to move focus between controls” in Keyboard Preferences in the Shortcuts Tab*

**FIRST TASK: CREATE KEYBOARD SHORTCUT TO TILE APP WINDOWS**

**Open System Display Preferences:** Alt \+ F2 or use spotlight

**Move to System Preferences Main Menu:** cmd F to search

**Tab to Keyboard Preferences:** Tab to exit search bar then up down arrows

**Enter Keyboard Preferences:** Spacebar

**Move to Shortcuts:** While in the tab menu use arrow left or right

**Tab to App Shortcuts in the left menu:** Tab then use arrow down or up

**Tab to \+ then add:** Tab then spacebar

**Enter the Menu Title:** “Move Window to Right Side of Screen”

**Tab to Keyboard Shortcut then enter custom shortcut:** Tab 

*(suggestion: ctr \+ alt \+ cmd \-\>)*

*Add and repeat for moving to left side of screen…*

**Exit System Preferences:** Cmd \+ W

**SECOND TASK: USE LAUNCHPAD TO OPEN OR FIND APPS**

**Enter Launchpad:** Cmd \+ Space  
			  
**Navigate Launchpad Spaces:** 

* use arrow keys to move between spaces   
* enter to go into a space  
* enter to open an app  
* fn \+ esc to move out of a space  
* fn \+ F4 to close out of Launchpad

**THIRD TASK: USE MISSION CONTROL**

**Enter Mission Control:** F3

**Exit Mission Control:** F3

**Enter Preview:** Ctrl \+ up

**Cycle Preview:** Ctrl \+ left/right

**Jump to Desktop:** Ctrl \+ 1/2/3/4

**Cycle Desktops:** Ctrl \+ left/right

**FOURTH TASK: USE SPOTLIGHT**

**Enter Spotlight Search:** Cmd \+ Space Bar

**Open Safari App:** Type Safari and press enter on the app

**Take Full Screen Shot:** F4

**Close Safari Window:** Cmd \+ W

**Quit Safari:** Cmd \+ Q

**Enter Spotlight Search:** Cmd \+ Space Bar

**Open Calendar App:** Type Calendar and press enter on the app

**Open App Preferences:** Cmd \+ ,    
(when in docs this changes the cursor, but it works for chrome otherwise)

**Close App Preferences:** Cmd \+ w

**Hide Calendar Window:** Cmd \+ h

**SIXTH TASK: HIDE AND UNHIDE WINDOWS**

**Hide the windows of the front app:** Cmd \+ H

**Unhide windows:** Cmd \+ tab (is there a way to unhide all?)

**SEVENTH TASK: LEARN A NEW SHORTCUT**

**Open Keyboard Shortcuts:** Cmd \+ / (works for docs not for finder)

**Learn a New Shortcut:** Cmd \+ Opt \+ Shift \+ I opens the document explorer  
       
**Learn a New Shortcut:** Ctrl \+ Opt \+ F, E, V, I, O, T, or N enters the menu  
NOTE: Can use arrows to move between menus

**Undo Typing:** Cmd \+ Z          

**Redo or Repeat:** Cmd \+ Y 

**OR:** Shift \+ Cmd \+ Z

**EIGHTH TASK: NAVIGATE FINDER WITHOUT MOUSE, CREATE FOLDER, DELETE FOLDER,  AND EMPTY TRASH**

**Navigate to Finder:** Cmd \+ Tab

**Cycle through Finder Windows:** Cmd \+ \`

**Hide all Finder windows:** Cmd \+  H

**Hide all windows except Finders:** Cmd \+ Opt \+ H

**Open Finder Preferences:** Cmd \+ ,

**Close Active Window (Preferences):** Cmd \+ W

**Open New Finder Window:** Cmd \+ N

**Minimize a Finder Window:** Cmd \+ M (notice it goes to app icon not bottom app bar) 

**UnMinimize a Finder Window:** ?

**Navigate to Top Level Folder:** Cmd \+ Shift \+ C

**Navigate to Applications Folder:** Cmd \+ Shift \+ A

**Navigate to Utilities Folder:** Cmd \+ Shift \+ U

**Navigate to Desktop Folder:** Cmd \+ Shift \+ D

**Use address for a folder to go to:** Cmd \+ Shift \+ G  
*NOTE: this only searches folders and is CASE SENSATIVE: belle will yield no results for Belle*

**Navigate sidebar in a Finder Window:** ?

**Search for a folder to go to:** Cmd \+ F

**In the Search use tab to select folder from the is dropdown:** Shift \+ Tab then down arrow

**Enter the file browsing window:** Shift \+ Tab several times then arrow forward

**Create new folder in active window:** Cmd \+ Shift \+ N

**Duplicate the file:** Cmd \+ D

**Get info of selected item:** Cmd \+ I

**Show Hidden Files:** Cmd \+ Shift \+ .

**Show the Path Bar:** Cmd \+ P

**Open Selected Item:** Cmd \+ O  
*NOTE: this is for opening files not folders*

**Open a new Tab:** Cmd \+ T

**Cycle forward Tabs:** Ctr \+ Tab

**Cycle backwards Tabs:** Ctr \+ Shift \+ Tab

**Open Recents Folder:** Cmd \+ Shift \+ F

**Show Active Window in Icon mode:** Cmd \+ 1

**Show Active Window in list mode:** Cmd \+ 2

**Show Active Window in column mode:** Cmd \+ 3

**Show Active Window in gallery  mode:** Cmd \+ 4

**Move Selected Item to trash:** Cmd \+ Del

**Empty Trash:** Cmd \+ Shift \+ Delete

**Close Active Window:** Cmd \+ W  
*NOTE: no crying in baseball and there is no quitting Finder therefore Cmd \+ Q does nothing*
