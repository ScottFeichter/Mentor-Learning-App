# Routing

&nbsp;

## Routing Between Networks

Routing is the process of identifying the best path to a remote destination device.

A **router** is a networking device that connects multiple Layer 3 (IP) networks and makes forwarding decisions based on the Layer 3 IP address.

Anytime the network portion of the IP addresses of the source and destination hosts do not match, a router must be used to forward the message.

&nbsp;

---

&nbsp;

## Messages Within The Same Network

1. The sending host checks the IP of the receiving host and uses the subnet mask to determine if they are on the same network
2. If yes, it uses the MAC address to send it directly via a switch
3. If the host does not have the destination MAC address it sends an ARP request to obtain it

&nbsp;

---

&nbsp;

## Messages Between Different Networks

1. The sending host determines the destination is on a different network
2. It checks if it has the MAC of the Default Gateway (router) — if not it sends an ARP request
3. The router receives the frame, removes the Ethernet header, and looks up the destination IPv4 in its routing table
4. The router re-encapsulates the frame with its own source MAC address
5. The router checks its ARP table for the destination MAC and forwards the frame through the correct port

&nbsp;

If no default gateway is configured on the host, or if it is incorrect, the host cannot communicate with remote network hosts.
