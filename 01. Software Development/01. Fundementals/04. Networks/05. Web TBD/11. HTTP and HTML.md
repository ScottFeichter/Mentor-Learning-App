# HTTP and HTML

&nbsp;

## How A Web Page Loads

1. Client sends request to DNS to get the IP of the URL
2. Client uses the IP to send a request via HTTP on port `80`
3. The server responds with the web page using markup languages
4. The browser interprets the HTML and renders the page

HTTP is not secure and can be easily intercepted. HTTPS is secure HTTP using port `443` and secure transport protocols.

## FTP — File Transfer Protocol

FTP provides an easy method to transfer files from one computer to another.

The FTP service uses two ports:

- **Port 21** — Control connection (commands)
- **Port 20** — Data connection (file transfer)

FTP can operate in two modes:

- **Active** — the server takes an active role by approving a request for data. Can have problems with firewalls.
- **Passive** — the user establishes both channels. The server merely listens.

Pros:
- Can transfer multiple files at the same time
- Can resume a transfer if connection is lost
- Can schedule transfers

Cons:
- Lack of security — not encrypted
- FTP support is dropping due to security concerns

Alternatives to FTP:
- SFTP (works over SSH port 22)
- HTTPS
- AS2
- FTPS
