# What Is An API?

&nbsp;

A set of <span class="purple-bold">commands</span> used as a liason for code to talk to other code.

## What Is Meant By Commands?

In most **APIs** the commands are <span class="purple-bold">functions</span> or <span class="purple-bold">text similar to functions</span>.

## What Does An API Do?

- <span class="subheading-highlight">Provide access to functionality of code but not the code itself.</span>

- <span class="subheading-highlight">Abstract away the inner workings of already written code.</span>
