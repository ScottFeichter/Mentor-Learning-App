# Web APIs

&nbsp;

A **Web API** is an **API** accessed over the <span class="blue-bold">Web</span> using <span class="purple-bold">HTTP Methods</span> and <span class="pink-bold">URLs</span>.

## The Web

The <span class="red-bold">Internet</span> is the global public network of interconnected machines that communicate via <span class="red-bold">TCP/IP</span>.

The <span class="blue-bold">Web</span> refers to the system of <span class="pink-bold">Resources</span> and <span class="purple-bold">Services</span> that run on top of the <span class="red-bold">Internet</span>.

## URL

A <span class="pink-bold">Uniform Resource Locator (URL)</span> is an identifier for finding a <span class="pink-bold">Resource</span> on the web.

### Storefront Analogy

We can think of the <span class="pink-bold">Resource</span> as a brick and mortor business in the real world.

The <span class="pink-bold">URL</span> is like a storefront sign we would use to find the building from a street.

### How About The IP Address?

In this analogy an <span class="red-bold">IP Address</span> would be like a postal address for the business.

<span class="pink-bold">URLs</span> and <span class="red-bold">IP Addresses</span> work in tandem to assist the routing of internet traffic.

## HTTP Methods

<span class="purple-bold">HTTP Methods</span> aka <span class="purple-bold">HTTP Verbs</span> are <span class="purple-bold">text commands</span>.

### Similar To Functions

They are similar in concept to <span class="purple-bold">functions</span>.

In fact they are referred to as <span class="purple-bold">methods</span> for this reason.

### Not Exactly Functions

However, they are not <span class="purple-bold">methods</span> in a technical syntactic sense.

This is because they are not <span class="purple-bold">functions</span> of an object.

### Not Part Of A Programming Language

In fact they are not an entity belonging to a programming language.

Instead they belong to a protocol called <span class="purple-bold">HTTP/HTTPS</span>.
