# Git Terminology

&nbsp;

## General

- **REPO** — short for Repository
- **REPOSITORY** — a place where things are stored

## Volatile Directories

These are directories that have changes which are NOT committed. 

- **WORKING** — the Working Directory
- **STAGING** — the Staging Index
- **STASH** — area to temporarily store changes without committing

## History

- **COMMIT** — the Commit Tree
- **COMMIT TREE** — a timeline of branches and committed changes
- **HEAD** — pointer to the tip of the current branch

## Branches

- **MAIN BRANCH** — timeline following the production version
- **DEV BRANCH** — development version
- **FEATURE BRANCH** — version for a specific feature (merged into dev when done)
- **ORIGIN** — naming convention for a local branch referencing the remote

## Distributed Collaborative Working

- **REMOTE** — the repo on GitHub (in the cloud)
- **LOCAL** — the repo on your machine

## Actions

- **TRACKING** — git records deltas (changes)
- **ADDING** — staging changes
- **COMMITTING** — saving staged changes to history
- **CLONING** — creates repo copy on local machine
- **BRANCHING** — only keeps track of the deltas
- **CHECKING OUT** — switching to a branch to work in
- **MERGING** — bringing in changes from another branch (`git merge <branchname>`)
- **PUSHING** — sending committed changes from local to remote (`git push`)
- **PULLING** — getting committed changes from remote to local (`git pull`)
- **FORKING** — makes a copy of the whole repository on GitHub
