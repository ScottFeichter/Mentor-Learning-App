# Shell Scripting Basics

## Types of Shells

Two fundamentally different sets of shell script syntax:

### Bourne-compatible shells
- sh
- bash
- zsh
- ksh

### C-shell-compatible shells
- csh
- tcsh
- bcsh (C shell to Bourne shell translator/emulator)

The Bourne shell syntax is significantly more flexible and more widely used.

Each dialect differs slightly. Many shells also have variations denoted by a prefix (e.g., pdksh).

## Interpreter Line (Shebang)

The script starts with `#!` — called the **shebang**.

```bash
#!/bin/bash
```

If you don't specify an interpreter line, the default is usually `/bin/sh`. Always specify it for consistency.

## Shell Interacting vs Shell Scripting

- **Interacting** — typing commands one at a time at the prompt
- **Scripting** — writing a file of commands to be executed together
