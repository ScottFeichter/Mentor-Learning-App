# Node.js Exports

## CommonJS (CJS)

### Default Export
```javascript
// Single export
module.exports = function myFunction() {
  return 'Hello';
};

// Export object
module.exports = {
  func1,
  func2,
  myVariable
};
```

### Named Exports
```javascript
// Using exports shorthand
exports.func1 = function() { };
exports.func2 = function() { };
exports.myVariable = 'value';

// Note: Cannot reassign exports directly
// exports = { func1 }; // ❌ Won't work
// module.exports = { func1 }; // ✅ Works
```

### Mixed Pattern
```javascript
// Export default with properties
module.exports = myMainFunction;
module.exports.helper1 = helper1;
module.exports.helper2 = helper2;
```

## ES Modules (ESM)

### Named Exports
```javascript
// Export as you declare
export const myVariable = 'value';
export function func1() { }
export class MyClass { }

// Export existing items
const func2 = () => { };
const func3 = () => { };
export { func2, func3 };

// Export with alias
export { func2 as myFunc };
```

### Default Export
```javascript
// Export default function
export default function myFunction() {
  return 'Hello';
}

// Export default class
export default class MyClass { }

// Export default value
const value = 42;
export default value;

// Anonymous default
export default { func1, func2 };
```

### Combined Exports
```javascript
// Named + default in same file
export const helper = () => { };
export default function main() { }

// Re-export from another module
export { func1, func2 } from './other.js';
export * from './other.js';
```

## Key Differences

| Feature | CommonJS | ES Modules |
|---------|----------|------------|
| Syntax | `module.exports` / `exports` | `export` / `export default` |
| Default export | `module.exports = value` | `export default value` |
| Named exports | `exports.name = value` | `export { name }` or `export const name` |
| Multiple exports | Object with properties | Multiple export statements |
| Dynamic | Can export conditionally | Must be top-level (static) |
| Reassignment | `exports` is reference to `module.exports` | Each export is independent |

## Important Notes

### CommonJS Gotcha
```javascript
// ❌ This breaks the reference
exports = { func1, func2 };

// ✅ Always use module.exports for reassignment
module.exports = { func1, func2 };

// ✅ Or add properties to exports
exports.func1 = func1;
exports.func2 = func2;
```

### ESM Restrictions
```javascript
// ❌ Cannot export conditionally
if (condition) {
  export const value = 1; // Syntax error
}

// ✅ Export at top level
export const value = condition ? 1 : 2;

// ❌ Cannot use export in functions
function myFunc() {
  export const x = 1; // Syntax error
}
```

## Examples

### CommonJS Module
```javascript
// math.js
const add = (a, b) => a + b;
const subtract = (a, b) => a - b;

module.exports = {
  add,
  subtract
};
```

### ES Module
```javascript
// math.js
export const add = (a, b) => a + b;
export const subtract = (a, b) => a - b;

// Or with default
export default {
  add,
  subtract
};
```
