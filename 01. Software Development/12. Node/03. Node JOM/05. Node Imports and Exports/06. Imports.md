# Node.js Imports

## CommonJS (CJS)

```javascript
// Import entire module
const module = require('./module');

// Import and destructure
const { func1, func2 } = require('./module');

// Import built-in modules
const fs = require('fs');
const path = require('path');
```

## ES Modules (ESM)

```javascript
// Import entire module
import module from './module.js';

// Named imports
import { func1, func2 } from './module.js';

// Import everything as namespace
import * as module from './module.js';

// Import with alias
import { func1 as myFunc } from './module.js';

// Import built-in modules
import fs from 'fs';
import path from 'path';
```

## Key Differences

- **CommonJS**: Uses `require()`, synchronous, default in Node.js
- **ES Modules**: Uses `import`, asynchronous, requires `.mjs` extension or `"type": "module"` in package.json
- **File extensions**: ESM requires explicit `.js` extension in imports
