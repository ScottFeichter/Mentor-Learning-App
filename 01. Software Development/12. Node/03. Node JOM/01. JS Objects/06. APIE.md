# APIE

&nbsp;

<span style="font-size:1.2em;font-weight:900;color:#6c0101;">**APIE**</span> is an acronym to represent the four pillars of **Object Oriented Programming (OOP)**.

<div class="indent">

<p style="margin-left:20px;margin-top:24px;margin-bottom:12px;"><span style="font-size:1.2em;font-weight:900;color:#3D7EF0;">A</span><span class="olive-bold" style="font-size:1.2em;font-weight:900;">bstraction</span></p>

<p style="margin-left:40px;">Hiding complex details ie using a method without knowing the internal workings.</p>

<p style="margin-left:20px;margin-top:24px;margin-bottom:12px;"><span style="font-size:1.2em;font-weight:900;color:#3D7EF0;">P</span><span class="olive-bold" style="font-size:1.2em;font-weight:900;">olymorphism</span></p>

<p style="margin-left:40px;">The same method name can behave differently depending on which object is calling it.</p>


<p style="margin-left:20px;margin-top:24px;margin-bottom:12px;"><span style="font-size:1.2em;font-weight:900;color:#3D7EF0;">I</span><span class="olive-bold" style="font-size:1.2em;font-weight:900;">nheritance</span></p>

<p style="margin-left:40px;">A class can inherit properties and methods from another class.</p>

<p style="margin-left:20px;margin-top:24px;margin-bottom:12px;"><span style="font-size:1.2em;font-weight:900;color:#3D7EF0;">E</span><span class="olive-bold" style="font-size:1.2em;font-weight:900;">capusulation</span></p>

<p style="margin-left:40px;">Controlling access to the internal data of a class or object.</p>

</div>
