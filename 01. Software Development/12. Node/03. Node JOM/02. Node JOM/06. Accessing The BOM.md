# Accessing The BOM

&nbsp;

All **BOM** objects are properties of <span class="purple-bold">globalThis</span> and can therefore be access through it.

Since <span class="purple-bold">window</span> is a self reference to <span class="purple-bold">globalThis</span> we can access **BOM** with it too.

## Syntactic Sugar

This refers to a shorthand way to write something that the language could already do.

It doesn't add new functionality, it just makes the code easier to write and read.

### BOM Syntactic Sugar

<span class="js-yellow">JS</span> provides a <span style="color: #6c0101; font-weight: bold;">syntactic sugar</span> abstraction for accessing **BOM** properties.

We can reach them directly without keying in to the parent object as show below.

## Many Ways To Access BOM Syntactically

What this means:

- `globalThis.location`
- `window.location`
- `location`

Refer to the same thing when in the browser environment.

### Example

```js

Boolean(
    globalThis.location === window.location &&
    window.location === location &&
    globalThis.location === location
);

// true
```
