# window

&nbsp;

We looked at an incomplete approximation of what <span class="purple-bold">globalThis</span> could look like syntactically.

We noted <span class="purple-bold">globalThis</span> browser and <span class="node-green">Node</span> implementations differ slightly.

We can distinguish this difference by referring to <span class="purple-bold">globalThis</span> in the browser as <span class="purple-bold">window</span>.

## The window Object

In the browser the <span class="purple-bold">window</span> object is the <span class="purple-bold">globalThis</span> object.

They are one and the same; in fact <span class="purple-bold">window</span> is a self reference to <span class="purple-bold">globalThis</span>.

```js
let globalThis = {

  window: globalThis,
  // ... etc JS built-ins
}

Boolean(window === globalThis) // true
```

## Browser Access

In the browser <span class="purple-bold">globalThis</span> lets <span class="js-yellow">JS</span> interact with the browser itself — not just the page content.

This is referred to conceptually as the **Browser Object Model (BOM)**.

The **BOM** is the set of objects the browser exposes to <span class="js-yellow">JavaScript</span> through <span class="purple-bold">globalThis</span>.
