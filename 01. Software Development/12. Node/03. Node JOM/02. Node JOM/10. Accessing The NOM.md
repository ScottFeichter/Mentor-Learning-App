# Accessing The NOM

&nbsp;

All **NOM** objects are properties of <span class="purple-bold">globalThis</span> and can therefore be access through it.

Since <span class="purple-bold">global</span> is a self reference to <span class="purple-bold">globalThis</span> we can access **NOM** with it too.

## Syntatic Sugar

*Syntactic Sugar* is a shorter or more readable way to write something that the language could already do.

It doesn't add new functionality, it just makes the code easier to write and read.

### NOM Syntactic Sugar

<span class="js-yellow">JS</span> has also made a *syntactic sugar* abstraction for **NOM** properties.

Therefore we can access some things directly without keying in to the parent object.

## Many Ways To Access NOM Syntactically

What this means:

- `globalThis.process`
- `global.process`
- `process`

Refer to the same thing when in the browser environment.

### Example

```js

Boolean(globalThis.process === global.process && global.process === process); // true
```
