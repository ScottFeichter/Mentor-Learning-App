# Accessing The BOM

&nbsp;

All **BOM** objects are properties of <span class="purple-bold">globalThis</span> and can therefore be access through it.

Since <span class="purple-bold">window</span> is a self reference to <span class="purple-bold">globalThis</span> we can access **BOM** with it too.

## Syntatic Sugar

*Syntactic Sugar* is a shorter or more readable way to write something that the language could already do.

It doesn't add new functionality, it just makes the code easier to write and read.

### BOM Syntactic Sugar

JS has also made a *syntactic sugar* abstraction for **BOM** properties.

Therefore we can access some things directly without keying in to the parent object.

## Many Ways To Access BOM Syntactically

What this means:

- `globalThis.location`
- `window.location`
- `location`

Refer to the same thing when in the browser environment.

### Example

```js

boolean(globalThis.location === window.location === location); // true
```
