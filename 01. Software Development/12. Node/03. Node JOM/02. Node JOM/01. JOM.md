# The JavaScript Object Model

&nbsp;

The **JavaScript Object Model (JOM)** is not an official term.

But it's a useful way to think about what <span class="js-yellow">JavaScript</span> itself provides.

We can think of this as a nested Russian doll with the outer most layer being an object called <span class="purple-bold">globalThis</span>.

## Built-Ins

Contained within <span class="purple-bold">globalThis</span> are objects, classes, and functions.

Referred to as <span style="color: #6c0101; font-weight: bold;">built-ins</span>, these exist in every <span class="js-yellow">JS</span> runtime, be it a browser or <span class="node-green">Node</span>.

These are most items the language needs as defined by the ECMAScript specification.
