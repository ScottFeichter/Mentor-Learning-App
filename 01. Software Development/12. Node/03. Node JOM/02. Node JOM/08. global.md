# global

&nbsp;

We noted <span class="purple-bold">globalThis</span> browser and <span class="node-green">Node</span> implementations differ slightly.

We learned that in browsers the <span class="purple-bold">window</span> object is a reference to <span class="purple-bold">globalThis</span>

We can distinguish this difference by referring to <span class="purple-bold">globalThis</span> in <span class="node-green">Node</span> as <span class="purple-bold">global</span>.

## The global Object

In <span class="node-green">Node</span> the <span class="purple-bold">global</span> object is the <span class="purple-bold">globalThis</span> object.

They are one and the same; in fact <span class="purple-bold">global</span> is a self reference to <span class="purple-bold">globalThis</span>.

```js
let globalThis = {

  global: globalThis,
  // ... etc JS built-ins
}

Boolean(global === globalThis) // true
```

## NOM Access

Unlike the browser, in <span class="node-green">Node</span> there is no **BOM** and therefore no **DOM**.

Instead, <span class="node-green">Node</span> provides top level objects with global scope to access:

- runtime environment
- the process
- I/O
- timers
- module system

In this course this is referred to conceptually as the **Node Object Model (NOM)**.
