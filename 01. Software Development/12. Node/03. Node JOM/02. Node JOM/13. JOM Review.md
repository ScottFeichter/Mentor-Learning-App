# JOM Review

&nbsp;

**JOM** is the concept of objects in <span class="js-yellow">JS</span> environments nested like a Russian doll.

---

## globalThis

The outer most object of both browsers and <span class="node-green">Node</span> but not identical across environments.

<div class="indent">

### window

The self reference to <span class="purple-bold">globalThis</span> in browsers.

<div class="indent">

#### BOM

Browser objects accessible via <span class="purple-bold">globalThis</span> (and <span class="purple-bold">window</span>) in browser environments.

</div>

### global

The self reference to <span class="purple-bold">globalThis</span> in <span class="node-green">Node</span>.

<div class="indent">

#### NOM

<span class="node-green">Node</span> global objects accessible via <span class="purple-bold">globalThis</span> (and <span class="purple-bold">global</span>) in the <span class="node-green">Node</span> environments.

</div>

</div>
