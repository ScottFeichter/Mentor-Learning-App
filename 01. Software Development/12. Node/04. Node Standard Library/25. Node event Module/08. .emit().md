# .emit()

## Calling .emit()


## Triggering with .emit()

When the event name is emitted the handler is executed.

```js
const EventEmitter = require('events');


const myEventEmitter = new EventEmitter();

// 1. Register an event to listen for using .on()
myEventEmitter.on('statusUpdate', (status, secretCode) => {
    console.log(`System status changed to ${status} (Code: ${secretCode})`);
});

// 2. Trigger the event somewhere else in your code
myEventEmitter.emit('statusUpdtate', 'activeStatus', 'secretCode');
```
