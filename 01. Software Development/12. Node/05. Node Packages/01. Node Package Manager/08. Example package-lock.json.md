# Example package-lock.json

Here is a simplified snippet of what a `package-lock.json` looks like:

```json
{
  "name": "my-app",
  "version": "1.0.0",
  "lockfileVersion": 3,
  "requires": true,
  "packages": {
    "": {
      "name": "my-app",
      "version": "1.0.0",
      "dependencies": {
        "express": "^5.1.0"
      }
    },
    "node_modules/express": {
      "version": "5.1.0",
      "resolved": "https://registry.npmjs.org/express/-/express-5.1.0.tgz",
      "dependencies": {
        "body-parser": "^2.2.0",
        "cookie": "^0.7.1",
        "router": "^2.2.0"
      }
    },
    "node_modules/body-parser": {
      "version": "2.2.0",
      "resolved": "https://registry.npmjs.org/body-parser/-/body-parser-2.2.0.tgz"
    }
  }
}
```

## Key Observations

- **Exact versions** - no `^` or `~`, just the precise version installed
- **Resolved URLs** - where each package was downloaded from
- **Nested dependencies** - shows the full dependency tree
- **Much larger** than `package.json` - can be thousands of lines

## Remember

- This file is auto-generated - never edit it manually
- Commit it to version control so your team gets identical installs
