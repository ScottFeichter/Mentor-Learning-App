# nvm Commands

&nbsp;

**`nvm`** is the base command needed for anything you do with **Node Version Manager**

---

## Commonly Used Commands

&nbsp;

```bash
nvm install <node_version_number>
```
Installs the version of <span class="highlight">Node</span> specified.

<!-- --- -->

&nbsp;
```bash
nvm install --lts
```
Installs the most current long-term supported version of <span class="highlight">Node</span>.

<!-- --- -->
&nbsp;
```bash
nvm ls
```
Lists all versions of <span class="highlight">Node</span> on your machine.

<!-- --- -->
&nbsp;
```bash
nvm alias default <node_version_number>
```
Specifies the default version of <span class="highlight">Node</span> to use.

<!-- --- -->
&nbsp;
```bash
nvm use <node_version>
```
Tells your machine which version of <span class="highlight">Node</span> to use during this session.

<!-- --- -->
&nbsp;
```bash
nvm -v
```
Tells your machine which version of **nvm** is currently installed.

<!-- --- -->
&nbsp;
```bash
node -v
```
Not an **nvm** command but a <span class="highlight">Node</span> command - displays <span class="highlight">Node</span> version currently in use.
