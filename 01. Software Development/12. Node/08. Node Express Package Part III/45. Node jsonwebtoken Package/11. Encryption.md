# Encryption

## What is Encryption?

Encryption is the process of converting readable data (plaintext) into an unreadable format (ciphertext) using an algorithm and a key. Only those with the correct key can decrypt it back to the original data.

## Key Concepts

- **Plaintext**: Original readable data
- **Ciphertext**: Encrypted unreadable data
- **Key**: Secret used to encrypt/decrypt
- **Algorithm**: Method used to encrypt (AES, RSA, etc.)

## Types of Encryption

### 1. Symmetric Encryption

**Same key** encrypts and decrypts data.

**Pros**: Fast, efficient for large data
**Cons**: Key distribution problem (how to share the key securely?)

```javascript
// Conceptual example
const key = "secret123";

// Encrypt
const encrypted = encrypt("Hello World", key);
// Output: "X7$mK9@pL2"

// Decrypt
const decrypted = decrypt("X7$mK9@pL2", key);
// Output: "Hello World"
```

**Common algorithms**: AES, DES, 3DES, Blowfish

### 2. Asymmetric Encryption

**Two keys**: Public key (encrypts) and Private key (decrypts).

**Pros**: Secure key exchange, digital signatures
**Cons**: Slower than symmetric

```javascript
// Conceptual example
const { publicKey, privateKey } = generateKeyPair();

// Encrypt with public key
const encrypted = encrypt("Hello World", publicKey);

// Decrypt with private key
const decrypted = decrypt(encrypted, privateKey);
// Output: "Hello World"
```

**Common algorithms**: RSA, ECC, ElGamal

## Simple Examples

### Example 1: Caesar Cipher (Basic Concept)

```python
# Shift each letter by 3 positions
plaintext = "HELLO"
shift = 3

# Encrypt: H→K, E→H, L→O, L→O, O→R
ciphertext = "KHOOR"

# Decrypt: Shift back by 3
decrypted = "HELLO"
```

### Example 2: Password Encryption

```javascript
// User enters password
const password = "myPassword123";

// Encrypt before storing
const encrypted = encrypt(password, secretKey);
// Store: "8f7a9b2c1d3e4f5g6h7i8j9k"

// When user logs in
const inputPassword = "myPassword123";
const encryptedInput = encrypt(inputPassword, secretKey);

// Compare encrypted values
if (encrypted === encryptedInput) {
  console.log("Login successful!");
}
```

### Example 3: HTTPS (Web Encryption)

```
1. Browser requests website
2. Server sends public key
3. Browser encrypts data with public key
4. Server decrypts with private key
5. Secure connection established
```

### Example 4: File Encryption

```python
# Encrypt a file
encrypt_file("document.pdf", key)
# Creates: "document.pdf.encrypted"

# Decrypt the file
decrypt_file("document.pdf.encrypted", key)
# Restores: "document.pdf"
```

## Encryption vs Hashing

| Feature | Encryption | Hashing |
|---------|-----------|---------|
| **Reversible** | Yes (with key) | No |
| **Purpose** | Protect data | Verify integrity |
| **Output** | Variable/fixed | Fixed size |
| **Use case** | Secure communication | Password storage |

**Example**:
```javascript
// Encryption (reversible)
encrypt("secret") → "X7$mK9" → decrypt → "secret"

// Hashing (one-way)
hash("secret") → "5ebe2294ecd0e0f08eab7690d2a6ee69" → ❌ cannot reverse
```

## Real-World Uses

1. **HTTPS/SSL** - Secure web browsing
2. **Messaging apps** - WhatsApp, Signal (end-to-end encryption)
3. **File storage** - Encrypted cloud backups
4. **VPNs** - Secure internet connection
5. **Email** - PGP/GPG encryption
6. **Databases** - Encrypt sensitive fields
7. **Payment systems** - Credit card data protection

## Common Encryption Standards

- **AES-256**: Industry standard for symmetric encryption
- **RSA-2048/4096**: Common for asymmetric encryption
- **TLS/SSL**: Secures internet communications
- **PGP**: Email encryption
- **BitLocker/FileVault**: Full disk encryption

## Best Practices

- Use strong, established algorithms (AES, RSA)
- Never create your own encryption algorithm
- Use long, random keys
- Store keys separately from encrypted data
- Use HTTPS for web applications
- Keep encryption libraries updated
- Use encryption + authentication (HMAC, GCM)
