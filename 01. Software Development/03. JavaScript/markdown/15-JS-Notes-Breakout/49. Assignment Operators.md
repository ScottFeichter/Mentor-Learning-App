# Assignment Operators

&nbsp;

```javascript
OPERATOR    EXAMPLE     SAME AS

=                              x = y                     x = y

+=                            x += y                   x = x + y

-=                            x -= y                   x = x - y

*=                            x *= y                   x = x * y

/=                            x /= y                   x = x / y

%=                            x %= y                   x = x % y

<<=                            x <<= y                   x = x << y

>>=                            x >>= y                   x = x >> y

>>>=                    x >>>= y           x = x >>> y

&=                            x &= y                   x = x & y

^=                            x ^= y                   x = x ^ y

|=                            x |= y                   x = x | y

**=                            x **= y                   x = x ** y
```
