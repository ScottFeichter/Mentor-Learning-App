# Sharp (Filters & Effects)

**npm:** `sharp`

Sharp's built-in image processing operations for photo effects. Includes blur, sharpen, tint, grayscale, gamma correction, normalize, median filter, and threshold.

**Use cases:**
- Applying blur/sharpen to uploaded photos
- Converting to grayscale or applying tint
- Normalizing image brightness/contrast
- Threshold-based image segmentation

**Note:** Same package as Sharp (General Purpose) — this documents its filter/effect capabilities specifically.
