# What is Node?

&nbsp;

Node is an application:

- Photoshop is for editing photos.
- Browsers are for exploring the Internet.
- Node is for running JavaScript.

## Node vs Node.js

Node and Node.js are the same thing.

Node.js is the more formal name.

In this course we will use Node.

## Node Does Not Have A GUI

To use it we must issue commands in a terminal.

```bash
node -version
```
We must use the base command **```node```** followed by a sub command.

The base command tells computer the sub command is for Node application.
