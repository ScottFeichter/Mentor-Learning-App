# Chrome Browsing

&nbsp;

Browsing with **Chrome** utilizes several features of the app.

## The Address Bar

<div class="indent">

### What It Is

The address bar is the input field at the top of the browser.

This is where where you type URLs or search queries.

It also displays the current page's URL and security status.

### View Security Info

Click the lock icon at the left of the URL to view a site's security certificate and connection details.

### Search Or Navigate

Type a URL to navigate directly to a site, or type any text to search using your default search engine.

### Search Shortcuts

Utilize these shortcuts to refine your search right in the address bar.

| Shortcut | Example | Result |
|---|---|---|
| `@` | `@youtube javascript` | Search within a specific site |
| `site:` | `site:mozilla.org javascript` | Search within a specific domain |
| `filetype:` | `filetype:pdf javascript guide` | Find a specific file type |
| `" "` | `"what is a closure"` | Search for an exact phrase |
| `-` | `javascript -java` | Exclude a word from results |
| `OR` | `javascript OR python` | Search for one term or the other |
| `..` | `javascript course $10..$50` | Search within a number range |
| `related:` | `related:stackoverflow.com` | Find sites similar to a given one |
| `cache:` | `cache:example.com` | View Google's cached version of a page |
| `define:` | `define:recursion` | Get a dictionary definition |

</div>

## Tabs

<div class="indent">

### What They Are

Tabs allow multiple web pages open at the same time within a single browser window.

Each tab runs independently and can be switched between by clicking on it.

### Opening And Closing

Tabs are opened and closed using the tab bar at the top of the browser.

Click the `+` icon to open a new tab, or click the `x` on a tab to close it.

### Reopen A Closed Tab

A recently closed tab can be reopened via the History menu.

### Pin A Tab

Right-click a tab and select Pin to keep it small and persistent on the left of the tab bar.

Pinned tabs survive browser restarts.

### Tab Groups

Right-click a tab and select Add to new group to organize tabs by color and label.

### Move Tabs

Click and drag a tab to reorder it, or drag it out of the window to open it in a new window.

</div>

## The Toolbar

<div class="indent">

### What It Is

Sitting below the tab bar it contains navigation controls, the address bar, and the extensions area.

### Back And Forward Buttons

Click the left and right arrows to navigate back and forward through your browsing history.

Right-click either arrow to see a list of recent pages.

### Reload Button

Click the reload icon to reload the current page.

A hard reload bypasses the cache and can be triggered by holding Shift while clicking reload.

### Home Button

The home button is hidden by default.

Enable it via Settings > Appearance > Show home button.

### Extensions Area

Installed extensions appear as icons to the right of the address bar.

Click the puzzle piece icon to manage which extensions are visible.

</div>

## The Menu

<div class="indent">

### What It Is

The menu is the main access point for **Chrome**'s features and settings.

It is represented by the three-dot icon in the top right corner of the browser.

### Opening The Menu

Click the three-dot icon in the top right corner of **Chrome** to open the main menu.

### What It Contains

The menu provides access to settings, history, bookmarks, downloads, print, zoom, and more.

### Settings

Type `chrome://settings` directly in the address bar to jump straight to settings.

</div>

## Bookmarks Bar

<div class="indent">

### What It Is

Sitting below the address bar it shows your saved bookmarks for quick access.

### Toggle It

The bookmarks bar can be shown or hidden via the View menu or **Chrome** settings.

### Organize Bookmarks

Right-click anywhere on the bookmarks bar to add folders and organize your bookmarks.

</div>

## The Status Bar

<div class="indent">

### What It Is

The status bar appears temporarily at the bottom left of the browser window.

It shows the URL of a link when you hover over it.

</div>

## History

<div class="indent">

### What It Is

History is a log of every page you have visited in **Chrome**.

It is organized chronologically and is searchable by keyword.

### View History

Type `chrome://history` in the address bar or open it via the **Chrome** menu.

### Search History

Use the search bar at the top of the history page to find previously visited pages by keyword.

### Delete History

Individual entries can be removed by clicking the three-dot icon next to them.

All history can be cleared via the **Chrome** menu > Clear browsing data.

### Reopen A Closed Tab

Recently closed tabs appear at the top of the history page and can be reopened with a click.

</div>

## Downloads

<div class="indent">

### What It Is

When a file is downloaded a bar appears at the bottom of showing download progress.

### Downloads Page

Type `chrome://downloads` in the address bar to view all past downloads.

</div>

## Zoom And Display

<div class="indent">

### What It Is

Zoom controls let you increase or decrease the size of the content on a page.

Display settings also include full screen mode which removes the browser UI entirely.

### Zoom In And Out

The page zoom level can be adjusted via the **Chrome** menu or keyboard shortcuts.

### Full Screen

Full screen mode hides the browser UI and expands the page to fill the entire screen.

Toggle it via the View menu or a keyboard shortcut.

</div>

## Finding Content On A Page

<div class="indent">

### What It Is

A built in search tool for searching the visible text of the current page.

It does not search the internet — it only searches the page you are already on.

### Find On Page

The find bar lets you search for any text on the current page.

It highlights all matches and lets you cycle through them one by one.

</div>

## Profiles

<div class="indent">

### What Is A Profile

A profile is a separate **Chrome** environment.

It has its own bookmarks, history, extensions, and sign-in.

It is useful for separating work and personal browsing.

### Add A Profile

Click the profile icon in the top right corner of **Chrome** and select Add.

</div>
