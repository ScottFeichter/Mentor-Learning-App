# Chrome DevTools - Overview

&nbsp;

In addition to browsing **Chrome** is excellent for troubleshooting web development.

## What Are Chrome DevTools?

**Chrome DevTools** is a set of web developer tools built directly into the **Chrome** browser.

It allows you to inspect, debug, and profile web pages in real time without leaving the browser.

## Using Chrome DevTools

<div class="indent">

### How To Open DevTools

Right-click anywhere on a page and select Inspect.

Or use the keyboard shortcut `Cmd+Option+I` (Mac) or `Ctrl+Shift+I` (Win/Linux).

### Docking Position

**DevTools** can be docked to the bottom, left, right or opened as a separate window.

Click the three-dot menu inside **DevTools** to change the dock position.

### Reopening The Last Panel

**DevTools** remembers which panel you had open last and will reopen to it automatically.
