# Chromium Parts

&nbsp;

The main parts of **Chromium** are as follows.

## Rendering Engine

Turns HTML and CSS into the visual pixels you see on screen.

<div class="indent">

### Blink

Blink is the rendering engine used by **Chromium**.

It parses HTML and CSS and paints the visual output to the screen.

Blink is a fork of WebKit, which is the engine used by Safari.

</div>

## JavaScript Engine

Reads and executes the JavaScript code on a page.

<div class="indent">

### V8

V8 is the JavaScript engine used by **Chromium**.

It compiles and executes JavaScript code.

V8 is also the engine used by Node.js.

</div>

## Networking

Handles all communication between the browser and the internet.

<div class="indent">

### Network Stack

**Chromium** has its own network stack to handle HTTP, HTTPS, and WebSocket communication.

It manages DNS resolution, caching, cookies, and SSL/TLS connections.

</div>

## Multi-Process Architecture

Isolates tabs and extensions into separate processes to improve stability and security.

<div class="indent">

### How It Works

**Chromium** runs each tab, extension, and plugin in its own separate process.

This means if one tab crashes, it does not bring down the entire browser.

### The Browser Process

The browser process is the main process that manages the UI and coordinates all other processes.

### Renderer Processes

Each tab runs in its own renderer process.

The renderer process uses Blink to parse and render the page content.

### The GPU Process

The GPU process handles hardware-accelerated rendering.

It communicates with the graphics card to paint content to the screen efficiently.

</div>

## Developer Tools

A built-in panel for inspecting, debugging, and profiling web pages.

<div class="indent">

### DevTools

**Chromium** ships with built-in developer tools.

These are the same as in **Chrome**, Edge, and other **Chromium**-based browsers.

</div>

## Storage

Manages all data that web pages save on the user's device.

<div class="indent">

### Local Storage

**Chromium** manages several types of client-side storage.

These include cookies, localStorage, sessionStorage, IndexedDB, and the Cache API.

</div>

## Security

Protects the user and the operating system from malicious web content.

<div class="indent">

### Sandboxing

Each renderer process runs in a sandbox.

This limits what the process can access on the operating system.

The purpose is to reduce the impact of security vulnerabilities.

### Safe Browsing

**Chromium** includes a Safe Browsing component.

It checks URLs against a list of known malicious sites.

</div>
