# Chrome Extensions

&nbsp;

The following **Chrome** extensions can help you as a developer and are highly recommended.

## Install Extensions For Chrome

In **Chrome** visit: https://chromewebstore.google.com/category/extensions

<div class="indent">

### CollorZilla Color Picker

Identify any color directly from a webpage, similar to an eyedropper tool in design software.

### WhatFont Font Picker

Identify the font family, size, weight, and line height of text from a webpage.

### JSON Formatter

Formats raw JSON responses in the browser into a readable, collapsible tree structure.

### Wappalyzer

Detect technologies a website is built with — frameworks, CMS, analytics tools, hosting, and more.

### React Developer Tools

Adds a React panel to **Chrome DevTools** for inspecting the component tree, props, and state.

### Redux DevTools

Adds a Redux panel to **Chrome DevTools** for inspecting dispatched actions and state changes.

### Google Docs Offline

Create and edit Google Docs, Sheets, and Slides without an internet connection.
