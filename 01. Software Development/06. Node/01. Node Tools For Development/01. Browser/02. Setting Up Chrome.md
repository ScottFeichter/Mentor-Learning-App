# Setting Up Chrome

&nbsp;

These steps are highly recommended for after download and install of **Chrome**.

## Settings On Your Computer

<div class="indent">

### Chrome As Default Browser

This helps for example a link in an email will open **Chrome** rather than a different browser.

### Open Chrome At Login

This makes **Chrome** open automatically when you turn on or log on to your computer.

### Pin To Taskbar or Keep In Dock

Make app icon easily available on taskbar (Windows), dock (Mac), or dash (Linux) .

</div>

## Settings On Chrome Browser

<div class="indent">

### Sign In To Chrome With Google Account

An advantage to signing in is the ability to port settings and bookmarks from elsewhere.

### Import Your Data

A prompt may appear to import bookmarks, saved passwords, and history from an old web browser.

### Adjust Chrome Settings

<div class="indent">

#### Privacy And Security

Control cookie behavior, site permissions, and enable Safe Browsing.

#### Appearance

Customize the **Chrome** theme, font size, and whether the bookmarks bar is shown.

#### On Startup

Enter the URLs you want **Chrome** to load automatically each time it launches.

</div>

### Profiles

<div class="indent">

#### What Is A Profile

A profile is a separate **Chrome** environment via a different Google logon.

Profiles have their own bookmarks, history, extensions, and sign-in.

You can have multi profiles in their own **Chrome** windows simultaneously.

#### Add A Profile

Click the profile icon in the top right corner and select Add to create a new profile.

Profiles are useful for separating work and personal browsing.

</div>
