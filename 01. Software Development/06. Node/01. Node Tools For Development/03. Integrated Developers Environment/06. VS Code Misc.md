# VS Code Misc

&nbsp;

A collection of useful **VS Code** features that are worth knowing.

## Command Palette

<div class="indent">

### What It Is

The Command Palette gives you access to every **VS Code** command by name.

Open it with `Cmd+Shift+P` on Mac or `Ctrl+Shift+P` on Windows.

### Common Uses

- Opening settings
- Running extensions
- Changing the color theme
- Toggling features on and off

</div>

## Keyboard Shortcuts

<div class="indent">

### Viewing All Shortcuts

Open the full shortcuts reference with `Cmd+K Cmd+S` on Mac or `Ctrl+K Ctrl+S` on Windows.

### Useful Defaults

- `Cmd+P` — quick open a file by name
- `Cmd+/` — toggle line comment
- `Cmd+D` — select next occurrence of current word
- `Opt+Up/Down` — move a line up or down
- `Cmd+Shift+K` — delete current line

</div>

## Integrated Terminal

<div class="indent">

### Opening The Terminal

Open the integrated terminal with `` Ctrl+` `` or via **Terminal → New Terminal**.

### Why Use It

It lets you run Node, npm, and Git commands without leaving **VS Code**.

You can have multiple terminal tabs open at the same time.

</div>

## Multi-Cursor Editing

<div class="indent">

### What It Is

Multi-cursor editing lets you place multiple cursors in the file and type in all of them at once.

### How To Use

Hold `Opt` on Mac or `Alt` on Windows and click to place additional cursors.

Use `Cmd+D` to select the next matching word and add a cursor there.

</div>

## Emmet

<div class="indent">

### What It Is

**Emmet** is built into **VS Code** and lets you expand shorthand into full HTML or CSS.

### Example

Type `div.container>ul>li*3` and press `Tab` to expand it into:

```html
<div class="container">
  <ul>
    <li></li>
    <li></li>
    <li></li>
  </ul>
</div>
```

</div>
