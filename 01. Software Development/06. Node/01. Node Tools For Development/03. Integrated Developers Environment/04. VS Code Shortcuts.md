# VS Code Shortcuts

&nbsp;

Utilize these keyboard shortcuts to enhance your **VS Code** experience.

## General

&nbsp;

<div class="center">

| Action | Mac | Win/Linux |
|---|---|---|
| Command Palette | `Cmd+Shift+P` | `Ctrl+Shift+P` |
| Quick open file | `Cmd+P` | `Ctrl+P` |
| Open settings | `Cmd+,` | `Ctrl+,` |
| Open keyboard shortcuts | `Cmd+K Cmd+S` | `Ctrl+K Ctrl+S` |
| Toggle sidebar | `Cmd+B` | `Ctrl+B` |
| Toggle terminal | `` Ctrl+` `` | `` Ctrl+` `` |

</div>

## Panels

&nbsp;

<div class="center">

| Action | Mac | Win/Linux |
|---|---|---|
| Explorer | `Cmd+Shift+E` | `Ctrl+Shift+E` |
| Search | `Cmd+Shift+F` | `Ctrl+Shift+F` |
| Source Control | `Cmd+Shift+G` | `Ctrl+Shift+G` |
| Run and Debug | `Cmd+Shift+D` | `Ctrl+Shift+D` |

## Editing

&nbsp;

<div class="center">

| Action | Mac | Win/Linux |
|---|---|---|
| Cut line | `Cmd+X` | `Ctrl+X` |
| Copy line | `Cmd+C` | `Ctrl+C` |
| Delete line | `Cmd+Shift+K` | `Ctrl+Shift+K` |
| Move line up | `Opt+Up` | `Alt+Up` |
| Move line down | `Opt+Down` | `Alt+Down` |
| Duplicate line down | `Opt+Shift+Down` | `Alt+Shift+Down` |
| Toggle line comment | `Cmd+/` | `Ctrl+/` |
| Format document | `Opt+Shift+F` | `Alt+Shift+F` |
| Select next occurrence | `Cmd+D` | `Ctrl+D` |
| Select all occurrences | `Cmd+Shift+L` | `Ctrl+Shift+L` |
| Add cursor above | `Cmd+Opt+Up` | `Ctrl+Alt+Up` |
| Add cursor below | `Cmd+Opt+Down` | `Ctrl+Alt+Down` |

</div>

## Navigation

&nbsp;

<div class="center">

| Action | Mac | Win/Linux |
|---|---|---|
| Go to line | `Ctrl+G` | `Ctrl+G` |
| Go to definition | `F12` | `F12` |
| Go back | `Ctrl+-` | `Alt+Left` |
| Go forward | `Ctrl+Shift+-` | `Alt+Right` |
