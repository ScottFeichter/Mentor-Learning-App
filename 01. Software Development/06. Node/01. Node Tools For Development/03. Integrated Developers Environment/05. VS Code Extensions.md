# VS Code Extensions

&nbsp;

Extensions add features to **VS Code** beyond what ships out of the box.

## Installing Extensions

<div class="indent">

### Extensions Panel

Open the Extensions panel with `Cmd+Shift+X` on Mac or `Ctrl+Shift+X` on Windows.

Search for an extension by name and click **Install**.

### From The Command Palette

Open the Command Palette with `Cmd+Shift+P` and type `Extensions: Install Extensions`.

</div>

## Recommended Extensions

<div class="indent">

### ESLint

Highlights JavaScript errors and style issues as you type based on your ESLint config.

### Prettier

Automatically formats your code on save to keep style consistent across a project.

### GitLens

Enhances the built-in Git support with inline blame, history, and diff tools.

### Path Intellisense

Autocompletes file paths as you type them in import statements.

### Bracket Pair Colorizer

Colors matching brackets so nested code is easier to read at a glance.

### Thunder Client

A lightweight REST API client built into VS Code — similar to **Postman** for quick request testing.

</div>

## Managing Extensions

<div class="indent">

### Disabling

You can disable an extension globally or just for a specific workspace.

Right-click the extension in the Extensions panel and select **Disable**.

### Workspace Recommendations

You can recommend extensions to teammates by adding them to `.vscode/extensions.json` in your project.

**VS Code** will prompt anyone who opens the project to install the recommended extensions.

```json
{
  "recommendations": [
    "esbenp.prettier-vscode",
    "dbaeumer.vscode-eslint"
  ]
}
```

</div>
