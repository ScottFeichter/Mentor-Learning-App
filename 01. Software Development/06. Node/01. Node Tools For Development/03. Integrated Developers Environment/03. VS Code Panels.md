# VS Code Panels

&nbsp;

**VS Code** is organized into panels — each one serves a specific purpose in your workflow.

## Activity Bar

<div class="indent">

### What It Is

The Activity Bar runs along the far left edge of the window.

It contains icons that switch between the main panels.

</div>

## Explorer

<div class="indent">

### What It Is

The Explorer panel shows your project's file and folder structure.

Open it with `Cmd+Shift+E` on Mac or `Ctrl+Shift+E` on Windows.

### What You Can Do

- Open, rename, move, and delete files
- Create new files and folders
- Drag and drop to reorganize your project

</div>

## Search

<div class="indent">

### What It Is

The Search panel lets you search and replace text across your entire project.

Open it with `Cmd+Shift+F` on Mac or `Ctrl+Shift+F` on Windows.

### Like Spotlight

It works similarly to Spotlight on Mac — type any word or phrase and **VS Code** finds every file that contains it.

### What You Can Do

- Search across all files in the workspace
- Filter results by file type or folder
- Replace matches one at a time or all at once
- Use regular expressions for advanced searches

</div>

## Source Control

<div class="indent">

### What It Is

The Source Control panel is the built-in Git interface.

Open it with `Cmd+Shift+G` on Mac or `Ctrl+Shift+G` on Windows.

### What You Can Do

- Stage and unstage file changes
- Write commit messages and commit
- View diffs of changed files
- Push and pull from a remote repository

</div>

## Run And Debug

<div class="indent">

### What It Is

The Run and Debug panel lets you run and step through your code with a debugger.

Open it with `Cmd+Shift+D` on Mac or `Ctrl+Shift+D` on Windows.

### What You Can Do

- Set breakpoints to pause execution at a specific line
- Inspect variable values at runtime
- Step through code line by line
- View the call stack

</div>

## Extensions

<div class="indent">

### What It Is

The Extensions panel is where you browse, install, and manage **VS Code** extensions.

Open it with `Cmd+Shift+X` on Mac or `Ctrl+Shift+X` on Windows.

</div>

## Terminal

<div class="indent">

### What It Is

The integrated Terminal panel runs a shell directly inside **VS Code**.

Open it with `` Ctrl+` `` on both Mac and Windows.

### What You Can Do

- Run Node, npm, and Git commands without leaving the editor
- Open multiple terminal tabs side by side
- Split the terminal into multiple panes

</div>
