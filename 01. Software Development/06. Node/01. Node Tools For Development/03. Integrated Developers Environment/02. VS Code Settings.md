# VS Code Settings

&nbsp;

**VS Code** has a wide range of settings to customize your development environment.

## Accessing Settings

<div class="indent">

### Settings UI

Open settings via **Code → Settings → Settings** on Mac or **File → Preferences → Settings** on Windows.

You can search for any setting by name in the search bar at the top.

### settings.json

All settings are stored in a `settings.json` file.

Click the **Open Settings (JSON)** icon in the top right of the Settings panel to edit it directly.

</div>

## Recommended Settings

<div class="indent">

### Format On Save

Automatically formats your code every time you save a file.

```json
"editor.formatOnSave": true
```

### Tab Size

Sets the number of spaces used per indentation level.

```json
"editor.tabSize": 2
```

### Word Wrap

Wraps long lines so you don't have to scroll horizontally.

```json
"editor.wordWrap": "on"
```

### Font Size

Adjust the editor font size to your preference.

```json
"editor.fontSize": 14
```

### Auto Save

Automatically saves files after a short delay.

```json
"files.autoSave": "afterDelay"
```

### Minimap

The minimap is a small code overview on the right side of the editor.

Disable it if you prefer a cleaner workspace.

```json
"editor.minimap.enabled": false
```

### Default Formatter

Set the default formatter so **VS Code** knows which extension to use when formatting.

```json
"editor.defaultFormatter": "esbenp.prettier-vscode"
```

</div>

## Workspace vs. User Settings

<div class="indent">

### User Settings

User settings apply globally across all projects on your machine.

### Workspace Settings

Workspace settings are stored in a `.vscode/settings.json` file inside your project folder.

They override user settings and only apply to that project.

They can be committed to version control so the whole team shares the same settings.

</div>
