# Postman Newman - CLI

&nbsp;

We don't have to use Postman from the native app UI we can use it in CLI via **Newman**.

## CLI Installation

<div class="indent">

### Install Globally

Install **Newman** globally so it is available as a command in your terminal.

```bash
npm install -g newman
```

### Verify Installation

```bash
newman --version
```

</div>

## CLI Usage

<div class="indent">

### Basic Run

```bash
newman run collection.json
```

### With An Environment

```bash
newman run collection.json --environment env.json
```

### With Reporters

```bash
newman run collection.json --environment env.json --reporters cli,json
```

The `cli` reporter prints results to the terminal.

The `json` reporter writes results to a file for further processing.

### Export From Postman

Export your collection and environment from **Postman** via **File → Export**.

Pass the exported `.json` files to **Newman** as shown above.

</div>
