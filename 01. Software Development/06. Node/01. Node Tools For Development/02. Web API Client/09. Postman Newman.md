# Postman Newman

&nbsp;

**Newman** is **Postman**'s official collection runner for use outside the native UI.

## About Newman

<div class="indent">

### Overview

**Newman** lets you run **Postman** collections from command line or a Node.js script.

It is maintained by the **Postman** team and available as an npm package.

### When To Use It

Use **Newman** when you want to run API tests without opening **Postman**.

It is the standard way to integrate **Postman** collections into a CI/CD pipeline.

</div>

## One Package, Two Uses

**Newman** is not two separate tools.

It is one package that supports both CLI and programmatic use.

<div class="indent">

### How It Works

When you run `newman` in the terminal it utilizes Node.js under the hood.

Like all npm CLI tools, the shell executes the **Newman** package via Node.

### CLI Wrapper

The CLI is a thin wrapper that parses your arguments and calls **Newman**.

It runs the same underlying Node code you would call programmatically.

</div>

## Installation

You can install **Newman** in different ways depending on use case.

With either way you can use `newman --version` in terminal to verify install.

<div class="indent">

### Global For CLI

Installing it globally gives you the `newman` command in your terminal.

```bash
npm install -g newman
```

### Package Local For Node

Installing it locally gives you the Node.js API for use in a script.

```bash
npm install newman
```

</div>
