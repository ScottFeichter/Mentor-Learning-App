# Postman Collections

&nbsp;

A **Collection** is a saved group of related requests in **Postman**.

## What Collections Are For

<div class="indent">

### Organization

Collections keep your requests organized by project, feature, or API.

Instead of rebuilding requests each session, you save them once and reuse them.

### Sharing

Collections can be exported and shared with teammates.

This makes it easy to onboard others to an API without explaining every endpoint.

</div>

## Creating A Collection

<div class="indent">

### How To Create

Click the **+** icon next to **Collections** in the left sidebar.

Give the collection a name that reflects the API or project it covers.

### Adding Requests

Save any request into a collection using the **Save** button.

You can also drag existing requests into a collection from the sidebar.

### Folders

Use folders inside a collection to group requests by resource or feature.

Example: a `Users` folder and an `Orders` folder inside a single API collection.

</div>

## Collection Variables

<div class="indent">

### What They Are

Collection variables are key-value pairs scoped to a single collection.

### Why Use Them

They let you define shared values like a base URL once and reference them across all requests.

### Example

Define `{{baseUrl}}` as `https://api.example.com` at the collection level.

Then use `{{baseUrl}}/users` in every request URL instead of repeating the full URL.

</div>

## Running A Collection

<div class="indent">

### Collection Runner

The **Collection Runner** lets you run all requests in a collection in sequence.

Open it by clicking **Run** on the collection in the sidebar.

### Use Cases

- Smoke testing an API after a deployment
- Running a full set of endpoints to check for regressions

</div>
