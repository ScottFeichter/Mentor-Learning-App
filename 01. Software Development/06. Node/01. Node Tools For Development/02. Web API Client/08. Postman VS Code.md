# Postman VS Code Extension

&nbsp;

**Postman** has an official extension that brings its API client directly into VS Code.

## What It Is

<div class="indent">

### Overview

The **Postman for VS Code** extension is a full **Postman** client embedded in the editor.

It lets you send requests, manage collections, and work with environments without leaving VS Code.

### How To Install

Search for **Postman** in the VS Code Extensions panel and install the official extension.

Sign in with your **Postman** account to access your existing collections and workspaces.

</div>

## What It Can Do

<div class="indent">

### Core Features

- Send HTTP requests and inspect responses
- Create and manage collections
- Switch between environments
- Write and run pre-request scripts and tests

### What It Shares With The Desktop App

Collections, environments, and workspaces sync via your **Postman** account.

Work done in the extension is available in the desktop app and vice versa.

</div>

## Extension vs. Desktop App

<div class="indent">

### When The Extension Works Well

- Lighter API work during development
- Quick request checks without switching windows
- Developers who prefer to stay entirely in VS Code

### When The Desktop App Is Better

- Managing large collections with many folders and requests
- Team collaboration and workspace management
- Full access to all **Postman** features and settings

### General Preference

Many developers prefer the desktop app for serious API testing.

However they prefer the extension for quick checks during coding.

</div>

## Newman vs. The Extension

<div class="indent">

**Newman** and the VS Code extension are separate tools that serve different purposes.

**Newman** is a CLI/programmatic runner for automation and CI/CD.

The VS Code extension is an interactive client for manually sending and inspecting requests.

</div>
