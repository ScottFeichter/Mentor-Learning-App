# Postman Newman - Node

&nbsp;

We don't have to use Postman from the native app UI we can use it in Node via **Newman**.

## Node.js Package Usage

<div class="indent">

### Install Locally

```bash
npm install newman
```

### Running A Collection From A Script

```js
const newman = require('newman');

newman.run({
  collection: require('./collection.json'),
  environment: require('./env.json'),
  reporters: 'cli'
}, (err) => {
  if (err) throw err;
  console.log('Collection run complete.');
});
```

### When To Use This

Use the Node API when you need to trigger collection runs programmatically.

For example, from a test runner or a custom build script.

</div>

## CI/CD Integration

<div class="indent">

### How It Works

Add a **Newman** command as a step in your pipeline configuration.

The pipeline runs the collection on every push and reports pass or fail.

### GitHub Actions Example

```yaml
- name: Run Postman Collection
  run: newman run collection.json --environment env.json
```

### Use Cases

- Verifying API endpoints after every deployment
- Catching regressions before they reach production

</div>
