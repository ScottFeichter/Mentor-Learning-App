# Postman Sending Requests

&nbsp;

Once a request is formed, **Postman** sends it and displays the full response.

## Sending A Request

<div class="indent">

### How To Send

Click the **Send** button to dispatch the request to the server.

**Postman** displays the response in the panel below.

### Response Status

The status code tells you whether the request succeeded.

- `200` — OK
- `201` — Created
- `400` — Bad Request
- `401` — Unauthorized
- `403` — Forbidden
- `404` — Not Found
- `500` — Internal Server Error

</div>

## Reading The Response

<div class="indent">

### Body

The response body contains the data returned by the server.

Switch between `Pretty`, `Raw`, and `Preview` views depending on what you need to inspect.

### Headers

The response headers show metadata like `Content-Type` and `Set-Cookie`.

### Time And Size

**Postman** displays the response time in milliseconds and the response size in KB.

These are useful for spotting slow or bloated responses.

</div>

## Saving A Request

<div class="indent">

### Why Save

Saving a request lets you reuse it without rebuilding it each time.

### How To Save

Click **Save** in the top right of the request tab.

Give the request a descriptive name and save it to a Collection.

</div>
