# Postman Forming Requests

&nbsp;

A request in **Postman** is built from several parts before it is sent.

## Method

<div class="indent">

### What It Is

The HTTP method tells the server what action you want to perform.

### Common Methods

- `GET` — retrieve data
- `POST` — send new data
- `PUT` — replace existing data
- `PATCH` — partially update existing data
- `DELETE` — remove data

### How To Set It

Use the method dropdown on the left side of the request bar.

</div>

## URL

<div class="indent">

### What It Is

The URL is the address of the resource you are targeting.

### Example

`https://api.example.com/users/1`

### Path Variables

Some URLs contain dynamic segments like `/users/:id`.

**Postman** detects these automatically when present in the URL.

You can also fill in their values in the Params tab instead.

</div>

## Headers

<div class="indent">

### What They Are

Headers pass metadata alongside the request.

### Common Headers

- `Content-Type` — tells the server the format of the request body
- `Authorization` — passes an API key or token
- `Accept` — tells the server what format you expect back

### How To Set Them

Open the **Headers** tab and add key-value pairs.

</div>

## Body

<div class="indent">

### When To Use It

A body is used with `POST`, `PUT`, and `PATCH` requests to send data to the server.

### Body Formats

- `raw` — write JSON, XML, or plain text directly
- `form-data` — used for file uploads and form submissions
- `x-www-form-urlencoded` — used for simple key-value form data

### JSON Example

Set the body type to `raw` and select `JSON` from the format dropdown.

```json
{
  "name": "Alex",
  "email": "alex@example.com"
}
```

</div>

## Params

<div class="indent">

### Query Parameters

Query parameters are appended to the URL after a `?`.

Example: `https://api.example.com/users?role=admin&active=true`

**Postman** lets you add these in the Params tab without manually editing the URL.

### Path Variables

Path variables are defined in the URL with a `:` prefix.

Fill in their values in the Params tab under Path Variables.

</div>
