# The Node Object Model

&nbsp;

The **Node Object Model (NOM)** is not an official term.

But it's a useful way to think about <span class="node-green">Node</span>'s global environment.

## window vs global

Just as the browser has `window` as its global object, <span class="node-green">Node</span> has `global`.

It exposes objects and functions; they are available everywhere in a <span class="node-green">Node</span> program without needing to import them.

### NOM Global Objects

The **NOM** is the set of global objects <span class="node-green">Node</span> exposes to <span class="js-yellow">JavaScript</span> through <span class="purple-bold">globalThis</span>.

Since <span class="purple-bold">global</span> is <span class="purple-bold">globalThis</span> we can use either to access them.

**NOM** gives you access to the runtime environment, the process, I/O, timers, and module system.

You may hear the components of the **NOM** referred to as <span class="node-green">Node</span> globals.

```js
let global = {

  process: {
    pid: 12345,
    version: "v20.0.0",
    platform: "darwin",
    arch: "arm64",

      NODE_ENV: "development",

    on: function(event, callback) {},
    stdout: {},
    stderr: {},
    stdin: {}
  },

  console: {
    log: function(message) {},
    error: function(message) {},
    warn: function(message) {},
    table: function(tableData) {},
    time: function(label) {},
    timeEnd: function(label) {}
  },

  Buffer: {
    from: function(data, encoding) {},
    alloc: function(size) {},
    isBuffer: function(obj) {}
  },

  setTimeout: function(callback, ms) {},
  setInterval: function(callback, ms) {},
  clearTimeout: function(id) {},
  clearInterval: function(id) {},
  setImmediate: function(callback) {},
  clearImmediate: function(id) {},

  __filename: "/Users/username/project/app.js",
  __dirname: "/Users/username/project",

  require: function(module) {},

  module: {
    id: ".",
    filename: "/Users/username/project/app.js",
    loaded: true,
    exports: {},
    paths: []
  },

  exports: {},

  URL: function(url, base) {},
  URLSearchParams: function(init) {},

  fetch: function(url, options) {},

  crypto: {
    randomUUID: function() {},
    randomBytes: function(size) {}
  },

  structuredClone: function(obj) {},
  atob: function(data) {},
  btoa: function(data) {}

}
```
