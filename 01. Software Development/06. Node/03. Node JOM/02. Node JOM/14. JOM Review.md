# JOM Review

&nbsp;

**JOM** is the concept of objects in <span class="js-yellow">JS</span> environments nested like a Russian doll.

---

## globalThis

<span class="purple-bold">globalThis</span> is the outer most object of both browsers and <span class="node-green">Node</span>.

However, <span class="purple-bold">globalThis</span> is not identical across environments.

<div class="indent">

### window

<span class="purple-bold">window</span> is a  self reference to <span class="purple-bold">globalThis</span> in browsers.

<div class="indent">

#### BOM

Browser objects accessible via <span class="purple-bold">globalThis</span> (and <span class="purple-bold">window</span>) in browser environments.

- `window.history`
- `window.location`
- `window.navigator`
- `window.document`
- `window.screen`
- `window.console`

</div>

### global

The self reference to <span class="purple-bold">globalThis</span> in <span class="node-green">Node</span>.

<div class="indent">

#### NOM

<span class="node-green">Node</span> global objects accessible via <span class="purple-bold">globalThis</span> (and <span class="purple-bold">global</span>) in the <span class="node-green">Node</span> environments.

- `global.process`
- `global.console`
- `global.module`
- `global.require`
- `global.__dirname`
- `global.__filename`

</div>

</div>
