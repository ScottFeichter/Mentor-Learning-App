# globalThis

&nbsp;

As stated, the outer most object in both the browser and <span class="node-green">Node</span> is <span class="purple-bold">globalThis</span>.

However, <span class="purple-bold">globalThis</span> in the browser is not identical to <span class="purple-bold">globalThis</span> in <span class="node-green">Node</span>.

## Similarities in Browser and Node

We will explore differences of <span class="purple-bold">globalThis</span> later in this chapter.

First let's see what browser <span class="purple-bold">globalThis</span> and <span class="node-green">Node</span> <span class="purple-bold">globalThis</span> have in common.

### Built-Ins Present In Both Browsers and Node

Here is a list of <span class="purple-bold">globalThis</span> built-ins identical in both the browser and <span class="node-green">node</span>:

1. <u>**Core ECMAScript Built-ins (The Language Itself)**</u>
   - <span class="muted-dark">**Object & Array Classes:**</span> Object, Array, Function, RegExp, Date
   - <span class="muted-dark">**Primitive Wrappers:**</span> String, Number, Boolean, Symbol, BigInt
   - <span class="muted-dark">**Collections:**</span> Map, Set, WeakMap, WeakSet
   - <span class="muted-dark">**Asynchronous Tools:**</span> Promise, AsyncFunction, Generator
   - <span class="muted-dark">**Math & Data Namespaces:**</span> Math, JSON, Reflect, Proxy
   - <span class="muted-dark">**Error Constructors:**</span> Error, TypeError, SyntaxError, ReferenceError
   - <span class="muted-dark">**Global Functions:**</span> parseInt(), parseFloat(), isNaN(), isFinite()

&nbsp;

2. <u>**The Shared Web APIs (Modern Standardizations)**</u>
   - <span class="muted-dark">**Networking:**</span> fetch(), Request, Response, Headers, WebSocket
   - <span class="muted-dark">**Timers:**</span> setTimeout(), setInterval(), clearTimeout(), clearInterval()
   - <span class="muted-dark">**Performance & Control:**</span> performance, AbortController, AbortSignal, queueMicrotask()
   - <span class="muted-dark">**Data Handling:**</span> TextEncoder, TextDecoder, atob(), btoa()

It is not important to memorize this information; merely noting the concept is sufficient.
