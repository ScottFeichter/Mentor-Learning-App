# Accessing The BOM

&nbsp;

All **BOM** objects are properties of <span class="purple-bold">globalThis</span> and can therefore be access through it.

Since <span class="purple-bold">window</span> is a self reference to <span class="purple-bold">globalThis</span> we can access **BOM** with it too.

## Syntactic Sugar

<span style="color: #6c0101; font-weight: bold;">Syntactic sugar</span> refers to a shorthand way to write something the language could already do.

It doesn't add new functionality, it just makes the code easier to write and read.

### BOM Syntactic Sugar

<span class="js-yellow">JS</span> provides a <span style="color: #6c0101; font-weight: bold;">syntactic sugar</span> abstraction for accessing **BOM** properties.

That is we can reach them directly without keying in to the parent object.

## Many Ways To Access BOM Syntactically

**BOM** objects are properties of <span class="purple-bold">globalThis</span>.

<span class="purple-bold">window</span> is a self reference to <span class="purple-bold">globalThis</span> in browser environments.

There is a <span style="color: #6c0101; font-weight: bold;">syntactic sugar</span> shorthand built in to the language.

### Example As Syntax

Therefore for **BOM** objects such as location we can use 3 different syntax to access them:

- `globalThis.location`
- `window.location`
- `location`

These all refer to the same thing when in the browser environment.

### Example As Boolean

```js

Boolean(
    globalThis.location === window.location &&
    window.location === location &&
    globalThis.location === location
);

// true
```
