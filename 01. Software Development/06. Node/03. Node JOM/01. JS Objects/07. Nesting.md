# Nesting

&nbsp;

Nesting is placing data hierarchically inside other data.

This allows data to be structured in a way that reflects the real world.

## Nesting Possibilities Are Endless

- Objects can be nested in other objects
- Arrays can be nested in objects
- Objects and Arrays can have mixed nesting
- Nesting allows for sophisticated data modeling and structures

### Example

```js
const band = {
  name: 'The Midnight',
  genre: 'Synthwave',
  members: ['Tyler', 'Tim'],
  latestAlbum: {
    title: 'Monsters',
    year: 2022,
    tracks: ['Monsters', 'Fire', 'Avalanche']
  }
};

console.log(band.name);                        // 'The Midnight'
console.log(band.members[0]);                  // 'Tyler'
console.log(band.latestAlbum.title);           // 'Monsters'
console.log(band.latestAlbum.tracks[1]);       // 'Fire'
```
