# OOP

&nbsp;

**Object Oriented Programming (OOP)** is a coding paradigm to use objects to organize related data.

## OOP Benefits

One of the benefits of **OOP** is to more accurately model things from the real world.

This is because in life most things have characteristcs and behaviors.

In **OOP** these are represented with properties and methods.

### Example

```js
const radio = {
  station: 101.1,
  volume: 5,
  isOn: false,

  turnOn() {
    this.isOn = true;
    console.log('Radio is on.');
  },

  turnOff() {
    this.isOn = false;
    console.log('Radio is off.');
  },

  changeStation(station) {
    this.station = station;
    console.log(`Tuned to ${this.station}.`);
  }
};

radio.turnOn();
radio.changeStation(98.7);
radio.turnOff();

// Radio is on.
// Tuned to 98.7.
// Radio is off.
```
