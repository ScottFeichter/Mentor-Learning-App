# JS Objects Review

&nbsp;

A summary of the key concepts from this section.

---

## Objects

An **object** is a container for <span class="purple-bold">properties</span>.

A <span class="purple-bold">property</span> whose value is a function is called a <span class="subheading-highlight">method</span>.

---

## Notation

Use **dot notation** by default.

Use **bracket notation** when the key is:

- dynamic
- stored in a variable
- contains special characters

---

## Built-In Object Methods

- `Object.keys(obj)` — returns an array of keys
- `Object.values(obj)` — returns an array of values
- `Object.entries(obj)` — returns an array of `[key, value]` pairs

---

## POJO vs CIJO

A **POJO** is declared as a plain object literal.

A **CIJO** is instantiated from a Class using `new`.

---

## Classes

A **Class** is a blueprint for creating objects.

Classes have a `constructor` method that runs when a new instance is created.

**Instance methods** are called on an instance.

**Static methods** are called on the class itself.

---

## OOP

**Object Oriented Programming** uses objects to model real-world things with properties and methods.

---

## APIE

The four pillars of OOP:

- **A**bstraction — hiding complex internal details
- **P**olymorphism — same method name, different behavior per object
- **I**nheritance — a class can inherit from another class
- **E**ncapsulation — controlling access to internal data

---

## Nesting

Objects and arrays can be nested inside each other to model complex data structures.

Access nested values by chaining dot and bracket notation.
