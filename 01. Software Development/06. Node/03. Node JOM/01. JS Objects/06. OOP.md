# OOP

&nbsp;

**Object Oriented Programming (OOP)** is a coding paradigm for how to organize related data.

---

## Philosophy Built On Features

**OOP** is a philosophy for intentional combining certain capabilities of JS.

### Mechanics Of OOP

**OOP** as a design pattern is built on features:

- nesting
- private class fields
- functions as properties (methods)
- classes as prototypes for other classes or objects


**OOP** is a way to use these mechanics together to organize a program.

### OOP Modeling

**OOP** helps us to more accurately model things from the real world.

This is because in life most things have characteristcs and behaviors.

In **OOP** these are represented with properties and methods.

### Example

```js
const radio = {
  station: 101.1,
  volume: 5,
  isOn: false,

  turnOn() {
    this.isOn = true;
    console.log('Radio is on.');
  },

  turnOff() {
    this.isOn = false;
    console.log('Radio is off.');
  },

  changeStation(station) {
    this.station = station;
    console.log(`Tuned to ${this.station}.`);
  }
};

radio.turnOn();
radio.changeStation(98.7);
radio.turnOff();

// Radio is on.
// Tuned to 98.7.
// Radio is off.
```
