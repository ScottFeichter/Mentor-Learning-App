# Nesting

&nbsp;

Nesting is placing data hierarchically inside other data.

---

## Structured Data

This allows data to be structured in ways that express our needs.

### Endless Possibilites With Nesting

- Objects can be nested in other objects or arrays
- Arrays can be nested in other arrays or objects
- Nesting allows for sophisticated data modeling

### Example

```js
const response = {
  status: 200,
  message: 'OK',
  data: {
    user: {
      id: 1,
      name: 'Alice',
      email: 'alice@example.com',
      address: {
        city: 'Austin',
        state: 'TX'
      }
    },
    posts: [
      {
        id: 101,
        title: 'Getting Started With Node',
        tags: ['node', 'javascript']
      },
      {
        id: 102,
        title: 'Understanding REST APIs',
        tags: ['api', 'rest']
      }
    ]
  }
};

console.log(response.status);                        // 200
console.log(response.data.user.name);                // 'Alice'
console.log(response.data.user.address.city);        // 'Austin'
console.log(response.data.posts[0].title);           // 'Getting Started With Node'
console.log(response.data.posts[1].tags[0]);         // 'api'
```
