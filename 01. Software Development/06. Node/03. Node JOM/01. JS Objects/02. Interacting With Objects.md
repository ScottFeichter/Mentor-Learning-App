# Interacting With Objects

&nbsp;

We can interact programatically with **objects** using notation and built-in methods.

## Notation

There are two syles of notation that work with **objects**.

### Dot Notation
```js
myObject.someProperty = "adding a new property";
```

### Bracket Notation
```js
myObject["someOtherProperty"] = "adding yet another property";
```

There are nuanced differences between these notation styles.


## Built In JS Object Methods

All **object** methods return arrays and one returns an array of 2 element arrays.

### Return An Array

- ```Object.keys(obj)```
- ```Object.values(obj)```

### Return An Array Of Arrays

- ```Object.entries(obj)```

```js
let entriesOfMyObject = Object.entries(myObject);

console.log(entriesOfMyObject)

// [
//  [ 'someKey', 'someValue' ],
//  [ 'anotherKey', 'anotherValue' ],
//  [ 'thisKeyHasAFunctionForItsValue', [Function] ],
//  [ 'someProperty', 'adding a new property' ],
//  [ 'someOtherProperty', 'adding yet another property' ]
// ]
```
