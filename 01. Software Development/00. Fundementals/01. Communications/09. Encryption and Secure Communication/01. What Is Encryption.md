# What Is Encryption?

&nbsp;

Encryption is the process of transforming readable data into an unreadable format so that only authorized parties can access it.

The original data is called <span class="subheading-highlight">plaintext</span>.

The encrypted data is called <span class="subheading-highlight">ciphertext</span>.

## How It Works

Encryption uses a mathematical algorithm and a key to transform plaintext into ciphertext.

The same or a related key is used to reverse the process — called decryption — to recover the original data.

Without the key, the ciphertext is computationally infeasible to reverse.

## Why It Matters

Encryption protects data in transit and at rest from unauthorized access.

Without it, anyone who intercepts a network transmission or gains access to a storage device can read the data directly.

## Encryption vs Encoding

Encoding converts data into a different format for compatibility — anyone who knows the scheme can decode it.

Encryption converts data to protect it — only someone with the key can decrypt it.
