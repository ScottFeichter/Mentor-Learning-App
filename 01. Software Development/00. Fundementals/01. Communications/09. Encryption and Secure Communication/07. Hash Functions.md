# Hash Functions

&nbsp;

A hash function is a one-way mathematical function that takes an input of any size and produces a fixed-size output called a hash or digest.

## Key Properties

- <span class="olive-bold">Deterministic</span> — the same input always produces the same hash
- <span class="olive-bold">One-way</span> — it is computationally infeasible to reverse a hash back to the original input
- <span class="olive-bold">Avalanche effect</span> — a tiny change in the input produces a completely different hash
- <span class="olive-bold">Collision resistant</span> — it is extremely unlikely for two different inputs to produce the same hash

## Common Algorithms

- <span class="olive-bold">SHA-256</span> — produces a 256-bit hash, widely used in TLS, certificates, and Bitcoin
- <span class="olive-bold">SHA-3</span> — newer standard, different internal design from SHA-2
- <span class="olive-bold">MD5</span> — older, now considered cryptographically broken, still used for non-security checksums
- <span class="olive-bold">bcrypt</span> — designed specifically for hashing passwords, intentionally slow

## Uses

- <span class="olive-bold">Password storage</span> — passwords are stored as hashes, never in plaintext
- <span class="olive-bold">Data integrity</span> — verifying a file has not been tampered with
- <span class="olive-bold">Digital signatures</span> — signing a hash of a document rather than the document itself
- <span class="olive-bold">Blockchain</span> — each block contains the hash of the previous block
