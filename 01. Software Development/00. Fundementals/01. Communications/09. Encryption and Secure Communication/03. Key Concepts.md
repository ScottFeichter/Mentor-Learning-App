# Key Concepts

&nbsp;

Understanding encryption requires familiarity with a core set of terms and concepts.

## Plaintext and Ciphertext

- <span class="olive-bold">Plaintext</span> — the original readable data before encryption
- <span class="olive-bold">Ciphertext</span> — the scrambled unreadable output after encryption

## Keys

A key is a piece of data used by an encryption algorithm to transform plaintext into ciphertext and back.

The security of encrypted data depends on keeping the key secret, not on keeping the algorithm secret.

## Algorithms

An encryption algorithm is the mathematical procedure used to encrypt and decrypt data.

Common algorithms include AES, RSA, and ChaCha20.

## Cipher

A cipher is a specific algorithm or method for performing encryption and decryption.

## Key Length

Key length is measured in bits — longer keys are exponentially harder to break by brute force.

A 128-bit AES key has 2¹²⁸ possible values — computationally infeasible to brute force with current technology.

## Brute Force Attack

An attempt to break encryption by trying every possible key until the correct one is found.

Longer keys make brute force attacks impractical.

## Entropy

A measure of randomness in a key or password — higher entropy means harder to guess or crack.
