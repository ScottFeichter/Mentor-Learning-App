# Asymmetric Encryption

&nbsp;

Asymmetric encryption uses a pair of mathematically related keys — a public key and a private key.

What one key encrypts, only the other can decrypt.

## The Key Pair

- <span class="olive-bold">Public key</span> — shared openly with anyone
- <span class="olive-bold">Private key</span> — kept secret by the owner

## How It Works

If someone wants to send you an encrypted message, they encrypt it with your public key.

Only your private key can decrypt it — so even though anyone can encrypt a message to you, only you can read it.

## Common Algorithms

- <span class="olive-bold">RSA</span> — one of the oldest and most widely used asymmetric algorithms
- <span class="olive-bold">ECC (Elliptic Curve Cryptography)</span> — provides equivalent security to RSA with much shorter keys, used in TLS and mobile
- <span class="olive-bold">Diffie-Hellman</span> — used for key exchange rather than encryption directly

## Advantages

- Solves the key distribution problem — public keys can be shared freely
- Enables digital signatures and certificate-based authentication

## Limitations

- Much slower than symmetric encryption
- Not practical for encrypting large amounts of data directly

## In Practice

Asymmetric encryption is used to establish a secure channel and exchange a symmetric key.

After that, the faster symmetric encryption handles the actual data.
