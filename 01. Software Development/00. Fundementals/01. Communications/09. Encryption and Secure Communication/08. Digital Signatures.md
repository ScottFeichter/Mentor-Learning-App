# Digital Signatures

&nbsp;

A digital signature is a cryptographic mechanism that proves the authenticity and integrity of a message or document.

It answers two questions: who sent this, and has it been tampered with?

## How It Works

1. The sender creates a hash of the message
2. The sender encrypts that hash with their private key — this is the signature
3. The sender transmits the message and the signature
4. The receiver decrypts the signature using the sender's public key to recover the hash
5. The receiver independently hashes the message and compares the two hashes
6. If they match, the message is authentic and unaltered

## What It Proves

- <span class="olive-bold">Authenticity</span> — only the holder of the private key could have created the signature
- <span class="olive-bold">Integrity</span> — any change to the message would produce a different hash and the signature would not match
- <span class="olive-bold">Non-repudiation</span> — the sender cannot deny having signed the message

## Uses

- Code signing — verifying software has not been tampered with
- Email signing (S/MIME, PGP)
- SSL/TLS certificates
- Legal documents and contracts
- Blockchain transactions
