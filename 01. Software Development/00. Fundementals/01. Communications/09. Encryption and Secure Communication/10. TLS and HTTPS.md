# TLS and HTTPS

&nbsp;

TLS (Transport Layer Security) is the cryptographic protocol that secures communication over the internet.

HTTPS is HTTP running over TLS — the standard for secure web browsing.

## What TLS Does

- Encrypts data in transit so it cannot be read by anyone intercepting the connection
- Authenticates the server using a digital certificate so you know you are talking to the right party
- Ensures data integrity so tampering is detectable

## The TLS Handshake

Before any data is exchanged, TLS performs a handshake to establish a secure session:

1. Client sends supported TLS versions and cipher suites
2. Server responds with its chosen cipher suite and its certificate
3. Client verifies the certificate against trusted CAs
4. Both parties use asymmetric encryption to exchange or derive a shared symmetric session key
5. All subsequent communication is encrypted with the symmetric session key

## HTTP vs HTTPS

- <span class="olive-bold">HTTP</span> — data is transmitted in plaintext, visible to anyone on the network
- <span class="olive-bold">HTTPS</span> — data is encrypted by TLS, unreadable to anyone intercepting the connection

## TLS Versions

- TLS 1.0 and 1.1 — deprecated, considered insecure
- TLS 1.2 — widely supported, still in use
- TLS 1.3 — current standard, faster handshake and stronger security
