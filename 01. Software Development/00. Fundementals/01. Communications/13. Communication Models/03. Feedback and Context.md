# Feedback and Context

&nbsp;

Feedback and context are two elements that make communication more reliable and meaningful.

## Feedback

Feedback is the receiver's response to the sender's message.

It closes the loop — confirming that the message was received, understood, or acted upon.

### In Human Communication
A nod, a reply, or a question are all forms of feedback.

### In Technical Communication
- TCP acknowledgment packets confirm that data was received
- HTTP response codes tell the client whether the request succeeded
- Error messages are feedback that something went wrong

Without feedback, the sender has no way of knowing whether the message arrived or was understood.

## Context

Context is the surrounding information that affects how a message is interpreted.

The same message can mean different things depending on context.

### In Human Communication
Tone, body language, shared history, and cultural background all provide context.

### In Technical Communication
- HTTP headers provide context about the request and response
- Protocol version numbers tell the receiver how to interpret the message
- Session state provides context across multiple requests

## Why They Matter

Communication without feedback is one-way broadcasting.

Communication without context is ambiguous.

Reliable systems are designed to provide both.
