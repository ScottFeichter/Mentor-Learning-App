# What Is Encoding?

&nbsp;

Encoding is the process of converting information into a specific format for transmission or storage.

It transforms data from one representation into another that is suitable for a particular medium or system.

## How It Works

Before information can be transmitted, it must be represented in a form the transmission medium can carry.

Encoding defines the rules for that representation — how bits map to signals, how characters map to numbers, how numbers map to binary.

## Examples

- <span class="olive-bold">ASCII</span> — encodes text characters as numbers
- <span class="olive-bold">UTF-8</span> — encodes Unicode characters as sequences of bytes
- <span class="olive-bold">Base64</span> — encodes binary data as printable text characters
- <span class="olive-bold">Manchester Encoding</span> — encodes binary data as voltage transitions on a wire

## Encoding vs Encryption

Encoding is not encryption.

Encoding is about format and compatibility — anyone who knows the scheme can decode it.

Encryption is about security — only someone with the key can decrypt it.
