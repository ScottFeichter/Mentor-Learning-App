# What Is Synchronous Communication?

&nbsp;

Synchronous communication is communication where both parties must be present and engaged at the same time.

The exchange happens in real time — one party sends, the other receives immediately.

## In Human Communication

- A phone call
- A face to face conversation
- A live video call

## In Computing

Synchronous refers to operations that block — the program waits for the operation to complete before moving on.

```javascript
const data = fs.readFileSync('file.txt'); // blocks until file is read
console.log(data);
```

In networking, synchronous transmission means data is sent in a continuous stream timed by a shared clock signal between sender and receiver.

## Advantages

- Immediate feedback
- Simpler to reason about — things happen in a predictable order

## Limitations

- Both parties must be available at the same time
- In computing, blocking operations can make programs unresponsive while waiting
