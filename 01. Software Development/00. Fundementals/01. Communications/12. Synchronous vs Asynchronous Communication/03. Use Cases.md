# Use Cases

&nbsp;

Choosing between synchronous and asynchronous communication depends on the requirements of the situation.

## When To Use Synchronous

- <span class="olive-bold">Real time collaboration</span> — video calls, pair programming, live support
- <span class="olive-bold">Time sensitive operations</span> — trading systems, live data feeds
- <span class="olive-bold">Simple sequential logic</span> — when order and immediate results matter more than responsiveness

## When To Use Asynchronous

- <span class="olive-bold">I/O operations</span> — reading files, making network requests, querying databases
- <span class="olive-bold">Background tasks</span> — sending emails, processing uploads, generating reports
- <span class="olive-bold">Distributed systems</span> — message queues allow services to communicate without being online simultaneously
- <span class="olive-bold">User interfaces</span> — keeping the UI responsive while waiting for data

## In Web Development

Most web communication is asynchronous.

HTTP requests, database queries, and file reads are all operations that take time — blocking on them would freeze the application.

JavaScript's event loop, Promises, and async/await are all tools for managing asynchronous operations.
