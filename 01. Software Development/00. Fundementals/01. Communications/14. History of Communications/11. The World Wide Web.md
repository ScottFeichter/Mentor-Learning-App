# The World Wide Web

&nbsp;

The World Wide Web is a system of interlinked documents and resources accessed via the internet using HTTP.

It was invented by Tim Berners-Lee in 1989 while working at CERN.

## The Problem It Solved

Researchers at CERN needed a way to share documents and information across different computers and operating systems.

Berners-Lee proposed a system of hyperlinked documents that could be accessed over the internet from any machine.

## The Three Core Technologies

- <span class="olive-bold">HTML</span> — a markup language for creating web documents
- <span class="olive-bold">HTTP</span> — a protocol for requesting and transferring web documents
- <span class="olive-bold">URLs</span> — a standardized addressing system for locating resources

## Timeline

- <span class="olive-bold">1989</span> — Berners-Lee proposes the web at CERN
- <span class="olive-bold">1991</span> — first website goes live at CERN
- <span class="olive-bold">1993</span> — Mosaic, the first graphical web browser, released — makes the web accessible to non-technical users
- <span class="olive-bold">1994</span> — Netscape Navigator released, rapid public adoption begins
- <span class="olive-bold">1995-2000</span> — the dot-com boom

## The Web vs The Internet

The internet is the infrastructure.

The web is one service that runs on top of it — the most widely used, but not the only one.

## Impact

The web transformed the internet from a research tool into a global public medium for information, commerce, communication, and culture.
