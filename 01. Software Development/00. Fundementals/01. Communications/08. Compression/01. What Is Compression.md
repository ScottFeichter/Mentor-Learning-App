# What Is Compression?

&nbsp;

Compression is the process of reducing the size of data so it takes up less storage space or can be transmitted more quickly.

## How It Works

Data often contains redundancy — repeated patterns, predictable sequences, or information that can be approximated.

Compression algorithms exploit that redundancy to represent the same information using fewer bits.

## Two Categories

- <span class="olive-bold">Lossless</span> — the original data can be perfectly reconstructed from the compressed version
- <span class="olive-bold">Lossy</span> — some data is permanently discarded in exchange for greater compression

## Why It Matters

Compression is fundamental to modern communications.

Without it, video streaming, audio files, web pages, and file transfers would require far more bandwidth and storage than is practical.
