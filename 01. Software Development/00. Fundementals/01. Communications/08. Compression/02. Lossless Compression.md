# Lossless Compression

&nbsp;

Lossless compression reduces file size without discarding any data.

The original file can be perfectly reconstructed from the compressed version.

## How It Works

Lossless algorithms find and eliminate redundancy in data without losing any information.

Common techniques include replacing repeated sequences with shorter references and encoding frequent values with fewer bits.

## Common Algorithms

- <span class="olive-bold">Huffman Coding</span> — assigns shorter bit sequences to more frequent symbols
- <span class="olive-bold">LZ77 / LZ78</span> — replaces repeated sequences with references to earlier occurrences
- <span class="olive-bold">DEFLATE</span> — combines LZ77 and Huffman coding, used in ZIP and PNG

## Common Formats

- <span class="olive-bold">ZIP</span> — general purpose file compression
- <span class="olive-bold">PNG</span> — lossless image format
- <span class="olive-bold">FLAC</span> — lossless audio format
- <span class="olive-bold">GZIP</span> — used for compressing web content and files

## When To Use It

Lossless compression is used when the integrity of the data is critical — text files, code, executables, and documents where any change would corrupt the content.
