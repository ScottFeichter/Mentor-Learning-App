# Lossy Compression

&nbsp;

Lossy compression reduces file size by permanently discarding some data.

The original file cannot be perfectly reconstructed — the decompressed version is an approximation.

## How It Works

Lossy algorithms identify data that is less perceptible to humans and discard it.

For images this might mean reducing color detail in areas the eye is less sensitive to.

For audio it means removing frequencies outside the range of human hearing or that are masked by louder sounds.

## Common Formats

- <span class="olive-bold">JPEG</span> — lossy image compression, widely used for photographs
- <span class="olive-bold">MP3</span> — lossy audio compression, removes inaudible frequencies
- <span class="olive-bold">AAC</span> — lossy audio used by streaming services and Apple devices
- <span class="olive-bold">H.264 / H.265</span> — lossy video compression used in streaming and broadcasting

## Tradeoff

The more aggressively you compress, the smaller the file but the lower the quality.

This tradeoff is controlled by a quality setting — higher quality means larger file, lower quality means smaller file with more artifacts.

## When To Use It

Lossy compression is used when some quality loss is acceptable in exchange for significantly smaller file sizes — photos, music, and video are the primary use cases.
