# UDP

&nbsp;

UDP (User Datagram Protocol) is a transport layer protocol that sends data without establishing a connection or guaranteeing delivery.

## Key Characteristics

- <span class="olive-bold">Connectionless</span> — no handshake, data is sent immediately
- <span class="olive-bold">Unreliable</span> — no guarantee packets arrive
- <span class="olive-bold">Unordered</span> — packets may arrive out of order
- <span class="olive-bold">Fast</span> — no overhead from acknowledgments or retransmission

## How It Works

The sender packages data into datagrams and sends them to the destination.

There is no acknowledgment, no retransmission, and no connection state.

If a packet is lost, it is simply gone.

## When To Use UDP

UDP is used when speed matters more than perfect reliability:

- <span class="olive-bold">Video streaming</span> — a dropped frame is better than buffering
- <span class="olive-bold">Online gaming</span> — low latency is critical, occasional packet loss is tolerable
- <span class="olive-bold">VoIP</span> — real time voice, slight loss is acceptable
- <span class="olive-bold">DNS</span> — small single request-response queries where TCP overhead is unnecessary
- <span class="olive-bold">HTTP/3</span> — built on QUIC which runs over UDP

## UDP vs TCP

| | TCP | UDP |
|---|---|---|
| Connection | Yes | No |
| Reliability | Guaranteed | Not guaranteed |
| Order | Guaranteed | Not guaranteed |
| Speed | Slower | Faster |
| Use case | Web, email, files | Streaming, gaming, DNS |
