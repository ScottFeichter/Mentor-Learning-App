# DNS

&nbsp;

DNS (Domain Name System) is the protocol and distributed database that translates human-readable domain names into IP addresses.

It is often described as the phone book of the internet.

## Why It Exists

Computers communicate using IP addresses — but humans remember names, not numbers.

DNS allows you to type `google.com` instead of `142.250.80.46`.

## How It Works

1. You type a URL into your browser
2. Your device checks its local DNS cache — if the IP is known, it uses it
3. If not, it queries a DNS resolver (usually provided by your ISP or a service like 8.8.8.8)
4. The resolver queries the DNS hierarchy — root servers, TLD servers, authoritative servers
5. The authoritative server for the domain returns the IP address
6. Your device caches the result and connects to the IP

## DNS Record Types

- <span class="olive-bold">A</span> — maps a domain to an IPv4 address
- <span class="olive-bold">AAAA</span> — maps a domain to an IPv6 address
- <span class="olive-bold">CNAME</span> — maps a domain to another domain name
- <span class="olive-bold">MX</span> — specifies mail servers for the domain
- <span class="olive-bold">TXT</span> — stores arbitrary text, used for verification and security records

## Port

DNS uses port 53.
