# History of Protocols

&nbsp;

Communication protocols have evolved alongside the technology they govern — from early telegraph codes to the internet standards that underpin modern computing.

## Early Protocols

- <span class="olive-bold">Morse Code (1837)</span> — a standardized encoding of letters and numbers as dots and dashes for telegraph transmission
- <span class="olive-bold">Baudot Code (1870)</span> — a 5-bit character encoding used in early teleprinters

## The Birth of Networking Protocols

- <span class="olive-bold">1969</span> — ARPANET established, the first packet-switched network
- <span class="olive-bold">1974</span> — TCP (Transmission Control Protocol) proposed by Vint Cerf and Bob Kahn
- <span class="olive-bold">1983</span> — TCP/IP becomes the standard protocol suite for ARPANET, the foundation of the modern internet
- <span class="olive-bold">1984</span> — DNS introduced to replace manual host tables

## The Web Era

- <span class="olive-bold">1991</span> — HTTP 0.9 introduced by Tim Berners-Lee alongside the World Wide Web
- <span class="olive-bold">1995</span> — HTTP 1.0 formalized, SSL introduced for secure communication
- <span class="olive-bold">1999</span> — HTTP 1.1 — persistent connections and chunked transfer
- <span class="olive-bold">2015</span> — HTTP/2 — multiplexing and header compression
- <span class="olive-bold">2022</span> — HTTP/3 — built on QUIC over UDP rather than TCP

## Standardization

Most internet protocols are defined by RFCs (Request for Comments) published by the IETF (Internet Engineering Task Force) — an open standards organization anyone can participate in.
