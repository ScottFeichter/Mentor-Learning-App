# WebSockets

&nbsp;

WebSockets is a protocol that provides a persistent, full-duplex communication channel between a browser and a server over a single TCP connection.

## How It Differs From HTTP

HTTP is request-response — the client must initiate every exchange.

WebSockets allow both the client and server to send messages to each other at any time without a new request.

## How It Works

A WebSocket connection begins as an HTTP request — the client sends an upgrade request:

```
GET /chat HTTP/1.1
Upgrade: websocket
Connection: Upgrade
```

If the server supports WebSockets, it responds with a 101 Switching Protocols status and the connection is upgraded.

From that point, both parties can send messages freely over the persistent connection.

## Use Cases

- <span class="olive-bold">Real time chat</span> — messages appear instantly without polling
- <span class="olive-bold">Live notifications</span> — push updates from server to client
- <span class="olive-bold">Collaborative tools</span> — multiple users editing simultaneously
- <span class="olive-bold">Live data feeds</span> — stock prices, sports scores, dashboards
- <span class="olive-bold">Online gaming</span> — low latency bidirectional communication

## Port

WebSockets use port 80 for `ws://` and port 443 for `wss://` (secure WebSockets over TLS).
