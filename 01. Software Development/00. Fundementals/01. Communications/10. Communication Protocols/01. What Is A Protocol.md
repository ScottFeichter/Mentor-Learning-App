# What Is A Protocol?

&nbsp;

A protocol is a set of rules that defines how two or more parties communicate.

It specifies the format of messages, the order of exchanges, and how errors are handled — so that systems built independently can still understand each other.

## Why Protocols Exist

Without agreed upon rules, two systems have no way to communicate reliably.

A protocol is the contract between communicating parties — as long as both follow the same rules, they can exchange information regardless of how they are built internally.

## Protocols Are Everywhere

- Two people agreeing to speak the same language is a protocol
- A handshake is a protocol
- HTTP defines how browsers and servers exchange web content
- TCP defines how data is reliably transmitted across a network

## Key Properties of a Protocol

- <span class="olive-bold">Syntax</span> — the format and structure of messages
- <span class="olive-bold">Semantics</span> — the meaning of each part of a message
- <span class="olive-bold">Timing</span> — when messages are sent and how fast
- <span class="olive-bold">Error handling</span> — what happens when something goes wrong
