# TCP

&nbsp;

TCP (Transmission Control Protocol) is a transport layer protocol that provides reliable, ordered, and error-checked delivery of data between applications.

## Key Characteristics

- <span class="olive-bold">Connection-oriented</span> — a connection is established before data is sent
- <span class="olive-bold">Reliable</span> — guarantees all data arrives and is acknowledged
- <span class="olive-bold">Ordered</span> — data arrives in the same order it was sent
- <span class="olive-bold">Error-checked</span> — corrupted packets are detected and retransmitted

## The Three-Way Handshake

TCP establishes a connection using a three-way handshake:

1. Client sends `SYN` — I want to connect
2. Server responds `SYN-ACK` — acknowledged, I'm ready
3. Client sends `ACK` — connection established

## How Reliability Works

Every packet sent is acknowledged by the receiver.

If an acknowledgment is not received within a timeout period, the packet is retransmitted.

## When To Use TCP

TCP is used when data integrity is critical — web browsing, email, file transfer, database queries.

The overhead of acknowledgments and retransmission is acceptable because losing data would be worse than the delay.

## TCP vs UDP

TCP guarantees delivery at the cost of speed.

UDP sacrifices reliability for speed — used when some data loss is acceptable, like video streaming or gaming.
