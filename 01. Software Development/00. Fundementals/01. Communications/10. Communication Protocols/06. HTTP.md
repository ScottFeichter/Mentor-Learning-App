# HTTP

&nbsp;

HTTP (Hypertext Transfer Protocol) is the application layer protocol that defines how browsers and servers exchange web content.

It is the foundation of the World Wide Web.

## How It Works

HTTP follows a request-response pattern.

A client (browser) sends an HTTP request to a server.

The server processes the request and sends back an HTTP response.

## HTTP is Stateless

Each request is independent — the server retains no memory of previous requests.

State is managed separately using cookies, sessions, or tokens.

## Request Structure

- <span class="olive-bold">Method</span> — what action to perform (GET, POST, PUT, DELETE, etc.)
- <span class="olive-bold">URL</span> — the resource being requested
- <span class="olive-bold">Headers</span> — metadata about the request
- <span class="olive-bold">Body</span> — optional data sent with the request

## Response Structure

- <span class="olive-bold">Status code</span> — indicates success or failure (200, 404, 500, etc.)
- <span class="olive-bold">Headers</span> — metadata about the response
- <span class="olive-bold">Body</span> — the requested content (HTML, JSON, etc.)

## Versions

- <span class="olive-bold">HTTP/1.1</span> — persistent connections, most widely supported
- <span class="olive-bold">HTTP/2</span> — multiplexing, header compression, faster
- <span class="olive-bold">HTTP/3</span> — built on QUIC/UDP, lower latency

## Port

HTTP uses port 80 by default.
