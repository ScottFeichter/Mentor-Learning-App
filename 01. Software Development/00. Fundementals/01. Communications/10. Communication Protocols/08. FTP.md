# FTP

&nbsp;

FTP (File Transfer Protocol) is an application layer protocol for transferring files between a client and a server over a network.

## How It Works

FTP uses two separate connections:

- <span class="olive-bold">Control connection</span> — port 21, used for sending commands and receiving responses
- <span class="olive-bold">Data connection</span> — port 20, used for the actual file transfer

The client connects to the server, authenticates, and then issues commands to navigate directories and transfer files.

## Modes

- <span class="olive-bold">Active mode</span> — the server initiates the data connection back to the client
- <span class="olive-bold">Passive mode</span> — the client initiates both connections, works better through firewalls

## Limitations

FTP transmits data including credentials in plaintext — it is not secure.

## Secure Alternatives

- <span class="olive-bold">FTPS</span> — FTP with TLS encryption added
- <span class="olive-bold">SFTP</span> — SSH File Transfer Protocol, a completely different protocol that runs over SSH and is the preferred modern alternative
- <span class="olive-bold">SCP</span> — Secure Copy Protocol, also runs over SSH

## Port

FTP uses port 21 for control and port 20 for data.
