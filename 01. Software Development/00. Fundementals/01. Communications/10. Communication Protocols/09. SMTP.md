# SMTP

&nbsp;

SMTP (Simple Mail Transfer Protocol) is the application layer protocol used for sending email between servers and from email clients to servers.

## How It Works

SMTP is used to push email from one server to another.

When you send an email, your email client connects to your mail server via SMTP and hands off the message.

Your mail server then uses SMTP to deliver the message to the recipient's mail server.

## SMTP is For Sending Only

SMTP handles outgoing mail.

Retrieving email from a server uses different protocols — IMAP or POP3.

## The SMTP Exchange

SMTP communication is text-based — the client and server exchange a series of commands and responses:

- `HELO` / `EHLO` — identify the client
- `MAIL FROM` — specify the sender
- `RCPT TO` — specify the recipient
- `DATA` — begin the message body
- `QUIT` — end the session

## Security

Original SMTP has no encryption or authentication.

Modern SMTP uses:
- <span class="olive-bold">STARTTLS</span> — upgrades the connection to TLS
- <span class="olive-bold">SMTP AUTH</span> — requires authentication before sending

## Ports

- Port 25 — server to server relay
- Port 587 — client to server submission (with authentication)
- Port 465 — SMTP over SSL (legacy)
