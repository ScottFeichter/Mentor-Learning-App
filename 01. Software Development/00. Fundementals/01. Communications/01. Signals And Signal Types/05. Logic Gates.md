# Logic Gates

&nbsp;

A logic gate is a circuit component that performs a basic logical operation on one or more binary inputs and produces a single binary output.

They are the building blocks of all digital computation.

## Binary Logic

Computers operate on binary — everything is either a 0 or a 1, off or on, low voltage or high voltage.

Logic gates take those binary values as inputs and produce a binary output based on a defined rule.

## Common Gates

- <span class="olive-bold">AND</span> — output is 1 only if all inputs are 1
- <span class="olive-bold">OR</span> — output is 1 if any input is 1
- <span class="olive-bold">NOT</span> — inverts the input <span class="muted">(1 becomes 0, 0 becomes 1)</span>
- <span class="olive-bold">NAND</span> — output is 0 only if all inputs are 1 <span class="muted">(opposite of AND)</span>
- <span class="olive-bold">NOR</span> — output is 0 if any input is 1 <span class="muted">(opposite of OR)</span>
- <span class="olive-bold">XOR</span> — output is 1 if inputs are different

## Why It Matters

By combining logic gates, engineers can build circuits that add numbers, store data, and make decisions.

Every operation a CPU performs is ultimately a combination of logic gates switching on and off.
