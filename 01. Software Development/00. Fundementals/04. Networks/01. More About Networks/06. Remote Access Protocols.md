# Remote Access Protocols

&nbsp;

## Virtual Terminals

You can use these to access a server remotely:

- **SSH**
- **Telnet**

&nbsp;

---

&nbsp;

## Telnet

Telnet was developed in the 1970s to allow users to access systems remotely over a network.

- Provides a standard method of emulating text-based terminal devices over a data network
- Telnet servers listen for client requests on **TCP port 23**
- A connection using Telnet is called a **virtual terminal session (vty)**
- **Not considered secure** — data is transmitted as plaintext and easily intercepted
- SSH should be used instead in most environments

&nbsp;

---

&nbsp;

## SSH — Secure Shell

SSH provides the structure for secure remote login and other network services.

- Stronger authentication and encryption than Telnet
- Operates on **port 22**
- SFTP (SSH File Transfer Protocol) also works over SSH port 22
