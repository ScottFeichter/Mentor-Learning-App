# Network Basics

## Signal Transmission Types

1. **Electrical** — electronic pulses on copper wire
2. **Optical** — light pulses on fiber cable (glass or plastic)
3. **Wireless** — infrared, microwave, or radio waves in air

## Bandwidth vs Throughput

**Bandwidth** — the capacity of a medium to carry data (theoretical max):
- bps — bits per second
- kbps — thousand bits per second
- Mbps — million bits per second
- Gbps — billion bits per second
- Tbps — trillion bits per second

> NOTE: Bits measure data speed; bytes measure storage/file size. A gigabit ≠ a gigabyte.

**Throughput** — the actual transfer of bits across media over time. Usually less than bandwidth due to:
- Amount of data being sent/received
- Types of data being transmitted
- Latency from network devices between source and destination

## Network Types

- **PAN** — Personal Area Network
- **LAN** — Local Area Network
- **MAN** — Metropolitan Area Network
- **WAN** — Wide Area Network

## Ethernet

- Technology commonly used in LANs
- Developed at Xerox PARC, commercially introduced in 1980
- Standardized in 1983 as IEEE 802.3
- Devices access via an Ethernet **NIC** (Network Interface Card)
- Each NIC has a unique **MAC address** permanently embedded

## Communication Requirements

- Method
- Language
- Confirmation

Protocol characteristics:
- Message format, size, timing
- Encoding, encapsulation
- Message pattern

## Topology

Topology diagrams show network configuration. Devices don't see the network — they only know their own address. Protocols inform devices of necessary information.

## Media

The medium the signal uses to travel: metal cabling, air (electromagnetic waves), or fiber optic cabling.
