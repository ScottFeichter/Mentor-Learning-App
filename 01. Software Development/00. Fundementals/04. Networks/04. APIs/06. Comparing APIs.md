# Comparing APIs

## Different Contexts

### 1. Web APIs (HTTP/REST APIs)
```javascript
fetch('https://api.github.com/users/scottfeichter')
```
- Server exposes endpoints you can call over the internet
- Returns JSON data
- This is what most people think of as "an API"

### 2. Browser APIs (Web APIs)
```javascript
document.getElementById('button')  // DOM API
localStorage.setItem('key', 'value')  // Storage API
navigator.geolocation.getCurrentPosition()  // Geolocation API
```
- Functions the browser provides to JavaScript
- Let you interact with browser features

### 3. Operating System APIs
```c
// C code calling OS API
FILE* file = fopen("data.txt", "r");
```
- Functions the OS provides to programs
- Let you access files, network, hardware

### 4. Library/Framework APIs
```javascript
// React API
const [count, setCount] = useState(0);

// Node.js API
const fs = require('fs');
fs.readFile('file.txt', callback);
```
- Functions a library provides
- Let you use the library's features

### 5. Language APIs
```javascript
// JavaScript built-in API
const arr = [1, 2, 3];
arr.push(4);  // Array API
Math.random()  // Math API
```
- Built-in functions the language provides
