# Computer Science

&nbsp;

The study of computation — how problems are solved using algorithms, data structures, and software.

It is concerned with the theory and practice of writing programs that instruct computers to perform tasks.

## Where It Sits

Computer Science builds on top of the communications infrastructure that connects devices.

It provides the logic, languages, and systems that software is built from.

## What It Covers

- <span class="olive-bold">Algorithms</span> — step by step procedures for solving problems
- <span class="olive-bold">Data Structures</span> — how data is organized and stored in memory
- <span class="olive-bold">Programming Languages</span> — the tools used to write instructions for computers
- <span class="olive-bold">Operating Systems</span> — software that manages hardware and runs programs
- <span class="olive-bold">Software Engineering</span> — the practice of designing and building software systems
