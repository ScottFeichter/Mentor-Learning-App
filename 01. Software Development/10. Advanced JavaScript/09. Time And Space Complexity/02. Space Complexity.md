# Space Complexity

How will memory usage scale as the size of inputs increase?

Can also use Big O notation.

Space typically only uses **O(1)** or **O(n)**.

## Guidelines

| Type | Space Complexity |
|------|-----------------|
| Most primitives (numbers, booleans, undefined, null) | O(1) — constant |
| Strings | O(n) — where n is string length |
| Arrays | O(n) — where n is array length |
| Objects | O(n) — where n is number of keys |

## Examples

```javascript
// O(1) space — only uses a fixed number of variables
function sum(arr) {
  let total = 0;
  for (let i = 0; i < arr.length; i++) {
    total += arr[i];
  }
  return total;
}

// O(n) space — creates a new array proportional to input
function double(arr) {
  let newArr = [];
  for (let i = 0; i < arr.length; i++) {
    newArr.push(2 * arr[i]);
  }
  return newArr;
}
```
